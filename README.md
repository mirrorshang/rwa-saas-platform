# RWA SaaS Platform

从零建设多资产 RWA Tokenization SaaS 平台。本仓库是独立新项目，目前用于研究、规划与设计。

## 产品定位

- 核心竞品：Brickken
- 目标市场：日本、中东；中东优先研究阿联酋
- 产品形态：Issuer SaaS、Investor Portal、White-label、Open API、平台管理系统

## 当前阶段

竞品研究、产品规划和 UI/UX 设计。当前暂不开发正式业务代码；具体范围、流程及实现依据后续经确认的产品需求和冻结文档确定。
