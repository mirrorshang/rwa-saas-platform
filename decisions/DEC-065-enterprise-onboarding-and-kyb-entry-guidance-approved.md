## 一、批准事项

登录后尚未创建企业的用户进入企业创建与认证引导页。该页负责解释认证目标、所需准备资料、当前状态及下一步，不重复承载五步 KYB 资料表单。

页面内容：
- 标题：「创建企业并完成认证」。
- 说明：完成企业认证后激活 Free，可开始创建和管理正式资产资料、权益结构和发行方案。
- 简要展示五步认证流程：企业基本信息、企业业务信息、企业关联人员、企业证明材料、预览与确认提交。
- 说明认证前可准备的资料：常规企业注册证明、企业主体信息、相关人员信息，以及按实际情况需要的控制关系、授权或牌照材料。
- 主操作：「开始企业认证」；已有草稿时改为「继续填写」。
- 可返回工作台；一个邮箱账号最多对应一个企业，不显示多企业创建或选择入口。

## 二、状态呈现

| 企业状态 | 页面内容 | 主操作 |
|---|---|---|
| 尚未创建企业 | 创建企业并开始认证 | 开始企业认证 |
| KYB 草稿 | 认证尚未完成 | 继续填写 |
| 已提交/审核中 | 认证审核状态 | 查看申请状态 |
| 待补件 | 需要补充资料 | 补充资料 |
| 未通过 | 审核原因及可行后续 | 查看审核结果 |
| 已通过 | 企业认证已通过、Free 已激活 | 进入企业工作台 |

钱包开通状态与 KYB/Free 状态独立展示。钱包处理中或开通失败不得回滚 KYB 或 Free。

## 三、边界与引用

- 五步 KYB 的正式字段、条件规则、文件要求、草稿/提交/补件和版本快照，以已批准的《U01 KYB v0.3｜简化版五步企业认证批准决策》及 U01-UI-Ready PRD B01～B08 为准。
- 本页面只负责认证引导与状态分流，不重新设计或复制五步 KYB 表单。
- KYB 通过激活 Free，不代表真实发行、募资或 Token 生产执行获准；仍受 Standard 权益和独立生产准入约束。
- 不把企业钱包开通失败误判为 KYB 失败，不要求用户因此重新提交企业认证。

## 四、不包含

- 不改变 U01 已批准的五步 KYB 字段与规则、Free/Standard、企业钱包及订阅规则。
- 不授权修改官网或 Issuer 源码，不授权技术开发。
- 不修改 Frozen、193 项正式功能 ID 与首次交付版本归属；不关闭 X-01～X-13；不合并 PR #6 或 PR #8。
