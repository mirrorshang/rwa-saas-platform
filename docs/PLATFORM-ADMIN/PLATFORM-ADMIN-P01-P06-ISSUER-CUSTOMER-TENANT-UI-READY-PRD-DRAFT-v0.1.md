## 1. 本批沿用的已批准规则

| 规则 | 对页面的直接约束 |
|---|---|
| DEC-026 / M03-F001 | P可审核SaaS买方商业KYB、补件和复核；KYB通过不等于Issuer的资产/证券/Offering获准发行 |
| DEC-026 / M03-F002 | P可在授权范围管理Tenant开通、暂停、恢复和服务异常；M01是Tenant/商业授权唯一事实，P不建立第二套Tenant主账 |
| DEC-026 / M03-F005 | 默认只见最小必要资料；敏感原件必须走独立受控访问申请、审批、限时授权、撤销与审计，不在普通列表或详情中直接下载 |
| DEC-018 / DEC-019 | 邮箱验证即可创建受限Trial Tenant；14个自然日，无需预绑付款方式，不自动扣费；Trial到期后只读及30天恢复窗口；正式Standard商业付款前必须完成适用KYB；首期只有一个Standard付费套餐 |
| DEC-019 | Trial与Paid共用同一个Tenant身份；转正不得新建Tenant；Free为独立的长期免费层，不受14天Trial倒计时影响 |
| DEC-034 R01 | 平台只管理SaaS商业权限与受控服务，不控制Issuer资金、法定登记、Token、收益或Signer |
| DEC-034 R02 | 页面按钮/前端隐藏不等于授权；所有敏感访问与跨Tenant访问均需服务端守卫（本批仅设计产品行为） |
| DEC-034 R03 | 商业付款/订阅状态Unknown时先查原Intent，不盲目重扣；任务完成不等于商业付款或Tenant权益已完成 |
| DEC-034 R05/R06 | 报表只读、Provider与Tenant环境隔离；平台暂停或退租不抹除已有真实业务义务及证据 |

### 1.1 核心概念必须分开呈现

| 概念 | 定义 | 不可混同 |
|---|---|---|
| SaaS客户 | 购买或申请使用RWA SaaS的企业客户，是平台商业关系主体 | 不自动等于每个Offering的法定发行主体 |
| 商业KYB | 平台对SaaS买方及其代表的商业准入核验 | 不等于证券发行许可、资产权属审查、投资者KYC或Offering合法性审批 |
| Tenant | 一个企业在SaaS中的唯一隔离工作空间 | Trial转Standard不新建Tenant；同企业多个账号也不默认多Tenant |
| 套餐/商业权益 | Free、Trial、Standard及其有效期、能力、配额 | 不等于发行准入、资金授权或链上权限 |
| Tenant服务状态 | Tenant当前能否使用SaaS服务，以及受限/暂停/恢复状态 | 不等于底层链合约暂停或真实金融义务终止 |
| 商业账单/付款 | 企业向SaaS平台支付的订阅费用 | 与投资者向Offering支付的认购款、退款、收益/本金完全分离 |

## 2. 全局页面与交互规范

### 2.1 页面框架

- 左侧一级导航使用总体架构已确定的9个模块；本批当前模块为「平台工作台」「发行机构管理」。
- 顶部显示当前平台运营账号、角色、通知入口、帮助入口及退出登录；不展示客户或投资者隐私信息。
- 主内容区域采用页面标题、面包屑、简短说明、主要操作、筛选区、内容表格/详情区的标准结构。
- 复杂审核和Tenant操作使用独立页面；危险操作使用标准确认弹窗。**不将复杂表单放入右侧Drawer作为默认交互。**
- 桌面Web优先；不设计移动端专属页面。

### 2.2 列表页共用规范

| 项目 | 统一要求 |
|---|---|
| 搜索 | 仅提供与本页对象直接相关的关键搜索；输入后回车或点击搜索生效；支持清空 |
| 筛选 | 先展示最常用的2～4个筛选，其余低频筛选放入「更多筛选」；已选条件以可移除标签展示 |
| 表格 | 表头清楚、状态使用统一标签；长字段截断但可查看完整值；不在列表展示敏感原件 |
| 排序 | 默认按待处理优先，其次按最近更新时间倒序；允许对明确有意义的日期/名称排序 |
| 分页 | 显示总数、当前页和每页数量；切换筛选后回到第一页 |
| 行操作 | 默认只保留「查看」；暂停、恢复、审核、收费恢复等高影响动作进入详情页 |
| 空状态 | 区分无数据、筛选无结果、无权限、数据暂不可用；提供清除筛选或返回入口 |
| 数据更新时间 | 列表或关键汇总标注最近更新时间；过期或不完整数据不可伪装成实时成功 |
| 导出 | 本批默认不提供客户列表批量导出；确有需要必须走P-11/P-12受控导出审批 |

### 2.3 状态展示共用规范

- 业务状态必须显示中文名称；英文状态码只作为内部辅助，不作为主文案。
- KYB状态、Tenant服务状态、套餐权益状态、商业付款状态分开显示。
- 状态Unknown统一显示「状态待核实」，并提示「请先核对原业务记录，不要重复执行」。
- 任何「已通过」都需明确通过的对象，例如「商业KYB已通过」，不可只显示「已通过」。
- 状态变化记录展示操作者/来源、时间、原因和前后状态；历史记录不覆盖。

### 2.4 页面公共异常

| 场景 | 页面反馈 | 用户可执行操作 |
|---|---|---|
| 加载失败 | 「暂时无法加载，请稍后重试」 | 重试；保留当前筛选 |
| 数据部分缺失 | 「部分信息暂不可用，当前结果可能不完整」 | 查看可用信息、进入异常记录 |
| 权限不足 | 「你没有查看此信息的权限」 | 返回上一页或申请相应授权 |
| 状态Unknown | 「当前结果尚未核实，请勿重复操作」 | 查看原记录、发起核查任务 |
| 记录已更新 | 「该记录已发生变化，请刷新后再处理」 | 刷新；旧页面不允许继续提交过期操作 |
| 重复提交 | 「请求正在处理中，请勿重复提交」 | 查看原请求进度 |

## 3. P-01｜平台运营工作台

### 3.1 页面目标

平台运营人员登录后快速了解平台商业客户、商业KYB、Tenant服务状态及需要处理的关键异常。P-01是只读聚合和导航入口，不成为第二个审批系统，也不重复建设P-07运营工单。

### 3.2 页面结构

1. 页面标题：平台工作台；副标题：平台客户与服务运行概览。
2. 关键指标区：4～6张简洁统计卡。
3. 待处理事项区：只显示当前账号有权处理且尚未完成的关键事项。
4. 服务风险区：只显示影响Tenant服务或商业转正的异常。
5. 最近动态：最近发生的客户/KYB/Tenant/商业收费状态变化。
6. 快捷入口：客户申请、KYB审核、Tenant管理、商业收费异常。

### 3.3 指标卡及口径

| 指标 | 统计口径 | 点击行为 |
|---|---|---|
| SaaS客户总数 | 当前平台可见的已创建客户记录去重数；不包含M/V投资者账户 | 跳转P-02全部客户 |
| 待商业KYB审核 | 已提交且尚未得到最终商业KYB结论的申请数；补件待客户提交与外部核验Unknown单独标识 | 跳转P-02并筛选待审核/待补件/待核实 |
| Trial试用中 | 当前14天试用期内且服务可用的Tenant数；Free不计入Trial | 跳转P-04筛选Trial有效 |
| Trial恢复窗口 | Trial已到期且仍处于30天恢复窗口的Tenant数 | 跳转P-04筛选试用到期/恢复窗口 |
| Standard服务受限 | Standard因商业欠费、异常或受权暂停而受限的Tenant数；不含已终止但依法保留查询/交接能力的历史记录 | 跳转P-04筛选Standard受限 |
| 商业收费待核实 | 商业付款状态Unknown或付款确认与权益同步不一致的账单数 | 跳转P-06筛选待核实 |

说明：
- 指标按数据源返回的当前状态统计，不自行推断或合并状态。
- 每张卡显示统计截止时间/最近更新时间。
- 角色无权查看的指标不显示，不用0代替无权限。
- 不显示平台投资者总人数、投资金额、募集额、Token数量、收益额等不属于本模块的指标。

### 3.4 待处理事项字段

| 字段 | 展示 |
|---|---|
| 事项类型 | 商业KYB待审核／客户补件待复核／Tenant开通异常／Trial恢复申请／商业收费Unknown／权益同步异常 |
| 关联客户 | SaaS客户名称 |
| 关联对象 | 客户申请ID、Tenant ID或商业账单ID |
| 当前状态 | 对应领域状态中文标签 |
| 等待时间 | 自事项进入当前待处理状态起的时长；仅作排序，不推断逾期SLA |
| 当前负责人 | 已分配负责人；未分配显示「待分配」 |
| 下一步 | 查看详情 |

待处理列表只聚合原领域/M17任务引用，不复制审批记录。点击后进入P-03、P-05或P-06。

### 3.5 最近动态字段

- 发生时间
- 事件类型
- 客户名称
- 关联Tenant/申请/账单编号
- 变化摘要（例如「商业KYB：待审核 → 待补件」）
- 触发来源（客户提交、平台审核、商业支付回执、系统状态同步）
- 查看详情

默认展示最近10条；不显示原始身份证明、完整联系方式、Provider原始Payload。

### 3.6 操作与权限

- P-01无直接审核、暂停、恢复、付款或导出操作。
- 仅展示当前角色有权查看的待办和指标。
- 点击指标进入相应列表并带入筛选条件。
- 点击事项进入对应对象详情；权限在目标页面重新校验。
- 快捷入口只负责导航，不绕过任何业务Gate。

### 3.7 页面状态与验收

| 场景 | 预期结果 |
|---|---|
| 首次加载 | 显示指标骨架，完成后显示数值与更新时间 |
| 无客户数据 | 显示空状态和「暂无SaaS客户」；不显示虚构的0业务趋势 |
| 无待处理事项 | 显示「当前没有待处理事项」 |
| 单个数据源不可用 | 对应卡片显示「暂不可用」，其他卡片正常展示；提示数据不完整 |
| 当前账号无KYB权限 | 不显示KYB待办和详情入口 |
| 点击Trial卡片 | P-04自动筛选Trial有效Tenant |
| 点击商业收费待核实 | P-06自动筛选Unknown/权益同步异常 |
| 任意卡片数据过期 | 明确显示最后更新时间，不标记实时 |

## 4. P-02｜SaaS企业客户列表／申请队列

### 4.1 页面目标

统一管理购买或申请使用RWA SaaS的企业客户及其商业KYB进度。列表中的「客户」是SaaS商业买方，不是投资者，也不预设等同于每个Offering的法定发行主体。

### 4.2 页面结构

- 标题：发行机构管理；二级页签：企业客户、Tenant服务、商业收费异常。
- 当前页标题：企业客户。
- 主要操作：无全局新增按钮；客户由官网邮箱验证与企业流程创建。
- 搜索与筛选区。
- 客户列表。
- 点击客户行进入P-03或关联Tenant详情P-05。

### 4.3 搜索与筛选字段

| 字段 | 控件 | 规则 |
|---|---|---|
| 搜索 | 输入框 | 支持客户名称、客户编号、企业商务邮箱；不支持身份证件号等高敏字段搜索 |
| KYB状态 | 单选下拉 | 全部、未提交、待审核、审核中、待补件、已通过、已拒绝、待核实 |
| Tenant状态 | 单选下拉 | 全部、Trial试用中、Trial只读恢复期、Free有效、Standard有效、Standard受限、人工暂停、状态待核实 |
| 套餐 | 单选下拉 | 全部、Trial、Free、Standard |
| 所在国家/地区 | 下拉/搜索选择 | 取客户已提交的注册国家/地区；未填写显示「未提供」 |
| 注册时间 | 日期范围 | 按客户首次创建时间筛选 |
| 更多筛选 | 折叠区 | 最近更新时间、是否有待处理事项 |

默认排序：存在待处理事项的客户优先，其次按最近更新时间倒序。

### 4.4 列表字段

| 列 | 字段 | 说明 |
|---|---|---|
| 1 | 客户编号 | 平台客户唯一编号 |
| 2 | SaaS企业名称 | 客户声明的企业名称；未填写显示「企业资料待完善」 |
| 3 | 所在国家/地区 | 已提交的注册国家/地区 |
| 4 | 商务联系人 | 姓名；无资料显示「未填写」 |
| 5 | 商务邮箱 | 企业联系邮箱；列表中可部分遮蔽 |
| 6 | KYB状态 | 商业KYB独立状态 |
| 7 | 套餐 | Trial／Free／Standard |
| 8 | Tenant服务状态 | 独立显示服务可用/受限/暂停/Unknown |
| 9 | 注册时间 | 首次创建时间 |
| 10 | 最近更新时间 | 最近一次客户资料或业务状态变化 |
| 11 | 待处理事项 | 待审核、待补件、待核实等摘要；无则显示「—」 |
| 12 | 操作 | 查看详情 |

不展示：投资者数量、Offering详情、投资金额、客户钱包地址、Token数量、完整证件号、KYC原件、私钥/助记词。

### 4.5 客户记录详情入口

- 客户有未完成KYB申请：进入P-03当前申请。
- 客户已有Tenant：从关联信息进入P-05。
- 同一客户有历史KYB申请：P-03提供申请历史切换；不在客户列表重复生成多条客户主记录。
- 客户名称或联系人变更：显示当前值与历史变更记录；不覆盖历史审核证据。

### 4.6 列表操作

- 查看客户详情：进入对应业务详情。
- 创建运营待办：仅作为M17引用任务入口；本批可先通过标准「发起跟进」弹窗记录原因、责任人和关联对象，不创建独立CRM。
- 不提供批量通过KYB、批量暂停Tenant、批量导出客户资料。

### 4.7 空状态与异常

| 场景 | 反馈 |
|---|---|
| 无客户 | 「暂无SaaS企业客户」 |
| 筛选无结果 | 「没有符合条件的客户」＋清除筛选 |
| 客户已合并/重复申请待核实 | 显示「客户关系待核实」，禁止自动合并Tenant |
| Tenant信息读取失败 | 客户仍可显示，Tenant列标记「暂不可用」 |
| 商务邮箱重复 | 显示冲突提示并进入受权复核，不自动把两个客户合并 |

## 5. P-03｜商业KYB申请详情／补件／复核

### 5.1 页面目标

让平台受权审核人员完成SaaS买方商业KYB受理、资料核对、补件、复核及结论留痕。页面只决定平台商业准入中的KYB状态，不审批Issuer资产权属、证券/金融工具发行合法性或投资者资格。

### 5.2 页面布局

页面采用独立详情工作区，分为：

1. 顶部申请状态与主要操作。
2. 客户及Tenant摘要。
3. 企业主体资料。
4. 申请人/授权代表资料。
5. 提交材料目录及扫描状态。
6. 外部核验摘要。
7. 审核意见与补件记录。
8. 历史审核时间线。

### 5.3 顶部摘要字段

| 字段 | 展示规则 |
|---|---|
| KYB申请编号 | 唯一申请编号 |
| 客户编号 | 关联P-02客户 |
| SaaS企业名称 | 当前申请所申报主体 |
| Tenant编号 | 已创建则显示；尚未关联时显示「待创建/待关联」 |
| 当前KYB状态 | 待审核、审核中、待补件、已通过、已拒绝、待核实、已失效 |
| 提交时间 | 最近一次完整提交时间 |
| 当前审核人 | 已分配审核员；未分配显示「待分配」 |
| 申请套餐 | Trial/Standard意向；只作为商业申请信息，不代表已开通 |
| 最近更新时间 | 资料或审核状态最近变化时间 |

### 5.4 企业主体资料字段

字段从M01企业资料读取；未提交项明确显示「未提供」，不由平台人员代填：

| 字段 | 展示与访问要求 |
|---|---|
| 企业法定名称 | 默认显示 |
| 企业注册国家/地区 | 默认显示 |
| 企业注册编号 | 默认遮蔽部分字符；查看完整值须符合受控访问条件 |
| 注册地址 | 默认显示已提交地址；高敏附件不直接展开 |
| 企业类型/法律形式 | 按申请人提交内容显示 |
| 企业成立日期 | 已提供则显示 |
| 企业网站 | 已提供则显示可打开的外部链接；不代表平台已验证 |
| 企业业务描述 | 显示申请人提交的简要说明 |
| 与SaaS购买方的关系 | 企业自述；如发行主体不同，显示其声明关系，不自动认定法律关联 |

### 5.5 申请人及授权代表字段

| 字段 | 展示与访问要求 |
|---|---|
| 联系人姓名 | 默认显示 |
| 职务/角色 | 默认显示 |
| 商务邮箱 | 默认显示或按角色遮蔽 |
| 联系电话 | 默认遮蔽部分号码 |
| 是否声明为授权代表 | 是/否/未提供 |
| 授权证明状态 | 未提交/已提交/待核实；原件受控访问 |
| 代表身份核验状态 | 未请求/处理中/完成/Unknown；只显示摘要 |

不得将申请联系人自动视为法定代表人或有权签署人；需根据适用核验材料和授权证据判断。

### 5.6 材料目录

材料名称由适用KYB要求及客户提交结果决定，不在本页面硬编码单一国家的证照清单。

| 字段 | 说明 |
|---|---|
| 材料类别 | 企业注册证明、地址证明、代表授权材料或其他适用材料 |
| 文件名称 | 上传时的文件名 |
| 上传时间 | 文件上传时间 |
| 文件版本 | 每次补件形成新版本，保留历史版本 |
| 扫描/安全状态 | 待扫描、通过、隔离、失败、Unknown |
| 审核状态 | 未查看、已核对、需补件、不适用 |
| 原件访问 | 仅显示受控访问入口；不提供普通下载按钮 |

若需查看原件：跳转P-11「敏感资料访问申请」，填写访问目的、Tenant、指定文件/字段、访问期限；获得批准后按授权访问，过期或撤销立即失效。材料隔离/恶意文件风险时不得预览或下载。

### 5.7 外部核验摘要

| 字段 | 说明 |
|---|---|
| 核验类型 | 企业登记/代表身份/其他适用商业核验 |
| 服务来源 | 已配置且适用的Provider名称；未配置显示「未连接」 |
| 请求编号 | 外部核验请求引用ID |
| 核验状态 | 未发起、处理中、已完成、失败、Unknown |
| 结果摘要 | 只显示最小必要结论，不展示原始Payload |
| 最近核验时间 | Provider结果时间或平台接收时间，需标明时间类型 |
| 关联异常 | 若Unknown/失败，提供查看运营异常入口 |

外部结果Unknown不能被界面显示成通过；不得因Provider HTTP成功就自动批准商业KYB。

### 5.8 审核动作

| 动作 | 触发条件 | 弹窗/页面内容 | 提交后结果 |
|---|---|---|---|
| 开始审核 | 当前为待审核/已重新提交，且当前用户具备审核权限 | 显示审核任务及当前资料版本；确认接手 | 状态转审核中，记录审核人和时间 |
| 要求补件 | 审核中，存在明确缺失/不清晰材料 | 选择缺失材料类别、填写补充说明、可选补件期限（不预设统一SLA） | 状态转待补件；向客户发起M17补件任务并通过M18通知 |
| 商业KYB通过 | 资料完整、适用核验结论有效、审核人有权 | 展示本次通过范围、核验依据、备注；再次确认「仅通过SaaS商业KYB」 | KYB状态已通过；不自动收款、不自动开通Standard、不批准任何Offering |
| 商业KYB拒绝 | 有明确拒绝依据且审核人有权 | 必须选择拒绝原因并填写说明；提示客户可按规则申诉/重新提交（如适用） | 状态已拒绝，记录理由和审核人；不删除Trial Tenant |
| 提交复核 | 结果存在冲突、高风险或需要第二人判断 | 选择复核原因、证据和目标复核人 | 状态待复核，转入M17任务；原审核记录保留 |
| 核查Unknown | 外部核验或材料结果不确定 | 展示原请求编号、当前证据和异常原因 | 保持待核实/审核中；创建M17异常，不允许直接通过 |

### 5.9 审核必填项

- 审核结果。
- 审核意见/依据摘要。
- 资料版本引用。
- 外部核验结果引用（如适用）。
- 操作人和操作时间由系统生成。
- 补件时：缺失类别、补件说明；补件期限仅在有明确规则时填写。
- 拒绝时：拒绝原因类别与说明。
- 复核时：复核原因和复核责任人。

### 5.10 状态模型（产品表达，不是冻结技术枚举）

| 状态 | 含义 | 允许下一步 |
|---|---|---|
| 未提交 | 客户尚未提交商业KYB申请 | 客户提交 |
| 待审核 | 已提交完整申请，等待平台受理 | 开始审核 |
| 审核中 | 已有审核人处理 | 通过、补件、拒绝、复核或待核实 |
| 待补件 | 平台要求客户补充资料 | 客户补件后重新提交 |
| 待复核 | 需要独立复核 | 复核通过、退回补件或拒绝 |
| 已通过 | 商业KYB审核通过 | 可进入Standard合同/付款流程，但不代表Paid |
| 已拒绝 | 当前申请未通过 | 按适用规则重新提交或申诉 |
| 待核实 | 外部结果/证据不足或冲突 | 核查原请求并补充证据 |
| 已失效 | 资料过期、主体变化或需重新核验 | 重新提交/重新核验 |

### 5.11 历史记录与客户通知

- 时间线显示提交、补件、重新提交、审核接手、外部核验、通过/拒绝、复核等事件。
- 每条记录包含时间、操作者/来源、动作、状态前后变化、理由摘要、资料版本。
- 历史记录不可覆盖；更正以追加事件表达。
- 通知只发送必要状态与安全链接；打开链接时重新校验Tenant及用户权限。
- 已发送/已读不等于法律有效送达。

### 5.12 页面验收场景

1. Trial客户未提交KYB：P-02可见客户与Trial Tenant；P-03显示未提交，不阻断其试用登录。
2. 客户提交KYB：P-03显示待审核，材料目录与提交时间正确。
3. 审核员要求补件：状态变待补件，原因可见，客户收到通知；原申请和文件版本保留。
4. 客户补件后重提：原版本保留，新版本成为当前审核版本。
5. 外部核验Unknown：页面保持待核实，不出现通过按钮或成功状态。
6. KYB通过：仅商业KYB状态变已通过；Tenant仍按商业合同/付款Gate决定是否Standard。
7. 商业KYB拒绝：保留Trial与审核证据，不直接删除Tenant。
8. 无权限访问原件：P-03仅见材料元数据；必须跳转P-11申请受控访问。
9. 不同Tenant用户访问申请详情：服务端拒绝，页面不泄露客户名称、附件或历史。
10. 审核期间资料版本更新：旧页面提交被阻断，提示刷新后重新核验。

### 6.5 必须区分的套餐与服务状态

| 套餐 | 商业规则 | 列表表达 |
|---|---|---|
| Trial | 14个自然日，自首次激活起算；无需预绑支付方式，不自动扣费；到期后30天恢复窗口 | 显示起止时间与剩余/已过天数；到期后显示只读恢复期 |
| Free | 0费用的长期免费层，不按14天Trial到期 | 显示「Free有效／长期有效」；不得自动转TrialExpired |
| Standard | 首期唯一正式付费套餐，月付/年付；正式商业付款前需KYB通过 | 显示套餐、账单周期、当前订阅期间及商业付款状态 |

服务状态是另一维度：即使套餐为Standard，也可能因欠费、商业争议或安全原因受限；即使Trial到期，也不得与Paid有真实金融义务的保护状态混为一谈。

### 6.6 列表行为

- 点击Tenant行进入P-05。
- 点击KYB状态进入关联P-03申请。
- 点击商业付款状态进入P-06对应账单/异常。
- 不提供列表行内一键暂停、恢复、关闭、删除。
- 不提供批量Tenant操作。

### 6.7 页面验收场景

1. Free Tenant长期存在：显示Free有效，不出现Trial倒计时和到期日期。
2. Trial有效：显示14天期限及剩余时间。
3. Trial到期：显示只读恢复窗口及截止时间，不显示Paid逾期。
4. Standard有效：显示月付/年付和有效周期。
5. Standard付款Unknown：商业付款列待核实，不能显示Standard已生效（除非M01已有独立有效授权状态）。
6. Tenant被人工暂停：服务状态与套餐状态分别显示。
7. Tenant有未结真实义务：列表仅显示「需保留服务/交接」提示，不泄露具体投资者或金融数据。
8. 列表数据延迟：显示最后更新时间和部分数据不可用提示。

### 7.6 Tenant服务能力摘要

- 登录/工作台可用状态。
- 企业资料与KYB功能状态。
- 资产/Offering准备能力状态。
- 投资者门户配置/预览/发布授权状态（仅摘要）。

能力实际生效以M01/M19及相关业务Gate为准；P-05不能用手工开关替代M19或发行合法Gate。

如状态为待核实或存在未完成交接，阻断永久关闭/不可逆删除；可按权限执行临时限制新增商业服务，但不得阻断依法必要的投资者查询、退款、本息/收益履行或证据保留路径。

| 重新核对状态 | 原状态或Provider同步存在Unknown，且查询能力可用 | 展示原Tenant/账单/Intent引用，不生成新对象 | 查询原权威状态；不得新建Tenant或重复收费 |
| 恢复Trial | 仍在30天恢复窗口且KYB/合同/付款等适用条件满足；M01确认原Tenant可恢复 | 显示恢复依据、原Tenant ID、恢复后能力 | 受权恢复原Tenant；不得重建新Tenant |

| 永久删除Tenant | 本批不提供 | 无 | 不允许从P-05直接删除Tenant或业务证据 |

### 7.9 暂停确认弹窗字段

- 暂停原因（必填）：商业欠费/合同争议、安全风险/凭证风险、客户主动申请、运营纠错、其他。
- 影响范围（必填）：新增业务操作、企业工作台访问、对外门户配置等；按真实M01/M19能力映射，不提供任意自定义权限脚本。
- 是否影响既有真实义务：只读显示「不得影响」及当前核对结果。
- 是否需要复核：由适用高风险规则决定；若要求双人复核，当前操作人不能自批。
- 客户通知：显示将发送的必要通知类型；不把发送成功当成法律送达。
- 操作备注：必填。
- 确认按钮：根据动作显示「确认暂停商业服务」；不得使用模糊「确认」。

### 7.10 恢复确认弹窗字段

- 原暂停/受限原因。
- 当前商业KYB状态。
- 当前合同/付款状态。
- 原Tenant编号。
- 恢复依据/核对结果。
- 恢复后能力摘要。
- 备注。
- 若付款、合同或KYB为Unknown，按钮禁用并显示原因。

### 7.11 状态变化历史

每条记录展示：事件时间、事件类型、前状态、后状态、原因、操作者、审批任务引用、来源（M01/M17/平台操作）、关联商业账单或合同ID。历史不可编辑覆盖。

### 7.12 页面验收场景

1. Trial到期：显示只读恢复窗口，不能套用Paid欠费处理。
2. Trial恢复窗口内KYB/合同/付款条件满足：恢复同一Tenant，Tenant ID不变。
3. Trial恢复窗口过期：恢复按钮不可用；只提供政策允许的查询/导出/支持路径。
4. Free Tenant：不显示订阅到期、逾期或自动暂停提示。
5. Standard付款Unknown：阻断开通/恢复Standard；显示原账单核查入口。
6. Standard商业付款已确认但能力未同步：P-05提示转P-06核查，不允许人工直接改套餐状态。
7. 人工暂停：必须有原因、影响范围和审计记录；暂停不删除资产、订单、资金、Token、持有人或收益历史。
8. 保护性义务待核实：阻断永久关闭/删除；允许按规则限制新增非必要业务。
9. 恢复人工暂停：保留暂停和恢复两条独立事件。
10. 无权操作人：页面不显示或禁用高影响操作；即使构造请求也必须由服务端拒绝。
11. 同一恢复请求重复点击：幂等返回原结果，不新建Tenant或重复赋权。
12. Tenant状态Unknown：页面不允许执行不可逆操作，先核查原Tenant事件。

### 8.6 异常类型与处理规则

| 异常 | 识别条件 | P端处理 | 禁止行为 |
|---|---|---|---|
| 付款失败 | 商业支付权威明确返回失败 | 显示失败原因；通知客户从其订阅页面按原业务流程重新发起 | 平台运营人员直接重新扣款 |
| 付款Unknown | 原Intent结果不确定或Provider未给出最终回执 | 查询原Intent、查看事件、创建M17核查任务；保持Unknown | 新建支付请求、重复扣款、手工标记Paid |
| 付款已确认但权益未同步 | Provider权威确认商业付款，但M01权益状态未更新 | 核对原账单、KYB、合同、Tenant后，受权发起幂等权益同步/恢复；记录原Intent | 创建第二个Tenant、重新扣款、绕过KYB/合同Gate |
| 重复请求风险 | 同一客户/Tenant出现多个相同业务目的的未完成支付Intent | 聚合展示原Intent，按原业务对象核对；必要时升级 | 仅凭金额/时间相同就自动认定重复或删除其中一个 |
| KYB/合同Gate不满足 | 付款前置条件不满足或结果Unknown | 阻断权益激活；引导客户完成KYB/合同流程 | 因付款回执存在而绕过商业准入 |
| Provider回执冲突 | 不同事件/回调对同一Intent给出冲突结果 | 保留原始事件引用，状态设待核实，升级处理 | 覆盖历史回执或选取更有利结果直接通过 |

### 8.7 允许操作

| 操作 | 条件 | 操作结果 |
|---|---|---|
| 查询原Intent状态 | 具备商业账单查询权限且Provider查询可用 | 查询同一个原Intent，不创建新支付 |
| 查看事件历史 | 具备账单只读权限 | 查看状态变化和回执摘要 |
| 发起核查任务 | 存在Unknown、回执冲突或同步异常 | 创建/关联M17任务，指定责任人 |
| 通知客户 | 需要客户补充或从其订阅页面继续付款 | 通过M18发必要通知，保留发送记录 |
| 幂等权益同步/恢复 | 付款权威已确认、KYB有效、合同有效、Tenant匹配且有权操作 | 触发M01原Tenant权益核对/同步；不改支付事实、不创建新Tenant |
| 查看P-05 Tenant详情 | 所有账单均可关联原Tenant | 跳转P-05 |

不提供「手工标记已付款」「手工修改金额」「重新扣款」「退款」「删除账单」操作。商业账单争议如需退款，须另有正式商业财务规则和适格执行主体，本批不设计真实退款功能。

### 8.8 页面验收场景

1. 商业付款失败：显示失败，不赋Standard权益；客户在原订阅流程继续处理。
2. 商业付款Unknown：保持Unknown，查询原Intent，不生成第二个Intent。
3. 商业付款已确认、KYB未通过：权益仍不可生效，提示完成商业KYB。
4. 商业付款已确认、合同无效：权益不可生效，提示合同Gate不满足。
5. KYB/合同/付款均有效但权益同步失败：可按权限幂等同步原Tenant，不重复扣款。
6. 重复回调：保留事件并去重，不产生重复账单或重复订阅。
7. Provider回执冲突：进入待核实，不能选择任意一条回执覆盖原记录。
8. 商业账单与投资者认购款：列表和详情均不出现投资者认购数据。
9. 无账单异常：显示「当前没有商业收费异常」。
10. 账单原Intent不存在或不可查询：显示Unknown和异常任务入口，不允许重新扣款。

- [ ] 开通/恢复必须满足KYB、合同、付款等Gate。
- [ ] 暂停必须有原因、范围、审批和审计。
- [ ] Trial到期与Paid逾期采用不同保护规则。
- [ ] 真实存续义务和证据不得因商业暂停/退租消失。
- [ ] Unknown阻断不可逆操作。
- [ ] 退出交接未完成时不得最终关闭/删除。

### P-06 商业收费异常
- [ ] 只展示SaaS商业账单，不展示投资者认购款。
- [ ] 金额统一使用U展示，不在页面修改价格。
- [ ] 付款Unknown只查原Intent，不重复扣款。
- [ ] 已付款未同步权益时仅幂等恢复原Tenant权益。
- [ ] KYB/合同Gate不满足时不能激活Standard。
- [ ] 无手工标记Paid、手工改金额、直接退款或删除账单操作。

## 13. 尚未冻结的字段/技术决策门

下列内容本批不擅自定成生产规则：

1. KYB不同国家/地区的具体材料清单、法定代表/授权代表核验标准及有效期。
2. 商业KYB拒绝后的申诉/重新提交次数和期限。
3. 14天试用计时精度、时区、试用反滥用策略与重复企业识别。
4. Standard套餐价格、税费、发票、支付Provider、商业支付渠道及失败/争议的正式处理合同。
5. Trial恢复窗口到期后的具体数据留存、导出与删除期限；30天不是所有金融数据的法定删除期限。
6. Paid欠费宽限期、自动续费失败、暂停时间与恢复条件的精确数值。
7. 高风险暂停/恢复是否双人审批及具体阈值。
8. P端实际角色码、服务端RBAC、跨Tenant授权策略、敏感资料存储与导出机制。
9. Provider事件幂等、回调签名、状态查询频率、重试与商业付款对账接口。
10. 已有真实金融义务在Tenant暂停、退出、破产或法律争议时的法域责任和交接时限。

这些是后续技术/法律决策门，不阻碍本批前端产品信息结构、字段展示、交互与Mock原型设计；但在对应决策未批准前，不可把UI操作描述成真实生产能力。

## 14. 本批结论

- P-01～P-06六组页面的UI-Ready产品规格已形成Draft。
- 正式功能ID仍为M03-F001、M03-F002、M01-F004/F005/F006/F007/F008及M17/M19/M20等既有依赖；不新增ID、不调整版本。
- 14天Trial、30天恢复窗口、Free长期有效、单一Standard月/年订阅、KYB先于正式商业付款、商业收费与投资者认购款分离均按历史批准规则执行。

- 本批尚未获用户逐项批准，PR保持Draft/Open/Unmerged；不进入前端开发、后端/API/数据库或生产服务接入。
