## 2. MVP 资产范围与边界

### 2.1 当前支持范围

MVP 房地产模板仅支持**已建成、可明确识别的单一房地产资产**，并包含以下四种物业类别：

1. 住宅（Residential）
2. 办公（Office）
3. 商业（Commercial）
4. 工业物流（Industrial & Logistics）

选择房地产后，根据物业类别动态加载专属字段。公共字段、文件管理和披露规则保持统一。

### 2.2 V2.0 延后

以下不属于当前 MVP 模板：

- 在建地产、开发中项目及土地开发；
- 混合用途物业；
- 酒店及服务型物业；
- 专业用途物业；
- 多物业组合、跨物业组合及复杂持有结构；
- 其他资产类别的独立模板，包括债权、股权/证券、实物资产等。

底层保留多资产扩展方向，但不得把未完成模板展示为已支持，也不得把房地产字段直接复制到其他资产类别。

### 2.3 业务对象边界

- Asset 记录底层资产是什么。
- Instrument（用户界面名称统一为「权益结构」）记录投资者取得什么法律及经济权利。
- Asset 页面不定义权益类型、收益承诺、Token 数量、Token 单价或本轮认购规则。
- Asset Ready 仅表示必要资料达到基础完整性要求，不表示平台已核验权属真实性、估值真实性、法律效力或资产合规。

## 3. 账号与导航

- MVP 每家企业使用一个操作账号。
- 不建设企业成员邀请、内部角色分权、审核人员或企业内部审批流；权限配置延后 V2.0。
- 文件可见性仍须区分公开、合格投资者可见和企业内部可见；单账号不等于取消数据访问控制。

导航固定为：

**资产与发行 → 资产管理**

不增加三级导航。文件在资产页面内管理，不新增独立文件中心入口。

## 4. 页面清单与入口

| 页面 | 入口 | 主要目的 |
|---|---|---|
| 资产列表 | 资产管理 | 查看、筛选和管理企业资产 |
| 创建资产 | 资产列表 → 创建资产 | 创建房地产资产草稿 |
| 编辑资产 | 资产详情 → 编辑 | 修改当前可编辑资料并形成版本 |
| 资产详情 | 资产列表 → 资产名称 | 查看资产概览、专属信息、文件、版本和关联记录 |
| 文件预览 | 资产详情 → 文件资料 | 预览、下载和查看文件版本 |
| 归档/恢复 | 资产详情 → 更多操作 | 停止资产用于新业务或恢复资料准备 |

创建与编辑使用同一页面结构，采用**单页七个分区**，不拆成多步骤向导，不增加第三级导航。

## 5. 资产列表 UI

### 5.1 筛选项

- 资产名称关键词；
- 资产类型/物业类别；
- 资产状态；
- 国家/地区。

支持筛选重置。筛选条件不改变资产数据。

### 5.2 列表字段

| 字段 | 展示规则 |
|---|---|
| 资产名称 | 主识别信息，可进入详情 |
| 物业类型 | 住宅/办公/商业/工业物流 |
| 国家/地区 | 展示主要地区信息 |
| 主要面积 | 数值、单位及面积口径一起展示 |
| 资产状态 | Draft、Preparing、Ready、Restricted、Archived |
| 关联发行 | 展示关联权益结构/项目/发行信息摘要；无关联显示空态 |
| 更新时间 | 最近一次成功保存的时间 |
| 操作 | 查看、编辑；满足条件时显示归档/恢复 |

### 5.3 页面行为

- 默认显示企业当前可访问的资产。
- 无资产时显示空态，说明可创建房地产资产，并提供创建入口。
- 搜索无结果时显示无匹配结果及清除筛选操作。
- 列表加载失败时保留筛选条件并提供重试。
- 资产归档不等于删除，历史关联信息继续可查。

## 6. 创建/编辑页面：单页七分区

### 6.1 分区一：基本信息

| 字段 | 规则 |
|---|---|
| 资产名称 | 必填 |
| 资产分类 | 当前 MVP 固定为房地产；不展示未开放资产模板为可用选项 |
| 物业类别 | 必填：住宅、办公、商业、工业物流 |
| 物业子类型 | 按物业类别提供对应选项；具体子类型不得跨类别混用 |
| 资产描述 | 必填，面向资产事实的说明，不写入权益或收益承诺 |

### 6.2 分区二：地理位置

| 字段 | 规则 |
|---|---|
| 国家 | 必填 |
| 州/省 | 视地区情况填写 |
| 城市 | 必填 |
| 区域 | 可选 |
| 详细地址 | 必填 |
| 邮政编码 | 视地区情况填写 |

地址信息必须对应当前单一物业，不支持在 MVP 中用一个 Asset 表示多处物业组合。

### 6.3 分区三：物业基本情况

| 字段 | 规则 |
|---|---|
| 主要面积 | 必填，必须大于 0 |
| 面积单位 | 必填，仅支持 m² 或 ft² |
| 面积口径 | 必填，用于说明面积具体口径；不得只显示数字而隐藏口径 |
| 建成年份 | 可选 |
| 资产照片 | 支持上传；可指定封面照片 |

面积必须同时保存数值、单位和口径。系统不得将不同单位或不同面积口径的数值直接相加。

### 6.4 分区四：权属及运营信息

| 字段 | 规则 |
|---|---|
| 登记所有人 | 必填 |
| 企业与资产关系 | 必填，说明企业与登记所有人/资产的关系 |
| 实际持有主体 | 条件必填；登记所有人与实际持有主体不同时要求填写 |
| 运营主体 | 可选 |
| 当前运营状态 | 必填 |

平台仅记录企业填写的权属与运营信息。填写登记所有人、上传权属文件或填写企业关系，不代表平台确认产权或法律权利。

### 6.5 分区五：估值信息

| 字段 | 规则 |
|---|---|
| 是否提供估值 | 必填选择 |
| 估值金额 | 选择“提供”后条件必填；金额单位统一 U |
| 估值日期 | 选择“提供”后条件必填 |
| 估值依据 | 选择“提供”后条件必填 |
| 估值机构 | 使用独立评估时条件必填 |
| 估值报告 | 使用独立评估时条件必需，作为文件上传及版本引用 |
| 暂无估值原因 | 选择“不提供”时可填写说明 |

MVP 所有金额统一使用 U。不得在同一页面中混用 USD、EUR 等其他金额展示单位。估值金额是企业填写的数据，不是平台估值结论。

### 6.6 分区六：物业专属信息

物业类别改变时，仅展示该类别字段；不得将四种物业字段同时堆叠在同一表单中。

**A. 住宅（Residential）**

| 字段 | 规则 |
|---|---|
| 住宅类型 | 必填 |
| 总套数 | 多套住宅时条件必填 |
| 已入住套数 | 已录入总套数时条件必填 |
| 户型构成 | 可选 |
| 出租情况 | 可选 |
| 入住率 | 系统自动计算：已入住套数 ÷ 总套数 × 100% |

关联资料可包括户型图、单元清单、入住及出租汇总、租赁证明。

**B. 办公（Office）**

| 字段 | 规则 |
|---|---|
| 楼层数 | 可填写 |
| 办公单元数量 | 可填写 |
| 可出租面积 | 必填 |
| 已出租面积 | 可选 |
| 出租率 | 系统自动计算：已出租面积 ÷ 可出租面积 × 100% |

关联资料可包括楼层平面图、空间布局、租赁汇总和运营资料。

**C. 商业（Commercial）**

| 字段 | 规则 |
|---|---|
| 商铺总数量 | 可填写 |
| 已出租商铺数量 | 可填写 |
| 商业可出租面积 | 必填 |
| 已出租商业面积 | 可选 |
| 租户数量 | 可填写 |
| 商业出租率 | 系统自动计算：已出租商业面积 ÷ 商业可出租面积 × 100% |

关联资料可包括商业平面图、布局图、租赁汇总及运营资料。

**D. 工业物流（Industrial & Logistics）**

| 字段 | 规则 |
|---|---|
| 主要使用类型 | 必填 |
| 厂房或仓储面积 | 必填 |
| 当前使用面积 | 可选 |
| 建筑层数 | 可填写 |
| 使用率 | 系统自动计算：当前使用面积 ÷ 厂房或仓储面积 × 100% |

关联资料可包括厂房/仓储平面图、空间布局及运营资料。

**自动计算统一规则**

- 百分比由系统计算，企业不手动填写。
- 分母未填写或为 0 时，不显示虚假的 0% 或 100%；显示未提供/暂不可计算。
- 可选分子未填写时不默认填 0，不显示计算结果。
- 已出租面积不得大于可出租面积；当前使用面积不得大于厂房或仓储面积。
- 已入住套数不得大于总套数。
- 面积单位只使用 m²/ft²；计算前必须确保分子与分母使用相同单位和口径。
- 自动计算结果必须与源字段联动更新。

### 6.7 分区七：文件资料

资产文件统一在资产页面上传和管理，文件分为五类：

1. 权属文件；
2. 估值文件；
3. 资产介绍；
4. 运营资料；
5. 其他支持文件。

具体文件是否必需，依据资产情况和发行准备时的适用资料要求判定；不得因“文件类别存在”而将全部文件强制必填。

## 7. 文件管理与披露规则

### 7.1 文件元数据

每个文件记录：

- 文件名称；
- 文件分类；
- 出具主体；
- 出具日期；
- 生效日期；
- 到期日期；
- 语言；
- 可见范围；
- 文件说明。

### 7.2 可见范围及默认值

| 文件/资料 | 默认可见范围 | 说明 |
|---|---|---|
| 封面照片 | Public | 作为公开资产展示封面 |
| 权属证明 | Eligible Investors | 不默认向匿名公众公开 |
| 估值报告 | Eligible Investors | 按投资者资格和授权展示 |
| 平面图/空间布局 | Eligible Investors | 按资料敏感程度受控披露 |
| 运营汇总 | Eligible Investors | 仅披露必要摘要 |
| 内部运营资料 | Internal | 企业内部使用，不进入投资者门户 |
| 其他支持文件 | 上传时明确选择 | 不得默认全部公开 |

MVP 的企业账号只有一个操作账号；可见范围是对投资者披露的范围控制，不是企业内部角色权限。

### 7.3 上传、扫描、预览及下载

文件处理至少区分：

- 上传中；
- 待安全扫描；
- 扫描通过；
- 扫描失败/隔离。

扫描中或扫描失败的文件不得作为可公开文件。扫描失败文件应隔离并提示重新上传或处理，不得展示为正常可下载。

支持：
- 真实文件上传；
- 按五类分类；
- 文件预览；
- 文件下载；
- 替换为新版本；
- 查看历史版本；
- 查看可见范围和文件元数据。

### 7.4 版本和历史快照

- 文件替换必须创建新的 Document/File Version，不得覆盖旧文件内容。
- 已被 Offering、发行准备或投资者披露快照引用的文件版本必须保留。
- 投资者门户读取对应发行的 Publication Snapshot，不应自动读取企业当前最新文件而改变历史发行披露。
- 已公开或已被业务对象引用的文件不得物理删除；可按规则撤下当前展示或限制后续引用，但必须保留历史。
- 上传文件不代表平台核验其真实性、有效性或法律效力。

## 8. Asset 状态机

Asset 使用自身状态机，不套用 Instrument 状态。

| 状态 | 含义 | 允许操作 |
|---|---|---|
| Draft | 已建立资产草稿，资料尚未完整 | 编辑、保存草稿、补充资料 |
| Preparing | 资产资料准备中 | 编辑、上传/替换文件、完善信息 |
| Ready | 满足基础资料完整性，可用于配置权益 | 查看、按规则编辑非核心资料、进入权益配置 |
| Restricted | 存在重大异常或限制 | 查看、整改；限制期间不得作为新发行的正常资产使用 |
| Archived | 不再用于新的发行，保留历史记录 | 只读查询；按允许的恢复路径恢复为 Preparing |

### 8.1 状态转换

- Draft → Preparing：资产已建立并开始资料准备。
- Preparing → Ready：满足基础资料完整性。
- Ready → Preparing：重要资料发生变化，需要重新准备。
- Preparing → Restricted：发现重大异常/限制。
- Ready → Restricted：发现重大异常/限制。
- Restricted → Preparing：开始整改。
- Preparing → Ready：整改完成并再次满足完整性要求。
- Ready → Archived：企业归档。
- Preparing → Archived：企业归档。
- Archived → Preparing：恢复使用。

Ready 只代表资料完整，不代表平台真实性或合法性审查通过。

### 8.2 Restricted / Archived 的影响

- Restricted 期间只允许查看和整改；系统应触发关联存续 Offering 的影响检查。
- Archived 资产不得用于创建新的权益结构或新的 Offering。
- 归档不删除历史项目、发行方案、投资者持仓、Token 或文件快照。
- 归档确认弹窗应列出关联权益结构、Project、已发布 Offering 及存续发行。
- 恢复资产只恢复 Asset 的资料准备路径，不得自动恢复已暂停的 Instrument 或 Offering。

## 9. 详情页信息结构

资产详情分为四个主要区域：

1. **资产概览**：资产名称、物业类别、地区、主要面积、资产状态、封面及描述。
2. **专属信息**：按住宅/办公/商业/工业物流展示相应字段及自动计算结果。
3. **文件资料**：五类文件、元数据、可见范围、扫描状态、预览/下载及版本历史。
4. **版本与关联记录**：资产版本、操作记录、关联权益结构、Project、Offering 及历史发行引用。

详情页不得把 Instrument 权益、Offering 价格或 Token 发行数量混入 Asset 基础信息。

## 10. 主要按钮与交互

| 操作 | 位置 | 行为 |
|---|---|---|
| 创建资产 | 资产列表 | 打开七分区创建页面 |
| 保存草稿 | 创建/编辑页面 | 保存当前已填写内容，允许资料不完整 |
| 完成资料 | 创建/编辑页面 | 执行完整性和业务校验，满足条件后进入 Ready |
| 编辑 | 列表/详情 | 进入当前资产版本的编辑页面 |
| 上传文件 | 文件资料 | 上传真实文件并填写元数据 |
| 替换文件 | 文件资料 | 创建新文件版本，保留旧版本 |
| 预览/下载 | 文件资料 | 按可见范围和扫描状态控制 |
| 归档 | 详情更多操作 | 展示关联影响并二次确认 |
| 恢复 | 已归档资产详情 | 恢复为 Preparing，不自动恢复下游对象 |

保存草稿不要求全部必填字段完成；完成资料必须执行全部适用校验。提交操作应防重复。

## 11. 校验与异常

| 异常 | 系统行为 |
|---|---|
| 必填字段缺失 | 标记具体分区和字段，阻止完成资料；不阻止保存草稿 |
| 面积为 0 或负数 | 阻止完成资料 |
| 面积单位缺失 | 阻止完成资料 |
| 已入住套数大于总套数 | 阻止完成资料 |
| 已出租面积大于可出租面积 | 阻止完成资料 |
| 当前使用面积大于厂房/仓储面积 | 阻止完成资料 |
| 估值选择“提供”但金额/日期/依据不完整 | 阻止完成资料 |
| 独立评估缺少机构或报告 | 按条件必填阻止完成资料 |
| 可选运营字段为空 | 不默认填 0，不显示自动计算百分比 |
| 上传中断 | 保留其他表单内容，提示失败文件并允许重试 |
| 安全扫描中 | 不允许作为可披露文件 |
| 安全扫描失败 | 隔离文件，禁止公开及正常下载 |
| 保存失败 | 保留当前编辑内容，提示重试 |
| 重复提交 | 阻止重复创建/保存请求 |
| 版本冲突 | 提示数据已更新，展示变化并要求刷新/重新编辑，不静默覆盖 |
| 无权访问文件 | 拒绝访问，不返回文件内容 |
| 归档时存在关联发行 | 展示影响清单并要求确认；保留历史发行与持仓 |

## 12. UI 与验收标准

### 12.1 布局

- 1440px：完整展示导航、页面标题、主要操作、列表或七分区表单；信息层级清楚。
- 1280px：主要字段、按钮、表单分区可用，不得出现页面级横向溢出；必要时在内容区内处理长内容。
- 物业类别切换后，专属字段动态切换；不得同时显示四类专属字段。
- 文件可见范围、扫描状态和版本号在文件列表中可识别。
- 资产状态、资料完整性和法律真实性不得使用同一状态表达。

### 12.2 必测验收场景

1. 创建房地产资产草稿，字段不完整仍可保存。
2. 四类物业切换时只显示对应专属字段。
3. 住宅入住率、办公出租率、商业出租率、工业物流使用率按正确公式自动计算。
4. 面积单位缺失、面积小于等于 0 时不能完成资料。
5. 已入住/已出租/当前使用数量或面积超过对应总量时被阻止。
6. 估值“提供/不提供”切换时显示对应条件字段。
7. 文件上传、扫描中、扫描失败、预览、下载和替换版本按规则工作。
8. 文件替换后旧版本仍可在历史记录中查看，历史发行引用不变。
9. 保存失败、重复提交和版本冲突均有明确反馈，不丢失用户输入。
10. 归档前显示关联权益结构、Project、已发布 Offering 和存续发行；归档后不得新增发行关联。
11. Restricted 资产只允许查看与整改。
12. 在 1440px 和 1280px 完成列表、创建/编辑、详情、文件及归档流程验收。

## 13. 产品责任及生产边界

- 发行企业对资产信息、权属、估值、法律文件和披露内容负责。
- 平台负责字段完整性、数据一致性、文件安全扫描、版本及权限控制，不对文件真实性或法律有效性作实质核验。
- 资产 Ready 不代表法律合规或发行获批。
- Free Sandbox 仅允许模拟流程；不得产生真实资金、真实链上 Token 或真实投资者权利。
- Standard 订阅不自动授权生产发行；KYB、适用法律条件、正式协议、Provider、Signer、链网络及合约执行仍受原有生产准入 Gate 限制。
- 金额统一使用 U；V1.0 投资者支付仅支持 OP Mainnet USDT。该支付规则属于发行/认购配置，不应被混入 Asset 估值字段或 Asset 状态。
