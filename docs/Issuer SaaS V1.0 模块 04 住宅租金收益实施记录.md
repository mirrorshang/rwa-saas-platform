# 模块 04｜住宅租金收益实施记录

## 范围

正式 `apps/issuer` 增加住宅净租金上报、证明引用、确认、按固定 Record Date 持有人快照计算、唯一分配批次、逐笔 Sandbox 支付和投资者收益记录。租金业务操作位于「收益与分配」；模拟证明与支付结果设置位于独立「演示控制台」。这些记录只存在本地演示状态，不代表真实收租或到账。

## 操作顺序与状态

1. 在「演示控制台」创建明确标记的 Sandbox 租金证明引用，运行「扫描当前待处理文件」。
2. 在「收益与分配 → 存续管理」点击「上报住宅净租金」，选择 OFF-3001、2026-12、Record Date 2026-12-31，填写 8,000 CNY、演示换算 1 U=8 CNY、扣除 0 U，选择测试证明并保存。报告先为「资料待扫描」，扫描后「待确认」，点击「确认租金上报」为「已确认」。换算只用于本住宅案例。
3. 在「收益与分配 → 收益分配」点击「创建住宅租金批次」，选中已确认报告。页面预览固定快照 HSP-3001 中三名持有人的 500／300／200 U；创建 DST-1001 为「待复核」，进入详情后点击「确认合法批次」。计算状态「已计算」与支付状态「未发起」分开显示。
4. 在「演示控制台」按持有人逐笔选择 Sandbox 结果：成功、失败或 Unknown。Unknown 只能查询原意图；失败须用新尝试编号。三笔成功后批次为「支付完成」，持有人详情产生独立模拟到账记录。

同一 Offering／周期的有效报告和分配批次均防重复。六位小数舍入后的尾差按固定规则归于权益最多、编号最小的持有人。确认批次再次核对原报告金额、固定快照和权益版本。旧版存储缺少新集合时安全补空；坏记录隔离并保留原始内容。

## 实际验收

2026-11-19 在 `http://localhost:5174` 逐步点击完成上述流程；HOL-3001／3002／3003 分别模拟到账 500／300／200 U。先成功一笔时支付状态「部分成功」；HOL-3002 Unknown 后新意图被拦截，原意图查询成功；HOL-3003 失败后新意图成功。刷新后 DST-1001 仍为支付完成；重复创建同周期批次被拒绝。持有人 HOL-3001 详情显示 INC-3001、500 U 累计已支付收益。
