# RWA SaaS｜Platform Admin P-11～P-12：安全与审计 UI-Ready 产品规格（Draft v0.1）

> **文档状态：Draft｜2026-11-18**
>
> 本文细化平台总后台「安全与审计」模块：P-11 受控敏感资料访问申请/审批；P-12 审计证据、安全事件、留存及受控导出记录。
>
> 本文承接 M20-F001～F008 与 DEC-034 R02/R03/R05，仅定义桌面 Web 页面、字段、交互、状态、Mock 与前端验收；不实现服务端鉴权、存储、密钥、法定留存或真实安全响应。

## 0. 责任边界与核心规则

### 0.1 页面组

| 页面组 | 对应功能 | 页面责任 |
|---|---|---|
| P-11 敏感资料访问控制 | M03-F005、M20-F005 | 受控申请、独立审批、最小字段/时限授权、到期撤权 |
| P-12 安全与审计 | M20-F001～F004、F006～F008 | 追加审计、外部证据引用、安全事件、留存/交接、受控导出记录与凭证撤权协作 |

M20 是跨端统一安全与审计领域。P-11/P-12 是平台运营受权视图，不建立第二套审计主账，不替代原业务领域的法律、资金、Token 或登记事实。

### 0.2 强制原则

- 默认不展示 KYC 身份原件、完整证件号、原始 Provider Payload、客户私钥/助记词、Signer Secret 或外部服务密钥。
- 查看敏感资料必须有明确业务目的、合法依据、受权审批、最小字段范围和明确有效期。
- 普通平台客服/运营不能因拥有 P 后台账号而自动获得跨 Tenant 或原始 KYC 访问权。
- P-11 授权必须绑定具体请求人、Tenant、对象、字段、访问目的、方式和期限；不可生成可转发的通用访问链接。
- 授权到期/撤销后，服务端必须立即拒绝继续访问；前端缓存不能延续权限。
- P-12 审计日志追加保存；更正只能追加说明，不可覆盖或删除原事件。
- 外部 Tx Hash、Webhook、邮件或 Provider 回执只作为证据引用，不能单独推断真实到账、法定登记、Token 权利或法律送达。
- P-12 可记录凭证泄露/撤权事件并跳转 P-13 执行凭证处置；不得显示或复制密钥本身。

## 1. P-11｜敏感资料访问申请与审批

### 1.1 页面目标

对确有业务必要的敏感资料访问进行申请、审批、限时授权、撤销和追溯。P-11 不提供敏感资料浏览器或跨 Tenant 搜索。

### 1.2 页面结构

P-11 提供五个页签：

1. **待我审批**：当前账号有权审批且尚未完成的访问申请。
2. **待补充说明**：需要申请人补充业务目的、合法依据或范围的申请。
3. **授权生效中**：已批准且尚未到期/撤销的访问授权。
4. **已过期/已撤销**：只读查看历史授权。
5. **已拒绝**：只读查看拒绝原因和审计。

申请入口优先从 P-03、P-18、P-12 等原业务页面发起，并自动带入目标对象引用；P-11 不提供全库自由搜索。

### 1.3 申请列表筛选

| 字段 | 控件 | 规则 |
|---|---|---|
| 关键词 | 输入框 | 访问申请编号、业务对象编号、关联任务编号；不支持证件号搜索 |
| 目标数据类型 | 下拉 | 企业 KYB 材料、M 投资者 KYC 材料、业务证据文件、审计证据（按权限） |
| Tenant/Issuer | 输入/受权选择 | 只显示当前审批人有权处理的主体 |
| 访问方式 | 下拉 | 在线查看、受控下载（默认不开放） |
| 申请状态 | 下拉 | 待审批、待补充、已批准、授权生效、已拒绝、已过期、已撤销 |
| 申请人 | 下拉 | 仅当前权限范围内人员 |
| 申请时间 | 日期范围 | 提交时间 |

列表字段：
- 申请编号；
- 申请人/角色；
- Tenant/Issuer；
- 目标对象编号与类型；
- 申请目的类别；
- 请求字段范围摘要；
- 访问方式；
- 请求时长；
- 当前状态；
- 提交时间；
- 操作：查看申请。

列表只显示文件元数据和字段范围摘要，不直接显示原件或敏感值。

### 1.4 申请详情

固定分为六个区块：

**A. 申请人信息**
- 申请编号、申请人、所属团队/角色；
- 提交时间、当前负责人；
- 关联 M17 任务/工单（如有）。

**B. 业务目的与合法依据**
- 目的类别：商业 KYB 审核、投资者 KYC 问题核查、合规调查、安全事件、依法要求、其他；
- 业务目的说明（必填）；
- 合法依据/授权引用（必填，选择已登记依据或引用外部文件编号）；
- 关联业务对象和当前处理步骤；
- 预计处理完成时间（如适用）。

**C. 目标资料**
- Tenant/Issuer/M 投资者关联 ID；
- 数据类型、文件 ID、文件名、版本和所属业务模块；
- 数据敏感级别；
- 原件存储位置只显示受控引用，不暴露路径或可公开 URL；
- 是否涉及跨 Tenant/跨 Issuer 资料；默认阻断，必须有独立合法依据与额外审批。

**D. 请求访问范围**
- 申请访问字段（多选，仅允许白名单字段）；
- 访问方式：在线查看（默认）/受控下载（需更高审批）；
- 请求有效时长；
- 是否允许打印/下载（默认否）；
- 申请原因与最小必要说明。

**E. 审批评估**
- 是否必要；
- 是否存在低敏替代资料；
- 是否可以进一步缩小字段/时长；
- 是否涉及高敏/跨 Tenant；
- 审批意见。

**F. 历史记录**
- 申请、补充说明、批准/拒绝、授权生效、查看、撤销、到期事件；
- 操作者、时间、字段范围、授权期限；
- 关联 P-12 审计事件 ID。

### 1.5 审批操作与 Guard

| 操作 | 条件 | 结果 |
|---|---|---|
| 要求补充说明 | 目的/依据/字段范围不清楚但可补正 | 状态待补充，记录具体问题并通知申请人 |
| 批准最小范围 | 审批人有权、目的合法必要、目标对象明确 | 可缩小字段/时长；生成限时授权 |
| 批准受控下载 | 具备明确必要性及更高权限/审批要求 | 只授权指定文件和短时下载；生成下载审计 |
| 拒绝 | 无合法依据、目的不必要、范围过大或跨 Tenant 未获授权 | 记录拒绝原因；不生成访问权限 |
| 撤销授权 | 授权仍生效且当前用户有权，或发生安全事件 | 立即撤销服务端访问权；记录原因与时间 |
| 查看历史 | 具备审计只读权限 | 只读，不恢复授权 |

**不得自批：**申请人不能审批自己的访问申请。高敏/跨 Tenant 请求必须由与申请人职责分离的适格审批人处理；具体双人/多级审批按平台有效规则，不在本批设定未批准角色码。

### 1.6 授权结果字段

- Access Grant ID；
- 原申请编号；
- 被授权人（绑定唯一用户 ID）；
- Tenant/Issuer/目标对象；
- 允许访问字段；
- 访问方式；
- 下载/打印权限（默认否）；
- 合法目的引用；
- 生效时间、到期时间；
- 当前状态：已批准待生效、授权生效中、已过期、已撤销；
- 审批人、审批时间；
- 撤销原因/撤销人/撤销时间。

授权不得转授、不得改变目标对象、不得延长后自动续期。

### 1.7 访问页面体验

访问授权生效后，从原业务入口进入受控查看：
- 页面顶部显示「受控敏感资料访问」；
- 显示本次授权目的、字段范围和剩余有效时间；
- 未授权字段隐藏或脱敏；
- 不显示复制完整证件号、批量下载或跨对象跳转；
- 每次打开、查看、下载、打印尝试均追加审计事件；
- 授权到期或撤销时立即退出敏感视图并清除可见缓存；
- 访问链接不可分享；其他用户打开必须重新鉴权。

### 1.8 P-11 异常

- 申请人离职/角色撤销：待审批申请失效或重新分配；已生效授权按规则撤销。
- Tenant/对象归属变化：阻断原授权，要求重新核验。
- 文件版本变化：只允许访问申请批准的版本；新版本需重新授权。
- 权限缓存未更新：服务端拒绝，生成安全事件。
- 授权 Unknown：显示待核实，不允许先访问后补审。
- 访问目的失效：授权可立即撤销，保留历史。
- 跨 Tenant 请求无合法依据：直接拒绝，不提供搜索或文件存在性提示。

## 2. P-12｜安全与审计

### 2.1 页面目标

集中查询平台可见范围内的审计事件、安全事件、外部证据引用、数据留存/交接及受控导出记录，帮助平台安全人员调查、限制影响和追踪处理结果。

P-12 不编辑原业务记录、不管理客户私钥、不提供任意数据仓库查询。

### 2.2 页面结构

P-12 提供四个页签：

1. **审计日志**：平台关键访问、审批、状态变更和外部回执事件。
2. **安全事件**：越权访问、凭证泄露、Provider 异常、疑似数据泄露等调查。
3. **数据留存与交接**：Tenant 退出、法律保留、受权交接和删除申请的状态/证据。
4. **受控导出记录**：导出申请、审批范围、生成状态、下载访问和到期记录（不代表本批批准所有业务报表导出 UI）。

### 2.3 审计日志筛选

| 字段 | 控件 | 规则 |
|---|---|---|
| 关键词 | 输入框 | Event ID、Correlation ID、业务对象 ID、任务/申请编号 |
| 操作者 | 输入/下拉 | 当前账号权限范围内的用户 |
| 来源模块 | 下拉 | P-03～P-18、M17/M18/M19/M20/M22 等 |
| 事件类型 | 下拉 | 登录/访问、敏感查看、审批、状态变更、导出、凭证操作、外部回调 |
| 结果 | 下拉 | 成功、拒绝、失败、Unknown、待核实 |
| 风险等级 | 下拉 | 一般、重要、紧急 |
| Tenant/Issuer | 受权选择 | 只显示授权范围内主体 |
| 时间范围 | 日期时间范围 | 使用事件权威时间与时区说明 |

列表字段：
- Event ID；
- 事件时间；
- 操作者/主体；
- 来源模块；
- 动作；
- 目标对象引用；
- Tenant/Issuer（按权限脱敏）；
- 结果；
- 风险等级；
- Correlation ID；
- 操作：查看详情。

### 2.4 审计事件详情

展示：
- 事件 ID、Correlation ID、原业务 Intent/对象引用；
- 请求人、审批人、执行者（分别显示，不合并）；
- 事件类型、时间、来源模块、Tenant 范围；
- 动作及结果；
- 变更前/后状态摘要（只显示允许审计字段）；
- 规则版本/权限版本；
- 证据引用：Provider 回执 ID、Tx Hash、文件版本、签署/登记引用；
- 关联任务/访问申请/安全事件；
- 数据源与最后核验时间。

禁止显示：
- 私钥、助记词、Signer Secret、API Token 明文；
- 完整身份证件、原始 KYC Payload；
- 不属于当前权限范围的其他 Tenant 业务数据；
- 可直接复用的认证 Token 或敏感下载 URL。

日志不可编辑或删除。更正通过「追加更正说明」记录原 Event ID、原因、证据、操作者和时间。

### 2.5 安全事件列表与详情

事件类别：
- 跨 Tenant/跨 Issuer 越权访问尝试；
- 敏感资料异常访问/下载；
- 平台账号或权限异常；
- 外部 Provider 凭证泄露/误用；
- Webhook 验签失败、重放或异常调用；
- 受控访问到期未撤权/缓存仍可见；
- 数据导出异常；
- 其他平台安全事件。

列表字段：
- Security Event ID；
- 事件类型；
- 严重程度：一般/重要/紧急；
- 关联 Tenant/模块/对象（按权限）；
- 检测时间；
- 当前负责人；
- 当前状态：新建、调查中、已遏制、待复核、已解决、已关闭；
- 最近更新时间；
- 操作：查看详情。

详情字段：
- 事件摘要与检测来源；
- 影响对象/范围；
- 首次发生与最近发生时间；
- 关联 Audit Event IDs；
- 关联 P-11 Access Grant/申请；
- 关联 P-13 Provider/凭证引用；
- 已采取的限制/撤权/隔离动作；
- 责任人、升级记录；
- 证据引用与调查结论；
- 解决/关闭依据。

允许操作：
- 指派负责人；
- 提升严重程度；
- 记录遏制措施；
- 创建/关联 P-07 任务；
- 撤销 P-11 临时访问授权；
- 跳转 P-13 发起适格凭证暂停/撤销；
- 追加调查结论；
- 解决/关闭事件（必须填写依据）。

P-12 不直接显示、复制或导出任何密钥；凭证暂停/轮换由 P-13 与实际 Provider 执行。

### 2.6 数据留存与交接

P-12 只显示并协调经批准的数据留存/法律保留/退租交接记录，不提供一键删除。

字段：
- Retention/Transfer Case ID；
- Tenant/Issuer；
- 数据类别；
- 保留依据/法律保留引用；
- 未结真实业务义务摘要（不展开投资者敏感细节）；
- 当前状态：待核对、保留中、待交接、交接中、待批准删除、已完成；
- 责任人；
- 复核时间；
- 关联 P-05 Tenant 退出记录；
- 关联 M17 交接任务；
- 审批与审计引用。

保护：
- Tenant 退租/Standard 到期不等于删除数据或终止真实义务。
- 未结资金、法定登记、Token、收益/本金或投资者查询义务未完成时，禁止标记最终关闭/删除。
- 删除必须有合法依据、适格批准、保留期到期及证据；P-12 仅展示审批与执行证据，不绕过存储/数据责任人。
- 数据保留期限未由法域批准时显示「待法域确认」，不自行设天数。

### 2.7 受控导出记录

只展示平台已授权的受控导出申请与结果，不提供跨 Tenant 任意导出入口。

字段：
- Export Request ID；
- 申请人、用途；
- 数据范围/字段；
- Tenant/模块；
- 敏感级别；
- 审批人及结果；
- 生成状态；
- 下载次数/最近下载时间；
- 文件到期时间；
- 撤销/过期状态；
- 关联审计事件。

操作：
- 查看申请；
- 查看审批；
- 撤销尚未下载的授权（有权时）；
- 查看下载访问记录；
- 关联安全事件。

不得默认开放完整 KYC、其他 Tenant 数据、客户密钥、资金/法定名册原始记录的导出。Issuer 投资者/报表导出能力的 V2.0 归属不因 P-12 记录导出审批而改变。

### 2.8 P-12 异常与保护

- 审计源不可用：显示数据延迟/部分缺失，不把无记录显示成无事件。
- 事件时间冲突：保留原始时间与接收时间，不静默覆盖。
- 原业务状态 Unknown：审计详情标记待核实，不由 P-12推断成功。
- 证据链接失效：显示引用失效，保留原 ID/Hash。
- 安全事件关闭但凭证仍有效/风险未解除：阻断关闭或要求补充遏制证据。
- 数据留存依据 Unknown：不得执行删除。
- 导出授权到期：下载立即阻断；历史下载记录仍保留。

|---|---|---|---|
| AUDIT-001 | 受控资料访问 | 成功 | 操作者/授权/查看记录 |
| AUDIT-002 | 越权跨 Tenant 请求 | 拒绝 | 隔离和安全事件 |
| SEC-001 | Provider 凭证疑似泄露 | 调查中 | 跳转 P-13 受控撤权 |
| SEC-002 | Access Grant 到期未清理缓存 | 已遏制 | 服务端强制撤权 |
| RET-001 | Tenant 退出与数据交接 | 待核对 | 真实义务保护 |
| EXP-001 | 受控审计记录导出 | 已批准/未下载 | 下载权限与到期审计 |

全部为虚构数据，不含真实证件、KYC 报告、密钥或 Provider 凭证。

### 4.3 桌面 Web 验收用例

1. P-11 列表不直接展示任何敏感原件或完整身份字段。
2. 无合法目的/依据/字段范围的访问申请不能提交或批准。
3. 申请人不能自批；审批人无权时不能授权。
4. 批准权限绑定具体人、Tenant、对象、字段、方式和期限。
5. 授权到期/撤销后服务端立即阻断；缓存不能继续查看。
6. 跨 Tenant 访问请求被拒绝且在 P-12 生成审计/安全事件。
7. 完整证件、私钥、助记词和 API Secret 不出现在日志详情。
8. 审计日志不可编辑/删除；更正以追加事件表示。
9. Provider 凭证泄露事件只能跳转 P-13 适格撤权，不显示密钥。
10. Tenant 退出但仍有真实义务时，数据删除/最终关闭被阻断。
11. Export 授权过期后下载被拒绝，历史下载记录保留。
12. 未执行用例标记 Not Executed，不得标记 PASS。

## 5. 版本边界与待定决策

- P-11/P-12 细化 DEC-017 原 V1.0 M20-F001～F008 与 M03-F005；不新增正式功能 ID。
- 真实访问角色码、双人审批级别、数据保留期限、法定删除依据、跨 Tenant 共享合法依据均未在本批擅自确定。
- P-13 负责外部服务凭证/连接/健康；P-12 负责安全事件与审计引用，两者不重复管理密钥。
- P-07 负责任务与异常协作；P-12 不另建任务引擎。
- P-08 负责通知投递；P-12 不把通知记录当成法定送达。
- P-14/M21 只读消费业务数据；P-12 不生成第二套资金、Token、登记或报表真值。

**本批结论：P-11 敏感资料访问控制、P-12 安全与审计形成 UI-Ready 产品规格 Draft v0.1。敏感访问默认拒绝、授权限时最小化、审计追加不可覆盖；待产品负责人审核后进入原型。**


## 6. UI-Ready 补充收口：访问授权状态机、安全事件处置与关键弹窗

本节把 P-11/P-12 的核心操作进一步落实为可供桌面 Web 原型直接实现的状态、表单和反馈。实际审批角色码、保留期限和法定依据仍由相应决策门批准，不在 UI 中自行设定。

### 6.1 P-11 访问申请状态机

| 当前状态 | 操作 | 目标状态 | 必要条件 |
|---|---|---|---|
| 草稿 | 提交申请 | 待审批 | 目的、依据、对象、字段、方式、时长完整 |
| 待审批 | 要求补充 | 待补充 | 明确列出缺少的依据/字段/目的 |
| 待补充 | 申请人补充并重新提交 | 待审批 | 补充内容形成新版本，旧版本保留 |
| 待审批 | 批准 | 授权生效中/已批准待生效 | 审批人独立于申请人；范围经最小化 |
| 待审批 | 拒绝 | 已拒绝 | 拒绝原因必填 |
| 授权生效中 | 到期 | 已过期 | 服务端撤权；记录到期事件 |
| 授权生效中 | 主动撤销 | 已撤销 | 撤销人、原因、时间完整 |
| 已拒绝/已过期/已撤销 | 查看 | 原状态只读 | 不允许直接恢复旧授权；需要重新申请 |

- 授权对象、Tenant、文件版本、字段范围、访问方式和期限在批准后不可编辑；变更必须重新申请。
- 任何审批结果 Unknown 均显示「授权结果待核实」，不开放敏感视图。
- 高敏/跨 Tenant 请求不得由申请人自批；无法确认独立审批人的情况下保持待审批。
- 访问权限以服务端 Grant 状态为准，不能以页面仍显示为已登录推断授权有效。

### 6.2 P-11 申请表单字段与校验

| 字段 | 控件 | 校验 |
|---|---|---|
| 业务目的类别 | 固定单选 | 必选，不允许自由创建类别 |
| 业务目的说明 | 多行文本 | 必填，20～1000字；说明为什么不能使用低敏摘要 |
| 合法依据 | 受控引用选择 | 必填；无法提供依据时不得提交 |
| Tenant/Issuer | 受权选择 | 必选；仅列出当前用户有业务权限的主体 |
| 目标对象类型/编号 | 来源页面带入 | 必填；不提供全局自由搜索 |
| 目标文件/版本 | 受控选择 | 必填；锁定申请时所指向的文件版本 |
| 请求字段范围 | 白名单多选 | 至少选择一项；不得使用「全部字段」默认选项 |
| 访问方式 | 单选 | 在线查看默认；受控下载须更高权限 |
| 请求时长 | 固定档位/日期时间 | 必选；只能选择平台批准的时长档位，不允许无限期 |
| 打印/下载 | 开关 | 默认关闭；需额外说明必要性 |
| 关联任务/事件 | 引用选择 | 如因工单/安全事件申请则必填 |
| 申请说明 | 多行文本 | 必填，≤1000字 |

### 6.3 P-11 审批弹窗与授权生效确认

审批详情中显示申请原始范围与建议批准范围，审批人可缩小字段或期限，不得扩大申请范围。批准前确认弹窗必须展示：
- 申请人及是否为本人；
- Tenant/目标对象/文件版本；
- 申请目的及合法依据；
- 申请字段范围与最终授权字段范围；
- 访问方式、打印/下载权限；
- 生效时间和到期时间；
- 是否跨 Tenant/高敏；
- 关联审计事件；
- 按钮：「批准并创建限时授权」。

拒绝弹窗字段：
- 拒绝原因（固定选项：无合法依据/目的不必要/范围过大/对象不明确/职责冲突/其他）；
- 补充说明（必填，≤1000字）；
- 按钮：「确认拒绝」。

撤销弹窗字段：
- Grant ID、授权人、目标对象、授权字段及到期时间（只读）；
- 撤销原因（必填）；
- 是否关联安全事件；
- 按钮：「立即撤销访问」。

### 6.4 P-11 受控资料访问页面

访问页面顶部固定显示：
- 「受控敏感资料访问」提示；
- Grant ID、访问目的、授权对象；
- 允许查看的字段范围；
- 授权到期时间/剩余时间；
- 「报告异常」入口；
- 「退出受控查看」操作。

行为：
- 未授权字段以「无权查看」占位，不返回敏感值。
- 页面失焦、刷新、打开新标签不延长授权；每次请求重新验证 Grant。
- 授权到期/撤销后，敏感内容区域清空并返回无权状态。
- 禁止复制/下载/打印时，前端不提供相应入口，服务端也必须拒绝对应请求。
- 任何访问异常可创建/关联 P-12 安全事件，不在页面内自行放宽权限。

### 6.5 P-12 安全事件状态机与操作字段

| 当前状态 | 操作 | 目标状态 | 必要条件 |
|---|---|---|---|
| 新建 | 指派/开始调查 | 调查中 | 责任人有效 |
| 调查中 | 记录遏制措施 | 已遏制 | 措施、时间、操作者和证据引用完整 |
| 调查中/已遏制 | 请求复核 | 待复核 | 调查结论和影响范围完整 |
| 待复核 | 复核通过 | 已解决 | 风险解除证据和复核人完整 |
| 待复核 | 退回调查 | 调查中 | 退回原因必填 |
| 已解决 | 关闭 | 已关闭 | 相关凭证/授权/连接风险已解除；未结行动为零 |
| 任意未关闭状态 | 提升严重程度/升级 | 原状态＋升级记录 | 原因和新责任人完整 |

- 「已遏制」不代表风险已解决；「已解决」不等于删除审计证据。
- 若关联凭证仍有效、访问 Grant 仍可用、异常仍在发生，禁止标记已解决/关闭。
- 安全事件关闭后出现新证据时，重新打开必须产生新的事件记录并保留旧关闭记录。

### 6.6 P-12 关键操作弹窗

**追加更正说明：**
- 原 Audit Event ID（只读）；
- 更正原因（必填）；
- 依据/证据引用（必填）；
- 更正说明（必填，≤2000字）；
- 确认后生成新的追加事件，不修改原事件。

**记录遏制措施：**
- 安全事件 ID；
- 措施类型（限制访问/撤销 Grant/暂停连接/请求凭证撤销/其他）；
- 目标对象引用；
- 执行结果引用；
- 失败或 Unknown 原因；
- 按钮：「记录遏制措施」。

**关闭安全事件：**
- 风险根因及处理结论；
- 受影响对象/范围；
- 已完成遏制措施及证据；
- 关联 Grant/凭证/连接状态复核；
- 后续观察/复核要求；
- 按钮：「确认关闭事件」。

### 6.7 P-12 数据留存/交接状态保护

- 「待批准删除」仅表示进入审查，不代表已允许删除。
- 只有法律依据、留存期、未结义务核验、审批和执行责任人均完整，才允许进入受控删除流程。
- 任何未结真实资金、投资者权利、法定登记、Token、收益/本金或投诉调查义务均阻断最终删除。
- 交接完成必须引用接收方确认、数据范围、交接时间及完整性核验结果。
- Unknown 或证据缺失时状态保持「待核实」，不得自动推进到「已完成」。

### 6.8 P-11/P-12 UI-Ready 验收补充

- P-11 申请、补充、批准、拒绝、授权、到期、撤销各状态均可查看历史和责任人。
- 申请人自批、无依据批准、跨 Tenant 无授权、无限期授权均被阻断。
- 授权范围不可在生效后静默扩大；新文件版本必须重新申请。
- P-12 原审计事件只读不可覆盖；更正仅能追加。
- 安全事件关闭前检查所有关联 Grant、凭证和连接风险已处置。
- 数据留存/交接没有未经批准的删除按钮或默认保留天数。
- 导出记录与原导出服务状态一致；授权到期后下载入口不可用。
- 页面均具备空状态、加载、部分数据、无权限、Unknown、版本冲突和操作失败反馈。

## 7. 保持开放的决策门

| 决策门 | 待批准内容 | 当前 UI 处理 |
|---|---|---|
| P-SEC-01 | 访问申请审批角色码、双人/多级审批要求 | 只定义职责分离，不虚构角色名 |
| P-SEC-02 | 各类敏感资料的具体可申请字段白名单 | 使用数据类别占位，生产前由法务/安全批准字段表 |
| P-SEC-03 | 在线查看/下载/打印的适用场景与额外审批级别 | 默认在线查看，下载/打印默认关闭 |
| P-SEC-04 | 审计、安全事件、导出记录留存期限 | 显示待法域确认，不虚构天数 |
| P-SEC-05 | 数据删除的法律依据、执行主体及验证机制 | UI 不直接删除，等待正式数据治理流程 |
| P-SEC-06 | 安全事件严重程度阈值、通知/升级时限 | 只显示等级，不虚构 SLA |
| P-TECH-01 | 服务端撤权、缓存清除、不可篡改日志及证据存储实现 | 仅定义产品结果，不宣称生产能力 |

以上决策门不阻断页面、字段、状态和交互的 UI-Ready 设计；生产启用前必须完成批准。
