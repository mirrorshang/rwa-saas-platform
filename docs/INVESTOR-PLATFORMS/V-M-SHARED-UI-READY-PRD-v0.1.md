## 1. 全局信息架构与组件

PC 顶部导航：左侧 V 的 Issuer Logo＋展示名 / M 平台 Logo，中间“首页｜投资机会｜我的投资”，右侧“帮助与客服｜消息｜登录/账户下拉”；页面底部为帮助、协议、隐私、风险提示。**不使用移动 APP 底栏主导航，也不在投资网站使用 Issuer SaaS 工作台式一级侧边导航**。

“我的投资”内部页签：认购订单｜我的持仓｜收益与本金；“我的账户”内部左侧菜单：账户概览｜基本资料｜身份认证｜钱包管理｜账户安全｜我的工单。全站帮助与客服按钮可在订单、持仓、收益、KYC、钱包异常位置显示“提交工单”，并带入上下文。

共用基础组件：SiteHeader、IssuerBadge、OfferingCard、OfferingSearchFilter、AssetDetailShell、IssuerProfilePage、AssetTemplateFields、InstrumentTerms、SubscriptionPanel、OTPLogin、KYCStatus、WalletList、SubscribeStepper、PaymentStatusTimeline、OrderTable、HoldingView、DistributionView、DisclosureList、SupportTicket。一个 Offering 与同一发布快照的法定字段在 V/M 不得不同口径；真正可见范围通过服务端授权渠道过滤，不靠前端隐藏。

V 显示其 Issuer 发布且依法可见的 Offering；M 仅显示 P-15 审核通过且自动上架同步**最终成功**、当前 Listing 有效的 Offering。M Listing 下架不自动删除既有持仓、订单或收益授权记录。

## 3. 统一投资机会列表与资产详情

### 3.1 OfferingCard 一致字段

每张卡：经授权封面、Offering 名称、底层资产一级/二级类型、公开地区、权益类型、每 Token 认购价 U、实际最低认购额 U、状态；M 额外展示 Issuer 法定/展示名称。收益**不是共同必填字段**：固定利率债权显示“合同固定年利率 X%（非保证兑付）”；无息债权显示“无息”；股权/收益参与权仅对已批准披露的预期年化区间显示“发行方预期 X–Y%，非承诺”，无资料显示“未提供预期年化”。可以优先呈现分配频率/法律权利，禁止统一“保证年收益”。金额缺失/状态 Unknown 不伪装为 0。

筛选：分类一级/子类、权益类型、发行状态、地区；M 附加发行企业。搜索只匹配可公开的 Asset/Offering 名称；服务端过滤可见数据。状态候选“即将开放、认购中、暂停、已结束”，其可见性取决于 Offering/渠道规则；结束不抹除历史。

### 3.2 AssetDetailShell

PC 左右双栏：左侧封面、底层资产、投资者权益、发行企业、法律文件与风险；右侧“认购信息”常驻卡含本期单价、最低份数/实付额、发行总量、剩余可认购量（仅权威可用时）、开始/截止时间与时区、锁仓及唯一状态按钮。顶部可点击企业名称进入 V/M 共用企业资料页。

底层 Asset 数据、InstrumentVersion 及 OfferingSnapshot **三个不同版本**同时引用，详情不允许 Offering 改写法律权利条款，或用 Asset 估值替代 Offering 募集额；参见以下模板。

### 3.3 V1 六种已开放资产公开模板

| 底层资产模板 | 专属公开字段 | 适用提示 |
|---|---|---|
| 住宅 | 住宅形态（单套/整栋/住宅社区）、建筑面积、住宅套数（多套时） | 房地产公共字段另含位置、使用情况、权利性质、权利人关系、估值日期/依据；租金仅有可披露证据时出现 |
| 写字楼 | 建筑面积；可出租面积、出租率为条件/选填 | 不虚构租约与入住率 |
| 商铺 | 临街/商场铺位/商业综合体、建筑面积；可出租面积选填 | 历史经营数据不代表未来可分配收益 |
| 工业园/仓储物流 | 工业园/仓库/物流设施、建筑面积；可出租面积选填 | 不要求 V1 强制显示仓储容量 |
| 非上市企业普通股权 | 被投资法律实体、普通股类别、已纳入股数/比例、估值及权利限制；行业与简介按可披露数据 | 底层股份≠投资者一定直接登记为公司股东 |
| 单笔企业借款债权 | 债务人、原合同金额、有效未偿本金和时点、原债权人/担保（若可披露）、合同日期/到期/履约状态 | 底层债务利率≠投资者权益合同利率，两个口径不可混用 |

房地产公共信息来自 Issuer 批准披露的 Asset 资料快照；底层业绩、原始合同、KYC 和财产证明只按许可/法域显示摘要、可引用文件，不把后台所有材料自动公开。尚未开放的资产分类不可产生真实 Offering。

### 3.4 InstrumentTerms 三个权益模板

| 字段 | 股权型 | 债权型 | 收益参与型 |
|---|---|---|---|
| 投资者取得的法律权利 | 股份类别、每 Token 对应股数、表决/股息等真实权利说明 | 每 Token 名义本金、债务人和法律债权主体 | 每 Token 参与比例、收益责任主体 |
| 收益口径 | 实际有权股息决议；预期区间有资料才标非保证 | 固定利息或无息；合同固定年利率及 Actual/365 Fixed、Actual/360、30E/360 或合同特殊约定 | 收益来源、扣除/计算口径、授权比例、周期及期限 |
| 时间 | 公司决议/适用约定；无固定到期日默认 | 固定利率起息、还款到期、按月/季/半年/年或到期付息；到期还本 | 收益参与始末日期、月/季/年分配 |
| 回本 | 股权不默认保本或到期返还 | 到期一次还本，可能违约/延迟 | 仅当合同明文成立才显示相应清偿义务 |
| 风险 | 非上市流动性、公司经营、估值/权益登记 | 债务人信用、担保适用性、违约与延期 | 收入波动、成本扣减、报告真实性、支付责任 |

股权/收益参与权可披露预期年化区间及测算依据，**不参与实际应付收益计算**。固定债息由合同/法定登记/实际未偿本金核算；不能从 UI 假设未来必然兑付。Token 数量不是法律权益单位，须显示已批准精准映射。

### 3.5 企业资料页共用结构

入口：V/M 资产详情的 Logo/名称/查看企业详情。模块：企业 Logo＋展示名＋法定名称、注册国家/地区、企业简介、业务方向、经授权披露的登记/KYB 范围、已发布资产；固定免责声明“企业认证不代表对投资安全或收益的担保”。发行主体与底层资产登记权利人可不同，必须按实际主体关系标识。M 企业资料页不得展示该企业仅在 V 发布但未在 M 上架的 Offering。

## 4. 注册、KYC 与钱包

### 4.1 邮箱 OTP

字段“邮箱地址（必填，格式校验）”“六位验证码（根据 Provider 契约配置）”“验证码发送/重发冷却”“同意必要协议与隐私政策（首次建号）”。安全：限流、不透露邮箱是否存在、验证码失效与防重放、会话超时/退出；验证响应 Unknown 查询原会话，不能重复创建账户。首次验证自动创建**当前 V 或 M 业务范围账户**，不自动合并跨端历史。未登录可浏览公开内容；点击认购后保留 Offering 上下文，登录成功返回。登录/注册时不强制 KYC。

### 4.2 按需 KYC

Provider 实际核验个人/机构及适用代表身份；界面状态“未开始、认证中、待补件、已通过、未通过、过期、结果待核实”；按钮分别“开始认证/继续/补件/查看状态/重新认证”。投资者可浏览、登录、查看资产和管理钱包；**正式提交订单前 KYC Passed 且仍有效**，并检查必要平台级强制限制。不得添加 Issuer V1 自定义地区白名单、投资者类别人工审批或绕过外部法定/制裁要求。Provider 回跳不视为结果 Passed。

### 4.3 MPC 自动分配与自有钱包

首次注册：对每个当前账户范围使用唯一 MPC 分配操作 ID 异步调用合规 Provider；状态“创建中、已就绪、失败、Unknown”，失败不阻止普通浏览；Unknown 查原操作；同账户幂等只分配一个初始 MPC，已存在地址不再生成。创建完成且用户未主动另选默认钱包时自动设默认；不暴露私钥/助记词。未完成 KYC 可产品层触发钱包分配，但须通过 Provider 和所在法域开户限制，否则状态“待服务准入”，不虚构成功。

自有钱包：连接→服务端一次性挑战→地址签名验证→绑定→可设默认；连接不等于签名通过。切换默认需版本控制/幂等；只影响**新操作预选**，不改历史订单付款/Token 接收地址、法定持有人和已付款记录。本次认购必须再次确认付款钱包与 Token 接收地址；Gas 是否由用户承担/是否有已批准代付以生产契约为准。

## 5. 四步认购 UI-Ready

PC 横向进度“确认认购→协议确认与必要签署→钱包付款→交易进度”，左侧步骤主体、右侧固定报价摘要；每步只有一项主动作。登录和 KYC 在入口按需完成、不再增加强制注册后向导。

**Step 1**：整数份数，正整数且 ≥ceil(本期最低金额÷单价)，≤单笔最大份数/有效剩余容量/本人当前 Offering 累计金额上限折算份数；金额使用精确十进制 U，价格精度依 Offering 快照；手续费只按已经批准的报价显示。数量、价格、可售数量、身份和报价必须在服务端再验，旧报价失效提示重新确认。

**Step 2**：固定认购协议、权益条款、风险披露及适用附加文件版本；“已阅读”仅确认阅读，法律要求的签名通过签署 Provider 获得有效证据；签署/额度 Unknown 查原请求。未必要签署完成不得创建有效待付款订单。订单唯一请求键、个人本期金额额度与 Offering 内部 Token 预留共同成立后才能显示可付，期限以权威返回值为准。

**Step 3**：默认 MPC/经验证自有钱包、付款/Token 接收地址分别确认；固定 OP Mainnet + USDT；目标必须是已核实的 Offering 收款合约，不是 Issuer 结算钱包。显示真实 USDT 与 ETH Gas 可用性、合约授权、链上交易请求。用户拒签/余额不足不表示“已支付”；合约授权成功不等于认购付款成功。TX 广播/链已观察/最终确认/订单实收匹配拆分显示，Unknown 查原 Intent，禁止重复扣款。

**Step 4**：仅在 FinalMatched→合法配售确认→法定登记有效→Token 交付最终确认均具备时显示“认购全部完成”。如果 Token 交付已确认但法定登记 Unknown，提示“Token 已交付，法定登记待核实”，不冒充法定权利完成。每个子域附原引用/时间/可见交易哈希和下一步操作。

## 6. 订单、退款和客服（第五批修订）

我的投资订单：项目、Issuer、订单编号、Token 份数、金额 U、创建日期、当前主摘要、付款与交付详情。简化状态“待确认/待付款/付款核对中/履约处理中/已完成/已取消（仅历史受控结果）/已过期/异常处理中”，后台状态可更细；不得借页面标签改金融事实。

V1 **不显示投资者主动取消订单、取消有效认购、手动申请退款/填写退款金额/改退款地址**。未付款且无在途交易的待付款订单仅按 M10/M12 权威期限和安全规则自动过期。已付款或正在核对的订单不得被过期事件掩盖。订单历史中的“已取消”仅兼容有权业务决定/旧事实，不是用户操作入口。

支付交易整体回滚：USDT 转账不生效，不产生需要链上另退的已收款，Gas 不承诺退回；资金已经进入合约而后续失败：**只有生产合约/授权/法域明确支持且核验合法受益人、余额及幂等条件时自动退款**，否则进入受控人工处理。所有自动退款/人工退款都需独立保留真实指令、交易、授权及到账核验，不得把请求/审批/广播当 Paid。错链、多付、迟到账、交易 Unknown/重组、配售/Token 交付失败进异常队列，不能自动“成功”或自行发起第二笔退款。

全站“帮助与客服”入口；投资者提交工单字段：问题类型（订单付款/钱包/KYC/收益持仓/披露/其他）、关联订单/资产（存在时只读带入）、问题描述（必填）、可选截图/交易哈希、默认登录邮箱联系方式，明确禁止上传私钥/助记词/验证码。工单状态“待处理/处理中/待用户回复/已解决”，操作“提交/查看详情/回复补件/查看原业务状态”。工单关闭≠退款、登记、Mint 或支付完成；Issue 由 M17 共享任务服务管理并按责任方路由，消息通知 M18。

## 7. 我的持仓（V-13/M-14）

详情：法定权益登记（权利人脱敏、单位、数量、生效日期、证据引用）、Token 信息（网络、合约、数量、接收地址、交易）、来源订单、锁仓/链上限制/法定限制三条独立状态、文件版本及历史；本人可以联系支持但不能直接改写登记、余额、法定持有人、Mint/Burn。M 只聚合当前 M 账户依法有权访问的跨 Issuer 持仓，不把 V 账户历史自动拉入。

## 8. 收益、本金和领取（V-14/M-15）

列表/详情：Asset/Offering、权益类型、事件类型（股息/债权利息/债权本金/收益参与）、收益期间、Record Date、合同应付日/计划日/实际到账日、毛额、扣项、净应付、已注资、可领取、已实付、未支付、支付方式、状态及交易凭证。金额 U，缺权威值显示“待核实”；预计收益≠应付，批准≠注资，可领取≠已到账。

股权：必须有适格公司决议与有效法律权益快照才显示已确认股息。债权：按有效 InstrumentVersion 的固定利率或无息、实际未偿本金/计息天数及真实还本事件；本金偿还**单独区块**（应偿、已偿、未偿、到期/逾期/部分偿还），永不计入累计投资收益。收益参与：按已核验实际可分配金额/合法持有人份额，不从历史净租金或“发行方预期年化区间”直接计算“已应付”；无收益声明不产生虚假付款批次。

付款路径按每批已核准 Claim/Push/外部安排区分：Claim 确实可领取时出现领取按钮及钱包授权、处理原 Claim Unknown；Push 只显示执行/收款状态；外部付款只显示真实凭证及核验。不能为统一交互强迫所有收益领取，也不能因默认钱包切换重写已确认收款对象。
