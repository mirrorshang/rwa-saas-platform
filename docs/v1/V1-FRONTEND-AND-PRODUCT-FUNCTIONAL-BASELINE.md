# RWA SaaS V1｜前端与产品功能基线

> 2026-11-16。范围：本次交付的 W 官网与 I Issuer SaaS 双前端及其承接的 V1 规则。本文不是服务端 Developer PRD、生产准入证明或历史决策修订。

## 1. 产品与交付边界

RWA SaaS V1 面向发行企业和资产管理机构，覆盖企业入驻、资产建档、权益结构、发行方案、投资者认购、资金、登记、Token 和投后收益的业务链。本次仓库交付为两个可独立构建的应用：apps/website 承载官网与邮箱登录入口；apps/issuer 承载登录后的企业后台及九大模块。既有 V Issuer 投资者前台、M 平台统一投资端、P 平台运营后台及外部服务仍属于产品总体范围，但不在本次双前端源码交付中。

当前登录、KYB、文件、付款、登记、Token 和分配均为前端 Mock 或说明性页面。Mock 操作不产生真实认证、资金、法定权利或链上结果。以[现行 R2 产品基线](https://github.com/mirrorshang/rwa-saas-platform/blob/docs/r2-current-product-baseline/docs/03-product-prd/r2-current-baseline/RWA-SaaS-V1-PRODUCT-BASELINE-AND-FUNCTION-SCOPE-2026-11-09.md)和[2026-11-13 精简导航规格](https://github.com/mirrorshang/rwa-saas-platform/blob/docs/r2-current-product-baseline/docs/03-product-prd/r2-current-baseline/ISSUER-V1-LEAN-NAVIGATION-AND-PAGE-UI-READY-2026-11-13.md)描述目标产品；两者所在 PR #8 仍为 Draft、未合并。当前实现以[官网登录源码](../../apps/website/src/pages/Login.tsx)、[官网路由](../../apps/website/src/main.tsx)、[Issuer 应用](../../apps/issuer/src/App.tsx)及[数据模型](../../apps/issuer/src/data.ts)为证据。产品规则、源码现状和浏览器验收不互相替代。

## 2. 主要用户流程

官网浏览 → 邮箱输入与验证码验证 → 安全登录会话 → Issuer 首页 → 账号及企业状态判断 → 创建企业、五步 KYB → Free／Standard → Asset → Instrument → Offering → 投资者认购 → 付款核对 → 配售及法定持有人登记 → Token 交付 → 收益、本息与存续管理。

目标 V1 是首次邮箱验证成功时自动创建账号，一个账号对应一个企业。当前官网仅在本地演示模式生成固定 Mock 验证码 123456，验证后按 VITE_ISSUER_ORIGIN 跳转 Issuer 根页；Issuer 尚未接收安全身份会话，使用本地状态。正式构建的认证服务未开放。不得用 URL 明文邮箱、验证码或简单登录标记实现正式衔接。见[跳转配置](../../apps/website/src/issuerTarget.ts)和[Issuer 状态](../../apps/issuer/src/App.tsx)。

## 5. 核心业务规则

1. **账号与 KYB**：邮箱验证码登录，首次验证自动建账号；V1 一账号一企业，不提供企业切换。KYB 五步为基本信息、业务信息、关联人员、证明材料、预览确认。未通过时业务受控。当前只有前端 Mock，没有权威身份或企业隔离服务。
2. **Free／Standard**：Free 可准备 Asset、Instrument、Offering 资料并内部只读预览，不执行真实认购、资金、登记、部署、Mint 或收益运营。Standard 仍须满足法律、钱包、Provider／Signer、支付、合约等独立生产准入；原型 Standard 只解锁内部 Mock 演示。续费、宽限、降级及历史存续义务须由服务端落实。
3. **资产与权益**：目录为八大类、二十四二级分类；现行 R2 基线首批正式开放住宅、写字楼、商铺、工业园／仓储物流四种房地产模板。Asset → 唯一当前有效 Instrument → 多轮 Offering。Offering 固定引用 Instrument 版本，草稿不占正式容量；Token 权益不可精确拆分时拒绝，不静默取整；不能超发或静默覆盖已引用版本。Asset／Instrument Ready 不表示产权真实或已获发行许可。
4. **订单及权利事实**：投资者认购、Payment、Allocation、法定 Register／Holder 和 Token 交付分别保留 ID、状态、版本与证据。最终到账不自动等于登记或交付；Token 余额不能替代法定持有人名册。认购历史不重复建立订单主账。
5. **金额和网络**：V1 业务金额以 U 显示，按 USDT 计价；投资者认购付款仅支持 OP Mainnet · USDT。SaaS 订阅可按批准渠道使用 USDT 或法币，与投资者资金分账；Token 部署网络另行准入。“1 U = 8 元”只属于住宅 QA 用例，不是生产固定汇率。
6. **收益与债权**：预期收益披露、合同利率和实际收益分开。债权合同约定利息及到期本金分别形成事件和分配；本金返还不计累计收益。零有效持有人可保存草稿，不得确认或待付款；同期间不得重复确认、支付。合同到期或本金全部清偿后不得自动生成正常合同利息。
7. **隐私和证据**：投资者在 V／M 端完成统一 KYC，第三方核验，平台维护权威状态；Issuer 仅查看本企业授权范围内的脱敏资料和状态。上传、扫描、Ready、法律审核、生产准入分别记录。Mock 资金、登记、Token、收益事件不得直接迁入生产主账。
