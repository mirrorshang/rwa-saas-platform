# DEC-075｜V1 企业 SaaS 认购订单模块 UI-Ready 收口

> **日期：2026-11-11**  
> **状态：产品负责人授权范围内的 V1 页面设计收口；非真实金融/法律生产准入批准**  
> **适用入口：投资者与认购 → 认购订单**  
> **依据：用户授权产品负责人按小模块自行完成 MVP 闭环，优先精简易用、遵循已批准范围，并逐模块写入 GitHub。**

## 1. 背景

DEC-069 已把企业端投资者管理精简为平台统一 KYC 结果的脱敏只读视图；DEC-073 将「资产与发行 → 认购记录」限定为仅查询已完成认购的只读历史。本轮承接 DEC-052、DEC-032、U02-06 R19～R24 和上述决定，补齐「认购订单」从报价/签署、订单、预留、付款到配售/法定登记/Token 交付、取消与异常的**企业端完整订单进度工作台**，不重复创建业务主账。

## 2. 页面架构决定

- 仅在现有「投资者与认购 → 认购订单」下保留一个订单列表、一个订单详情、基础取消弹窗和异常详情侧栏，不新增二级菜单。
- 列表包含订单号、当前企业脱敏投资者、Asset/Offering、本期认购份数、报价金额 U、订单主进度、独立付款状态、独立 Token 交付状态及最近进展。
- 支持订单号/脱敏引用搜索、资产/发行联动、状态/付款/时间筛选、异常快捷筛选和分页；跨 Tenant 禁止检索。
- 详情使用一条阶段进度导航与六个信息分组：订单关系；报价及签署；本期内部额度预留；真实付款和企业结算；配售/法定登记/Token 交付；取消、退款、异常与操作历史。
- 各分组显示权威业务事实、更新时间、引用和责任模块入口；默认展开异常或下一步需要处理的分组。
- 不提供企业代投资者下单、改价、改数量、签署、支付、KYC 审核、强制 Mint、直接退款或修改法定名册的按钮。

## 3. 主进度与独立状态

| 主进度 | 最小展示定义 |
|---|---|
| 待确认 | 报价/签署/预留等前置条件尚未核实齐备 |
| 待付款 | 付款条件已经满足但未确认实际付款 |
| 付款核对中 | 支付已发起或结果不确定；不能按实收成功处理 |
| 履约处理中 | 实收已确认，配售、登记或 Token 交付尚未全部核实 |
| 已完成 | 真实实收已确认且 Token 交付已确认；法定登记状态继续独立显示 |
| 已取消 | 订单权威取消结果已确认；真实资金/容量/权益的后续状态仍独立追踪 |
| 已过期 | 已安全进入到期状态；不能因为计时到期就覆盖付款 Unknown 或释放额度 |
| 异常处理中 | 存在阻断正常履约的未结清异常 |

- 订单、真实付款、预留/配售、法定登记、Token 交付、退款与企业结算是彼此独立的业务事实。
- 只有资金权威确认的最终匹配，才可展示「实收已确认」；授权、交易广播、交易 Hash、截图不是已付款。
- 只有实收与 Token 交付均确认，认购订单才显示「已完成」；认购记录页同步引用同一订单，不建第二套主账。
- Token 余额不等于法定持有人登记；订单已完成也不等于企业最终收款钱包已结算到账。
- 订单级待付款容量属于该 Offering 已发布预留量的内部划分，不对同一 Instrument 再次扣减；M12 是容量唯一权威。

## 4. 取消/到期的安全交互

- 仅对**尚未产生真实支付待核或确认、合法配售/登记、Token 交付的可撤销订单**展示「申请取消」；需满足合同、当前订单、容量和权限条件。
- 取消弹窗包含订单摘要、原因、确认风险文案、勾选确认及二次状态核对。
- 取消申请已受理不等于订单已取消；订单取消不等于退款已执行或额度已释放。
- 对付款 Pending/Unknown、已观察资金、取消后迟到账、预留冻结、已产生合法权益等情形，停止直接取消并引导受权核对。
- 到期只能按实际权威条件处理；预留到期不代表无真实付款，不能盲放量。
- 退款批准与真实已退款分开显示；本模块只引导进入资金/退款责任入口，不执行真实退款。
- 重复操作不能生成重复订单、重复扣款、重复预留、重复退款或重复 Mint。

## 5. 与现有业务和导航关系

| 模块 | 作用 |
|---|---|
| 投资者管理 | 只读脱敏投资者与平台 KYC 状态 |
| Offering | 固定发布时发行条款、价格、文件和最终收款钱包快照 |
| 认购记录 | 只读展示「真实付款+Token 交付均已确认」的历史认购 |
| 资金与结算 | 真实付款、错链/少多付/迟到账、退款和企业结算的唯一权威 |
| 配售与持有人 | 内部额度、基础配售、法定登记和权益差异的唯一权威 |
| Token 管理 | 获授权 Token 链执行、真实交付与最终性 |
| 文书与签署 | 合同、披露及签署证据版本 |
| 平台统一 KYC | 投资者身份核验、结果与平台级强制限制 |

不改变九个一级导航，不增加「投资者资格」企业端入口，不恢复企业人工 KYC 审核。投资者本人在投资者端认购；企业只查看权威订单及在权限内申请安全取消或进入责任模块查看处理。
