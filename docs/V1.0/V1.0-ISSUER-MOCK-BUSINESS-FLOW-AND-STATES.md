# Issuer SaaS V1.0 正式应用 Mock 业务流程与状态（2026-11-19）

适用代码：`apps/issuer`，开发分支 `codex/issuer-v1-module01`。本文件记录可演示的前端状态；生产服务权威状态仍以 [Backend Developer PRD](V1.0-BACKEND-DEVELOPER-PRD.md) 为目标，不以浏览器本地记录替代。

## 对象与状态边界

| 对象 | 当前状态／动作 | 不得混同的事实 |
| --- | --- | --- |
| Asset | 草稿 → Ready；资料、模板必填项及文件扫描后重新检查 | Ready 不代表已经发行 |
| Instrument | 草稿 → Ready；固定权益量、Token 容量和版本 | 权益 Ready 不代表 Offering 已确认 |
| Project | Asset 与 Instrument 关联时自动创建，保存关联与进度 | 不要求企业单独创建 Project |
| Offering | 草稿 → 方案已确认；确认时锁定 Asset/Instrument 版本、条款、钱包、文件与容量；重复确认幂等 | 不设置无独立意义的 Pending Issuance |
| 发行准备 | 七组检查逐项通过，保存数据指纹；资料变化需重检 | 检查通过不代表执行成功 |
| 发行任务 | 未发起 → 已提交 → 执行中 → 已核验；失败和 Unknown 保留原任务，查询／受控重试 | 一个 Offering 只允许一个有效任务 |
| Contract | 未申请 → 部署处理中 → 模拟已部署 | 模拟部署不是真实链上部署 |
| Offering 发布 | 未发布 → Sandbox 已发布；同一个 Offering 唯一 Publication Snapshot | 发布不自动等于 Token Mint |
| Token 发行／交付 | 发行 Token 状态独立；投资者交付另有逐订单记录；到期处置另有逐持有人记录 | 模拟 Token 记录不是链上余额 |
| 认购销售 | 未开放 → Sandbox 认购中 → 已结束，按 UTC+8 的开始／结束时间及测试日期判断 | 已发布不代表认购已经开放 |
| 订单、付款、配售、登记 | 分别保存；最终匹配付款后才可配售，配售后才可模拟登记，随后模拟 Token 交付 | 付款成功不是合法持有人登记 |
| 持有人快照 | 按 Offering＋Record Date 固定有效登记权益 | 后续登记变化不得回写旧快照 |
| 租金上报 | 资料待扫描 → 待确认 → 已确认；确认后创建该周期唯一分配批次 | 上报金额不是实际收款证明 |
| 债权计划／事件 | Actual/365 Fixed；按起息到到期日生成各期应付事件，到期不再产生正常利息 | 4,000 U 只是简化月息参考，31 天首期为 4,076.712329 U |
| 分配批次 | 候选／计算完成 → 已确认 → 部分支付／支付完成；逐笔支付可失败、Unknown | 计算、确认、模拟支付和实际到账分开 |
| 债权完成 | 全期利息、本金、名册更新、Token 处置和未结义务检查通过 → Sandbox 清偿完成 | 本金收据不计入累计收益 |

## 主流程与守卫

1. 企业创建、KYB、Mock Standard、钱包验证；Asset Ready、Instrument Ready；Offering 草稿保存、确认并自动关联 Project。
2. 在「发行管理 → Offering 详情 → 进入发行准备」查看七组检查：KYB/Standard、Asset、Instrument、Offering、钱包、披露与签署、Sandbox 环境。失败原因给出返回修改入口。由当前企业账号确认责任声明，提交唯一任务；独立演示控制台执行和记录结果。成功生成唯一快照并按认购窗口开放。
3. 独立演示控制台创建模拟投资者、Mock KYC、订单、模拟支付、配售、模拟登记、Token 交付，按 Record Date 固定快照。正常业务页展示订单、付款、持有人和 Token 记录。
4. 住宅：证明引用 → 租金上报 → 确认 → 快照 → 候选批次与明细 → 确认 → 逐笔 Mock 支付 → 收益记录。同一 Offering、事件类型、周期、Record Date、Instrument 版本不得重复建有效批次；金额保留六位小数并处理尾差。
5. 债权：生成月度利息计划 → 每期到日且有快照 → 独立月息批次和支付 → 到期本金批次和支付 → 更新模拟名册 → Token 处置 → 清偿完成。每期以实际日数／365计算；本金不进入收益记录。

债权清偿前必须固定所有 24 期及到期本金所需快照；清偿后当前名册权益归零，页面拒绝事后补建历史 Record Date 快照并提示查询已固定记录。历史日期回溯重建不是当前 Mock 能力，生产需权威登记变更历史与生效时间。

## 本地数据恢复与生产边界

状态持久化使用浏览器本地 v4 存储，旧版本迁移幂等。解析、校验、引用冲突或写入异常时保留原始字节并停止写入；「本地数据需要核对」页可导出原始记录，修复后导入有效 JSON。请先备份再重置测试浏览器；不要直接改写存储伪造成功。

生产需服务端事务、租户权限、幂等键、付款最终性、法定登记、Provider 回调、真实合约与审计。V/M/Platform 联调不在本次 Issuer 内部 Mock 闭环验收范围，现有门户为配置和预览。
