# DEC-059｜预期年化收益区间与债权周期付息纳入 V1

> 日期：2026-11-09  
> 状态：**V1 功能范围 Approved；字段、交互及具体业务规则为 Candidate，待模块产品设计确认**  
> 批准依据：用户明确确认「预期年化、周期付息，建议都纳入 V1」  
> 维护分支：docs/r2-current-product-baseline｜PR #8 Draft / Open / Unmerged

## 1. 已批准的范围决定

用户已明确批准以下两项能力进入 V1：

1. **预期年化收益信息披露**：发行方可在权益结构中维护预期年化相关信息，并在适用的投资者展示页面呈现。
2. **债权周期付息**：债权型权益结构支持周期付息能力，并与发行后的本息管理流程衔接。

两项均复用既有 M04「资产与 Instrument」及 M13「收益 / 本息 / 存续」责任，不新增正式功能 ID；V1 正式功能数量仍为 157 项。

**批准边界：** 本次用户确认的是「纳入 V1」这一产品范围决定，并未逐项确认下文列出的具体适用权益类型、字段、频率选项、计息方法、日期递推、计算公式、异常规则或页面交互。以下内容均为产品设计建议，不能标记为用户已逐项批准。

## 2. 预期年化收益信息披露｜产品设计建议（Candidate）

### 2.1 建议适用范围

建议股权型、收益参与型 Instrument 可选填写发行方预期年化收益区间；债权型优先展示合同约定的固定年利率，避免将合同票息与预测收益重复表达。最终适用类型待 Instrument 详细设计确认。

### 2.2 建议字段

- 预期年化最低值（%）。
- 预期年化最高值（%）。
- 预期测算依据与假设说明。

建议最低值与最高值同时填写或同时留空；填写区间时要求说明测算依据。是否作为 Ready 条件、具体数值范围及展示格式待确认。

### 2.3 建议展示原则

- 投资者端使用「发行方预期年化收益区间」等明确表述。
- 应区分预测信息、合同约定利率和实际已发生收益。
- 不得将预测信息表达为保本、保证收益或平台承诺。
- 不建议将预期年化区间作为实际应付金额、收益分配、Token 数量或认购价格的计算输入。

以上为产品设计建议；具体文案、适用权益类型、披露位置和 Ready 规则待详细设计确认。

## 3. 债权周期付息｜产品设计建议（Candidate）

### 3.1 建议适用范围

建议优先支持债权型 Instrument 的固定利率周期付息，并与 M13 的本息事件、收益分配及实际支付记录衔接。无息债权是否允许配置其他本金偿还安排，仍按后续债权产品设计确认。

### 3.2 建议频率

初步建议考虑：

- 到期一次付息；
- 每月付息；
- 每季度付息；
- 每半年付息；
- 每年付息。

以上频率属于候选设计，不是本次用户已经逐项确认的固定选项。

### 3.3 建议字段与页面行为

可评估在 Instrument 中配置付息频率、首个付息日、后续日期规则及计息依据，并在 Offering 中只读引用已确定的 Instrument 版本；M13 负责展示对应期次、收益/利息事件及后续处理。

具体日期递推、月末日期、非工作日调整、计息日数规则、部分周期、利息计算公式、人工复核条件及历史版本修改保护，均须在债权与 M13 页面设计时逐项确认。

### 3.4 建议的复杂度边界

遵循 V1「常见、基础、能够跑通」原则，建议先不扩展复杂浮动/阶梯利率、复杂复利、任意不规则现金流、复杂本金摊还和自动逾期罚息模型。此为产品简化建议，最终范围随债权页面设计一并确认。

## 4. 与 M13 的页面衔接建议（Candidate）

建议 M13 能够识别并引用生效 Instrument 中的债权付息安排，展示合同应付期次、收益/利息计算或复核结果，并衔接后续分配批次、注资及实际到账记录。

合同应付日、发行方计划分配日、资金注入日、投资者实际到账日应分别表达，避免混成单一「已付息」状态。具体页面、字段、状态和操作尚待 M13 模块产品设计。

## 5. Free / Standard 既有规则继续适用（Approved）

- Free 与 Standard 均可创建、编辑、保存正式 Asset、Instrument 和 Offering 业务资料；两者均须先通过企业 KYB。
- Free 可在内部只读预览中查看相关投资者展示效果，但不获得真实发行、认购、收益分配或真实本息运营能力。
- Standard 只有在适用业务、法律及独立生产准入满足后，才能开展真实发行和发行后本息运营。
- 本次决定不改变 U01 E09 已批准的套餐矩阵。

## 6. 功能归属与版本追踪

- M04：承载预期年化信息及债权付息条款的 Instrument 产品设计。
- M13：承载债权付息事件、收益/本息计算与复核、分配和实付展示的产品设计。
- 不新增正式功能 ID；V1 仍为 157 项，完整版本追踪仍为 204 项。
- 具体页面、字段、状态、操作、校验及异常在对应模块详细产品设计中确认后，再更新专项 PRD。
