本文件是当前 V1 Offering 模块页面信息架构、字段、交互、状态、异常和页面衔接的**唯一当前 UI-Ready 执行规格**。历史批次批准文件继续作为业务原则来源；历史候选细化稿不再单独作为最终 UI 执行依据。

承接且不得推翻的已批准规则：

- U02-02：资产详情四 TAB（资产概览、资产资料、权益结构、发行管理）；Offering 从资产详情发行管理创建；发行准备属于 Offering，不新增二级菜单、Project 菜单或独立发行准备页面。
- U02-06 R01～R36：Offering 单页 A/B/C 分区、Asset/Instrument 确定版本继承、本期发行数量和价格、最低认购额、时间、企业最终收款钱包、资料与生产准入分离、投资者端预览、发布快照、生命周期、暂停/恢复/结束/关闭及在途义务保护。
- DEV-05-01：当前 Asset 的 Instrument 必须 Ready，才允许创建 Offering Draft；创建时再次检查并固定 InstrumentVersion。
- DEC-059 / DEC-071 / U02-08：预期年化披露、债权固定利率与周期付息属于 Instrument；Offering 只继承展示，不重复录入、不覆盖、不参与 Offering 价格计算。
- DEC-069：Issuer 不配置投资者类型、地区、KYC 等级或额外资格；投资者必须通过平台统一 KYC。Issuer 仅可查看本企业范围内的脱敏状态，不在 Offering 中查看个人 KYC 资料。
- DEC-070 / U02-07：资产相关方由 Asset 维护；Offering 可逐期选择需要向投资者披露的主体，公开字段严格脱敏。
- U01 / DEC-068：Free 与 Standard 均可完成业务资料准备；Free 仅内部只读预览，不公开发布、不真实募资/Mint；Standard 真实发行仍受独立生产准入约束。Offering 每期选择一个本企业已绑定且有效的钱包作为最终结算收款账户。

本文件新增的 MVP 产品细节均属于用户已授予的产品负责人独立设计权限；不扩大到法律责任判断、资金托管、链上执行或生产准入。

## 1. 模块目标与页面地图

### 1.1 模块目标

让发行企业围绕一项 Asset，完成某一期 Offering 的创建、资料配置、检查、投资者端预览、发布确认和发行生命周期管理。用户始终能回答三个问题：

1. 当前这期发行处于什么状态？
2. 还缺少什么？
3. 下一步应该做什么？

Offering 只负责**本期发行安排**，不重复管理底层资产、权益定义、认购订单、资金账本或 Token 主账。

### 1.2 唯一入口与页面组成

```text
资产与发行 → 资产管理 → 选择 Asset → 资产详情 → 发行管理 TAB

发行管理 TAB
  └─ 发行方案列表
       ├─ 新建发行方案 → Offering 创建/编辑单页
       └─ 选择已有发行方案 → Offering 详情

Offering 创建/编辑单页
  ├─ A. 发行信息
  ├─ B. 认购规则
  └─ C. 发行准备
       ├─ 业务资料完整性检查
       ├─ 真实生产准入状态
       └─ 投资者披露与文件

Offering 详情
  ├─ 发行条款与发布快照
  ├─ 当前状态、待处理事项、下一步操作
  ├─ 真实认购/支付/交付摘要（仅有权威事实时显示）
  ├─ 预览投资者端
  ├─ 认购记录 / 锁仓记录的关联入口
  └─ 生命周期操作与操作记录
```

- A/B/C 是同一页面的内容分区，不是三步向导。
- 「发行准备」不新增独立页面或导航；检查、文件、披露和生产准入均在 Offering 编辑页 C 区完成。
- Project 仅由系统维护内部关联，不向企业用户展示独立入口或要求手动创建。
- 预览可作为全屏只读视图打开；不产生真实公开链接或订单。
- 统一投资端上架不属于本模块自动发布动作。企业如需申请统一投资端分发，仍走独立申请与平台审核；本页不增加自动上架或自动通过逻辑。

## 2. 页面一：发行方案列表（资产详情「发行管理」TAB）

### 2.1 页面目标与入口

- **使用者：** 已通过企业准入、且有权查看当前企业资产的企业账号。
- **入口：** 资产管理 → 资产详情 → 发行管理。
- **目标：** 查看当前 Asset 的所有发行期次，识别每期状态，并进入继续编辑或查看详情。
- 不允许从此处切换 Asset；Asset 上下文由详情页固定。

### 2.2 页面布局

**顶部资产上下文**
- 面包屑：资产管理 / [资产名称]。
- 标题：发行方案。
- 辅助说明：管理该资产的各期发行安排。
- 只读摘要：资产名称、当前权益结构类型、当前有效权益结构版本、当前可用 Token 份数（仅有可信容量事实时显示）。
- 主按钮：新建发行方案。

**列表工具栏**
- 搜索框：按发行名称搜索。
- 状态筛选：全部、草稿、等待开始、认购中、已暂停、认购结束、已关闭。
- 默认排序：创建时间倒序，最新创建的期次在前。
- 不提供复杂高级筛选、批量操作或多字段组合筛选。

**列表字段**

| 字段 | 展示规则 |
|---|---|
| 发行方案 | 发行名称；可在副行显示「第 N 期」及固定权益结构版本 |
| 状态 | 草稿、等待开始、认购中、已暂停、认购结束、已关闭 |
| 认购时间 | 开始时间—结束时间，并显示该 Offering 的时区 |
| 本期发行数量 | 正整数 Token 份数 |
| 每 Token 价格 | 固定价格，单位 U |
| 计划最高募集额 | 本期发行数量 × 每 Token 价格，单位 U；明确是计划上限，不是实际募集/到账 |
| 最近更新 | 最近一次成功保存或状态变化时间 |
| 操作 | 草稿显示「继续完善」；其他状态显示「查看详情」 |

- 列表不展示未经确认的「已募金额」「已 Mint 数量」「投资者人数」等经营指标。
- 如果后续有可信主账数据，真实进度只在 Offering 详情呈现，不用计划值冒充实际值。
- 点击发行名称或整行进入该 Offering 详情；操作列保留明确主动作。
- 不在列表行提供暂停、恢复、结束、关闭等高风险操作。

### 2.3 新建按钮与前置状态

| 当前 Asset / Instrument 状态 | 页面表现 | 用户下一步 |
|---|---|---|
| Asset 不存在、未 Ready 或无权访问 | 不进入发行管理详情；按企业准入规则拦截 | 返回资产列表或完成企业准入 |
| 没有 Instrument | 不显示可执行的新建按钮；显示说明 | 前往权益结构 TAB 创建权益结构 |
| Instrument 为 Draft | 不允许新建 Offering | 继续完善权益结构 |
| Instrument 检查失败、核心文件待扫描/失败、Ready 已失效 | 不允许新建 Offering；明确显示阻断原因 | 返回权益结构修复 |
| Instrument 当前有效版本 Ready | 显示「新建发行方案」 | 创建 Offering Draft |
| 当前可用 Token 份数为 0 | 仍显示权益结构容量为 0 的真实事实；新建后无法通过发行数量检查 | 提示先处理权益容量，不制造可发行额度 |

- 点击「新建发行方案」后再次校验当前 Tenant、Asset、Instrument 确定版本和 Ready 状态。
- 新建成功自动绑定当前 Asset、当前 Ready InstrumentVersion 和必要的内部 Project 关系；不让用户手动选择或创建 Project。
- Draft 不预留 Token，不产生认购、支付或 Token 事实。
- 允许同一 Asset 预先存在多个 Draft；同一 Instrument 同时最多一轮对外开放认购，发布时再次检查冲突。

### 2.4 空状态

**状态 A：无 Instrument**
- 标题：先完成权益结构。
- 说明：完成权益定义和 Token 拆分后，才能创建发行方案。
- 主操作：前往权益结构。

**状态 B：Instrument 未 Ready**
- 标题：权益结构尚未准备完成。
- 说明：当前权益结构仍有待补资料或文件问题。
- 主操作：继续完善权益结构。

**状态 C：Instrument Ready，暂无 Offering**
- 标题：还没有发行方案。
- 说明：可以开始配置该资产的第一期发行。
- 主操作：新建发行方案。

**状态 D：已有 Offering**
- 显示列表；最新期次在前。
- 不把历史已关闭 Offering 作为当前待办。
- Asset 概览 TAB 的唯一下一步动作仍按真实状态决定，不与列表页竞争。

**状态 E：搜索/筛选无结果**
- 标题：没有符合条件的发行方案。
- 操作：清除搜索和筛选。
- 不误显示成该资产从未创建过 Offering。

### 2.5 搜索、分页与响应式

- 搜索只匹配发行名称，不搜索文件内容、地址或投资者信息。
- 状态筛选可单选；默认「全部」。
- 默认按创建时间倒序；不增加用户自定义多列排序。
- 每页最多 10 条；超过 10 条显示简单分页；不足 10 条不显示分页器。
- 桌面端使用表格；窄屏/手机端改为纵向卡片，保留名称、状态、时间、数量、价格、计划最高募集额和唯一操作。
- 长名称换行/省略并可查看完整名称；金额统一 U；时间显示明确时区。

## 3. 页面二：Offering 创建/编辑单页

### 3.1 页面目标与总体布局

- **使用者：** 当前企业中已具备业务准备权限的账号。
- **入口：** 发行方案列表 → 新建发行方案 / 草稿 → 继续完善。
- **页面形式：** 同一业务对象的创建与编辑共用单页，不拆成向导。
- **顶部固定区：**
  - 面包屑：资产管理 / [资产名称] / 发行管理 / [发行名称]。
  - 标题：新建发行方案或编辑发行方案。
  - 状态：草稿。
  - 保存状态：未保存更改 / 正在保存 / 已保存及时间 / 保存失败。
  - 完成提示：待完善事项数量。
  - 唯一下一步：优先显示「继续完善资料」或「检查发行准备」；预览作为常驻次级动作。
- **主体：** A 发行信息、B 认购规则、C 发行准备三个纵向分区；顶部可用区内锚点快速定位，不显示步骤编号或进度向导。
- **底部固定操作栏：** 保存草稿、检查准备情况、预览投资者端；仅当 Standard 与所有真实生产门均通过时才可出现可执行的「发布发行」。Free 显示升级说明，不伪装成可发布。
- 表单支持分区折叠，但默认展开有缺项或需要用户操作的分区；错误字段自动展开并滚动定位。

### 3.2 只读继承信息

| 信息 | 来源 | UI 规则 |
|---|---|---|
| 资产名称、编号、分类、地区 | 当前 Asset | 只读，不允许在 Offering 中切换资产 |
| 资产资料状态及版本 | 当前 Asset | 只读；显示 Ready 与引用版本 |
| 权益类型 | 当前 InstrumentVersion | 只读：股权、债权或收益参与权 |
| 权益结构名称及版本 | 当前 InstrumentVersion | 只读，显示确定版本号 |
| 每 Token 对应权益 | InstrumentVersion | 只读展示；不在 Offering 重复填写 |
| Instrument 总 Token 份数 | InstrumentVersion | 只读 |
| 当前已发行、有效预留、可用份数 | 权益容量权威记录 | 只读；仅在真实数据可用时显示，Draft 不预留 |
| Project | 系统内部关联 | 不显示，不要求用户填写 |

顶部摘要应优先展示「权益结构版本 / 每 Token 对应权利 / 当前可用份数」，避免用户误把 Offering 本期发行数量当成权益总量。

### 3.3 A 区：发行信息

| 字段 | 控件 / 默认值 | 必填与校验 | 说明与反馈 |
|---|---|---|---|
| 发行名称 | 单行文本；默认「资产名称 + 第 N 期」，允许修改 | 保存草稿和业务检查时必填；1～120 字符 | 期次按该 Asset 已有 Offering 顺序建议，不重排历史期次；不强制用户采用默认名称 |
| 投资者展示简介 | 多行文本 | 业务检查时必填；最多 2,000 字符 | 仅描述本期发行要点；不得重复资产权属或权益条款，不得把预期收益写成保证承诺 |
| 本期发行 Token 数量 | 正整数输入 | 必填；大于 0；不得超过创建/检查/发布时的最新可用份数 | 错误定位在输入框下方；不允许小数、负数或科学计数法 |
| 每 Token 认购价格 | 金额输入，单位 U | 必填；大于 0；最多 6 位小数 | 采用精确十进制输入和展示，不静默舍入；生产支付资产精度仍需独立准入验证 |
| 单笔最低认购金额 | 金额输入，单位 U | 必填；大于 0；最多 6 位小数 | 表示单笔订单最低应付金额，不是最低募集目标 |
| 单笔最高认购 Token 份数 | 正整数输入；选填 | 选填；不得低于最低可购买份数，且不得超过本期发行数量 | 普通单笔交易数量上限；留空表示不单独设置单笔上限，仍受本期剩余可售份数及投资者本期累计金额上限约束 |
| 单个投资者本期累计最高认购金额 | 金额输入，单位 U；选填 | 选填；大于 0、最多 6 位小数；如填写不得低于单笔实际最低应付金额，且不得超过本期计划最高募集额 | 当前 Offering 下，同一投资者可有效认购的累计金额上限；留空表示不单独设置个人累计上限，仍受 Offering 总量/剩余额度约束 |
| 计划最高募集额 | 系统计算，只读 | 无单独输入 | = 本期发行 Token 数量 × 每 Token 认购价格；单位 U；明确标记「计划上限」 |
| 最低可购买 Token 份数 | 系统计算，只读辅助提示 | 自动计算 | = ceil(单笔最低认购金额 ÷ 每 Token 认购价格)，至少 1 份；展示实际最低需支付金额 |
| 实际最低应付金额 | 系统计算，只读辅助提示 | 自动计算 | = 最低可购买 Token 份数 × 每 Token 价格；如最低 Token 份数超过本期发行数量，阻断业务检查 |
| 认购开始时间 | 日期+时间选择器 | 业务检查必填 | 默认不预填任意未来日期；使用本 Offering 显示时区 |
| 认购结束时间 | 日期+时间选择器 | 业务检查必填；必须晚于开始时间 | 结束时刻到达后停止新增认购；发布后不可直接修改 |
| 时区 | 可搜索的时区选择器 | 必填 | 默认取 Asset 所在地可确定的时区；无法确定时取企业资料中设置的时区；仍无设置时要求用户明确选择。页面始终显示时区名称，不静默使用浏览器时区 |

**金额和数量规则**
- 所有金额统一使用 U；不出现 USDC 或其他可选支付币种。
- 价格和最低认购金额最多 6 位小数；该规则是产品输入精度，不代表真实链上 Token decimals 或支付服务已通过。
- 所有金额计算使用精确十进制语义；不得以二进制浮点误差、截断或静默四舍五入产生应付金额。
- 若单价 120 U、最低认购金额 200 U，页面提示「至少购买 2 份，实际最低支付 240 U」。
- 若最低认购金额低于单价，最低购买仍为 1 Token，实际最低支付为 1 份价格。
- 若最低认购金额换算出的最低份数超过本期发行数量，显示错误并阻断业务资料完整性。
- 若填写单笔最高认购 Token 份数，必须不低于最低可购买份数且不超过本期发行 Token 数量；订单创建/确认时按最新剩余可售份数再次校验。
- 若填写单个投资者本期累计最高认购金额，系统按当前 Tenant + Offering + 平台返回的本企业投资者引用编号累计核算；覆盖有效订单/预留、已付款待配售及已确认配售金额。同一订单在状态迁移中只累计一次，不重复相加。
- 只有订单取消/过期/退款等释放条件获得权威确认后，才从累计占用中释放；Unknown、付款待核、退款待核或预留待核均继续占用，不得提前释放。
- 订单创建/确认时重新核验当前累计已占用金额和剩余个人额度；并发订单以权威容量/订单服务结果为准，不能仅依赖页面缓存。
- 此上限仅按当前 Issuer/Tenant 内同一投资者引用编号及当前 Offering 计算；不跨 Issuer、V/M 账户或其他 Offering 合并投资者身份/额度。
- 不设置最低募集成立金额，不提供超募或动态价格字段。
- Draft 可以保存不完整/非法字段并显示待完善；业务检查和发布必须通过全部适用校验。
- 发布时重新核验当前权益可用容量，不能使用打开表单时的旧缓存。

**时间规则**
- 开始时间必须早于结束时间。
- Draft 可先保存未来或已过期时间；发布时要求结束时间仍在未来。
- 发布时开始时间在未来，发布成功后状态为「等待开始」；开始时间已到且其他条件均满足，才可进入「认购中」。
- 结束时间到达，停止新认购并进入「认购结束」。
- 发布后不允许直接编辑开始/结束时间；延期或提前结束不属于 V1 自助快捷操作，需受控处理。
- 夏令时或无效时区导致时间不存在/重复时，提示用户重新选择明确的有效时间，不静默偏移。

### 3.4 B 区：认购规则

| 字段/信息 | 控件 / 默认值 | 必填与校验 | 说明与反馈 |
|---|---|---|---|
| 投资者 KYC | 固定只读说明 | 固定规则，不可关闭 | 「投资者须完成平台统一 KYC 且状态为通过，方可进入认购确认。」Issuer 不配置 KYC 等级、例外或人工审核 |
| 投资者类型 | 不展示配置项 | 不适用 | 不允许 Issuer 选择个人/机构 |
| 允许认购地区 | 不展示配置项 | 不适用 | 不提供 Issuer 自定义地区白名单；适用法律/制裁等平台级强制限制由平台侧执行 |
| 锁仓方式 | 单选：不锁仓 / 固定天数；初始不替用户选择 | 必选 | 用户必须明确选择；不锁仓不代表豁免法律或合约层面的强制转让限制 |
| 锁仓天数 | 整数输入；仅选择固定天数时展示 | 固定天数时必填；1～36,500 天正整数 | V1 只支持单一固定期限，不支持分期解锁、多段锁仓或按投资者等级配置；从 Token 实际交付时点起算 |
| 支付网络与币种 | 固定只读 | 固定规则 | 「OP Mainnet · USDT」；不提供切换网络或币种的控件 |

- B 区不设置「投资者资格」独立配置区。
- 不显示投资者 KYC 证件、姓名、个人身份信息或第三方 KYC 报告。
- 发行方只能看到平台统一 KYC 规则说明；投资者个人 KYC 结果在认购流程中由平台判断，企业端只接收必要的脱敏业务状态。
- 锁仓天数只表达本期发行的统一基础锁仓规则，不替代法定转让限制；生产开放前仍需完成适用规则确认。
- 固定天数锁仓的真实 Offering 发布前，发行准备检查还必须确认所选 Token 方案/合约模板或其他依法批准的执行安排能够实施并核验该限制；没有获准执行/核验方式时阻断真实发布。此项不增加企业自定义锁仓策略。

### 3.5 C 区：发行准备

#### 3.5.1 企业最终收款钱包

| 字段 | 控件 / 默认值 | 必填与校验 | 说明与反馈 |
|---|---|---|---|
| 最终结算收款钱包 | 单选钱包卡片 | 业务资料检查必填；必须属于当前企业且状态有效 | 默认预选企业当前默认钱包；用户可更换为本企业其他已绑定、已验证且与本期结算范围相容的钱包 |
| 钱包展示信息 | 只读 | 必须完整 | 钱包名称、MPC/自连接来源、网络、缩略地址、验证状态 |
| 无可用钱包 | 空状态与链接 | 阻断业务完整性，不阻断保存 Draft | 提示「请先在企业管理 → 钱包管理中配置并验证收款钱包」；跳转钱包管理，返回后保留 Offering 草稿 |

- 不允许在 Offering 中手动输入陌生地址。
- 不允许将企业最终结算钱包描述为投资者支付地址或认购合约地址。
- 企业默认钱包后续切换，不自动改变已选择的 Offering 钱包。
- 钱包失效/解绑后保留原选择记录并标记无效，要求重新选择；不静默切换其他钱包。
- 发布快照固定最终收款钱包；发布后不得直接更改。

#### 3.5.2 发行协议、风险披露与关联文件

| 文件分组 | 控件 | 必填规则 | 展示和版本保护 |
|---|---|---|---|
| 认购协议 | 选择已有文件或上传新版本 | 业务资料检查必需 | 显示文件名、版本、扫描状态、预览/更换；固定引用 File ID + Version ID |
| 风险披露文件 | 可选择多个已验证文件或上传 | 至少一份适用风险披露文件 | 显示文件名、版本、扫描状态；固定引用版本 |
| Asset 关联证明 | 从当前 Asset 已有文件中选择 | 继承 Asset Ready 所要求的有效核心文件；不重复上传 | 显示来源、文件名和版本；引用固定版本 |
| Instrument 权益文件 | 从当前 InstrumentVersion 已有文件中选择 | 继承 Instrument Ready 所要求的有效核心权益文件 | 显示权益类型、文件名和版本；不得替换历史 Instrument 引用 |
| 其他补充披露 | 选择文件/上传 | 选填 | 可增加补充材料；不改变必需文件行 |

- 文件扫描中、扫描失败、无权访问、版本失效或不属于当前 Tenant 的文件不能作为有效引用。
- 上传新版本不得静默替换当前已引用版本。
- Draft 可保存文件缺失状态；业务资料检查时必须明确指出缺失的文件及修复入口。
- 文件上传/扫描通过不代表文件具有法律效力、签署已完成或监管审核已通过。

#### 3.5.3 投资者披露：资产相关方

- 展示当前 Asset 已维护的资产相关方列表；由发行企业逐期勾选本期需要披露的主体。
- 每个主体卡片展示内部识别信息供企业确认，但投资者端只输出允许公开的字段。
- 对外允许展示：主体名称、资产相关方角色、简要职责说明、可披露的注册国家/地区。
- 对外禁止展示：注册编号、联系人姓名、电话、邮箱、许可编号、内部备注、原始附件及其他非公开字段。
- 选择主体后显示「将向投资者展示上述公开字段」摘要；可查看实际预览。
- 如果未选择任何主体，业务检查时要求明确勾选「本期无需要披露的资产相关方」；不因遗漏选择而静默通过。
- Asset 相关方后续修改不自动回写已发布 Offering；发布时固定本期披露快照。

#### 3.5.4 两层准备检查

**第一层：业务资料完整性**

| 检查项 | 通过条件 | 不通过时的下一步 |
|---|---|---|
| Asset 资料 | Asset 属于当前企业且 Ready；引用版本有效 | 前往资产资料修复 |
| Instrument 权益结构 | 当前固定版本 Ready；权益文件引用有效 | 前往权益结构修复 |
| 发行信息 | 名称、简介、数量、价格、最低/最高单笔认购、时间和时区通过校验 | 定位 A 区具体字段 |
| 认购规则 | 锁仓方式明确；平台 KYC 固定规则已展示；支付范围固定 | 定位 B 区 |
| 企业收款钱包 | 已选择本企业有效、验证通过的钱包 | 前往企业钱包管理 |
| 认购协议与风险披露 | 必需文件存在、扫描通过、版本固定 | 定位文件行并上传/更换 |
| Asset / Instrument 文件 | 必需核心文件引用有效 | 返回对应资产/权益页面 |
| 资产相关方披露 | 已选择披露主体，或明确确认本期无相关方披露 | 定位披露分组 |
| 发布前预览 | 已完成最终预览并确认当前展示版本 | 打开最终预览 |

检查结果仅表示业务资料是否完整，不代表真实生产许可或实际发行成功。

**第二层：真实生产准入**

| 检查项 | 企业端展示 | 通过条件 |
|---|---|---|
| 套餐与企业认证 | Free / Standard、KYB 状态 | 必须为有效 Standard 且 KYB 通过 |
| 适用法律与合规 | 待平台确认 / 通过 / 未通过 | 由有权主体完成适用审核；企业不能自行标记通过 |
| 平台发行能力 | 未开放 / 待确认 / 通过 | 平台真实发行能力已获得独立准入 |
| 支付与结算能力 | 未开放 / 待确认 / 通过 | 当前支付网络、资金路径和结算责任已通过独立准入 |
| 本期发布条件 | 待检查 / 通过 / 阻断 | 生产准入、权益容量、发行互斥、钱包和文件快照均满足 |

- 企业端不展示 Provider、Signer、合约地址、密钥或内部技术检查细节；只展示可理解的业务结果、责任方和下一步。
- Unknown、未开放、待确认或未通过均不能视为通过。
- Free 显示「Free 套餐支持发行方案准备和内部预览，不支持真实发布」及升级 Standard 入口。
- Standard 但生产准入未通过时，显示明确阻断原因；不得出现假成功。
- 真实生产准入不因本文件或任何 UI-Ready 完成而自动通过。

### 3.6 草稿保存与资料检查

| 操作 | 可用条件 | 执行结果 | 用户反馈 |
|---|---|---|---|
| 保存草稿 | 具备企业业务准备权限 | 保存当前已填写字段和文件固定引用；不要求业务完整 | 显示保存成功时间；失败保留所有输入并允许重试 |
| 检查准备情况 | 已有 Offering Draft | 分别检查业务资料完整性和真实生产准入 | 显示通过/待完善/检查中/阻断及可定位下一步；不改变生命周期 |
| 预览投资者端 | 已有 Offering Draft | 打开内部只读预览；可显示未完成字段占位 | 标注「内部预览 · 非公开发行」；缺项可返回编辑 |
| 最终预览与确认 | 业务资料完整，准备发布 | 生成当前配置预览与快照摘要 | 用户确认后才能进入发布确认；修改任何关键字段需重新预览 |

- 保存失败提示：「保存失败，当前输入仍保留在本页，请检查后重试。」
- 版本冲突提示：「该发行方案已在其他页面发生更新。当前输入已保留，请刷新对比后再保存。」不得静默覆盖。
- 页面退出前如存在未保存更改，提醒保存或离开；离开不自动删除已保存 Draft。

## 4. 页面三：投资者端预览与最终确认

### 4.1 普通内部预览

预览必须使用投资者端真实页面结构与同一字段映射，不另造一套仅供企业看的展示模板。

**预览展示顺序**

1. 资产卡片：资产名称、类别、地区、封面、投资者展示简介。
2. 资产详情：已批准对投资者披露的资产摘要和展示资料。
3. 权益说明：股权/债权/收益参与类型、投资者获得的权利、每 Token 对应权益；债权付息和 Instrument 预期年化披露按 InstrumentVersion 原文展示。
4. 本期发行信息：发行名称、每 Token 价格 U、本期发行数量、单笔最低认购金额、单笔最高认购 Token 份数（如设置）、单个投资者本期累计最高认购金额（如设置）、计划认购起止时间、锁仓方式。
5. 平台统一 KYC 说明：投资者需完成平台 KYC 且状态通过后方可认购。
6. 支付说明：OP Mainnet · USDT。
7. 发行方本期披露的资产相关方：仅展示已选择且允许公开的字段。
8. 发行协议、风险披露及可向投资者提供的关联文件。

**预览禁止展示**
- 虚构的已募集金额、投资者人数、持仓数量、收益或 Mint 数量。
- 未提供或未经批准的预期收益承诺。
- 投资者 KYC 证件、个人身份信息、第三方报告。
- 资产相关方注册编号、联系人、联系方式、许可编号、内部备注和原始附件。
- 尚未被发布确认的内容不得显示成公开可认购状态。

### 4.2 预览交互

- 顶部固定提示：「内部预览 · 尚未公开发布」。
- Free 与 Standard 的 Draft 预览均不产生公开链接、不创建订单、不触发支付或 Token 操作。
- 预览缺少内容时，在对应区域显示「待完善」，不伪造占位业务事实。
- 企业可点击「返回修改」并定位至对应 A/B/C 字段。
- 预览关闭返回原编辑位置；保留滚动位置和未保存输入。
- 最终预览必须基于当前最新已保存数据；如果存在未保存更改，先提示保存，不能把未保存值误称为已确认快照。

### 4.3 发布前最终确认

最终确认层展示：
- Asset 名称与 Asset 资料版本；
- Instrument 类型、确定版本和每 Token 权利；
- Offering 名称、本期 Token 数量、单价 U、计划最高募集额 U；
- 最低认购金额、实际最低 Token 份数和实际最低应付金额；
- 单笔最高认购 Token 份数（如已设置）；
- 单个投资者本期累计最高认购金额 U（如已设置）；
- 认购开始/结束时间及明确时区；
- 锁仓方式与天数；
- OP Mainnet · USDT；
- 企业最终结算收款钱包名称和缩略地址；
- 认购协议、风险披露、Asset/Instrument 文件的文件名及固定版本；
- 本期披露的资产相关方及其投资者端公开字段。

**必需确认动作**
- 复选框：「我已核对本期发行条款、权益结构版本、披露文件和最终收款钱包，并确认按上述内容发布。」
- 主按钮：「确认发布」；次按钮：「返回修改」。
- 未勾选确认框时主按钮不可执行。
- 确认时再次检查 Standard、KYB、生产准入、权益容量、同一 Instrument 的开放认购互斥、钱包状态和文件版本。
- 任何检查变化导致不通过时，关闭确认层并定位阻断项；不得部分发布或显示假成功。
- 成功发布后固定发布快照并按批准规则预留本期 Token 数量；起始时间未到则进入等待开始，已到且其他条件满足则进入认购中。

### 4.4 Free / Standard 预览与发布差异

| 企业状态 | 保存 Draft | 内部预览 | 最终发布确认 | 对外发布 |
|---|---|---|---|---|
| KYB 通过的新 Free | 允许 | 允许 | 显示套餐限制 | 禁止 |
| Standard 且 KYB 通过 | 允许 | 允许 | 生产准入全部通过后允许 | 仅在全部独立准入通过后 |
| Standard 宽限期 | 按 U01 限制新增业务操作 | 可查看既有授权范围 | 禁止新增真实发行 | 禁止 |
| 降级 Free 的历史 Standard 企业 | 历史方案只读 | 历史预览只读 | 禁止 | 禁止 |
| KYB 未通过/补件/审核中 | 按企业认证拦截规则处理 | 不绕过认证门 | 禁止 | 禁止 |

## 5. 页面四：Offering 详情与发行生命周期

### 5.1 详情页结构

**顶部状态区**
- Offering 名称、期次、所属 Asset、固定 InstrumentVersion。
- 生命周期状态：草稿、等待开始、认购中、已暂停、认购结束、已关闭。
- 独立显示业务资料检查结果和真实生产准入结果，不把它们混成生命周期状态。
- 当前待处理事项数量。
- 唯一主操作由当前状态决定。

**发行摘要**
- 本期 Token 数量、每 Token 价格 U、计划最高募集额 U。
- 认购起止时间和时区。
- 锁仓规则。
- 最终结算收款钱包（名称与缩略地址）。
- 关联文件与资产相关方披露快照。

**详情内容分组**
1. 发行信息：本期发行名称、简介、数量、价格、募集上限、时间。
2. 认购规则：最低认购金额、平台统一 KYC 固定说明、锁仓、OP Mainnet USDT。
3. 投资者披露：Asset/Instrument 继承内容、选定资产相关方、协议与风险文件。
4. 发行准备：业务资料检查、生产准入结果、发布快照时间。
5. 发行进度：仅展示可核验的真实订单、支付、Token 交付和结算事实。
6. 操作记录：草稿创建/保存、检查、预览确认、发布、等待开始、暂停、恢复、结束、关闭及失败事件的时间和结果。

### 5.2 真实业务数据展示规则

- Draft：不展示「已认购 0」「已到账 0」「已 Mint 0」等虚构生产指标；显示「尚未发布」。
- Waiting：显示「等待开始」和计划起售时间；不可认购。
- Active：只有权威主账存在真实数据时，才展示已确认订单、已确认付款、已交付 Token 等数据。
- Paused：展示暂停时间/原因（如有）及「新认购已停止」；历史订单继续跟踪。
- Ended：展示结束时间和待处理订单/支付/交付/退款数量；不把认购结束等同于结清。
- Closed：展示关闭时间、结清结果和历史记录；只读。
- 没有可信数据时不显示推测值；如真实确认值为 0，可明确标注「已确认 0」，但必须有权威来源。

### 5.3 生命周期状态与操作

| 当前状态 | 状态含义 | 主操作 | 次级操作 / 限制 |
|---|---|---|---|
| 草稿 Draft | 尚未真实发布，不预留 Token | 继续编辑 | 检查准备情况、内部预览 |
| 等待开始 Waiting | 已成功发布，起始时间尚未到 | 查看发行详情 | 预览；不接受认购；不提供未经批准的撤回/提前开始按钮 |
| 认购中 Active | 已发布且处于有效认购窗口 | 暂停认购 | 查看详情、认购记录、锁仓记录；不允许直接改关键条款 |
| 已暂停 Paused | 停止新增认购，既有订单继续处理 | 满足条件时恢复认购 | 到期后不可恢复；不释放预留 |
| 认购结束 Ended | 已到截止时间，停止新增认购 | 处理待完成事项 / 满足条件后关闭 | 不接受新认购；不允许直接恢复 |
| 已关闭 Closed | 在途义务处理完，未分配且无义务的剩余预留已按规则释放 | 查看历史详情 | 永久只读，不可重新开放 |

**不提供的 V1 自助操作**
- 发布后直接修改价格、发行数量、收款钱包、权益版本、认购协议、风险披露或资产相关方披露。
- 直接修改认购开始/结束时间、延期、提前结束或撤回等待开始的 Offering。
- 关闭后重新开放。
- 通过创建第二个 Instrument 或复制权益结构重置容量。
- 在 Offering 中人工修改投资者 KYC、身份或资格。

以上变更如确有必要，进入有权主体的受控处理；V1 不提供可绕过发布快照和投资者既有权利的自由编辑入口。

### 5.4 暂停、恢复、结束和关闭确认

**暂停认购**
- 仅 Active 可操作。
- 二次确认文案：「暂停后将停止接受新的认购。已创建的订单、付款、Token 交付和退款仍会继续处理，不会因暂停而取消。」
- 确认后状态为 Paused；不释放已预留份额。
- 失败时保留 Active 状态并显示原因。

**恢复认购**
- 仅 Paused 且当前时间早于结束时间、生产准入和发布条件重新满足时可操作。
- 二次确认文案：「恢复后将重新接受新的认购。请确认认购时间仍有效，且本期发行条件没有发生变化。」
- 不重新预留 Token，不重置历史订单。
- 已到结束时间或条件不满足时不显示可执行恢复按钮，并解释原因。

**认购结束**
- 到达结束时间后自动停止新认购并进入 Ended。
- 不提供普通快捷按钮提前结束或延期。
- 已存在订单、支付、Token 交付和退款继续处理。

**关闭发行**
- 仅 Ended 可操作。
- 关闭前展示待处理清单：待付款核对/迟到账或 Unknown、已付款待配售、待法定登记/登记回执或更正核验、已配售待 Token 交付、交付失败/Unknown、退款处理中、资金/容量/Token 对账差异及其他争议/异常。每项显示权威责任模块和下一步。
- 存在任何未结清义务时，关闭按钮不可执行，并提供认购订单、配售与持有人、资金与结算或 Token 管理入口定位处理项。法定登记仅在适用时要求；若登记状态为待核、待回执、差异或 Unknown，不得因订单主进度已完成而跳过关闭守卫。
- 全部必要义务处理完成且容量核对通过后，允许二次确认关闭。
- 关闭只释放没有待处理义务的未分配预留；已交付 Token 保持已发行占用；仍存在义务的份额不得释放。
- 关闭 Offering 不会自动解除投资者已有锁仓；锁仓按锁仓记录及其自身规则继续。已完成必要配售、适用法定登记和 Token 交付后，仍在期限内的锁仓属于存续期限制，不单独阻止 Offering 关闭，但必须继续保留在锁仓记录中。
- 关闭后不可重开；需要新一轮发行时新建 Offering 并重新校验权益容量。

### 5.5 关联记录入口

- 「查看认购记录」跳转至企业 SaaS「认购记录」，自动带入当前 Asset 和 Offering 筛选条件。
- 「查看锁仓记录」跳转至企业 SaaS「锁仓记录」，自动带入当前 Asset 和 Offering 筛选条件；锁仓记录字段、状态、到期与链上核验以 [DEC-079](../../../decisions/DEC-079-lockup-records-ui-ready-v1-closeout-approved.md) / [锁仓记录 UI-Ready 最终规格](LOCKUP-RECORDS-UI-READY-CLOSEOUT-2026-11-11.md) 为准。
- Offering 不复制订单、支付、退款、Token、持仓或锁仓主账；仅展示可信摘要和跳转入口。
- 持有人管理、收益上报、清退等发行后业务由各自模块承载，不在本模块重复建设。

## 6. 全局异常、空态和错误反馈

| 场景 | 页面反馈 | 用户下一步 | 必须保护 |
|---|---|---|---|
| Instrument 不存在/未 Ready | 明确提示需先完成权益结构 | 跳转权益结构 | 不创建 Offering |
| Instrument 文件扫描中/失败 | 标明具体文件及状态 | 返回文件行修复 | 不把未验证文件标记 Ready |
| 可用 Token 份数不足 | 显示最新可用份数与超额字段 | 调整本期数量 | 不超发、不使用旧缓存 |
| 最低认购额高于本期可买上限 | 显示最低应买份数与本期最大份数冲突 | 调整最低认购额或本期数量 | 不静默降低门槛 |
| 时间倒置/时区无效 | 定位具体时间字段 | 修改时间/时区 | 不错误提前开售 |
| 钱包未配置/失效/解绑 | 钱包行显示阻断原因 | 前往钱包管理或重新选择 | 不丢 Draft、不自动切换收款账户 |
| 认购协议/风险披露缺失 | 文件行显示待补 | 上传或引用有效版本 | 不允许业务资料检查通过 |
| 文件扫描失败/版本失效 | 显示文件状态和版本 | 重新上传/选择有效版本 | 不静默替换历史引用 |
| 资产相关方披露未确认 | 提示选择主体或确认无披露 | 完成确认 | 不意外公开全部内部主体 |
| 已有另一轮开放认购 | 阻断发布并说明冲突期次和状态 | 查看现有 Offering | 不允许同一 Instrument 同时开放两轮 |
| Free 点击发布 | 显示升级 Standard 说明 | 升级套餐或返回编辑 | 零真实发布副作用 |
| Standard 生产准入未通过/Unknown | 列出业务可理解的阻断项 | 等待平台/有权主体处理 | 不显示假成功 |
| 发布前钱包或文件状态变化 | 提示资料已变化，要求重新检查和确认 | 返回 C 区修复 | 不使用旧快照发布 |
| 发布后尝试修改关键条款 | 提示该发行已固定发布快照 | 查看历史或联系有权处理 | 不覆盖既有订单、权利或受益人 |
| 暂停后仍尝试新认购 | 显示本期已暂停 | 查看发行状态 | 新认购必须阻断 |
| 到期后尝试恢复 | 显示认购期已结束 | 处理待结事项 | 不重新开放 |
| 存在在途订单时关闭 | 显示待处理数量及记录入口 | 先处理相关订单 | 不误释放预留、不丢义务 |
| 重复点击暂停/恢复/关闭 | 显示当前最新状态和已处理结果 | 返回详情 | 不重复执行状态变更 |
| 跨企业访问 Asset/Offering/Wallet/File | 显示无权访问 | 返回当前企业资产列表 | 不泄露其他企业数据 |
| 保存失败/刷新/离开 | 保留输入并提醒重试/保存 | 重试或选择离开 | 不静默丢失未保存内容 |

## 7. 页面与模块关系

| 关联模块 | Offering 使用的数据 | Offering 输出/提供的入口 | 不重复承担的责任 |
|---|---|---|---|
| 资产管理 | Asset 基础资料、Ready 状态、固定文件版本、资产相关方 | 投资者披露快照、Asset 详情状态 | 不编辑底层资产事实 |

| 企业套餐与 KYB | 当前套餐、KYB 状态、宽限/降级状态 | 是否允许准备或申请真实发布 | 不修改订阅和 KYB |

| 投资者门户 | 投资者端页面字段映射和披露内容 | 预览及符合准入后的发布内容 | Free 不生成公开门户；本页不管理门户主题/域名 |
| 认购记录 | 真实订单状态和汇总事实 | 认购记录跳转与待处理统计 | 不创建/修改订单主账 |
| 锁仓记录 | 真实锁仓状态 | 锁仓记录跳转 | 不管理具体持仓锁仓主账 |
| 统一投资端分发 | 无自动依赖 | 不自动申请或上架 | 仍按独立申请和平台审核处理 |

## 9. V1 明确不做

- Issuer 自定义投资者类型、地区、KYC 等级、资格例外或人工投资者准入审批。
- 多方收款钱包、发行费用比例配置、平台自动分账配置。
- 多阶段/动态定价、阶梯价格、超募、复杂最低募集目标。
- 分期锁仓、分层解锁、按投资者分级的锁仓策略。
- 发布后自由修改关键发行条款、自由改收款钱包、延期/提前结束快捷操作。
- Offering 内独立 Project 管理、独立发行准备菜单、重复权益结构表单。
- 在 Offering 内复制认购、支付、退款、Token、持仓、收益或清退主账。
- 统一投资端自动上架或自动通过审核。
- 任何未经独立准入的真实支付、资金托管、Mint、合约部署或生产发行能力。
