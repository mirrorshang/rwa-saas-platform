# RWA SaaS V1｜权益结构单页 UI-Ready 最终细化规格

> **设计日期：2026-11-11**  
> **状态：V1 详细设计基线（依据用户授权，由产品负责人完成字段、交互和版本规则收口）**  
> **适用范围：Issuer 企业 SaaS｜资产与发行 → 资产管理 → 资产详情 → 权益结构**  
> **维护分支：docs/r2-current-product-baseline｜PR #8 Draft / Open / Unmerged**

## 0. 依据与优先级

本文件承接并细化以下既有批准内容：

- U02-02：资产详情四 TAB；权益结构只在资产详情内管理，不新增独立二级导航。
- U02-05：一个 Asset 最多一套当前有效 Instrument；股权、债权、收益参与三选一；单页面三区域；用户输入权利总规模和 Token 拆分份数，系统计算每份权利；多期 Offering 共用同一授权容量。
- R13～R18：公共字段、三类权益基础字段、Token 数量与不静默取整、每类一份核心权益证明、草稿与资料检查规则均已批准。
- DEC-059：预期年化收益区间披露和债权周期付息纳入 V1。
- U02-04 文件收口：可引用 Asset 既有文件的固定版本；Instrument 专属权益协议仍归 Instrument。
- DEC-070/U02-07：Asset 相关方结构化信息及其披露位置已收口；Instrument 可引用已有 Asset 主体信息，但不将 Asset 相关方角色自动推断为 Instrument 的法律责任角色。
- U01：Free/Standard 的业务资料准备权限和历史降级只读规则继续有效。

**产品边界：** 本文件批准的是 V1 用户可见字段、页面组织、资料 Ready、版本与异常交互。权益文件的法律效力、真实债权/股权成立、适用法域、Token 标准、链上 decimals、Signer、支付和生产发行仍需独立准入。

## 1. 页面入口与最终单页结构

### 1.1 唯一入口

资产与发行 → 资产管理 → 选择 Asset → 资产详情 → **权益结构** TAB。

不增加「权益结构」二级菜单，不增加独立向导页面，不允许同一 Asset 创建第二套并行 Instrument。

### 1.2 页面布局

§§§text
顶部：资产名称（只读）｜当前权益结构版本｜资料状态｜保存状态

A. 权益定义
   权益类型：股权 / 债权 / 收益参与（三选一）
   权益结构名称
   权利责任主体（随类型改变字段标签）
   投资者获得的权利说明
   当前权益类型的专属条款

B. 权益规模与 Token 拆分
   本权益对应的权利总规模（带单位）
   计划拆分的 Token 总份数（正整数）
   系统计算：每 Token 对应的权利
   资料检查：是否能够精确拆分

C. 法律文件
   当前权益类型核心证明文件（固定必需行）
   引用当前 Asset 已有文件（固定版本）
   添加其他文件（选填）

底部固定操作：[保存草稿] [完成资料检查]
§§§

- A/B/C 是同一页面的三个分区，不是三步向导。
- 页面顶部始终突出当前状态、缺项数量和唯一下一步操作。
- 不出现 Offering 的认购价格、募集目标、认购起止、企业收款钱包、支付网络或投资者门户发布配置。
- 不展示没有真实业务事实支撑的「已 Mint 0」「已认购 0」「预留 0」运营指标。

## 2. 公共字段与责任主体

### 2.1 公共字段

| 字段 | 控件与规则 | Draft | Ready |
|---|---|---|---|
| 关联资产 | 从当前 Asset 自动继承，只读 | 系统自动关联 | 必须仍属于当前 Tenant 且有效 |
| 权益类型 | 单选：股权、债权、收益参与 | 必选 | 必选；与专属字段及核心文件类型一致 |
| 权益结构名称 | 默认「资产名称 + 权益类型」，允许修改 | 必填，最大 120 字符 | 非空 |
| 权利责任主体 | 动态主体信息卡片 | 可暂缺 | 必填 |
| 投资者获得的权利 | 多行文本，最大 2,000 字符 | 可暂缺 | 必填；说明权利范围、来源和限制 |

### 2.2 权利责任主体：动态标签与主体复用

同一个字段区域按权益类型显示不同名称，避免用户误以为三类权益的责任主体完全相同：

| 权益类型 | 页面字段名称 | 含义 |
|---|---|---|
| 股权 | **对应股权的法律实体** | 被纳入本 Instrument 的普通股所对应的法律实体 |
| 债权 | **债务人** | 对本 Instrument 所代表债权承担偿还义务的主体 |
| 收益参与 | **收益责任主体** | 对约定收益来源、计算口径及分配义务承担合同责任的主体 |

主体字段采用轻量主体卡片：

- 主体名称：必填，最大 160 字符。
- 主体类型：企业、自然人、政府/公共机构、其他。
- 注册国家/地区：企业及公共机构必填；自然人选填。
- 注册编号：选填；不收集个人身份证件号码。
- 与资产的关系：资产登记权利人、资产相关方、其他；选择「其他」时补充说明。
- 主体说明：选填；权利内容本身统一填写在「投资者获得的权利」字段。

**主体复用：**
- 可从当前 Asset 已有的登记权利人/资产相关方中选择主体，继承名称、主体类型、注册地区及编号等已录入信息。
- 选择已有主体只表示引用同一主体资料，不自动把 Asset 相关方角色改成债务人、股权对应实体或收益责任主体。
- 若不适用已有主体，可在本页录入新的 Instrument 责任主体信息；不建立跨 Asset 的全局主体名录。
- 不允许默认将 Issuer Tenant、Asset 登记权利人或 SPV 自动等同于权利责任主体；必须由用户明确选择或填写。

## 3. 三类权益的最终字段与 Ready 规则

### 3.1 股权型

| 字段 | 控件 | Ready 规则 |
|---|---|---|
| 对应股权的法律实体 | 主体卡片 | 必填 |
| 股份类别 | 固定显示「普通股」 | V1 只支持普通股，不提供优先股、可转换股或复杂类别 |
| 股东/持有人权利说明 | 使用公共「投资者获得的权利」字段 | 必填 |
| 纳入本权益结构的普通股总数 | B 区整数输入，单位「股」 | 正整数 |
| Token 总份数 | B 区正整数输入 | 正整数 |
| 每 Token 对应股份数 | 系统只读计算 | 必须为整数股；不能精确拆分时阻断 Ready |

- V1 不支持分数股。
- Token 份数不代表已完成法定股东名册登记；链上 Token 不自动等于股东身份。
- 不在 Instrument 中配置发行认购价格，价格只在 Offering 中配置。

### 3.2 债权型

| 字段 | 控件 | Ready 规则 |
|---|---|---|
| 债务人 | 主体卡片 | 必填 |
| 债权本金总额 | B 区金额输入，单位 U | 大于 0；最多 6 位小数 |
| 利息方式 | 单选：无息 / 固定利率 | 必选 |
| 固定年利率 | 百分比输入 | 固定利率时必填且大于 0；无息时不显示 |
| 起息日期 | 日期选择器 | 固定利率时必填 |
| 到期日期 | 日期选择器 | 必填；必须晚于起息日期（无息债权只校验到期日） |
| 付息方式 | 到期一次付息 / 周期付息 | 固定利率时必选 |
| 付息频率 | 每月 / 每季度 / 每半年 / 每年 | 周期付息时必填 |
| 首个付息日 | 日期选择器 | 周期付息时必填；晚于起息日且不晚于到期日 |
| 计息日数规则 | Actual/365 Fixed、Actual/360、30E/360、合同其他约定 | 固定利率时必选；「合同其他约定」需填写说明并标记人工核算 |
| 非工作日调整约定 | 条件性多行文本；仅当合同约定顺延/提前或特殊营业日处理时填写 | 有明确约定时记录合同规则；无明确约定时标记「合同未约定/需人工确认」；V1 不自动调用法定节假日日历或推算调整日 |
| 还本方式 | 固定只读「到期一次还本」 | V1 不提供本金分期摊还 |

**付息日期生成规则：**
- 到期一次付息：仅生成到期日付息事件，不要求首个付息日。
- 周期付息：从首个付息日开始，按月、3 个月、6 个月或 12 个月递推。
- 目标月份没有对应日时，取该月最后一个自然日；不重复生成日期。
- 若最后一个完整周期日期未到达合同到期日，则增加到期日作为最后一期，标记「非完整周期，需人工核算」。
- V1 不自动执行周末/法定节假日顺延或提前；合同约定的实际支付日如需调整，由有权主体在收益/付款环节人工确认。
- 无息债权不生成付息计划；本金仍按到期一次还本。

**V1 不支持：** 浮动利率、阶梯利率、复利、复杂本金分期、任意不规则付息日期列表、自动逾期罚息及自动法定节假日日历。

### 3.3 收益参与型

| 字段 | 控件 | Ready 规则 |
|---|---|---|
| 收益责任主体 | 主体卡片 | 必填 |
| 收益来源 | 单行/多行文本 | 必填，说明收入来源 |
| 收益计算口径 | 多行文本 | 必填，说明收入项、费用扣除范围及计算口径 |
| 收益参与开始日 | 日期选择器 | 必填 |
| 收益参与结束日 | 日期选择器 | 必填；必须晚于开始日 |
| 分配频率 | 每月 / 每季度 / 每年 | 必选 |
| 授权参与比例 | B 区百分比输入 | 大于 0%，不超过 100% |
| Token 总份数 | B 区正整数输入 | 正整数 |
| 每 Token 对应参与比例 | 系统只读计算 | 必须在产品允许精度内精确表示 |

- 收益参与权不等于底层资产所有权，不自动承诺保本或固定收益。
- V1 不支持多层瀑布分配、优先劣后、阶梯收益、复杂费用瀑布或复合权益。

## 4. 权益总规模、Token 拆分与精确性

### 4.1 用户输入与系统计算

用户只填写：
1. 本 Instrument 纳入的权利总规模（按类型选择单位）；
2. Token 总份数（正整数）。

系统只读计算：
- 每 Token 对应权利；
- 本 Instrument 的最大 Token 份数；
- 有真实发行事实时的已确认占用、有效预留和剩余可用份数。

不提供第三个可编辑「每 Token 对应权益」字段，不允许用户手动改写计算结果。

### 4.2 V1 用户输入精度

| 权益类型 | 总规模输入 | 输入精度 | 拆分要求 |
|---|---|---|---|
| 股权 | 普通股总数 | 正整数股 | 总股数必须能被 Token 份数整除 |
| 债权 | 债权本金 U | 最多 6 位小数 | 每 Token 名义本金必须在 6 位小数内精确表示 |
| 收益参与 | 授权参与比例 % | 最多 6 位小数 | 每 Token 参与比例必须在 6 位小数内精确表示 |

- 上述输入精度是 V1 产品表单精度，不等于链上 Token decimals、法定股份最小单位或任何法域的法律许可。
- 所有拆分按精确数值运算；如果出现无限循环小数或超出对应输入精度，拒绝 Ready。
- 不使用四舍五入、截断、向上/向下取整来制造一个看似可用的每 Token 权利数。
- Token 总份数必须为正整数；不设置任意套餐 Token 数量上限。

### 4.3 共享容量

- 单 Asset 只有一个当前 Instrument 和一份共享授权容量；多期 Offering 引用确定 InstrumentVersion，但不产生新的权益池。
- Draft Offering 不占有效预留；有效预留和已确认占用不能重复统计。
- 版本更新不能增加同一 Asset 的授权权益池容量；不能通过复制 Instrument 或新建版本重置剩余 Token。
- 已确认的权益占用不因 Offering 结束、关闭或版本更新自动释放。
- 没有真实发行事件时，仅显示总拆分份数及每 Token 对应权益；不显示虚构的已发行/预留/剩余运营指标。

## 5. 预期年化收益区间（DEC-059 V1）

### 5.1 适用范围

- **股权型、收益参与型：** 可选填「预期年化收益区间」。
- **债权型固定利率：** 直接展示合同固定年利率，不再重复填写预期年化区间。
- **债权型无息：** 不展示预期年化区间。
- 该字段仅用于发行方信息披露，不参与 Offering 认购价格、Token 数量、M13 应付金额或收益分配计算。

### 5.2 字段与校验

| 字段 | 控件 | 规则 |
|---|---|---|
| 预期年化最低值 | 百分比输入，最多 4 位小数 | 允许为 0 或正数 |
| 预期年化最高值 | 百分比输入，最多 4 位小数 | 必须与最低值同时填写，且不低于最低值 |
| 测算依据与假设 | 多行文本 | 填写区间时必填，说明测算期间、关键假设和数据来源/口径 |

- 三项全部留空：允许 Ready，投资者端显示「发行方未提供预期年化收益区间」。
- 只填写区间一端：阻断 Ready，定位缺失字段。
- 填写区间但缺少依据：阻断 Ready。
- 投资者端固定显示「发行方预期年化收益区间」及不可关闭的非承诺提示；不将其表述为保证收益或固定回报。
- 预期年化数据随 InstrumentVersion 固定；Offering 不允许另行覆盖。

## 6. 法律文件与版本引用

### 6.1 每类一项核心权益文件

| 权益类型 | 固定必需文件行 |
|---|---|
| 股权 | 股权权益协议或适用权利证明 |
| 债权 | 债权协议或债权形成证明 |
| 收益参与 | 收益参与协议 |

每行显示：必需标签、文件状态、文件名/版本、上传/查看/更换入口。其他文件通过「＋添加其他文件」选择类型后按需上传。

### 6.2 Asset 文件引用

- 支持从当前 Asset 的文件中选择已扫描且可引用的确定版本。
- 显示文件类型、名称、版本、状态；确认后固定引用 File ID + Version ID。
- Asset 文件后续产生新版本时，不静默改变 Instrument 已引用的旧版本。
- Instrument 专属权益协议仍归 Instrument 文件关联；Offering 认购协议和风险披露归 Offering。
- 上传完成不等于安全扫描通过、签署完成或法律有效。

## 7. 草稿、Ready、类型切换与版本保护

### 7.1 Draft 与 Ready

- Draft 最低条件：已选择权益类型、权益结构名称非空。
- Draft 可暂缺其他 Ready 必填字段；可保存、重新打开、继续编辑。
- 点击「完成资料检查」时，检查当前类型全部必填字段、条件字段、文件状态和 Token 精确拆分。
- Ready 只表示产品定义的资料完整性检查通过，不表示法律权利已成立、合约已部署或真实发行获准。
- 修改任何 Ready 必填字段、核心权益文件版本或 Token 拆分后，Ready 自动失效，必须重新检查。

### 7.2 权益类型切换

- 仅在尚未被任何 Offering 引用时允许切换类型。
- Draft 或未被引用的 Ready 切换类型前，显示确认弹窗：「切换权益类型后，原类型专属条款和核心文件关联将清除；资产资料、权益结构名称和已上传文件实体保留。」
- 确认后清除不兼容的类型专属字段及核心文件关联；文件实体仍保留在文件中心，不物理删除。
- 切换后状态回到 Draft，用户重新填写新类型字段并执行 Ready 检查。
- 一旦被任一 Offering 引用，禁止切换权益类型。

### 7.3 已被 Offering 引用后的版本

- Offering 创建时固定引用当前 Ready InstrumentVersion。
- 已被 Offering 引用的版本不能原地覆盖。
- V1 提供「创建修订版本」入口：复制当前版本为新草稿，允许修改说明、核心文件版本、预期年化披露、债权付息安排及收益参与期限/口径等条款；修改后重新 Ready。
- 修订版本不得改变权益类型、责任主体、权益总规模、权利单位或 Token 总份数；这些是同一 Asset 权益池的不可变容量核心。
- 新版本不增加或重置授权容量；旧 Offering 继续引用旧版本，新 Offering 只可引用最新 Ready 版本。
- 已有认购、配售、持仓或其他存续义务的 Offering 不迁移到新版本；不提供批量替换历史版本。
- 如需变更权益类型、责任主体或授权容量，V1 不提供自助修改流程，必须另行走有权主体的受控变更/法律处理，不以复制新 Asset 绕过历史义务。

## 8. 页面反馈、异常与权限

| 场景 | 页面反馈 | 保护 |
|---|---|---|
| Asset 尚无 Instrument | 「先确定投资者获得的权利，再设置 Token 份数。」 | 不显示第二套权益入口 |
| Draft 缺字段 | 显示缺项数量，定位到字段 | 仍可保存 Draft |
| Token 数量为 0/负数/小数/空 | 「请输入大于 0 的整数份数。」 | 不计算 NaN/Infinity |
| 股权不能整除 | 「普通股总数必须能按整数份数精确拆分，请调整股数或 Token 份数。」 | 阻断 Ready |
| 债权/收益参与无法精确拆分 | 「当前总权益无法按所选份数精确表示，请调整权益规模或 Token 份数。」 | 阻断 Ready，不静默舍入 |
| 固定利率缺日期/频率 | 定位缺失字段并提示补齐 | 无息债权不要求付息字段 |
| 付息日超出到期日/重复 | 显示冲突日期 | 不自动删除或移动合同日期 |
| 收益参与缺来源/口径/期限 | 定位具体字段 | 不允许 Ready |
| 预期年化只填写一端 | 「请同时填写区间上下限，并说明测算依据。」 | 不允许 Ready |
| 核心文件未上传/待扫描/失败 | 对应文件行显示上传、等待或重试 | 不误报可引用 |
| 已引用版本尝试直接编辑 | 「该版本已被发行方案引用，不能直接覆盖。」 | 提供查看关联 Offering / 创建修订版本 |
| 网络保存失败 | 「保存失败，当前输入仍在本页，请重试。」 | 不清空表单、不假成功 |
| Free 企业 | 可创建/编辑/Ready 正式 Instrument 资料 | 不可真实发布、Mint、募资 |
| Standard 降级历史只读 | 显示只读原因 | 不开放新建或编辑写操作 |

## 9. 与 Offering、M13 的页面衔接

- Offering 只继承 InstrumentVersion 的权益类型、责任主体、每 Token 权利、固定利率/付息安排、预期年化披露和确定文件版本；不得在 Offering 重复编辑权益总量或 Token 映射。
- Offering 只配置本期 Token 数量、认购单价 U、最低认购金额、认购时间、锁仓、企业收款钱包、投资者披露和发行准备。
- M13 周期付息事件从 Offering 引用的 InstrumentVersion 读取付息计划，按期次承接；M13 负责收益上报、应付计算/复核、注资和实付对账，不允许发行方在收益上报中重复创建同一期合同付息事件。
- 预期年化区间只在投资者端披露，不参与 M13 计算或 Offering 定价。

## 11. 明确不纳入 V1 的复杂能力

- 多 Instrument、多权益池、复合/优先劣后/分层权益；
- 分数股、浮动/阶梯利率、复利、复杂本金摊还、任意不规则付息日；
- 多层收益瀑布、优先分配、复杂费用扣除规则引擎；
- 自动法定节假日历、自动法律意见、自动牌照验证；
- 复杂权益类型迁移、历史持有人批量转换、强制转移权益；
- 自动从预期年化区间推导实际收益或承诺投资回报。
