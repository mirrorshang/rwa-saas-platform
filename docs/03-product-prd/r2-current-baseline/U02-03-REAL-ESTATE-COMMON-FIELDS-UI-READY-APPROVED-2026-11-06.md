## 2. 字段规则与控件
说明：「草稿必需」仅对创建/首次保存草稿生效；「Ready 必需」允许草稿暂不填；「条件」指满足条件时 Ready 必需。除自动/只读字段外，用户可编辑和再次保存。

### R15 全平台基础字段（②基础信息）
| 字段 | 控件 | 状态/校验 |
|---|---|---|
| 资产编号 | 后台自动生成、只读 | 创建记录时分配租户内唯一编号；不得用户自行改写 |
| 一级资产分类 | 继承①、只读展示 | 房地产 |
| 二级资产分类 | 继承①、只读展示 | 六个已批准分类之一；回到①时可修改，但已填专属数据的转换与损失提示需后续细化 |
| 资产名称 | 单行文本 | **草稿必需**，非空、去首尾空格，最大 120 字符 |
| 资产简介 | 多行文本 | 选填；对外展示/正式投资者端预览所需的内容完备性由后续 Offering 发布准入检查 |
| 所属发行企业 | 当前企业 KYB 关联、只读 | 依据当前登录 Tenant 关联，不让用户在 Asset 表单重新录入或选取其他 Tenant；**不推定企业=登记权利人** |

### R16 房地产位置与展示（②基础信息）
| 字段 | 控件 | 状态/校验 |
|---|---|---|
| 国家或地区 | 可搜索国家/地区选择 | **Ready 必需**；用稳定代码保存，页面显示中文名称 |
| 城市或行政区域 | 地区选择/文本（取决于数据可用性） | **Ready 必需**，非空 |
| 详细地址／地块位置 | 多行文本 | **Ready 必需**；土地可使用明确的地块位置描述，避免强行要求门牌号 |
| 资产封面 | 图片上传 | Asset Ready **选填**；正式投资者端上架前须具备可展示封面（Offering/门户发布校验） |
| 资产图片 | 多图上传 | 选填，可排序/移除、按权限受控 |
| 资产视频 | 文件上传 | 选填，MVP 不强制 |

文件格式：封面/图片 JPG/PNG；视频 MP4；单文件建议上限 **20MB**。格式、大小前后端均校验，超限和格式不符显示明确错误；视频能否处理/转码仍取决于实际技术实现门，不能默许生产自动转码。

### R17 房地产基本情况（②基础信息；特性归④）
| 字段 | 控件 | 状态/校验 |
|---|---|---|
| 资产用途 | 二级分类带入、只读展示 | 用途说明依据当前子类显示；不再重选形成矛盾分类 |
| 当前使用情况 | 单选 | **Ready 必需**；候选：自用、出租、混合使用、闲置、其他；针对土地等子类仅提供适用值，具体动态选项后续审校 |
| 使用情况说明 | 多行文本 | 选填；「其他」时**条件 Ready 必需** |
| 面积/规模 | 子类特定字段输入 | **不设所有物业通用的建筑面积必填**；住宅/写字楼/商铺/酒店/工业园仓储/土地各定义自己的口径、单位和必填门槛，另批审核 |

### R18 房地产权属与持有主体（③法律与估值）
| 字段 | 控件 | 状态/校验 |
|---|---|---|
| 登记权利人 | 单行文本 | **Ready 必需**，非空；不从发行企业自动替代 |
| 权利性质 | 下拉单选 | **Ready 必需**；所有权、土地使用权、租赁/经营权、其他；适用性受二级类别/法域约束，选其他需说明其法律依据 |
| 权利登记编号 | 单行文本 | **选填**；不强制无登记号的合法权利凭证填写 |
| 与发行企业的关系 | 单选 | **Ready 必需**；同一主体、关联主体、受托/授权、其他 |
| 关系说明 | 多行文本 | **条件 Ready 必需**：非「同一主体」时 |
| 资产运营/管理主体 | 单行文本 | 选填；如与权利人不同可填写 |
| 抵押及其他权利限制 | 单选 | **Ready 必需**：无、有、尚未确认；「尚未确认」允许存草稿但**阻断 Ready** |
| 权利限制说明 | 多行文本 | **条件 Ready 必需**：选择「有」时 |

- **不建立必填 SPV 表单**。若 SPV 是实际登记权利人就填其名称；Instrument/Offering 的真实责任主体关系仍按其独立对象管理。
- 权属/授权/负担状态来自发行企业填报和证据，平台仅作结构化记录与必要核查，不自动证明其法律真实有效。

### R19 房地产估值（③法律与估值）
| 字段 | 控件 | 状态/校验 |
|---|---|---|
| 参考估值 | 金额输入 | **Ready 必需**，严格大于 0；界面按 V1 的 U（USDT 计价）显示，与 Offering 发行金额、Token 单价严格分离 |
| 估值基准日期 | 日期选择器 | **Ready 必需**，不接受晚于实际当前日期的“已发生估值”基准日 |
| 估值依据 | 下拉单选 | **Ready 必需**；第三方评估、近期成交价、其他可核验依据 |
| 评估机构 | 单行文本 | **条件 Ready 必需**：估值依据为第三方评估时 |
| 估值说明 | 多行文本 | 选填；估值依据为「其他」时**条件 Ready 必需** |

- 文件的原始币种、计价时点、U 换算及参考估值是否可使用属于后续证据/生产校验范围；**不在本次批准隐式汇率转换或让未经核验金额自动进入 Offering 定价**。
- 估值字段不构成平台或第三方对资产价格的真实性保证。

## 3. R19 + 用户补充批准：文件清单与上传交互（③法律与估值）
### 3.1 清晰的「必需文件」固定列表
**用户明确要求：必需上传的逐项列出，每项右侧直接有上传按钮。**

| 页面固定行 | Ready 要求 | 右侧操作 |
|---|---|---|
| **资产权属证明**（必需） | 依当前资产/法域提交能支撑已填权利性质、登记权利人及标的范围的文件；**Ready 必需** | 「上传文件」→ 上传完成显示「查看 / 更换」 |
| **资产估值依据文件**（必需） | 提供与选定估值依据一致的评估报告、成交证据或其他可核验资料；**Ready 必需** | 「上传文件」→ 上传完成显示「查看 / 更换」 |
| **抵押／权利限制证明**（条件必需） | R18 选择「有」时显示或标为必需；**Ready 条件必需** | 「上传文件」→ 上传完成显示「查看 / 更换」 |

- 权属证明不是全法域固定一种文件名；可按模板/法域提示「不动产权证／土地登记证明／合法权利合同及其他适用材料」，但**不在此单一清单擅自认定某一种材料的法定充分性**。
- 选择无抵押限制时，不显示为未完成的必需项；选择「尚未确认」时阻止 Ready，提示查证，而非要求上传一个虚构的“未知证明”。
- **其他选填材料**采用默认折叠的「＋ 添加其他文件」：先选择文件类别（如运营证明、补充合同、其他资产材料），再上传，允许添加多项和编辑备注；**不把大批选填空行铺满初始页面**。选填项类型与具体子类额外必需材料，后续模板审核可扩展。
- 所有必需文件行固定显示**未上传、上传中、待安全扫描、可引用、失败/需重新上传**等适用状态；失败/扫描未通过不能冒充完整。显示文件名、上传时间、版本、预览/更换（受权限控制）；历史文件版本留痕，关联文件唯一权威实体主责 M06。
- 建议格式 **PDF/JPG/PNG**，单文件最大 **20MB**；扩展名/MIME/大小前后端校验，非法、超限或上传失败显示本行错误，不能静默清除草稿或错误地通过 Ready。文件上传/扫描正常不代表证据法律真实有效。
- 法律文件中由 Instrument 定义的权益协议、由 Offering 定义的认购协议及投资者签署文件**不在资产登记时要求必填**，按关联对象和版本引用。

## 4. R20：草稿、Ready、最终预览/检查及状态边界（⑤预览提交）
- **保存草稿**：一级/二级分类已选择、资产名称为非空且满足 120 字符上限，即可创建 Draft；自动编号、发行企业关联无需用户输入。允许在第②～④步随时保存。当前已填写的字段必须通过其基本格式检查，不能保存不合法日期/金额格式为有效数据。
- **返回/恢复**：保留已存数据及当前向导位置；存在未保存内容时离开提示，不静默丢失。未完成字段显示「待补」，不提前要求所有 Ready 条件。
- **下一步**：检验当前字段输入的合法格式和已触发的条件关系，不因为剩余 Ready 字段缺失阻止用户保存草稿或继续补充；对于尚未实现的子类模板须有明确未开放说明，不能伪装已交付。
- **第五步资产资料预览**：展示所选分类、名称、地区、产权/主体关系、参考估值及上传文件状态、④子类字段摘要；明确「缺失/无效/条件待核」项和跳回修改入口。
- **检查资料完整性 / 达到 Ready**：只有当前已适用的 Ready 必需字段齐备、值合法、必需文件存在且符合预定扫描/可引用要求、未存在权利限制未知阻断时，才能达到业务资料完整。若有问题，逐项给出「所属步骤 → 字段/文件 → 原因 → 去补充」；不能用「上传成功」冒充安全/法律审核通过。
- **继续后续流程**：资产数据准备完成后进入资产详情四 TAB，按实际进度提示下一步创建 Instrument；不能仅因此自动发布 Offering、合约部署、Mint、上架或认购。
- Free 与 Standard 共享真实 Asset 数据准备，Free 没有真实发行权；「资产资料预览」与 Offering 阶段的「投资者端最终发布预览」是**两个不同操作与页面**。
