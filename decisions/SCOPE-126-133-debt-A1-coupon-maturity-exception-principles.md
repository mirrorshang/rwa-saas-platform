## 二、与现有流程及范围的关系

- A1 是固定收益债权型**产品验证构型**：同一 Series 的销售期内新发单位共享明确的到期日和适用付息计划，但**同权性、后入定价及投资者权利生效均依合法文件**。
- M11 认购付款、M12 配售/法定登记、M07 链上 Token、M13 到期本息/偿付各有独立权威事实；**票息计算通过 ≠ 钱已付；Token Burn ≠ 法律债务解除**。
- 12 张 A-D 专项卡和先前 A-T16 张卡只是需求案例，状态不因本次批准被改成 PASS。
- M01～M22 和原 187 项 **P0 125 / P1 21 / P2 21 / V2 6 / 商业批次待定 14** 不变；White-label 和 Open API 商业交付继续独立。
- A 样本专项原则审核可以阶段性收口；**下一份工作转为 B：SPV 股份或类似实体权益**的发行、权威权益登记、可选分配、转让限制及 Token 对照验证。
