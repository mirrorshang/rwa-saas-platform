## 二、官网全站统一口径（由已批准规则推导）

| 主题 | 统一产品事实 | 页面表达原则 |
|---|---|---|
| 产品定位 | 面向发行企业/资产管理机构的多资产 RWA Tokenization SaaS | 聚焦资产准备、权益结构、发行方案、认购与运营，不展示交易所/二级市场承诺 |
| 企业登录 | 邮箱 + 6 位验证码；首次认证自动创建账号 | **一个入口**，不再分开「先注册账户」与「已有账号登录」两条业务路径 |
| 企业 | 一个账号对应一个企业；V1 无团队角色/多企业切换 | 禁用「企业切换」「邀请团队成员」「管理员/普通成员权限」等客户权益营销 |
| KYB | 企业创建后开始五步 KYB；通过后激活 Free；未通过时仍可看到导航/认证状态引导 | 不宣称邮箱验证后即完成 KYB 或自动获得 Free 业务操作权限 |
| Free | 永久免费；KYB 通过后真实准备 Asset/Instrument/Offering；内部只读投资者效果预览 | **不是 Sandbox 全模拟募资产品**；无真实公开发行、对外门户、认购、资金、Token 持仓和收益运营 |
| Standard | 可在相应条件满足后使用真实发行、对外门户、认购和后续运营 | 订阅付费不等于具体 Offering 已合法发布或真实资金/Token 能力已开通 |
| SaaS 订阅 | 月付/年付；USDT 或法币；价格待配置；自动续费默认关闭，按受支持渠道和用户主动同意启用 | SaaS 订阅付款网络/币种**不等于**投资者认购的 OP Mainnet USDT |
| 资产与发行 | 从资产管理创建 Asset → 该资产唯一当前 Instrument → 多期 Offering；Project 是内部关联对象 | 不要宣传独立 Project 创建/列表作为用户必经步骤 |
| 资产类别 | 8 一级/24 二级目录；V1 先开放 4 个房地产子类 | 不把「8 类资产都能创建/发行」作为当前 V1 已实现能力 |
| 统一投资端 | 属于 V1 产品范围，发行方按 Offering 可选申请，平台独立渠道审核；V 与 M 投资者身份/账户分离 | 目前官网 M 入口可显示筹备，不应称功能「不在 V1」或暗示已有可认购 Offering |
| 术语 | Instrument 中文统一「权益结构」；Offering 用「发行方案」 | 营销首现可注明英文；不向用户强制展示 Project / Tenant / M23 等内部术语 |

## 三、全站导航与 CTA（保留现有页面结构）

### 3.1 顶部导航

保留：Logo、产品功能、解决方案、订阅、投资者平台、帮助中心、企业登录。

- **主用户入口文案推荐**：「免费开始」；与「企业登录」均进入**同一邮箱验证码身份入口**（当前现有 `/login`，不另建注册体系）。若服务暂不可用，在同一入口展示开放状态和了解产品的返回路径，不模拟真实成功。
- 未登录时，两个入口目的地可相同，但主 CTA 用意是开始企业入驻，次 CTA 是已有企业登录；**不应因文案不同而出现两种账户流程**。
- 已登录且 KYB 未通过：主 CTA 改为「继续企业认证」或「查看认证状态」，进入该企业的 KYB 工作区。
- 已登录且 KYB 已通过：主 CTA「进入工作台」；订阅升级始终从工作台企业管理进入。
- 投资者平台导航在尚未正式开放时进入官网 `/investor-platform` 筹备页；独立投资者门户 V 不与企业登录共用身份入口。

### W-01｜官网首页

**保留：** 现有 Hero、六项能力、工作台示意、投资者入口介绍、流程、两类机构、底部 CTA 的视觉结构。

- Hero 标题：**「让资产 Token 化发行，更清晰、更高效」**。
- Hero 说明：「为发行企业和资产管理机构提供统一工作台，从资产资料、权益结构到发行方案，连接投资者认购与发行后管理。」
- 主 CTA：「了解产品功能」→ `/features`；次 CTA：「免费开始」→ 统一登录入口。
- 六项能力第 2 项将「项目与 Offering」改为**「权益结构与发行方案」**；明确一项资产定义权益结构，可安排多期发行；不再写独立项目管理中心。
- 流程建议：**完成企业认证 → 创建资产 → 配置权益结构 → 创建发行方案并预览 → 满足条件后发布与管理**。
- 底部 Free 说明：「Free 可永久免费准备资产、权益结构与发行方案，并查看内部预览；正式发行及运营需要 Standard 和相应准入条件。」
- 不把工作台示意中的「Sandbox」混为 Free 权益；若图例仅为静态 UI 样稿，使用「页面示意」而非「Free Sandbox 可用」。

### W-02｜产品功能

**保留：** 现有七大能力及「发行准备 / 发行执行 / 发行后运营」三阶段布局；不增加第八块。

- 能力 1「资产管理」：按模板录入资产资料，初期开放四个房地产子类；未来其他资产类别逐步开放。
- 能力 2「权益结构与发行方案」：在资产详情内配置唯一当前权益结构，并创建多期 Offering；每期填写价格、数量、时间、投资者条件与文件，预览并检查准备情况。
- 能力 3「Token 管理」：展示 Token 计划与相关交付、状态记录，不暗示 Free 可 Mint。
- 能力 4「投资者门户」：区分 Issuer 自有 V 门户和自愿申请平台 M 统一投资渠道；Free 仅内部预览。
- 能力 5「投资者与认购」：介绍个人/机构投资者资格、认购订单与配售登记，由 Standard 相应条件承载。
- 能力 6「资金与结算」：区分订单、到账、退款与结算状态；不把 USDT 付款网络混同 SaaS 订阅。
- 能力 7「发行后运营」：持有人登记、收益上报、本息/分配、清退兑付、到期等。
- 预览图例中的「项目列表/项目创建」改为「资产 / 权益结构 / 发行方案」；含分阶段流程的示意从「项目准备」改为「资产准备」。
- 能力区 CTA 统一「了解业务流程」或「免费开始」，不宣传 Free 能模拟认购与资金流程。

### W-03｜解决方案

**保留：** 资产管理机构与发行企业两类客户结构；不复制套餐页或增加团队权限章节。

- 资产管理机构：核心卖点改为「多资产资料与各期发行方案集中管理，按资产查看状态和后续运营事项」。
- 发行企业：核心卖点改为「从第一项资产出发，依次完成权益结构、发行方案和投资者端预览」。
- 删去「多项目独立创建」「协调内部多角色审批」作为 V1 操作步骤。
- 两类流程共用：登录 → 创建/认证企业 → 资产 → 权益结构 → Offering → Standard 条件下的发布/认购及发行后管理。
- 用户不需事先学习 Project 与 Offering 的内部对象区别。

### W-04｜订阅方案（`/pricing`）

- Hero 标题：**「从 Free 开始准备业务，按需升级 Standard」**。
- Hero 说明：「两种方案使用同一企业工作台。Free 永久免费；Standard 支持月付或年付，价格以正式公布为准。」
- Free 卡：**「免费准备发行资料」**；Standard 卡：**「按条件开展正式发行与运营」**。
- Free 包含：企业 KYB 后使用、管理企业钱包、创建/编辑资产、配置权益结构、创建发行方案、内部只读预览、查看自身资料进度。
- Free 不包含：真实 Token 发行/部署/Mint、对外门户、认购、资金运营、投资者持仓、收益运营、白标/API。
- Standard 包含：在同等资产准备能力基础上，**符合相应准入时**配置公开门户、真实发布、认购、配售、资金对账、Token 与发行后管理；白标/API 的 Standard 归属仍未批准，**不作为 Standard 已开放承诺**。
- 权益比较建议 13 行（保留表格密度）：

| 功能 | Free | Standard |
|---|---|---|
| 费用 | 永久免费 | 月付/年付；价格待公布 |
| 企业 KYB | 必须完成 | 必须完成 |
| 企业钱包 | 可配置 | 可配置 |
| 创建资产 | 支持 | 支持 |

| 创建发行方案 | 支持 | 支持 |

| 持仓/锁仓 | 不支持 | 满足独立准入后 |

**不再独立进行「注册 Free」或「创建账号」表单。** 推荐展示简短的「开始使用企业工作台」说明并进入统一邮箱验证码入口 `/login`（历史收藏链接不失效）；若保留原视觉布局，只保留产品说明和一个主 CTA「使用邮箱继续」。

删除「Free 无须 KYB」「完整模拟投资者认购」「先注册再邮箱链接激活 Free」等旧内容。

### W-09｜原邮箱验证页（`/verify-email`）

产品的邮箱验证动作属于 W-10 统一登录的第二步（6 位验证码），不是独立邮件链接验证后再开通 Free。历史 URL 直接访问时，显示「请从企业登录开始验证邮箱」并返回统一入口；已有有效入口流程不重复制造 Account。

验证码应覆盖：发送中、错误、过期、已用、频率限制、重新发送及修改邮箱；不得在仅输入邮箱时显示已完成认证。

### W-10｜企业登录（`/login`）

**推荐主标题：「使用邮箱登录或开始使用」**；字段仅邮箱地址与验证码（首次需同意适用 SaaS 条款/隐私政策），不再询问用户「已有账号/立即注册」。

流程：

1. 输入邮箱，获取 6 位验证码。
2. 输入验证码并确认。
3. 如为新邮箱，完成首次条款确认后自动建账号；已有账户直接登录。
4. 登录后进入 Issuer 工作台；没有企业则引导创建企业并开始 KYB；KYB 未通过则工作台主区域显示认证状态与下一步。
5. KYB 通过后展示 Free/Standard 实际权限和业务页面。

不出现「登录后选择企业」的正常步骤，不因缺少企业而让用户反复跳注册页面。

### W-11｜Free 开通/企业认证引导（`/free-onboarding`）

**页面职责改为「企业创建与认证进度」**，不再把它解释为邮箱验证后的即时 Free 开通。

根据业务状态，显示一个明确主操作：

| 当前状态 | 主标题 | 主要操作 |
|---|---|---|
| 已登录、尚无企业 | 创建您的企业 | 「创建企业并开始认证」 |
| KYB 草稿 | 继续完善企业认证 | 「继续填写」 |
| KYB 审核中 | 企业认证正在审核 | 「查看申请状态」 |
| KYB 待补件 | 企业认证需要补充资料 | 「补充资料」 |
| KYB 未通过 | 企业认证未通过 | 「查看原因/允许的重新提交方式」 |
| KYB 已通过、Free 已激活 | 企业工作台已可使用 | 「进入工作台」 |
| KYB 已通过、钱包开通仍进行中/失败 | Free 权益正常可见，钱包状态独立提示 | 「进入工作台」并提示「查看钱包状态」 |

第 5 步 KYB 预览确认应发生在 Issuer 企业认证流程，不需要在官网复制一整套 KYB 表单。**KYB 通过激活 Free，与 MPC 钱包处理结果分离**。

### W-12｜原企业选择页（`/organizations`）

V1 不展示多企业卡片、成员权限、企业搜索或切换。老链接依实际状态提供单一去向：

- 未登录 → W-10 企业邮箱入口；
- 已登录且无企业 → 创建企业/KYB；
- 已登录有企业且 KYB 未通过 → KYB 状态；
- 已登录有企业且 KYB 已通过 → 进入该企业唯一工作台；
- 历史失效链接 → 清楚说明入口已统一，提供「进入工作台」，而不是报错或循环。

保留 URL 的兼容责任，不将此页计为当前 V1 必须新增的业务页面。

### W-13｜Standard 升级说明（`/standard-upgrade`）

- 标题：**「在原企业工作台升级 Standard」**。
- 一句话：「不需要新建企业或重复进行商业 KYB；在订阅管理中选择周期与支付方式，完成有效付款后使用对应权益。」
- 推荐五步：① 登录现有企业工作台；② 确认 KYB 已通过；③ 选择 Standard 月/年周期；④ 选择 USDT/法币并确认订阅；⑤ 查看支付结果与 Standard 激活状态。
- 删去「选择企业」「提交商业 KYB」「只支持 TRON/BNB/Ethereum 的 USDT 订阅付款」及「自动续费完全不支持」旧内容。
- 说明自动续费默认关闭；仅在支付渠道支持且用户主动开启时启用，不能误写成默认扣费。
- 到期提醒按已批准的 7/3/1/当日；到期进入 7 天宽限期并暂停新真实发行，宽限后降级历史只读；必要存续义务保留。
- 主 CTA：「进入企业订阅管理」（未登录先走统一登录，并保留升级意图）；无订阅能力/价格尚未配置时展示真实状态，不生成虚拟账单。
- **不把 SaaS 订阅币种/网络与投资者认购 OP Mainnet USDT 混淆。**

### W-14｜本地存储及 Cookie 说明

保留当前本地/会话存储说明、政策入口及目前可用的操作，不虚构尚未存在的可选追踪同意功能。具体 Cookie 分类同意要求根据实际网站功能与适用法律另行确定；本轮不增加营销科技/复杂隐私控制作为 V1 主业务产品。

### W 增量｜统一投资平台介绍（`/investor-platform`）

此页面不增加到历史 W-01～W-14 编号中。

- 标题建议：「统一投资入口 · V1 产品规划中」；开放状态仍为「筹备中」。
- 投资者侧：「未来可在独立平台查看适用地区、获准展示的不同 Issuer Offering，并逐项完成资格判断。」
- Issuer 侧：「企业可保留自有门户，也可选择针对具体 Offering 申请统一平台展示，平台独立审核。」
- 当前没有真实 Offering 时，不提供虚构「立即认购」「钱包付款」按钮，也不宣称现已公开交易。
- 明确 M/V 账户独立，Issuer 企业登录不等于投资者登录，M 也不是二级交易市场。

## 五、官网 → SaaS 关键状态流（全局唯一口径）

| 状态/意图 | 用户看到的下一步 | 不能出现的错误体验 |
|---|---|---|
| 首次访客点击「免费开始」 | 统一邮箱验证码入口 | 再问「注册还是登录」并要求不同表单 |
| 新邮箱 OTP 成功 | 自动建账号 → 工作台 → 创建企业 | 直接称 Free 已开通 / 立即支付 Standard |
| 旧邮箱 OTP 成功 | 进入同一账号 → 该企业当前状态 | 要求重复注册、重新选择多个企业 |
| 无企业 | 创建企业并进入五步 KYB | 循环跳转官网注册 |
| KYB 草稿/待补件 | 回到原申请对应步骤 | 创建第二个企业或清空旧草稿 |
| KYB 审核中 | 查看审核状态 | 将审核中当作 Free 已授权操作 |
| KYB 通过且有效 Free | 进入 Asset/Instrument/Offering 正式资料准备 | 展示 Sandbox 模拟交易为套餐功能 |
| Free 点击 Standard | 企业管理 → 订阅管理 → 月/年及 USDT/法币 | 新企业、独立商业 KYB、多企业选择 |
| Standard 订阅支付成功 | 显示相应订阅权益；发行仍需对应业务准入 | 直接显示「发行成功」 |
| Standard 到期/宽限/降级 | 清晰说明存续、冻结新发行、历史只读与恢复路径 | 把降级 Free 当成新 Free 可编辑 |
| 外部服务/注册/付款尚未开放 | 明示当前不可用及可用的了解/返回入口 | Mock 表单假成功或无限点击 |
