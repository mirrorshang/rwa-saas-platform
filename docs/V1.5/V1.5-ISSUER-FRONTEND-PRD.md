## 9. UI-Ready 详细规格：Asset 创建与编辑（八种模板）

本节把第 4 节的模板方向细化为前端可实现规格。只约束页面、字段、交互、前端校验和 Mock；不定义 API、数据库或真实资料核验。Asset 模板描述底层资产事实，Instrument 描述投资者取得的权益，两者不得互相代填。

### 9.1 页面结构与操作

**页面容器**：沿用现有 \`BusinessWorkspace\` 全页工作区，不改成 Drawer，不新增一级导航。沿用 Issuer 现有色彩、字体、表单控件、按钮、状态标签、提示条和间距体系；本批不重做全局视觉。仅桌面 Web，按现有桌面内容区排版，不另做移动端页面。

**新建/编辑统一采用真实四步表单**（当前源码的四步进度条是静态展示，所有字段实际堆在同一页；V1.5 应让步骤真正可前进/返回）：

| 步骤 | 页面标题 | 内容 | 前进条件 |
|---|---|---|---|
| 1 | 基本信息 | 资产模板选择、资产名称、所在地、资产描述 | 模板、名称、所在地已填 |
| 2 | 资产资料 | 仅显示当前模板的专属字段 | 当前步必填字段通过；条件字段按下方规则 |
| 3 | 证明材料 | 按模板展示必需/选填文件清单、文件名和状态 | 必需文件已添加；文件扫描状态可在此步显示 |
| 4 | 确认预览 | 按分组只读展示已填写信息、缺项、文件状态和重要提醒 | 可保存草稿；资料检查通过后才可标记 Ready |

- 顶部显示步骤名称和当前进度；已完成步骤可返回修改，未完成步骤不可跳过。返回不清空数据。
- 每一步均提供「上一步」「下一步」「保存草稿」；最后一步提供「保存草稿」和「保存并检查资料」。
- 「保存草稿」允许资料不完整，但至少要求资产名称和所在地；保存后状态为 Draft。
- 「保存并检查资料」执行全部模板字段校验及 Mock 文件可引用检查。通过后状态为 Ready；不通过仍为 Draft，并列出缺项，点击缺项可返回对应步骤/字段。
- 「Ready」只表示前端资料完整且 Mock 文件检查通过，不表示权属真实、估值有效、法律审查通过或具备发行许可。
- 「填充示例数据」放在表单顶部或步骤 1 操作区；只填空字段、不覆盖用户已输入内容；已有内容时先确认。示例文件仅供 QA/演示环境使用并标记为演示文件；正常业务页面不提供「模拟添加文件」按钮，模拟扫描/文件状态由独立 QA 控制台触发。
- 新建过程中更换模板，如已填写模板专属资料或添加文件，先提示将清除不兼容的专属字段和文件；确认后清除，取消则保留。已保存 Asset 的模板类型锁定，不提供直接改型。
- 已被确认 Offering 引用的 Asset 不允许直接覆盖；保留当前保护提示。已关联 Instrument 但未被确认 Offering 引用时，修改 Asset 后将 Instrument 标回 Draft，并提示需要重新检查上游资料。
- 每类文件一项清单支持一个文件记录；多页材料应合并为一个 PDF。允许 PDF、PNG、JPG/JPEG；文件大小限制沿用当前前端统一上传限制，不另设不同模板规则。
- 文件状态仅显示「待扫描」「可引用」「异常」等 Mock 状态。页面不显示冗长产品注释；只在条件字段旁给出简短、直接的说明。

- 所有数值字段拒绝负数；数量、面积、重量、股数等必须大于 0。金额字段按币种显示精度，不用浮点展示造成的静默取整。

- 所有模板均支持「填充示例数据」；示例值与示例文件必须显式为演示数据，填充不得覆盖手工输入。

## 10. UI-Ready 详细规格：Instrument 权益结构（3 种模板）

本节沿用当前原型的三种选择：股权、债权、收益参与权。三者是投资者权益配置模板，不等于全球统一的法律工具分类。历史批准文件中 A 债权/B SPV 实体权益的原文不修改；V1.5 在当前前端中保留第三种「收益参与权」配置，但其具体法律性质必须由适用法域和实际专业责任主体确定，前端不得显示法律有效性结论。

### 10.1 资产与权益结构的关系

- 一个 Asset 在 V1.5 前端只允许关联一套当前有效 Instrument；不允许同一 Asset 重复创建多套并行权益结构。
- Instrument 必须选择已有 Ready Asset；Draft Asset 不出现在可选列表中。若无可选 Asset，显示空状态及「先完成资产资料」入口。
- Asset 记录底层资产事实；Instrument 记录投资者取得的权利。底层资产本金、估值、租金、股权数量不能自动复制为投资者本金、收益或法律权利。
- Equity 统一在界面显示为「股权（SPV 权益）」，明确投资者取得的是 SPV/持有主体的股权，不暗示投资者直接取得底层房产、金属或目标企业的登记产权。
- 每种 Instrument 的责任主体必须明确：债权为偿付义务主体；SPV 股权为 SPV/持有主体；收益参与权为承担合同分配义务的主体。
- Ready 只代表前端字段和 Mock 核心协议检查通过，不代表 SPV 已成立、债权真实有效、收益权依法可转让或发行已获批准。

### 10.2 Asset 模板与权益结构适用矩阵

创建 Instrument 时，根据已选 Asset 模板过滤不适用选项；不允许所有资产无差别显示全部权益类型。

| Asset 模板 | 股权（SPV 权益） | 债权 | 收益参与权 | 产品规则 |
|---|---|---|---|---|
| 住宅物业 | 可选 | 可选 | 可选 | 股权代表持有物业的 SPV 权益；收益参与按合同净租金/其他明确收益口径 |
| 写字楼 | 可选 | 可选 | 可选 | 同房地产通用规则 |
| 商业商铺 | 可选 | 可选 | 可选 | 同房地产通用规则 |
| 工业园/仓储物流物业 | 可选 | 可选 | 可选 | 同房地产通用规则 |
| 非上市企业普通股权 | 可选 | 可选 | 可选 | 股权代表持有目标公司股份的 SPV 权益；不把底层目标公司股份自动登记给投资者 |
| 单笔企业借款债权 | **不提供** | 可选 | 可选 | 债权资产不得选择股权（SPV 权益）；收益参与仅按可核验的回款现金流配置 |
| 企业应收账款 | **不提供** | 可选 | 可选 | 应收款不得选择股权（SPV 权益）；收益参与仅按该笔应收款实际回款配置 |
| 贵金属 | 可选 | 可选 | **不提供** | V1.5 不把无经营现金流的金属持有自动包装为收益参与权；如未来存在独立经营现金流，另行扩展 |

- 不适用类型直接不显示，不用禁用卡片制造选择困惑；选择列表下方仅显示一句「可选权益结构由资产类型决定」。
- 此矩阵只处理产品模型中明显不匹配的组合，不替代法域法律审查；不在矩阵内的资产类型保持「暂未开放」，不能借用最相近模板。
- 不提供用户自定义任意组合、复合 Instrument、分层优先级、可转债、收益瀑布或多类权益并存。

### 10.3 共通字段

| 字段 | 控件 | 必填 | 校验/行为 |
|---|---|---|---|
| 关联 Asset | 下拉/选择卡片 | 是 | 仅显示 Ready 且尚未有当前 Instrument 的 Asset；显示名称、模板、所在地和状态 |
| 权益结构类型 | 选择卡片 | 是 | 按 10.2 矩阵过滤；默认不自动选中 |
| 权益结构名称 | 单行文本 | 是 | 2–80 字；用于列表、详情、Offering 选择器 |
| 权利/义务责任主体 | 单行文本 | 是 | 根据权益类型提示「偿付主体」「SPV/持有主体」或「分配义务主体」 |
| 投资者取得的权利描述 | 多行文本 | 是 | 清楚描述投资者取得什么权利；不允许仅写「享有资产收益」 |
| 权益起始日 | 日期 | 是 | 必填；不得晚于适用结束日 |
| 权益期限/到期方式 | 单选 | 按类型 | 股权可选无固定到期/约定期限；债权必须有到期日；收益参与权必须明确结束日或终止条件 |
| 法定权益总量 | 数字 | 是 | 大于 0；整数，不允许小数份额 |
| Token 最大份数 | 整数 | 是 | 大于 0；必须与权益总量精确整除 |
| 每 Token 对应权益量 | 自动计算 | 自动 | 只读展示；不可整除时阻止保存为 Ready |
| 核心协议 | 文件 | 是 | 股权/债权/收益参与权分别显示对应协议名称；Mock 状态可引用才可 Ready |

### 10.4 股权（SPV 权益）字段

| 字段 | 控件 | 必填 | 校验/行为 |
|---|---|---|---|
| SPV/持有主体法定名称 | 单行文本 | 是 | 不从 SaaS 企业名称自动推定；如相同需显式确认 |
| SPV 注册国家/地区 | 文本/地区选择 | 是 | 不推断注册地或适用法域 |
| SPV 注册编号 | 单行文本 | 是 | 记录申报编号；不代表已核验成立 |
| 股份类别 | 下拉 | 是 | V1.5 仅普通股；优先股等复杂类别暂不开放 |
| 发行/代表股份数量 | 整数 | 是 | 大于 0；与 Token 份数精确映射 |
| 表决权 | 单选 | 是 | 有/无；选择有时填写每份股份对应表决权数量 |
| 分红权 | 单选 | 是 | 有/无；选择有时填写分配依据说明，不填写固定保证收益率 |
| 清算剩余财产分配权 | 单选 | 是 | 有/无；说明适用顺位或引用协议，不设计复杂瀑布 |
| 转让限制 | 下拉+说明 | 是 | 无/有；有时说明限制依据 |
| 退出/清算安排 | 多行文本 | 是 | 描述约定安排；不强制设置固定到期日或固定回购价格 |

核心协议：SPV 股东/成员协议或等效权益文件必需；SPV 注册证明及股份/成员权益证明作为必需材料。页面显示「待补充/待检查」，不显示「SPV 已成立」或「投资者已成为股东」。

### 10.5 债权字段

| 字段 | 控件 | 必填 | 校验/行为 |
|---|---|---|---|
| 债权/偿付义务主体 | 单行文本 | 是 | 明确谁向投资者承担偿付义务，不默认等于底层债务人 |
| 投资者本金总额 | 金额 | 是 | 大于 0；币种统一显示 U |
| 计息方式 | 单选 | 是 | 固定利率/无息 |
| 固定年利率 | 百分比 | 条件必填 | 固定利率时必填且大于 0；无息时隐藏 |
| 计息规则 | 下拉 | 条件必填 | 固定利率时选择；V1.5 仅支持完整自然月按年利率÷12 |
| 付息频率 | 下拉 | 条件必填 | 固定利率时必填；V1.5 支持每月付息 |
| 本金偿还方式 | 下拉 | 是 | V1.5 仅支持到期一次还本 |
| 到期日 | 日期 | 是 | 必须晚于起始日；不使用 Offering 结束日代替 |
| 提前偿还/逾期说明 | 多行文本 | 否 | 记录适用约定；不配置复杂罚息公式 |

固定利率模式下，年利率、计息规则、付息频率必填；无息模式下不显示利率、计息和付息频率，不生成利息预览。两种模式均保留本金到期偿还。V1.5 不支持分期摊还、多段利率、浮动利率、复利或复杂罚息。

核心协议：投资者债权/认购协议必需。债权本金与底层 Asset 未偿本金分开录入；二者不一致时显示差异提醒，不自动改写任何一方。

### 10.6 收益参与权字段

| 字段 | 控件 | 必填 | 校验/行为 |
|---|---|---|---|
| 分配义务主体 | 单行文本 | 是 | 明确承担合同分配义务的主体 |
| 收益来源 | 多行文本 | 是 | 明确来自租金、经营回款或指定应收款回款等 |
| 可分配收益口径 | 固定选项 | 是 | V1.5 统一按「可分配净收益」；不同时提供复杂毛收入/净收入瀑布 |
| 扣除项说明 | 多行文本 | 是 | 说明在形成可分配净收益前扣除的税费、运营成本或其他项目 |
| 投资者参与比例 | 百分比 | 是 | 大于 0 且不超过 100%；不得超过合同允许总比例 |
| 分配频率 | 下拉 | 是 | 每月/每季度 |
| 权益开始日、结束日 | 日期 | 是 | 结束日晚于开始日 |
| 退出/终止安排 | 多行文本 | 是 | 说明期限届满、资产处置或其他约定终止方式 |

核心协议：收益参与协议必需。页面不显示固定利率、保证收益率或自动还本字段；不得将收益参与权描述为底层资产所有权或债权本金。无可核验现金流来源时，不允许保存为 Ready。

### 10.7 创建、编辑与检查交互

- 创建页采用三段式信息结构：①选择 Ready Asset 与可用权益类型；②填写该类型的权利/现金流条款；③设置权益总量、Token 份数、添加核心协议并预览。
- 选择 Asset 后显示其模板、所在地、估值/币种和 Ready 状态；权益类型卡片只显示兼容项。切换 Asset 时如已填写条款，先确认清空不兼容字段。
- 选择权益类型后只展示该类型字段；切换类型时提示将清空旧类型专属字段，确认后清空，取消保留。
- 每步均可返回；「保存草稿」允许缺项；「保存并检查」校验所有字段、整数映射和核心协议 Mock 状态。
- 一键「填充示例数据」只填空字段，不覆盖手工内容；示例协议文件显式标为演示文件。
- Asset 已有当前 Instrument 时，不显示在新建选择器中；从 Asset 详情进入时直接打开已有 Instrument 详情/编辑入口，避免重复建档。
- Instrument 被已确认 Offering 引用后，重要条款不允许原地覆盖；页面提示需保留当前引用和历史记录。V1.5 不增加复杂版本影响分析工作台。
- Ready 后可进入 Offering 创建入口；Draft Instrument 只可保存和编辑，不可用于 Offering 最终确认。

### 10.8 Instrument 校验与验收用例

| 用例 | 操作 | 预期 |
|---|---|---|
| I01 | 选择 Draft Asset 创建 Instrument | 不可选择；引导先完成 Asset |
| I02 | 选择债权/应收账款 Asset | 不出现股权（SPV 权益）选项 |
| I03 | 选择贵金属 Asset | 仅出现股权（SPV 权益）和债权 |
| I04 | 选择房地产 Asset | 出现三种权益结构 |
| I05 | 选择非上市企业普通股权 Asset | 出现三种权益结构；股权说明为 SPV 持有目标股权 |
| I06 | 创建固定利率债权 | 必须填写利率、计息方式、付息频率和到期日 |
| I07 | 创建无息债权 | 不显示利率和付息频率，不产生利息预览，仍要求本金到期安排 |
| I08 | 创建股权（SPV 权益） | 有表决/分红/清算权选项；不显示固定利率或强制到期日 |
| I09 | 创建收益参与权 | 有收益来源、净收益口径、扣除项、比例和周期；不显示固定利率/保证本金 |
| I10 | Token 份数不能整除权益总量 | 阻止 Ready，明确显示差值/计算结果，不静默取整 |
| I11 | 缺少核心协议或文件异常 | 允许保存 Draft；阻止 Ready |
| I12 | Asset 已存在当前 Instrument | 阻止创建第二套并行 Instrument |
| I13 | Instrument 被已确认 Offering 引用后尝试修改条款 | 阻止静默覆盖并显示原因 |

**本节完成判定**：三种权益结构的适用资产、字段、条件、校验、文件、交互和验收用例已明确；真实法律适用性、法定成立和链上执行不属于本节前端规格。


## 11. UI-Ready 详细规格：跨页面流程、状态与异常

### 11.1 业务入口与页面关系

不新增一级/二级导航，不把 Asset、Instrument、Offering 合并为一个对象。沿用当前九大模块和「资产管理」入口，按现有页面容器展示列表、详情和新建工作区。

| 当前页面 | 主操作 | 下一步 |
|---|---|---|
| 资产管理列表 | 搜索、筛选、查看详情、新建资产 | 新建后进入 Asset 详情 |
| Asset 详情 | 查看基本信息、模板资料、文件状态、缺项；编辑 Draft；运行资料检查 | Ready 后显示「创建权益结构」 |
| Instrument 详情 | 查看权益类型、权利条款、权益总量、Token 映射、核心协议和缺项 | Ready 后显示「创建发行方案」入口 |
| Offering 创建入口 | 选择 Ready Instrument，沿用现有 Offering 表单和确认预览 | 本批只补充正确的上游状态守卫，不重做 Offering 页面 |

### 11.2 状态与按钮规则

| 对象状态 | 页面显示 | 允许操作 | 不允许操作 |
|---|---|---|---|
| Asset Draft | Draft 标签、缺项数量、缺项清单 | 编辑、保存草稿、运行资料检查 | 创建 Ready Instrument |
| Asset Ready | Ready 标签、最近一次检查结果 | 查看、编辑未被确认 Offering 引用的资料、创建 Instrument | 实质修改后自动回到 Draft，需重新检查；将 Ready 理解为权属/法律审核通过 |
| Instrument Draft | Draft 标签、缺项数量 | 编辑、保存草稿、运行权益检查 | 创建/最终确认 Offering |
| Instrument Ready | Ready 标签、权益映射结果 | 查看、进入 Offering 创建 | 将 Ready 理解为法律发行许可 |
| 已被确认 Offering 引用 | 引用状态和 Offering 名称 | 查看历史资料 | 直接覆盖已引用的关键字段 |

- Asset/Instrument 的 Draft 与 Ready 是前端资料状态，不增加 PendingReview、LegalApproved 等容易误导的状态。
- 保存草稿只做最小字段校验，不自动变 Ready；保存过程中按钮显示「保存中」并禁用，防止重复点击。
- 资料检查失败时，返回字段级缺项；成功时显示 Ready 和检查时间。
- 修改 Asset 后，若已有 Instrument，Instrument 自动回到 Draft 并显示「上游资产资料已变更，请重新检查」。
- 修改 Instrument 的关键权益条款后，若尚未被确认 Offering 引用，重新执行完整检查；已被确认 Offering 引用时阻止直接覆盖。
- Offering 创建入口只允许选择 Ready Instrument；Draft 选项不显示，不以灰色禁用列表制造困惑。

### 11.3 空状态、错误与异常反馈

| 场景 | 页面反馈 | 操作 |
|---|---|---|
| 尚无 Asset | 简洁空状态：「还没有资产」+「创建资产」主按钮 | 直接进入新建 Asset |
| 无 Ready Asset 可创建 Instrument | 「暂无可用资产，请先完成资产资料」 | 返回资产列表或打开 Draft Asset |
| Asset 缺字段 | 显示缺项名称、所在步骤和字段定位 | 点击缺项定位到字段 |
| 数字/日期校验失败 | 字段下方显示具体原因，字段边框提示错误 | 用户修改后即时清除错误 |
| 必需文件缺失/异常 | 在文件清单对应行显示状态和原因 | 替换文件或通过 QA 控制台更新演示扫描状态 |
| 更换模板会丢失资料 | 确认弹窗列明将清除「模板专属字段和文件」 | 确认后切换；取消保留原内容 |
| 关闭/返回时存在未保存修改 | 离开确认弹窗 | 继续编辑或放弃本次未保存内容 |
| Asset 已被确认 Offering 引用 | 页面顶部显示只读保护提示 | 不提供覆盖保存操作 |
| 本地 Mock 保存失败 | 明确提示保存失败，保留当前表单输入 | 用户可重试；不得显示保存成功 |

### 11.4 页面操作文案

| 场景 | 主按钮 | 次按钮/反馈 |
|---|---|---|
| 新建 Asset | 下一步 / 保存草稿 | 上一步；填充示例数据 |
| Asset 预览 | 保存草稿 / 保存并检查资料 | 返回修改 |
| Asset 详情 Draft | 编辑资料 / 运行资料检查 | 查看缺项 |
| Asset 详情 Ready | 创建权益结构 | 编辑资料 |
| 新建 Instrument | 下一步 / 保存草稿 | 上一步；填充示例数据 |
| Instrument 预览 | 保存草稿 / 保存并检查权益 | 返回修改 |
| Instrument 详情 Ready | 创建发行方案 | 查看条款 |
| 不可覆盖的已引用对象 | 不显示保存/覆盖主按钮 | 查看引用来源和限制原因 |

所有按钮必须有真实前端动作；没有动作的按钮不得显示为可点击。成功/失败反馈同时更新页面状态，不允许仅 Toast 显示成功而列表和详情没有变化。

## 12. UI 视觉与交互规范

- 复用当前 Issuer 原型的设计变量、字体、背景、边框、圆角、按钮、输入框、状态标签和提示条；V1.5 不重做整套 Design System。
- 新建/编辑 Asset 使用全页工作区；步骤条、页面标题、表单分组和底部固定操作区层级清楚。长表单按逻辑分组，不把所有字段挤成一列超长页面。
- 桌面宽屏下优先两列字段布局；地址、描述、权利说明、合同说明等长字段占整行。窄桌面窗口可自然降为单列，不做移动端导航或手机专用布局。
- 必填标记统一使用星号；选填字段不重复写「选填」提示，除非其条件关系容易误解。字段名直接表达业务含义，单位和币种紧邻输入框。
- 错误提示放在对应字段下方；跨字段错误（如日期区间、总量整除）放在相关字段组下方，并提供可理解的原因。Toast 只用于保存成功等短反馈，不代替字段错误。
- 说明文案只保留完成当前操作必需的信息；删除装饰性说明、开发注释、无意义占位文字和虚构业务文案。
- 页面业务区不展示「模拟添加文件」等 QA 按钮；一键填充示例数据作为明确的演示辅助入口。模拟文件扫描、Mock 付款等测试动作集中在独立 QA 控制台，不混入正常业务页面。
- 全站只做桌面 Web；不新增移动端页面、移动端导航或移动端专属交互。

## 13. V1.5 UI-Ready 交付验收清单

V1.5 产品设计文档只有同时满足以下条件，才可标记 UI-Ready：

1. 八种 Asset 模板均有字段、控件、必填/选填、条件显示、校验、材料清单和 Ready 守卫。
2. 三种 Instrument 模板均有适用 Asset 范围、字段、条款、条件校验、核心协议和 Token 整数映射规则。
3. Asset → Instrument → Offering 的入口、前置条件、状态变化和失败路径一致。
4. 所有保存、返回、切换模板、未保存离开、重复创建和已引用对象保护都有明确交互。
5. 空状态、加载/保存中、成功、失败、字段错误、文件异常和无可选上游对象均有页面反馈。
6. 页面视觉沿用现有设计系统，字段布局、按钮层级、提示位置和桌面窗口适配有明确要求。
7. 一键示例填充不覆盖手工数据；QA Mock 能力与正常业务页面分离。
8. 每项关键功能都有可复现的正向和负向验收用例；未实际运行的用例不得标记 PASS。
