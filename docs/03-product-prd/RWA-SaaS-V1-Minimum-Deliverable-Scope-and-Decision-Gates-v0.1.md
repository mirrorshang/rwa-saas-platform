## 一、为什么另建本 Draft

SCOPE-001～052 已批准 22 模块 187 项功能的**范围方向**；SCOPE-053～058 又批准对 P0 必要业务进行共享 UI/工作流/合法外部执行的**最小实施原则**，并要求针对首发 Instrument 检查 P1 必要性。另已确认 **ARCH-001 与修订后的 SCOPE-060**：Issuer SaaS 自首期采用 API-First / Contract-First 共用业务核心；商业 Open API/SDK 的实际交付批次仍未批准，SCOPE-059、061、062 已在后续独立批准，详见本文件第七节。**并没有批准具体哪一个设计页面、外部签名主体、发币/支付/登记方案或完整 V1 交付列表**。

本文件把原 187 条功能逐一引用，不改动既有功能 ID 和 P0/P1/P2/V2/待定分级。新列的最小实现建议、外部责任模板及未决门**一律是 Draft 提议**。保留 M07 的必要合约级转让限制，但 M14 用户间转让产品 V1 不开发；M15/M16 实际商业交付批次未定。

## 二、目标业务闭环与安全底线

客户申请/合同授权开通 SaaS → Asset/Instrument 权利资料与审核 → Project 及 Offering 创建、审批与发布 → 机构投资者门户展示 → 必要 KYC/KYB/AML 与 Offering 专属资格判断 → 报价、签署、认购、额度预留 → 指定链 USDT/USDC 真实付款监测/对账 → 依据事前批准规则与逐笔条件自动配售 → 合法权威登记与实际链上 RWA Token Mint/交付 → 投资者持仓和必要存续期权益管理。

- M10 发预留请求，M12 对已批准额度/占用/配售账本有唯一业务核算责任。
- PaymentInstruction、OnchainTransfer、Reconciliation、Allocation、Register、Token、Refund 是不同权威对象，不能通过一个“已完成”合并。
- 外部执行不得绕过获授权资金和法律责任主体；SaaS 不默认控制生产密钥或投资者资金。
- Unknown、迟到账、回调重复、退款和 Mint 的不确定结果必须可查询与审计，不能盲目重试。
- 本稿不能替代具体法域法律意见、生产安全审批或开发授权。

## 六、架构约束更新：ARCH-001 / 修订版 SCOPE-060（已确认原则）

[ARCH-001 决策记录](../../decisions/ARCH-001-api-first-unified-business-core.md) 已获产品负责人确认。本草案全部 187 项「最小实现」均须遵循下列**已批准的横向架构原则**：

- **Issuer SaaS V1 是 API-Ready**：Web 端通过已定义契约的内部应用 API（按需 BFF）使用服务端共用业务服务。内部/外部调用共享业务状态、Guard、权限、审计、错误/幂等及必要事件机制；不得为 White-label 或 M16 Open API 再做独立的发行/认购/配售/Token 业务核心。
- **内部 API 不等于公开 API**：对外 API 必须额外校验调用者与授权、tenant/organization/resource/field 级权限、速率限制、法域/Offering 可见性及敏感动作许可。不会因为内部已实现一个接口就自动对外开放。
- **首期契约准备**：详细功能 PRD 需提出复用业务命令/查询、关键业务实体 ID、必要字段、权限/作用域、异步状态和幂等/错误语义、事件/Webhook（适用时）的产品级要求；具体 URL、接口协议、生成 SDK 和部署属于第 07 份技术设计。
- **不强制微服务**：模块化单体亦可满足原则；分层/BFF、网关与开发者对外接口的最终实现由架构阶段决定。
- **M16 商业交付里程碑和日期仍待决策**：本草案 G-06 的商业对外版本批次继续**待定**；Issuer SaaS V1 内部 API 安全和业务复用是架构底线，不代表完整商用开发者门户、SDK/Sandbox 同期交付或已明确延至 V2。
- **其他提案不自动批准**：SCOPE-059、SCOPE-061、SCOPE-062 现已另经产品负责人明确批准（[SCOPE-059～062 正式决策](../../decisions/SCOPE-059-062-issuer-v1-delivery-and-validation-decisions.md)）：White-label 独立交付里程碑；V1 持续购买优先完整实现；通用多资产 PRD 先行、冻结真实 V1 必交清单之前必须选择 1～2 类参考 Instrument。具体排期和首发法域仍待决定。
