# RWA SaaS｜V/M 投资者平台 PC Web 最终产品 PRD 与工程交接

> DEV-08｜2026-11-27｜PR #17 Draft 审核稿。依据已批准的 [共用 UI-Ready PRD](V-M-SHARED-UI-READY-PRD-v0.1.md)、[M 独有页 PRD](M-UNIQUE-PAGES-UI-READY-PRD-v0.1.md)、[一致性与验收基线](CROSS-PLATFORM-CONSISTENCY-AND-ACCEPTANCE-v0.1.md)及 DEV-02～07 实测原型编写。本文件记录**实际已实现的 Mock 前端**与后续生产产品行为；不修改冻结决策，也不把演示状态当作真实金融事实。

## 1. 产品、范围与术语

- **V**：单 Issuer 品牌投资者平台，本原型入口为海岚 `/v/harbor` 与杉衡 `/v/cedar`。首页强调 RWA 与本企业机会。**M**：`/m`，跨 Issuer 投资机会市场；仅展示当前 M 渠道有效公开 Listing。两者共用详情、账户、认购、投后、客服组件，品牌、公开范围、账户和本人记录按渠道隔离。
- 范围为 PC Web、橙黑极简金融视觉、前端本机 Mock。六类底层资产模板：住宅物业、写字楼、商铺、工业园/仓储物流、非上市普通股权、单笔企业借款债权；三种权益：收益参与权、股权、债权。**模板展示不等于可投资 Offering**。目前可演示认购的只有住宅 `residence-01` 与债权 `debt-01`；M 只显示这两项 active Listing。其他四项为 V 渠道「即将开放」字段模板，不进入认购。
- 关键对象：**Asset** 描述底层资产，**InstrumentVersion** 确定投资者法律权益、收益及限制，**Offering** 确定本期价格、容量、时间和认购状态，**Listing** 确定某渠道是否允许公开。Token 为份数/交付展示，不能代替法律持有人登记。`U` 为本机金额显示单位；生产付款产品规则是 OP Mainnet USDT，正式目标合约须先核实。
- 原型不会真实建号、发送邮件、验证身份、生成 MPC 私钥、签署法律文件、转账、配售、登记、Mint/交付 Token、支付收益、办理退款或发送客服通知。其可点击行为只在浏览器内保存或读取演示记录。真实投资者资格、披露、权益、资金与法律事实仍须权威来源支持。

## 2. 信息架构、导航与路由

下表中 `{base}` 为 `/m` 或 `/v/{issuerSlug}`，`{id}` 为相应对象 ID。正常页共用顶部「首页 / 投资机会 / 我的投资」、右侧「帮助 / 消息 / 登录或我的账户」，页脚「风险提示 / 帮助中心 / 使用条款 / 隐私政策」。`/demo` 无正常页面入口。根路径 `/` 为三渠道选择页；未知路由显示受控空态。

| 页面组 | 实际路由 | 入口与主要去向 |
| --- | --- | --- |
| 市场 | `{base}`；`{base}/opportunities`；`{base}/opportunities/{offeringId}`；`{base}/issuers/{issuerSlug}` | 首页分类/卡片→列表或详情→企业资料、认购、披露；企业页→当前渠道项目。M 企业直达也受 Listing 可见性保护。 |
| 账户 | `{base}/account`、`/account/profile`、`/account/kyc`、`/account/wallets`、`/account/security`、`/account/tickets` | 登录后进入账户侧栏；KYC、钱包、工单各有子页；从原项目进入登录可安全返回原渠道页面。 |
| 四步认购 | `{base}/subscribe/{offeringId}/quote`、`/documents`、`/payment`、`/progress` | 详情行动栏→金额→文件→付款→进度；只接受当前渠道可见且「认购中」的 Offering。Step 4 可独立预览，访问记录不等于业务完成。 |
| 我的投资 | `{base}/investments?tab=orders\|holdings\|returns`；`{base}/investments/orders/{orderId}`；`/holdings/{orderId}`；`/returns/{eventId}` | 三个标签分别进入本人订单、登记持仓、收益/本金；详情连向相关订单、持仓、客服。 |
| 支持 | `{base}/support`；`{base}/account/tickets/{ticketId}` | 顶部帮助、订单联系支持→工单表单→工单详情；`/account/tickets` 是本人列表。 |
| 内容 | `{base}/messages`、`/messages/{messageId}`；`{base}/disclosures`、`/disclosures/{offeringId}/{index}`、`/disclosures/announcements/{noticeId}` | 消息→关联业务；披露→可读文件或公告；文件详情可下载 Mock 文本。 |
| 辅助 | `{base}/terms`、`{base}/privacy`；`/demo` | 前两者**仅占位**，不得当作正式条款；后者为独立本机 Mock 场景控制台。 |

主路径：**首页→列表→详情→登录/KYC→报价→阅读文件→待付款订单→付款请求→独立进度→订单→登记持仓→收益或本金事件**。异常从付款、订单或持仓进入帮助/工单；消息只提示并回到原业务页复核，不改变业务事实。

### 2.1 共用显示与验收规则

- 以下逐页条目的默认复用规则：**同一页面结构与业务交互复用，V 显示当前 Issuer 品牌及其资产模板，M 显示跨 Issuer 中获准公开的项目**；登录态、订单、工单、消息及收益事件按账户和渠道隔离。同一 Offering 的 V/M 模拟可售容量共享。若条目另有限制，以该条目为准。
- 公开项目、详情、企业及文件均不得通过直接输入 URL 绕过渠道限制；当前账户不拥有的订单、持仓、工单、消息或事件显示不可访问空态。未知、待核实、失败和未开始不能显示成已完成。金额、数量、时间及版本在卡片、详情、认购、订单中应保持同一 Offering 快照的含义。
- 各页金融文案均标 `Mock`、`待核实`、`以项目文件为准` 等适当限定；不承诺收益或本金。视觉验收以 1280/1440/1920px PC 截图和 [DEV-07 综合验收](../../apps/investor-portal/qa/DEV-07-ACCEPTANCE.md)为证。

## 3. 逐页产品规格（按实际原型）

### P00 入口选择、独立演示控制台、未知页面

- **目的/入口/结构**：`/` 展示 V 海岚、V 杉衡、M 三入口；`/demo` 供开发验收直接访问，含场景、账户/KYC/MPC、订单/工单、收益/本金 Mock 控件；未知 URL 展示受控返回入口。
- **字段/控件/校验**：控制台可选渠道、本人订单/持仓/工单、模拟结果。仅已有本人记录可操作；分配金额须有效，退款与业务阶段分开。普通页不显示控制台链接。
- **主次操作/跳转/状态**：选渠道进入其首页；应用场景后跳至指定页面，清除页面场景不会删除账户记录。控制台的“成功”仅为模拟结果，不能自动转为生产事实；无账户或记录时控件不可用。无弹窗。
- **金融文案/复用/验收**：明确“只改变本机前端 Mock 场景”；三渠道可进，正常导航与 Footer 无 `/demo`，跨渠道结果互不污染。

### P01 V/M 首页

- **目的/入口/结构**：`{base}`；Hero 说明真实资产平台、分类入口、当前可见机会卡片、可信与风险提示、页脚。V 品牌位于左上，M 为多 Issuer 市场。
- **字段/条件**：卡片优先项目名称、资产类型、权益、最低认购额、收益机制、期限/分配周期、状态及 Issuer；图片仅视觉示意。只按当前渠道可见项目渲染，1～2 项保持合适宽度；没有公开项目显示空态，不补虚构 Offering。
- **操作/状态/验收**：主按钮“浏览投资机会”进列表；分类附带筛选参数，卡片进详情，更多进列表。无表单、弹窗。M 无 Listing 时空态；不得在 V 首页堆企业介绍或向 M 泄漏 V 待开放模板。

### P02 投资机会列表

- **目的/入口/结构**：`{base}/opportunities`；标题与结果数、搜索与筛选、投资卡片、必要时分页、空态。
- **字段/校验**：搜索项目/资产名称；资产大类、子类、权益、地区、认购状态、排序（最新上架/截止时间），M 另有 Issuer；筛选条件进入 URL，改变条件回第 1 页，分类变化重置子类；每页最多 20 条。筛选仅作用于当前渠道可见数据。
- **操作/状态/文案/验收**：主操作“查看项目详情”，次操作“清空筛选”、翻页；无弹窗。无匹配结果给清空入口；Mock 加载/异常场景各有明确状态，不呈现未经核实价格。卡片金融字段与详情一致，M 无有效 Listing 或 V 跨 Issuer 项目不可泄漏。

### P03 投资机会详情

- **目的/入口/结构**：`{base}/opportunities/{offeringId}`，来自卡片或直达；面包屑、项目标题/Issuer/状态、资产视觉、资产概览、权益收益、发行认购、企业、文件风险，以及右侧固定认购信息。
- **字段/条件**：Asset 版本及事实字段、InstrumentVersion 与权益条款、Offering 状态/起止/容量/单价/最低额/版本，右侧期限或分配频率、对应权益核心回报机制。住宅展示合法可分配收益，债权展示合同利息与到期本金，股权展示法律权利、股息条件和退出限制。待开放 V 模板明确不可认购；M 无公开 Listing 或未知 ID 为受控空态。
- **控件/校验/操作**：章节锚点、企业链接、文件版本清单；右侧主操作“开始认购”仅在认购中、可售容量不少于最低份数且非预览模板时可用。未登录先到当前渠道登录并返回；已登录但 KYC 未过可预览步骤，正式提交受阻。暂停、结束、未知状态按钮禁用并说明原因。无弹窗；不从估值推断募集额或收益。
- **验收**：认购条件、风险、期限/周期与列表一致，企业链接只打开可见资料，跨渠道直达不泄漏项目。

### P04 企业资料

- **目的/入口/结构**：`{base}/issuers/{issuerSlug}`；从详情进入或直达；企业名称、演示法律名、简介、地区、业务方向、公开资料状态、当前渠道项目。
- **条件/操作/状态**：V 只允许本企业；M **只有该企业存在当前 M 渠道允许公开的有效 Listing** 才展示资料。其他情况给受控空态。项目卡进入详情，返回来源页为次操作；无输入、弹窗。企业认证不代表资产安全或收益担保，KYB/登记资料未经授权不公开。
- **验收**：M 直达未 Listing 企业、V 跨 Issuer 企业均不可见；刷新后守卫仍生效。

### P05 邮箱登录与账户概览

- **目的/入口/结构**：`{base}/account`；未登录显示邮箱、验证码、首次建号确认；已登录显示账户概览及侧栏。
- **字段/校验**：邮箱格式、六位验证码、5 分钟有效期、重发倒计时；页面显示固定演示码 `246810`，不发真实邮件。首次建号确认只是 Mock 界面说明，不是有效协议签署。账户概览显示邮箱、KYC、MPC、默认钱包；从详情或认购进入可返回同一渠道安全来源。
- **操作/状态/验收**：主操作“获取 Mock 验证码 / 验证并登录”，次操作“浏览投资机会”；错误在表单内显示。首次登录 KYC 未开始、MPC 创建中；V/M 不自动合并账户，未登录仍可浏览公开机会。无弹窗。

### P06 基本资料、KYC、钱包与安全

- **目的/入口/结构**：`/account/profile` 看邮箱、渠道、创建时间及个人/机构资料未提交；`/account/kyc` 看身份状态与原申请；`/account/wallets` 看 MPC 操作与绑定自有钱包；`/account/security` 看会话并退出。
- **字段/校验/条件**：KYC 状态：未开始、处理中、补件、通过、失败、过期、未知；提交/回跳不等于通过，处理中/未知只查询原申请。MPC 保留操作 ID，创建中/就绪/失败/未知/服务门控分列。自有地址须 `0x` 加 40 位十六进制字符，连接地址≠签名验证；Mock 挑战通过后才可设默认。默认钱包可在已就绪 MPC 与已验证自有钱包之间切换，付款钱包和 Token 接收地址仍需认购时分别确认。
- **操作/状态/验收**：KYC“开始/补件/重试/查询原申请”、MPC“查询原操作并模拟就绪”、自有钱包“连接并创建挑战 / 模拟签名验证 / 设为默认”、安全页“退出当前渠道账户”。无弹窗；错误、待核实、不可用均保留明确提示；不收集真实身份文件、私钥或助记词。

### P07 四步认购：金额、文件、付款、进度

- **目的/入口/结构**：仅 `{base}/subscribe/{offeringId}/{quote|documents|payment|progress}`；步骤导航、主内容、右侧 Offering/权益/单价/份数/总额摘要。直接进入 Step 4 允许看进度，但前几步仅可显示“已查看/未查看”，不得标为已签、已付款或已交付。草稿按渠道、企业和 Offering 隔离。
- **Step 1 金额**：输入正整数 Token 份数，不低于 `ceil(最低认购额/单价)`，不高于 Mock 上限及当前可售容量；显示单价、份数、金额、最低份数、可售容量。无效值禁用下一步；报价不预留容量，创建订单时重新核验，V/M 同 Offering 共用 Mock 容量。
- **Step 2 文件**：逐份展开可读的最小 Mock 正文，显示名称与版本并分别勾选“已阅读”。所有文件已读、当前渠道已登录且 KYC 已通过、数量有效时，才能模拟确认并创建待付款订单；保留原请求避免重复创建。阅读勾选与订单快照**均不是有效电子签署**；正式签署需求见第 6 节。
- **Step 3 付款**：有本人待付款订单后显示 OP Mainnet、USDT、未核实的 Offering 收款目标、应付金额；分别选择已就绪付款钱包和 Token 接收地址并确认。主操作“模拟发起 USDT 付款”只记录请求，不能标实收；原请求存在时禁重复。目标合约未核实，原型不调用真实钱包或转账。
- **Step 4 进度**：独立显示付款、配售、法定登记、Token 交付四阶段及原交易引用；无订单则四阶段“未开始”。模拟推进必须依次核实原付款、确认配售、登记、交付；任一未知/失败不能误报完成，可链接客服查原交易。步骤访问、前端勾选、付款发起与四个业务结果各自独立。
- **操作/异常/验收**：主路径为“核对法律文件→创建待付款订单→模拟付款→查看进度”；返回详情、上一步、联系客服为次操作。无弹窗。不可见/未开放 Offering 直达受控；无订单、KYC 未通过、数量超限、付款失败/未知均有明确阻断。刷新后本人 Mock 订单保持，跨渠道草稿与订单不混用。

### P08 我的投资与订单详情

- **目的/入口/结构**：`/investments` 默认订单标签，可切 `?tab=holdings|returns`；`/investments/orders/{orderId}` 看订单快照、四阶段进度、付款钱包/接收地址、交易/异常/退款引用、文件版本。
- **字段/条件**：订单列表显示 Issuer、项目、编号/创建时间、份数、金额、状态。详情冻结单价、份数、金额、创建/有效期、文件阅读 Mock 与法律签署无效标记；业务进度逐项独立。异常有回滚、重组待核、履约失败等演示，退款资格审核、处理中、已核实到账分开，不能由付款失败或工单关闭推断退款。
- **操作/状态/验收**：主操作查看订单，次操作针对本人订单提交工单；无投资者主动取消或手动退款按钮。未登录引导登录，非本人/跨渠道 ID 显示不可访问；空订单引导浏览机会。到期或未知状态不可误报成功；无弹窗。

### P09 客服表单、本人工单与详情

- **目的/入口/结构**：`/support` 提交，`/account/tickets` 列表，`/account/tickets/{ticketId}` 详情/回复。来自订单的入口可预选本人订单。
- **字段/校验**：问题类型、关联本人订单（可空）、非空描述（最多 2000 字）、可选 `0x` 加 64 位十六进制交易哈希、可选截图**文件名**；截图内容不上传。详情显示联系邮箱、关联 Offering、时间、处理状态及对话。必须是当前渠道账户，不能引用非本人订单；回复不得为空。
- **操作/状态/文案/验收**：主操作“提交 Mock 工单 / 提交 Mock 回复”，次操作查看本人列表或关联订单。状态待处理、处理中、待用户回复、已解决；已解决不可继续回复，客服模拟结果在 `/demo` 设置。无弹窗。提交/关闭只反映沟通，不取消认购、不触发退款，也不改变付款或登记事实。

### P10 法定持仓列表与详情

- **目的/入口/结构**：`/investments?tab=holdings`、`/investments/holdings/{orderId}`；仅本人**法定登记已确认的 Mock 订单**进入列表，详情将法定权益、Token、对账、限制和来源文件分开。
- **字段/条件**：列表为项目、权益、来源订单、法定权益单位、Token 交付、当前可核余额和对账。详情含脱敏权利人、登记日期/证据、InstrumentVersion、交付数量/接收地址/交易引用、当前余额、合同锁仓及法定/链上转让限制。余额与真实对账无权威来源时显示“待核实”，不能因 Token 数量相同推断法定一致。
- **操作/异常/验收**：主操作“查看持仓详情”，次操作“来源订单 / 查看披露 / 联系支持”。原订单存在未决异常或退款时保留登记历史供核查，同时标注当前权益和分配资格待核实；付款完成但未登记不生成持仓。无本人持仓有空态；无弹窗。

### P11 收益与债权本金、事件详情

- **目的/入口/结构**：`/investments?tab=returns` 分列“收益与分配”和“债权本金偿还”，`/investments/returns/{eventId}` 展示一次本人事件。
- **字段/条件**：页首“已支付收益”与“已偿债权本金”独立汇总；无事件为待核实。事件展示 Offering/权益、类型、期间、Record Date、应付日/计划日、实际到账日、毛额、扣项、净应付、已注资、可领取、已实付、未支付、支付方式、交易凭证、原领取请求与法律依据。仅本人有效登记持仓可见；异常/退款待核持仓不应形成可支付资格。
- **操作/状态/验收**：仅当本批方式为 Claim 且状态为可领取，提供“模拟发起领取”；处理中只能查询原请求，不重复领取。演示方式可为 Claim、Push、外部付款或待核实，**不是统一获批的 Claim 规则**。本金偿还不得加进投资收益；预计金额不等于应付，应付不等于到账。无本人事件/错误 ID 空态；无弹窗。

### P12 消息列表与详情

- **目的/入口/结构**：`/messages`、`/messages/{messageId}`；按当前账户与渠道汇集订单、客服、收益和可见项目资料更新，详情含分类、标题、摘要、关联 Offering、创建/更新时间。
- **操作/状态/验收**：主操作“查看关联业务”，次操作“标为已读”。未登录先登录；无消息及无权 ID 各有空态。已读只改本机阅读状态，不是电子签署、法定送达或业务状态变更；M Listing 被撤销后不得从消息泄漏该公开项目。无弹窗。

### P13 公告、披露文件及详情

- **目的/入口/结构**：`/disclosures` 分项目公告和法律/风险文件；公告详情、`/disclosures/{offeringId}/{index}` 文件详情带版本、项目及可读 Mock 正文。
- **条件/操作/状态**：仅当前渠道公开项目或本人历史订单有权访问的资料可见；无权直达给空态。主操作查看公告/文件，文件可下载 Mock 文本；次操作返回列表/机会。无公告、无文件独立提示。查看/下载不构成签署、法定送达；演示文档不是经审核的法律或财务文件。无弹窗。

### P14 使用条款与隐私政策

- **目的/入口/结构**：`/terms`、`/privacy` 从页脚进入；当前为明确标记的**占位页面**，有返回渠道入口，不含获批准正式条款。无表单或弹窗。
- **验收/后续**：不可将占位内容用于生产建号同意、隐私告知或法律签署；上线前须有获批正式版本、有效期及可访问记录。

## 4. 端到端状态与业务约束

1. **发现与公开**：V 只见本 Issuer；M 项目与企业都以 M 有效公开 Listing 为门槛。项目状态可为认购中、即将开放、暂停、结束、待核实。非认购中或容量不足时，详情仍可浏览已获准公开资料，但不能创建订单。
2. **身份与资格**：邮箱 OTP 首次登录建独立渠道账户；KYC 认购前完成即可，未认证可浏览。KYC Provider 的处理中、未知或补件状态必须原申请查询；不得由按钮点击推断通过。MPC 创建结果与自有钱包挑战结果独立。
3. **认购与文件**：金额为份数×Offering 单价；核对最低额、上限、剩余容量；同一 Offering V/M 预留共用。逐份可读 Mock 文件的勾选仅模拟阅读。真实产品必须使用经批准的对应文件版本和有效签署证据，不能把当前 Mock 勾选升级为法律签名。
4. **资金与履约**：OP Mainnet USDT，目标必须是经核实的 Offering 收款合约；付款请求、链上结果、实收匹配、配售、法定登记、Token 交付逐项记录。未知、回滚、重组或失败先查询原请求，不重复转账；未有权威确认不得写成功。退款由独立授权结果确定，客服不能改变退款状态。
5. **投后**：法定登记形成持仓来源，Token 交付和当前余额另列并对账。收益参与按实际合法可分配金额和合同扣项；债权合同利息与本金偿还分列；股权股息须合法决议与可分配利润、退出无固定到期日。分配批次的应付、注资、可领取、处理中、实付分开；当前原型仅演示可选路径，不确立统一支付方式。
6. **异常与通信**：订单、工单、消息、公告各保留原状态与版本。工单已解决不等于资金、法律或 Token 状态已解决；消息已读不等于法律送达。所有失败/待核实页给返回原记录或联系客服路径。
