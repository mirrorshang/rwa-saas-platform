## 0. 设计依据与当前有效规则

本文件承接：
- DEC-069：投资者在投资者端（Issuer 自有 V 门户或平台统一 M 入口）提交 KYC；第三方服务商负责核验；平台维护权威结果；Issuer 只查看当前 Tenant 授权范围内的脱敏资料和状态。
- DEC-069：企业不查看或导出原始证件、完整身份号码、人脸/生物识别材料、第三方 KYC 原始报告或非必要风险细节；不人工批准、拒绝、覆盖或绕过 KYC。
- DEC-069：V1 不提供 Issuer 可配置的 Offering 级资格条件、投资者分级、资格例外或人工审批；KYC 通过不等于任何 Offering 自动可认购。
- DEC-069：投资者与认购导航为「投资者管理｜认购订单｜配售与持有人」；I-42 原 KYC 审核结果并入 I-41，I-43 不作为 V1 独立页面。
- DEC-007：默认租户隔离、跨场景复用须有明确合法依据和必要授权、敏感原始资料不默认共享、查看/导出/授权访问可审计。DEC-069 对 V1 企业端具体展示范围作进一步收敛。
- DEC-073 / U02-10：认购记录是已完成认购只读历史视图；完整订单生命周期归认购订单；两者共享唯一订单主账。
- 既有 V1 Free/Standard：Free 不生成对外投资者门户、不开展真实认购；Standard 在 KYB 通过和独立生产准入后开展真实业务；降级保留历史数据并按规则只读。

**本文件是投资者管理页面当前唯一 UI-Ready 执行规格。** 旧 I-41/I-42 页面候选和 M09 早期范围材料仅保留历史决策过程；与 DEC-069 冲突的 Issuer 人工 KYC 审核、AML 风险细节展示、Offering 资格配置均不作为 V1 页面能力。

## 1. 模块定位与闭环

### 1.1 模块定位

「投资者管理」不是 CRM，不是平台全局投资者数据库，也不是 KYC 工作台。

它是发行企业在自身业务范围内查看投资者关系的入口，让企业清楚了解：
1. 当前与本企业发生了哪些业务关联的投资者；
2. 平台统一 KYC 当前状态，以及投资者是否需要本人继续处理；
3. 该投资者与本企业哪些 Asset、Offering、认购订单和持有人登记记录相关。

### 1.2 MVP 业务闭环

```text
投资者进入 Issuer 自有门户 / 平台统一投资者入口
        ↓
投资者注册/登录，并在必要时确认相关资料披露与授权
        ↓
投资者本人提交 KYC / 按平台提示补件或重新核验
        ↓
第三方 KYC 服务商执行核验
        ↓
平台维护权威 KYC 状态及有效时间
        ↓
平台按当前 Issuer/Tenant 授权范围提供脱敏结果
        ↓
Issuer「投资者管理」显示投资者关系、KYC 状态
        ↓
投资者后续认购/持有业务进入认购订单、配售与持有人等权威模块
```

- 仅浏览公开 Offering、没有建立账户或授权业务关系的访客，不自动进入 Issuer 投资者列表。
- 投资者关系必须由当前企业门户/业务上下文中的有效账户关联、必要告知/授权或真实订单/持有人业务关系建立。
- 投资者可在不同 Issuer 产生不同的业务关系记录；不得仅凭姓名、邮箱、电话、证件或钱包相同而自动合并、暴露或推断跨 Issuer 关系。
- 平台可在合法依据和必要授权范围内引用有效 KYC 结果，但不因此共享原始证件，不合并 M/V 账户、钱包、订单历史或持仓。
- 投资者管理只读展示平台事实，不承担第三方核验执行，也不复制认购、资金、Token 或法定登记主账。

## 2. 页面地图与入口

**固定导航：** 投资者与认购 → 投资者管理。

页面仅包含：
1. 投资者列表；
2. 投资者详情（同一页面内分区展示，不另建 KYC 审核页面）。

不增加「KYC 审核」「风险审核」「投资者资格」「投资者分级」「投资者 CRM」等独立导航。

### 2.1 投资者列表

**页面顶部**
- 标题：投资者管理。
- 说明：查看与本企业发行和持有人业务相关、且已授权本企业查看的投资者信息。
- 摘要指标：
  - 关联投资者：当前 Tenant 可见的投资者关系记录数；
  - KYC 已通过：当前状态为有效通过的投资者数；
  - 待投资者处理：未开始、核验中、需补充资料、已失效/需重新核验的投资者数。
- 摘要按当前企业授权范围计算；数据同步中显示「统计更新中」，不能用 0 冒充未加载数据。
- 不显示全平台投资者总数、其他 Issuer 数量、跨 Issuer 关系或投资者资产总额。

**列表工具栏**

| 字段 | 控件 | 规则 |
|---|---|---|
| 关键词 | 单行搜索 | 仅支持本企业投资者引用编号、脱敏展示名称；不支持完整姓名、邮箱、电话、证件号、钱包地址 |
| KYC 状态 | 单选下拉 | 全部、未开始、核验中、需补充资料、已通过、未通过、已失效/需重新核验、暂不可确认、平台限制 |
| 投资者类型 | 单选下拉 | 全部、自然人、机构 |
| 关联资产 | 单选下拉 | 当前 Tenant 有权访问且存在该投资者业务关系的 Asset |
| 关联 Offering | 单选下拉 | 可按资产联动筛选；仅当前 Tenant 有权访问的 Offering |
| 重置 | 按钮 | 清除筛选，恢复默认结果 |

- 不提供投资者地区、国籍、风险等级、KYC 等级、投资者资格、收入/资产水平等筛选。
- 不提供全平台搜索、跨 Tenant 搜索或任意个人信息搜索。
- 默认按最近一次本企业业务活动时间倒序；没有业务活动时间时按首次建立本企业关系时间倒序。
- 每页 20 条；简单分页；不提供复杂多列排序或批量操作。

**列表字段**

| 字段 | 展示规则 |
|---|---|
| 投资者编号 | 当前企业范围内的脱敏引用编号；可复制，不作为跨 Issuer 搜索 ID |
| 投资者 | 脱敏展示名称；副行显示自然人/机构 |
| KYC 状态 | 平台返回的当前状态；通过必须是当前有效通过 |
| 核验有效期 | 仅在平台提供明确有效期时显示；没有有效期则显示「未提供」，不自行推算 |
| 关联发行 | 与该投资者关联的 Asset/Offering 数量 |
| 认购订单 | 当前企业范围内的订单数量；不显示订单金额合计 |
| 持有人登记 | 当前企业范围内的有效/历史登记记录数量；以 M12 为权威，不以钱包余额代替 |
| 最近业务活动 | 本企业最近一笔订单/配售/登记相关活动时间；不使用全平台浏览行为追踪 |
| 操作 | 查看详情 |

- 订单数、持有人登记数只显示数量，不在列表聚合展示投资者资产总额、财富排名或收益。
- KYC 状态与业务关系状态分开；「KYC 已通过」不显示成「可投资」或「全部 Offering 合格」。
- 列表仅显示当前企业有权查看的关联投资者；不展示未建立本企业关系的其他平台用户。
- 不提供新增、导入、删除、合并、封禁、导出投资者的操作。

### 2.2 列表空状态

**状态 A：Free 新企业**
- 标题：当前暂无投资者记录。
- 说明：Free 套餐不开放对外投资者门户和真实认购。升级 Standard 并满足企业认证及生产准入后，可开展真实投资者业务。
- 主操作：查看套餐。
- 不显示 Mock 投资者或模拟 KYC 结果。

**状态 B：Standard 企业暂无关联投资者**
- 标题：还没有关联投资者。
- 说明：当投资者通过本企业投资者门户建立业务关系，或产生认购/持有人记录后，将在这里显示脱敏信息和平台 KYC 状态。
- 主操作：查看投资者门户（仅在当前企业已开通有效 Standard 门户时显示）。
- 不允许企业手工创建一个虚拟投资者记录。

**状态 C：当前筛选无结果**
- 标题：没有符合条件的投资者。
- 操作：清除筛选。
- 不误显示为企业从未有过投资者。

**状态 D：数据加载/同步中**
- 显示加载状态或「投资者信息正在同步」。
- 不把暂时不可用显示成 0 人或 KYC 全部未开始。

**状态 E：无权或企业未完成 KYB**
- 按全局企业认证拦截规则显示引导；不得通过直接 URL 绕过。

## 3. 投资者详情页

### 3.1 页面顶部

- 面包屑：投资者与认购 / 投资者管理 / [投资者编号]。
- 标题：脱敏展示名称；副标题为当前企业范围内的投资者引用编号。
- 标签：自然人/机构；当前 KYC 状态。
- 辅助说明：「仅显示本企业获授权的投资者信息；身份核验由平台及其受权服务商负责。」
- 右侧唯一常规操作：复制投资者编号。
- 不提供编辑档案、手动审核、暂停投资者、重置 KYC、合并身份或删除投资者按钮。

### 3.2 详情摘要

摘要卡片：
- 关联 Offering 数；
- 认购订单数；
- 持有人登记记录数。

每项点击后跳转对应权威模块并自动带入当前投资者引用和 Tenant 范围：
- 认购订单 → 投资者与认购 / 认购订单；
- 持有人登记 → 投资者与认购 / 配售与持有人；
- 已完成认购历史 → 资产与发行 / 认购记录。

摘要只反映本企业数据，不汇总其他 Issuer 的订单、持仓、收益或钱包。

### 3.3 基础身份信息

| 字段 | 展示 | 规则 |
|---|---|---|
| 本企业投资者编号 | 完整引用编号 | 平台生成的当前企业范围引用；允许复制 |
| 展示名称 | 脱敏名称 | 自然人按平台脱敏规则展示；机构名称按平台允许披露的展示规则处理 |
| 投资者类型 | 自然人 / 机构 | 只读 |
| 关联建立时间 | 日期时间 | 当前企业业务关系建立时间，不代表平台账户注册时间 |
| 最近业务活动 | 日期时间 | 当前企业最近一笔认购/配售/登记业务活动 |
| 本企业关系状态 | 正常 / 历史只读 / 授权不可用 | 仅显示平台可向该企业披露的状态；不暴露授权撤回或隐私请求的非必要细节 |

**默认不展示**
- 完整法定姓名、完整机构注册资料、出生日期、国籍/居住地址；
- 证件号码、证件图片、地址证明、人脸/生物识别；
- 完整手机号、邮箱、社交账号；
- 实际控制人、受益所有人和授权代表的个人明细；
- 投资者完整钱包地址、私钥、签名资料；
- 第三方 KYC 报告、Provider Payload、内部风险备注。

如未来特定法域/Instrument 确需向发行方披露更细的法定持有人资料，必须由独立法律/责任边界决策确定，不能通过本模块自行扩大展示字段。

### 3.4 KYC 状态区

**核心展示字段**

| 字段 | 展示规则 |
|---|---|
| 当前 KYC 状态 | 平台权威状态的企业端友好映射 |
| 最近状态更新时间 | 平台提供的事件时间 |
| 最近通过时间 | 仅当当前/历史存在权威通过结果时显示 |
| 有效至 | 仅当平台提供明确有效期时显示；不推算 |
| 下一步提示 | 根据当前状态显示通用投资者自助指引 |
| 状态来源 | 固定说明「平台统一身份核验结果」；不强制展示服务商名称或内部 Case ID |

**企业端状态映射**

| 企业端展示 | 说明 | 是否可进入认购确认 |
|---|---|---|
| 未开始 | 当前企业关系已建立，但投资者尚未启动 KYC | 否 |
| 核验中 | 投资者已提交，等待平台/服务商结果 | 否 |
| 需补充资料 | 平台返回投资者需要补件 | 否 |
| 已通过 | 平台权威结果为通过且当前有效 | 仅清除 KYC 前置门槛，不代表 Offering 自动可认购 |
| 未通过 | 平台权威结果为未通过 | 否 |
| 已失效 / 需重新核验 | 结果过期、撤销或需要重新核验 | 否 |
| 暂不可确认 | 外部结果 Unknown、同步延迟或平台暂时无法确认 | 否 |
| 平台限制 | 平台存在不可向 Issuer 展开的限制，且平台允许披露一个通用状态 | 否 |

- 只有「已通过」且当前有效，才表示 KYC 这一项前置条件满足。
- 不显示 AML 命中原因、制裁名单详情、风险评分、内部调查备注或第三方判断细节。
- 「平台限制」只显示必要的通用提示，例如「当前暂不可继续认购，请联系平台支持」；不得泄露非必要风险信息。
- 结果 Unknown、过期、撤销或同步延迟不能按通过处理。
- KYC 状态不得被企业账号手工改写；所有状态变化来自平台权威结果。

**状态对应的用户提示**

| 状态 | 页面提示 |
|---|---|
| 未开始 | 投资者尚未完成身份核验。请投资者本人登录其投资者门户，根据页面指引开始核验。 |
| 核验中 | 投资者已提交身份资料，平台正在处理；请等待核验结果。 |
| 需补充资料 | 投资者需要登录投资者门户，按平台提示补充资料。企业端无法代为上传或审核。 |
| 已通过 | 平台已确认 KYC 通过。后续认购仍需满足 Offering 当前开放状态、时间、容量及其他适用交易条件。 |
| 未通过 | 平台返回未通过结果；如需重新处理，由投资者按平台提供的指引操作。 |
| 已失效 / 需重新核验 | 当前核验结果不可继续使用；投资者需按平台指引重新核验。 |
| 暂不可确认 | 暂时无法确认最新核验结果；在结果确认前不能继续认购。 |
| 平台限制 | 当前平台限制尚未解除；企业不能手动覆盖，请联系平台支持。 |

**KYC 状态历史**
- 只显示企业有权查看的状态事件：状态、发生时间、通用事件描述。
- 不显示原始证据、补件文件名称/内容、Provider 原始原因、内部调查过程。
- 历史通过记录保留其时间，但当前状态若已失效，不得仍显示成当前通过。
- 详情时间线默认最近在前；仅显示当前企业授权范围内、与该业务关系相关的必要事件。

### 3.5 本企业业务关系区

按 Asset/Offering 组织，展示该投资者与当前企业发生的真实业务关联。

| 字段 | 展示规则 |
|---|---|
| Asset | 资产名称；点击进入当前企业有权查看的资产详情 |
| Offering | 发行名称/期次；点击进入发行详情 |
| 认购订单数 | M10 当前企业订单记录计数；点击进入认购订单筛选结果 |
| 最近订单状态 | 显示最近一笔订单的真实状态；不把 KYC 状态当订单状态 |
| 已完成认购数 | 只引用 U02-10 已完成记录；付款和 Token 交付均确认 |
| 持有人登记状态 | M12 权威登记状态：未登记/处理中/已登记/存在差异/更正处理中等 |
| Token 交付状态 | 如有必要单独显示 M07 交付事实；不以 Token 余额替代法定登记 |
| 最近业务活动 | 该 Asset/Offering 下最近一笔权威业务事件时间 |
| 操作 | 查看认购订单 / 查看持有人登记 |

- 每个 Offering 的订单、配售、法定登记和 Token 交付状态分开呈现。
- Investor Account、实际付款钱包、Token 接收地址和法定持有人不强制视为同一主体；具体法定持有人以权威登记模块为准。
- 机构投资者的实际控制人、受益所有人和代表信息不在本页展开；需要查看法定持有人时跳转「配售与持有人」并遵循该模块权限。
- 不显示其他 Issuer 的资产、Offering、订单、持仓、收益或身份关系。
- 若投资者没有订单或持有人记录，仅有已建立授权关系，则显示空态：「当前尚无本企业认购或持有人记录」。

### 3.6 详情页允许操作

允许：
- 复制本企业投资者编号；
- 查看关联 Asset/Offering；
- 查看认购订单；
- 查看已完成认购记录；
- 查看配售与持有人登记；
- 返回投资者列表。

不允许：
- 新增、导入、删除或合并投资者；
- 编辑投资者身份资料、联系方式、法定姓名或机构资料；
- 查看/下载原始 KYC 文件、完整 Provider 报告或风险细节；
- 手工批准、拒绝、重置、撤销、延长 KYC；
- 代投资者提交补件、上传证件或发起重新核验；
- 为投资者设置资格、地区白名单、投资者等级或例外；
- 直接修改认购订单、付款、Token、持有人登记或锁仓记录；
- 发送营销消息、批量邀请、客户分群或自动推荐。

V1 不设置企业自由文本备注字段，避免将未经授权的身份、风险或敏感信息另行存入 SaaS。

## 4. 隐私、授权与租户隔离

### 4.1 投资者进入本企业列表的条件

必须至少满足一项当前企业业务关系：
1. 投资者通过本企业投资者门户建立账户关系，并完成必要的告知/授权；
2. 投资者在本企业 Offering 上发起需要建立身份关系的认购流程；
3. 投资者已存在本企业认购订单、配售或法定持有人登记记录。

仅公开浏览、搜索或访问营销页面不自动建立企业可见投资者档案。

### 4.2 跨 Issuer / M 入口复用

- 默认 Tenant 隔离。
- 平台仅在合法依据和必要授权范围内引用有效 KYC 结果；Issuer 只获得当前业务所需的脱敏状态。
- 不因平台内部存在统一投资者引用，就让 Issuer 搜索、枚举或推断其他企业的投资者关系。
- 不自动合并不同 Issuer 下的投资者档案、订单、钱包、持仓或法定登记。
- 投资者授权范围变化、撤回或结果失效时，平台更新可见状态；企业端不自行修改。
- 历史交易、法定登记和必要审计事实按适用留存责任保留；敏感身份字段在无授权时不继续展示。

### 4.3 数据访问与审计

- 所有列表、详情和关联记录查询均限制在当前 Tenant 和授权业务范围。
- 复制投资者编号、查看 KYC 状态、打开关联业务详情等关键访问按平台安全审计规则留痕。
- V1 不开放投资者数据批量导出；避免在企业端形成脱敏边界之外的批量数据副本。
- 不以前端隐藏代替服务端权限控制；直接 URL、搜索、筛选和详情请求均不得跨 Tenant 读取。
- 企业一个账号对应一个企业，沿用 U01 现行权限模型；不新增团队角色/分权审核。

## 5. 套餐、KYB 与数据可见权限

| 企业状态 | 投资者管理权限 |
|---|---|
| Free 新企业 | 显示套餐说明和空状态；不生成或展示模拟投资者、真实对外门户投资者或真实认购数据 |
| Standard 且 KYB 通过 | 可查看当前企业授权范围内的真实投资者脱敏档案、KYC 状态和业务关系 |
| Standard 宽限期 | 按 U01 规则保留历史业务查询；不新增真实投资者业务 |
| Standard 降级为 Free | 历史真实投资者关系和业务记录保留只读；不得新增真实门户投资者关系 |
| KYB 未通过/补件/审核中 | 按全局企业认证拦截规则，不泄露企业业务详情 |

- 套餐不改变平台 KYC 核验责任；Free/Standard 都不能在企业端人工审核 KYC。
- KYB 是发行企业准入，与投资者个人/机构 KYC 是两条独立核验链。
- Standard 订阅不等于真实 KYC Provider、跨境资料复用或生产合规准入已经通过。

## 6. 全局异常、空态与错误反馈

| 场景 | 页面反馈 | 下一步 / 保护 |
|---|---|---|
| 投资者未开始 KYC | 显示「未开始」及投资者自助提示 | 企业不可代为提交 |
| KYC 核验中 | 显示最近更新时间与等待提示 | 不允许按通过处理 |
| KYC 需补件 | 显示需投资者本人补充资料 | 不展示文件要求/原始原因，跳转投资者门户指引 |
| KYC 未通过 | 显示未通过及通用指引 | 企业不可手工覆盖 |
| KYC 过期/撤销/需重核 | 显示「已失效/需重新核验」 | 新认购前置不通过；历史业务保留 |
| Provider/平台 Unknown | 显示「暂不可确认」 | 不得按通过，等待平台核验 |
| 平台限制 | 仅显示通用限制提示 | 不暴露 AML/制裁敏感细节，不允许企业解除 |
| 投资者授权范围变化 | 显示「当前资料授权不可用」 | 隐藏无权继续展示的个人资料；历史业务记录按规则保留 |
| 同一投资者跨 Issuer | 当前企业仅显示自己的关系 | 不合并、不展示其他 Issuer 信息 |
| 同名/同邮箱/同钱包 | 不自动合并 | 以平台权威身份关联为准 |
| 投资者账户与法定持有人不同 | 分开展示业务账户和登记状态 | 跳转配售与持有人，不以账户身份代替法定权利人 |
| 订单与登记/Token 不一致 | 分别显示各权威状态和差异入口 | 不自动改写任何主账 |
| 数据同步延迟 | 显示同步中和最近成功更新时间 | 不将缺失结果当作未开始或通过 |
| 投资者不存在/无权访问 | 显示「记录不存在或无权访问」 | 不泄露跨 Tenant 记录是否存在 |
| Free 新企业 | 显示套餐限制空态 | 不显示 Mock 数据 |
| 降级 Free | 历史数据只读 | 保留历史记录，不开放新增业务 |

## 7. 与其他模块的责任边界

| 模块 | 投资者管理读取的事实 | 投资者管理不承担的责任 |
|---|---|---|
| 投资者门户 | 投资者建立的当前企业授权业务关系、门户展示身份 | 投资者注册、KYC 资料提交、补件、重新核验 |
| 平台统一身份/KYC（M09） | 当前有效 KYC 状态、核验时间、有效期、企业可见事件 | Provider 接入、真实身份核验、AML 决策和敏感证据保管 |
| 企业资产与发行 | Asset、Offering 关联关系和名称 | 修改发行条款或资产资料 |
| 认购订单（M10） | 当前企业订单状态和数量摘要 | 创建/取消订单、改价、确认订单 |
| 认购记录（U02-10） | 已完成认购历史 | 复制认购主账或手工标记完成 |
| 配售与持有人（M12） | 法定登记状态、持有人记录关联 | 作出配售决定、改写法定名册 |
| Token 管理（M07） | 必要的真实 Token 交付状态引用 | Mint、Burn、转账或修改链上余额 |
| 锁仓记录 | 当前企业关联锁仓记录入口 | 修改锁仓/解锁权威事实 |
| 平台支持/合规 | 平台限制的通用状态 | 将平台内部调查细节暴露给 Issuer |

## 8. UI-Ready 验收清单（设计目标，尚非代码测试）

| 验收项 | 设计要求 |
|---|---|
| 导航 | 固定在「投资者与认购 → 投资者管理」，不新增 KYC 审核或资格入口 |

| 详情 | 基础身份、KYC 状态、KYC 事件时间线、本企业业务关系完整 |
| KYC 状态 | 未开始、核验中、需补件、通过、未通过、失效/重核、Unknown、平台限制 |
| 业务边界 | KYC 通过不等于 Offering 可认购；不提供资格配置 |

| 体验 | 用户始终能看懂投资者状态、是否需要本人处理、对应本企业业务关系和下一步入口 |

## 9. V1 明确不做

- Issuer 企业端 KYC/KYB/AML 人工审核、批准、拒绝、复核、重置或覆盖。
- 投资者证件、地址证明、人脸/生物识别、原始 KYC 报告或完整 Provider Payload 展示/下载。
- 投资者等级、地区白名单、风险评分、Offering 级资格配置和资格例外。
- 全平台投资者目录、跨 Issuer 投资者搜索、未经授权的 KYC 复用或跨租户资料共享。
- 企业手工新增、导入、删除、合并、封禁投资者。
- 企业代投资者提交 KYC、补件、重新核验。
- CRM 联系人、营销分群、自动推荐、批量营销和消息触达。
- 投资者数据批量导出、企业自由文本敏感备注。
- 将 Investor Account、Pay Wallet、Token Receiver 和 Legal Holder 自动视为同一主体。
- 任何真实 KYC Provider 上线、法域法律判断、生产身份核验或合规准入能力。
