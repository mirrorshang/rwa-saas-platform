# Issuer SaaS V1.0 全流程操作手册

适用：正式 `apps/issuer` 的内部 Sandbox Mock 闭环。先同时启动 `apps/website`（`http://127.0.0.1:5175`）与 `apps/issuer`（`http://127.0.0.1:5174`），从 website 邮箱登录进入 Issuer；也可直接打开 Issuer 检查业务页。本轮已点击登录跳转，但两个应用尚无安全会话交换。操作记录按正式页面和按钮编写。`A` 为已在浏览器点击并观察状态／刷新，`B` 为页面存在但无完整处理，`C` 为本次范围外未实现，`D` 为须后端或其他端验证真实结果。A 仍仅代表 Mock。

## 开始前与测试数据

- 使用隔离浏览器配置。演示控制台可建立 Mock Standard、模拟钱包验证、模拟投资者和支付；不输入真实钱包私钥或使用资金。浏览器本地 v4 数据不是服务端主账。数据异常时停在「本地数据需要核对」，导出原始记录后修复／导入；不要清空存储来掩盖问题。
- 住宅：北京朝阳，2 室 1 厅、80㎡，约定价 ¥2,000,000、估值 ¥1,900,000、月净租金 ¥8,000。仅本案例采用 `1 U = ¥8`；Offering `OFF-3001` 为 25,000 Token × 10 U = 250,000 U，估值 237,500 U。三名模拟投资者按 12,500／7,500／5,000 Token 持有，即 50／30／20%。本期可分配净额 1,000 U，预期 500／300／200 U。
- 债权：单笔企业借款本金 400,000 U，固定年利率 12%，2026-12-01 起息、2028-12-01 到期，每月付息、到期一次还本，`Actual/365 Fixed`。Offering `OFF-3002` 为 4,000 Token × 100 U。两名模拟投资者分别持有 2,500／1,500 Token，本金 250,000／150,000 U。首个 31 天计息期应付 `4,076.712329 U`，不能把 4,000 U 写死为每月法定应付额。
- 案例资产、日期、文件及企业信息可用独立测试资料；下表中的 `OFF-3001/3002` 是已验收浏览器会话的编号，新隔离会话以页面实际生成编号为准。
