## 一、审核汇总

| 缺口性质 | 数量 | 判定含义 |
|---|---:|---|
| 可配置模型、权利/证据和外部集成扩展 | **9** | 依 M04/M05/M06/M12/M13/M19/M22 共享主责，通过家族参数/可信证据适配，不默认建设新的独立系统 |
| 未来专有业务引擎/完整流程（含条件触发 C05） | **9** | 不是既有 Issuer 连续认购/登记/Token 的简单字段扩展；真实商业产品化时需单独 PRD 和责任/法域/资金/执行验证 |
| **合计** | **18** | GAP 不是 18 个正式功能编号，也不是 18 个已批准的 V1 研发任务 |

**审核纠偏**：
1. **D 的外部经营收入**必须有独立事实与收入权威，不能将电影票房/音乐版税款项直接写入 **M11 投资者首次认购资金对账**；应由 M13 收益/存续事实与 M22 外部收入集成主责，并另行设计应收/实收和付款。
2. **C 的申赎并非认购取消/退款**：NAV 确认、份额成交时点、赎回责任及实际支付必须独立；M10/M11/M12 可复用横向业务 Guard 和支付事实。
3. **E 的托管库存不等于法定持有人登记或 Token 余额**：有独立托管/资产储备权威、权属证明及实物交付事实；原草案中 M22-F004“权威持有人登记”可以提供登记适配，但不能冒充通用储备托管服务。
4. 原 18 GAP 并非穷尽所有法律权益、基金附加机制或商品合规问题；今后具体 Instrument 与客户可触发新增独立需求，但不能据此次审核认定通用 SaaS 已支持完整 C/D/E。

## 三、拟采用的家族差异最小边界

### C｜基金/集合投资份额
- 保留通用 Issuer 用户、组织权限、资产/权利、专业文件、投资者身份与 Offering 资格、M11 真实稳定币入账、M12 法定登记引用、M07 链上 Token 事实。
- **新增风险域**：受权 NAV 提供者、估值/份额价格版本、可执行申赎窗口和定价时间、暂停/赎回责任、净资产与份额认定；私募基金承诺出资是**附加场景而非全部基金共同功能**。
- 最重要的“不等于”：基金资产可以买美债，并不意味着投资者持有债券 A。实际持有的基金份额按具体基金法律载体与证据确定。

### D｜合同收入/版税参与
- 合同义务人、权利比例、扣费、上限及终止都可在通用 Instrument 文件、规则和审计上扩展；无需再造一套认购支付和 Token 服务。
- **新增风险域**：收入报告与钱实际收到由不同第三方提供时的可信核验、扣除/瀑布分账、持有人记录日、追溯更正与争议、对外真实支付。
- 最重要的“不等于”：**发行认购收款与发行后经营收入来源属于不同业务事实**，不可借用 M11 形成第二套未授权账务权威。

### E｜实物权属/托管凭证
- 可复用统一权利文件、适格持有人资格、发行/Token、权威登记引用与合约限制。
- **新增风险域**：指定资产/批次识别、保管/库存证明、真实持有量与发行 Token 比率、储备不足的暂停/通知、实物提取/赎回申请、交付验真与法定权属/Token 的联动冲销。
- 最重要的“不等于”：**链上 Mint/持币量并不自动等于实物储备、法律物权及完成提货**。

| **SCOPE-114** | C/D/E 的家族×法域×租户/Issuer 权限×授权服务商能力共同控制可用性；Modeled/Validation Only/Production Eligible/Disabled 仅是**产品能力状态建议**，不等于金融许可或法域合法结论。尚未开放的家族禁止真实发行与危险 API 操作。 |
