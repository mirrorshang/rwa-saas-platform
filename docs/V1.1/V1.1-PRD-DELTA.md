# V1.1 产品需求增量

只列相对于 [V1.0 Backend Developer PRD](../V1.0/V1.0-BACKEND-DEVELOPER-PRD.md) §5、§6、§11、§12 的增量；正式批准依据为 PR #21 的 R01–R06。

| 决议 | V1.0 规则 | V1.1 增量 | 不变边界 |
| --- | --- | --- | --- |
| R01 | Asset 有六类模板、版本、文件与 Ready；公开摘要须授权 | 每类可公开字段逐项选取；缺值/未获授权不进入投资者 DTO。四类非闭环模板仅配置展示 | 不因模板存在而允许发行；底层资产价值不等于发行额 |
| R02 | Instrument 类型、容量、权益条款与固定版本 | 股权填股份发行主体/股类/股数/表决/股息/清算/退出；债权区分投资者名义本金、债务人、固定利率与底层借款；收益参与填实际收益来源、口径、比例、周期和责任主体 | Actual/365 Fixed、按月付息、到期一次还本的原债权闭环不变；Token 不是法定登记本身 |
| R03 | 发行主体和底层资产权利人需分别建模 | 选择不涉及或引用已有单层 SPV；记录法定名称、地区、注册号、发行角色、资产/企业关系及三类证明。缺依据不能 Ready | SPV 非第四种权益；不做设立、多层穿透、优先劣后 |
| R04 | Offering 固定 Asset/Instrument/钱包/条款快照 | 固定合同利率或有依据的发行方预期年化单值/区间；测算含价格、日期、期间、净/毛、增值、假设、费用税费、依据、风险；改价重新确认 | 不虚构回报；认购额非法律本金；预期不驱动真实应付 |
| R05 | 文件扫描、引用与版本 | 增加公开权限；只有已扫描、定版且获准公开的文件进入 DTO。直接访问按渠道与文件版本复核 | 阅读、确认、下载、有效签署四者分开；私密 KYB 不公开 |
| R06 | 门户发布引用 Offering 等版本 | `PublishedOfferingDisclosure 1.1.0` 从 Issuer 固定发布快照生成；V/M 加载同一文件，拒绝未知 schema；M 额外 Listing 许可 | 动态容量、订单、持仓、收益和本金由权威服务提供；本地 Mock 不冒充生产接口 |

历史数据缺少 SPV、回报或法律主体时显示“待核实/未提供”，不推断“无 SPV”或数值零。已确认快照和历史订单不因新版草稿修改而覆盖。其他模块无新增产品范围。
