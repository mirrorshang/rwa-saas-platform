## 9. UI-Ready 详细规格：Asset 创建与编辑（八种模板）

本节把第 4 节的模板方向细化为前端可实现规格。只约束页面、字段、交互、前端校验和 Mock；不定义 API、数据库或真实资料核验。Asset 模板描述底层资产事实，Instrument 描述投资者取得的权益，两者不得互相代填。

### 9.1 页面结构与操作

**页面容器**：沿用现有 \`BusinessWorkspace\` 全页工作区，不改成 Drawer，不新增一级导航。沿用 Issuer 现有色彩、字体、表单控件、按钮、状态标签、提示条和间距体系；本批不重做全局视觉。仅桌面 Web，按现有桌面内容区排版，不另做移动端页面。

**新建/编辑统一采用真实四步表单**（当前源码的四步进度条是静态展示，所有字段实际堆在同一页；V1.5 应让步骤真正可前进/返回）：

| 步骤 | 页面标题 | 内容 | 前进条件 |
|---|---|---|---|
| 1 | 基本信息 | 资产模板选择、资产名称、所在地、资产描述 | 模板、名称、所在地已填 |
| 2 | 资产资料 | 仅显示当前模板的专属字段 | 当前步必填字段通过；条件字段按下方规则 |
| 3 | 证明材料 | 按模板展示必需/选填文件清单、文件名和状态 | 必需文件已添加；文件扫描状态可在此步显示 |
| 4 | 确认预览 | 按分组只读展示已填写信息、缺项、文件状态和重要提醒 | 可保存草稿；资料检查通过后才可标记 Ready |

- 顶部显示步骤名称和当前进度；已完成步骤可返回修改，未完成步骤不可跳过。返回不清空数据。
- 每一步均提供「上一步」「下一步」「保存草稿」；最后一步提供「保存草稿」和「保存并检查资料」。
- 「保存草稿」允许资料不完整，但至少要求资产名称和所在地；保存后状态为 Draft。
- 「保存并检查资料」执行全部模板字段校验及 Mock 文件可引用检查。通过后状态为 Ready；不通过仍为 Draft，并列出缺项，点击缺项可返回对应步骤/字段。
- 「Ready」只表示前端资料完整且 Mock 文件检查通过，不表示权属真实、估值有效、法律审查通过或具备发行许可。
- 「填充示例数据」放在表单顶部或步骤 1 操作区；只填空字段、不覆盖用户已输入内容；已有内容时先确认。示例文件必须清晰标为演示文件，不能伪装成真实证明。
- 新建过程中更换模板，如已填写模板专属资料或添加文件，先提示将清除不兼容的专属字段和文件；确认后清除，取消则保留。已保存 Asset 的模板类型锁定，不提供直接改型。
- 已被确认 Offering 引用的 Asset 不允许直接覆盖；保留当前保护提示。已关联 Instrument 但未被确认 Offering 引用时，修改 Asset 后将 Instrument 标回 Draft，并提示需要重新检查上游资料。
- 每类文件一项清单支持一个文件记录；多页材料应合并为一个 PDF。允许 PDF、PNG、JPG/JPEG；文件大小限制沿用当前前端统一上传限制，不另设不同模板规则。
- 文件状态仅显示「待扫描」「可引用」「异常」等 Mock 状态。页面不显示冗长产品注释；只在条件字段旁给出简短、直接的说明。

### 9.4 共通校验与状态

- 所有数值字段拒绝负数；数量、面积、重量、股数等必须大于 0。金额字段按币种显示精度，不用浮点展示造成的静默取整。
- 所有日期按业务含义校验先后关系；不允许以 Offering 开放/结束日期代替底层合同、租约或债权到期日。
- 模板条件字段按状态即时显示/隐藏；隐藏字段保留草稿值但不参与当前校验。重新切回原状态时恢复原值。
- 必需文件未添加、文件状态为待扫描或异常时，不得标记 Ready；仅 Mock 状态为「可引用」时通过前端资料检查。
- Draft 可保存不完整资料；Ready 检查失败时，页面显示缺项名称、所在步骤和字段定位；不得只显示「资料不完整」。
- 资产列表与详情统一显示模板名称、所在地、估值币种/金额、Draft/Ready 状态和缺项数量；详情中可查看所有已填字段和文件状态。
- 所有模板均支持「填充示例数据」；示例值与示例文件必须显式为演示数据，填充不得覆盖手工输入。

### 9.5 Asset 模板验收用例

| 用例 | 操作 | 预期 |
|---|---|---|
| A01 | 从空白分别创建八种模板 | 每种模板均可选、字段组正确，不出现其他模板字段 |
| A02 | 住宅选择空置/自用 | 租金、租约隐藏且不要求租赁合同；仍可完成其他资料检查 |
| A03 | 住宅选择已出租 | 月净租金、周期、租约起止和租赁合同变为必填；结束日早于开始日被拒绝 |
| A04 | 写字楼/商铺/工业物业切换出租状态 | 按状态显示租赁字段；面积、出租率等校验按模板执行 |
| A05 | 非上市股权输入持股数与总股数 | 自动计算比例；持有股数超过总股数被拒绝 |
| A06 | 借款债权切换固定利率/无息 | 固定利率显示利率和起息日；无息隐藏两项；未偿本金超过合同本金被拒绝 |
| A07 | 应收账款输入应收与已收金额 | 未收余额自动计算；已收超过应收被拒绝；逾期显示提示；结清不能 Ready |
| A08 | 贵金属输入重量、单位、单价、纯度 | 总估值自动计算；重量/纯度越界被拒绝；已投保时保险文件必需 |
| A09 | 任一模板缺少必需文件或文件异常 | Ready 检查失败，列出文件缺项并定位 |
| A10 | 模板切换、刷新、返回和离开未保存表单 | 切换前确认；取消保留原数据；已保存草稿可恢复；未保存离开有提示 |
| A11 | 已被确认 Offering 引用的 Asset 尝试编辑 | 阻止静默覆盖并展示原因 |
| A12 | 点击填充示例数据 | 只填空字段，不覆盖已有输入；示例材料始终标明演示 |
