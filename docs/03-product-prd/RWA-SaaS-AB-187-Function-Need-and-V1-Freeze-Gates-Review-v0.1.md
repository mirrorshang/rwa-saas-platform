## 一、统一产品核心与两个法律权利样本

- **A（债权）**：固定息权、明确到期还本，A1 在合法同权条件下多次一级发行，同一 Series/到期与票息日期；晚入报价/应计/记录日要受权版本化。
- **B（实体权益）**：真实 SPV 股份或类似成员权益，B1 仅在获批法定发行额度内持续一级发行，否则合法公司方案可要求 B2 统一认购/配售。法定名册、优先认购权（如适用）、稀释、合法分红与回购，不是债权的固定息本义务。
- **共享核心**：Tenant→Asset/Instrument→Project/Offering→KYC 与 Offering Eligibility→版本化认购/额度→真实 USDT/USDC 付款及独立核对→受权配售→法定登记引用与真实链上 Token→合法存续期/异常；M11 资金、M12 法定权益登记、M07 Token、M13 实际收益出款不能融合为一个状态。
- **原有范围统计不变**：P0 125 / P1 21 / P2 21 / V2 6 / 批次待定 14；五类分类 73 共享业务核心、42 共享界面、10 受权外部执行、16 条件性 P1、46 非默认首期。
