# DEC-070｜资产管理列表、资产相关方与房地产模板控件 UI-Ready 收口

> **日期：2026-11-11**  
> **状态：Approved（依据用户授权，由产品负责人自主完成 V1 详细设计与必要精简）**  
> **适用范围：Issuer 企业 SaaS｜资产与发行 → 资产管理**  
> **维护分支：docs/r2-current-product-baseline｜PR #8 Draft / Open / Unmerged**

## 1. 决策背景

现行 U02 已批准资产集中式入口、资产详情四 TAB、五步资产创建、房地产首批四模板、资产相关方属于 V1 的既有 M04 能力。但资产相关方的字段、角色、文件、Ready 校验和投资者披露位置仍停留在模块补充稿中的候选细节；资产列表/详情的唯一下一步引导，以及房地产四模板的单位、控件和交叉校验也需要统一。

用户于 2026-11-11 明确授权：详细设计过程中可按 V1 易用性精简功能、合并入口、调整导航结构。基于该授权，本决策将上述细节收敛为可交付 UI-Ready 规格。

## 2. 正式设计决定

### 2.1 导航与页面归属

1. 保持「资产与发行」二级导航：**资产管理｜认购记录｜锁仓记录**。
2. 保持资产详情四 TAB：**资产概览｜资产资料｜权益结构｜发行管理**。
3. 资产相关方并入资产创建五步向导第③步「法律与估值」及资产详情「资产资料」分组；不新增二级菜单、独立页面或第五个 TAB。
4. 资产列表、资产概览和四 TAB 的详细职责及唯一下一步引导，以 [U02-07 资产管理补充 UI-Ready 规格](../docs/03-product-prd/r2-current-baseline/U02-07-ASSET-RELATED-PARTIES-AND-LIST-UI-READY-2026-11-11.md) 为准。

### 2.2 资产相关方角色与主体信息

1. 保留 R18「登记权利人」为 Asset 必需主权属主体，不以 Issuer 企业自动替代。
2. V1 相关方角色包括：资产持有主体/SPV、托管方、受托方/Trustee、资产管理方、资产运营方、估值机构、其他相关方。除登记权利人和触发的估值机构外，其余角色按真实资产结构条件化添加；不要求每个 Asset 都具备全部角色。
3. 同一主体在同一 Asset 中承担多个角色时，使用一张主体卡片多角色标记；SPV 与登记权利人相同时关联同一主体，不重复建档。
4. 相关方核心字段为：角色、主体名称、主体类型、注册国家/地区（企业/公共机构必填）、注册编号（选填）、与发行企业的关系、职责说明；许可/资质、官网、联系人、联系方式、合作期限、备注等归入折叠的更多信息。
5. 选择第三方评估时，估值机构必须有主体名称和估值机构角色；与 R19「评估机构」字段共用同一主体记录，不重复录入。
6. 资产相关方不承载 Instrument/Offering 的债务人、担保人、付款义务方、法定签署人、收款钱包或 Token Signer；不建设全局主体名录、受益所有权穿透或多层 SPV/信托图谱。

### 2.3 文件与 Ready 规则

1. 资产权属证明、估值依据文件、条件性抵押/权利限制证明继续使用现有固定文件行。
2. 相关方可按实际关系关联授权/委托、托管/受托、管理/运营、许可资质等文件；不新增所有角色通用必传文件。
3. 相关方卡片一旦创建，角色、主体名称、主体类型、与发行企业关系和职责说明必须完整；未创建的非适用角色不阻断 Ready。
4. 登记权利人、权利性质、与发行企业关系、非同一主体时的关系说明，以及现有 R18/R19 文件与条件校验继续作为 Asset Ready 门槛。
5. 上传、扫描、可引用、法律有效性和许可真实性是不同事实；Asset Ready 不代表法律或生产审核通过。

### 2.4 投资者披露

1. 资产相关方资料默认仅供 Issuer 企业内部查看；不得因保存 Asset 自动公开。
2. 披露按 **Offering** 单独选择，入口位于 Offering「发行准备 → 投资者披露 → 资产相关方」，最终进入该 Offering 的投资者端预览与披露快照。
3. 投资者端只可展示被本期 Offering 选中的主体名称、角色、简要职责说明及可披露的注册地区；不展示注册编号、个人身份资料、联系人、电话、邮箱、许可编号、内部备注或原始附件。
4. 未选择任何主体时不向投资者展示空白模块；Issuer 最终预览须提示确认本期是否存在适用披露义务。平台不替发行企业判断法域披露义务。
5. 已发布 Offering 的披露快照不随 Asset 资料编辑自动改变。

### 2.5 房地产四模板控件

1. V1 继续只开放住宅、写字楼、商铺、工业园/仓储物流四模板；酒店、土地及其他资产类别继续暂未开放。
2. 面积统一使用 m² 或 ft²；同一 Asset 所有面积字段共用一个单位。更换单位必须显示换算预览并经用户确认，不能只换单位标签。
3. 面积为正数，最多两位小数；可出租面积不得超过建筑面积。
4. 出租率/入住率为 0%～100%，最多两位小数；住宅套数/客房数量为正整数并按模板条件显示。
5. 四个模板的字段、控件、单位、交叉校验和错误定位以 U02-07 为准；不新增非必要的建成年份、主要租户、酒店等级、仓储容量等 MVP 强制字段。
