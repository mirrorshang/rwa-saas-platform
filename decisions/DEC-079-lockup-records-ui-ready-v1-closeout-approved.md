## 1. 决策依据与批准边界

本决策承接以下现行批准，不新增或改变原业务范围：

- U02-02：资产与发行保持「资产管理｜认购记录｜锁仓记录」三个二级入口；锁仓记录是跨 Asset / Offering 查询视图，不复制订单或 Token 主账。
- DEC-072 / U02-09：Offering 明确选择「不锁仓 / 固定天数」；固定天数为 1～36,500 天正整数；V1 不支持分期、多段、投资者等级差异化锁仓；锁仓从 Token 实际交付时点起算；Offering 关闭不会自动解除既有锁仓。
- DEC-076 / U02-13：持有人详情展示锁仓摘要并跳转锁仓记录；法律/管理限制与业务锁仓分开，锁仓到期不自动解除法律限制。
- DEC-078：Token 管理负责 Token 合约、Mint/链上执行和真实链上事实；业务锁仓记录归本页，Token 管理不另建锁仓主账。
- DEC-033：赎回、清退、到期清偿、公司行动及真实资金处理由收益与分配及其权威主体负责；锁仓到期不等于赎回、清偿或法律权利终止。
- DEC-058：V1 不开放自由交易、强制转账、任意锁仓策略；法律冻结/解除必须具备适用依据、真实授权及必要的链上执行。
- U01：Free 仅内部预览；Standard 付费和 KYB 通过不自动取得真实生产执行权。

本决策只将上述原则细化为锁仓记录页面的信息架构、字段、列表、详情、状态、异常、权限和验收目标；不新增正式功能 ID，不改变 V1/V2/V3 首次交付归属。

## 2. 页面结构决定

- 保持现有一级导航「资产与发行」及二级入口「资产管理｜认购记录｜锁仓记录」。
- 锁仓记录为一个跨资产/发行方案的统一列表及详情，不新增独立锁仓管理菜单。
- Offering 详情、持有人详情、Token 管理及相关异常页面均通过上下文链接进入本页；Offering 跳转时自动带入 Asset 与 Offering 筛选。
- 本页不提供手工新增、编辑、删除锁仓记录；由已发布 Offering 规则、真实有效配售和 Token 实际交付事实形成。

## 3. V1 核心规则

### 3.1 锁仓记录生成

- Offering 选择「不锁仓」不生成业务锁仓记录，但不代表不存在法律/管理或其他合约转让限制。
- Offering 选择固定天数后，真实有效配售先形成「待交付预期锁仓事项」；它不代表 Token 已锁定。
- Token 实际交付达到适用链上最终确认后，才生成正式锁仓记录并开始计时。
- 每条正式锁仓记录对应一个唯一实际 Token 交付批次/事件，固定关联 Offering 发布快照、配售决定、持有人引用和接收钱包。
- 正常路径一项配售对应一次完整交付；如依法获准的例外确需分批交付，每个真实交付批次独立形成记录、独立起算，不合并时钟。
- 未最终确认的 Mint Intent、仅有 TxHash 或链上 Unknown 均不能开始锁仓计时。

### 3.2 起算、到期与规则快照

- 起算时间来自真实 Token 交付事件的权威链上发生时间；平台回调、接收或企业点击时间不得替代。
- 平台确认时间和最近链上核验时间另列。
- 锁仓天数来自 Offering 已发布版本，记录页只读；不得在记录页改写。
- 预计到期时间按该 Offering/合约已批准的期限口径计算；缺少时间戳或规则口径时显示待核，不猜测。
- 业务期限到达只表示时间条件届满；链上限制是否解除须按批准执行方式查询真实状态。
- Offering 关闭、认购结束或企业套餐降级均不自动解除既有锁仓。

### 3.3 链上执行与法律限制分离

- 业务锁仓期限、链上转让限制、法律/管理限制是三个独立状态维度，可并存。
- 固定天数 Offering 在真实生产发布前，必须确认合约模板或其他依法批准的执行安排能够实现并核验该限制；缺少安排时阻断真实发布。
- 合约自动到期必须经真实链上状态核验后才显示已解除。
- 如已批准执行方式要求到期后显式链上解除，本页只跳转 Token 管理关联操作，由真实有权主体执行；本页不签名、不直接解除。
- 法律/管理冻结仍有效时，即使业务锁仓期限已到、链上时间锁已解除，也必须继续单独提示限制有效。
- 锁仓期间出现非预期 Transfer，进入重大差异调查；不自动强制转回或默认为合法。

### 3.4 V1 不支持

- 分期解锁、多段锁仓、按投资者等级/身份/金额差异化锁仓；
- 交付后自助修改锁仓天数、延长、缩短、提前解锁或批量解锁；
- 多锁仓计划叠加、自动续锁、滚动锁仓；
- 自由转让、C2C、撮合、二级市场交易、强制转账；
- 本页手工 Mint、Burn、冻结、解冻、改钱包或改 Token 数量；
- 将锁仓到期视为赎回、退出、还本付息、清退或法律权利终止。

有法律效力的提前退出/回购/公司行动按「收益与分配 → 到期与退出」及相应受权 Token 处置流程处理，不得伪装成普通提前解锁。

## 5. 与 Token 管理的衔接补充

- 锁仓记录由本页作为唯一业务记录入口维护；Token 管理只维护真实合约能力、链上锁仓/解除执行和链上事件事实。
- 若批准的合约模板采用自动时间到期，本页读取 Token 管理核验后的真实可转让状态；不能仅依据预计到期时间标记已解除。
- 若批准的合约模板要求显式解除操作，本页将原锁仓记录及固定参数带入 Token 管理的关联受权操作；Token 管理不得另建业务锁仓记录。
- 链上解除 Intent 唯一；Unknown 先核验原 Intent/交易，不得重复解除。
- Token 管理、配售与持有人、本页对业务锁仓、链上限制、法律/管理限制分别保留权威事实。
