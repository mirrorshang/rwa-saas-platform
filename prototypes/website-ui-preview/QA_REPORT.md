# WDEX SaaS 官网 UI 核查记录

更新日期：2026-10-27。范围为 W-01～W-14 中文桌面端前端。`?demo=1` 保留内部状态演示；普通访问路径按当前服务真实开放状态呈现。

## 本轮调整

- 普通访客不再继承浏览器中保存的演示角色。页头、套餐按钮与账户路径统一以访客状态显示。
- 首页和营销页改用「了解方案／查看开放状态」等准确入口；Standard 价格继续显示「价格待公布」，不暗示可立即付款或发行。
- W-02 七项功能分别绘制资产、发行、Token、门户、认购、资金、存续的静态产品示意。
- W-03 两类客户采用不同内容节奏；移除重复的总对比表。W-04 保留套餐决策信息，W-13 聚焦升级流程和付款注意事项，重复对比与 FAQ 已压缩。
- 咨询模拟回执不再宣称信息已发送。公开版注册、咨询、登录、邮箱验证、Free 开通与企业选择不展示可提交但无法完成的表单或操作。
- 四份法律文件改为清楚的待发布状态，移除重复的占位正文。Cookie 提示只说明当前本地存储，取消不存在的可选追踪类别「接受全部」操作。
- 增加逐页标题，清除普通页面的演示提示条；提高首页能力卡片编号和正文的对比度及字号。

## 发布前依赖

本项目仍是静态前端与 Mock 状态。真实注册、邮件验证、认证授权、企业工作台、咨询接收、商业 KYB、协议、价格、支付和权益服务尚未接入；正式法律文件与企业主体信息尚未确认。网站可用于视觉和内容评审，不能作为已可交易或已可正式开户的生产网站发布。本轮未独立验证 1280／1440／1920px 视口。
