# V1.1 API 差异候选

基于 [V1.0 完整 OpenAPI](../V1.0/openapi.yaml)；[V1.1 完整候选文件](V1.1-OPENAPI.yaml)由 `generate-openapi.mjs` 生成。原 75 条路径保留，新增 2 条。实际后端接口与权限实现 **NOT VERIFIED**。

| 路径 / 方法 | 差异 | 权限和错误 | 客户端影响 |
| --- | --- | --- | --- |
| `PATCH/GET /api/v1/assets/{id}` | 可选 `public_fields_v1_1:string[]`，引用经授权的六模板字段 | Tenant Scope；非法字段 422，版本冲突 409 | Issuer 逐字段授权；V/M 不读取完整 Asset |
| `PATCH/GET /api/v1/instruments/{id}` | 可选 `rights_v1_1` 三类判别结构、`spv_v1_1` 单层已有 SPV/null | Tenant Scope；缺条款/证明 422，已引用版本修改 409 | Issuer 独立表单和 Ready 校验；旧 `terms` 保留 |
| `PATCH/GET /api/v1/offerings/{id}` | 可选 `return_disclosure_v1_1`、`risk_disclosure_v1_1` | Tenant Scope；改价未重核 422；版本冲突 409 | 价格与测算一起冻结，不覆盖原快照 |
| `GET /api/v1/files/{id}` | 可选 `version_v1_1`、`visibility_v1_1` | Tenant Scope；直接 URL 仍应逐次授权 403 | 后台不能默认全公开 |
| `GET /api/v1/public-disclosures/{publicationId}?channel=V\|M` | 新增固定版本 `PublishedOfferingDisclosure 1.1.0` | 会话、V 授权或 M 独立 Listing；403/404/422 | V/M 校验 schema 并展示同源字段；不取内部 Asset/KYB |
| `GET /api/v1/public-disclosures/{publicationId}/files/{fileId}?version=n&channel=V\|M` | 新增授权文件读取，返回短期受控引用 | 文件 id+version、渠道、账户权限；403/404 | 文件查看/下载与签署分离；不可猜 URL 绕过 |

没有废弃接口；登录、KYB、订阅、钱包、订单、付款、登记、Token、收益与本金端点的 V1.0 请求/响应保持原语义。新增字段均为可选的版本化扩展，旧客户端仍可读取旧数据，但不得将缺失值解释为零、无 SPV 或公开。候选接口的字段命名、授权粒度、返回码和幂等要求须与实际工程实现核对后定稿。
