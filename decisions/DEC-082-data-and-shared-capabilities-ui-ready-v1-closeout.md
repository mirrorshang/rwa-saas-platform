# DEC-082｜RWA SaaS V1 数据与共享能力 UI-Ready 设计收口

> 日期：2026-11-11  
> 记录性质：在用户已授权的企业 SaaS V1 模块完整性与 UI-Ready 工作范围内，完成现有八个共享能力页面组的产品设计收口。  
> 本 DEC 不声称用户逐字段逐项再次批准，不把页面设计收口等同于新的业务规则批准、真实生产服务批准或 V1 整体冻结。  
> 维护分支：docs/r2-current-product-baseline｜PR #8 Draft / Open / Unmerged。

## 1. 依据与适用范围

本决策承继：
- DEC-024：M17～M21 共享工作流、通知、规则、审计和报表 31 项 V1 功能批准。
- DEC-027：M22 外部权威服务适配 8 项 V1 功能批准。
- DEC-056：Issuer 共享工作中心、规则、审计报表与外部服务安全六项方向批准。
- U01：V1 一个账号对应一个企业；不提供企业内部成员、角色、权限配置和多级审批。
- DEC-080/081：资产发行、认购、资金、Token、锁仓、收益与退出的现行页面和权威数据边界。

本 DEC 只覆盖 Issuer 企业 SaaS 现有导航体系中的八个共享能力逻辑页面组；页面分别通过工作台/顶部全局入口、企业管理、数据与报表进入。不新增一级/二级导航、不新增正式功能 ID，不设计平台运营后台、统一投资端或独立投资者前台。

## 2. 导航与八个页面组

沿用现有九个一级导航及全局入口，不新增第十个一级导航或新的业务菜单。八个逻辑页面组的入口归属如下：

| 现有入口归属 | 页面 | 原有逻辑页面 |
|---|---|---|
| 工作台首页/顶部待办入口 | 我的待办 | I-59 |
| 工作台首页/业务页面异常入口 | 异常工单 | I-60 |
| 顶部消息入口 | 消息通知 | I-61 |
| 企业管理 | 规则设置 | I-62 |
| 数据与报表 | 审计记录 | I-63 |
| 数据与报表 | 业务报表 | I-64 |
| 企业管理 | 外部服务 | I-65 |
| 顶部安全/服务告警及相关业务详情 | 安全与服务状态 | I-66 |

I-59/I-60/I-61/I-66 是全局横向入口；I-62/I-65 沿用企业管理；I-63/I-64 沿用数据与报表。以上仅收口现有页面入口，不新增一级/二级导航或功能范围。

## 3. 八个页面组 UI-Ready 结论

完整页面目标、信息结构、中文字段、筛选、校验、操作、状态、空态、异常、跨页跳转和验收目标见：
[数据与共享能力 UI-Ready 最终规格](../docs/03-product-prd/r2-current-baseline/DATA-AND-SHARED-CAPABILITIES-UI-READY-CLOSEOUT-2026-11-11.md)。

### 我的待办

- 汇总当前企业账号需要处理的资料、业务操作、补件和外部申请跟进。
- 只提供待处理、我发起的、已完成等清单；不提供企业内部审批人分配、员工角色、多级审批。
- 实际业务动作必须回到原业务模块；任务完成状态回源确认。

### 异常工单

- 汇总资料、资格、认购、资金、登记、Token、收益和外部服务异常。
- 显示原业务状态、技术状态、工单处理状态和证据来源。
- 支持补件、查询原 Intent/交易/回执、提交核对和跟进。
- 不提供一键退款、改名册、Mint/Burn、重放不可逆操作或手动标记业务成功。

### 消息通知

- 统一站内业务消息、待办提醒和必要邮件投递结果。
- 已读、已发送、技术送达与法定有效送达严格分开。
- 允许标记已读和在符合条件时申请重发通知；重发通知不得重放原业务动作。
- 不增加营销 CMS、自由群发或全渠道偏好。

### 规则设置

- 查看套餐能力、Instrument/Offering 条款、资格、认购/配售前置、平台强制规则的来源和版本。
- 规则修改回到唯一负责的原业务模块；本页不重复建设配置。
- Issuer 不自定义投资者资格、地区、限额或 AML 豁免。
- 不增加自由规则编辑器、脚本、自动配售引擎或复杂工作流。

### 审计记录

- 查询当前企业授权范围内的操作、版本、外部证据和关键状态历史。
- 审计只读、追加，不允许原地修改或删除。
- 仅允许系统明确开放的脱敏数据导出；KYC 原件、完整证件号、Signer Secret、私钥和银行敏感凭证不自助导出。
- 不擅自设定法定保留年限。

### 业务报表

- 提供项目/发行、投资者/认购、资金/结算、配售/登记/Token、收益/存续五类只读报表。
- 报价/订单与真实到账分开；M01 订阅费、M11 认购资金、M13 收益资金分开；法定名册与 Token 数量分开；应付、注资、可领取、实付和未领取分开。
- 每项指标显示单位、数据截至时间、来源和完整/部分/延迟/Unknown 状态。
- 不增加预测 BI、自动估值、未批准汇率换算或可用余额推断。

### 外部服务

- 显示当前企业实际使用或已获准服务的用途、责任主体、业务范围、环境、连接状态和最近核验时间。
- 覆盖 KYB/KYC/AML、USDT 收款监测、节点/Token 事件、电子签署及依法适用的外部登记服务。
- Issuer 自管法定名册继续是可用路径，不强制外部登记者。
- 不提供任意 Provider 市场、生产 Secret/私钥/Signer 管理或智能切换。

### 安全与服务状态

- 显示服务健康、Webhook 签名/去重、重复投递、凭证风险、外部故障和关联业务 Unknown。
- 技术状态与真实资金、法定登记、Token、收益状态分开。
- 企业账号可以查询、提交问题和联系支持；真正凭证撤销/生产隔离由适格凭证持有人及平台安全责任主体执行。
- Provider 恢复、Webhook Delivered 或技术事件关闭均不能自动改变原业务状态。

## 4. 当前 V1 账号与责任边界

1. 一个账号对应一个企业；不在本轮增加企业内部成员、角色、权限矩阵或审批人分配。
2. 任务中心只聚合企业账号需要完成的动作及已发起请求，不建设 Issuer 内部审批队列。
3. 公司决议、法律批准、法定登记、KYC/AML、资金付款和 Token 签名均由适格责任主体按原业务流程承担；SaaS 页面只记录和引用证据。
4. M17/M18/M19/M20/M21/M22 只承担协调、通知、规则版本、审计、只读汇总和技术服务适配，不复制 M01/M04/M05/M06/M07/M09/M10/M11/M12/M13 业务主账。
5. Tenant 隔离与敏感数据最小化仍执行，但不把系统安全控制包装为企业可配置的 RBAC。
6. Free 仅在资产/权益/Offering准备和内部预览范围使用；可查看 U01 已批准的真实 KYB/MPC 钱包等非交易型服务状态，但不开放真实投资者交易、生产资金、生产 Signer 或 Token 执行。Standard 仅有商业权益，真实生产服务仍须独立满足法律、合同、服务、安全和平台准入。
