# RWA SaaS V1｜锁仓记录 UI-Ready 最终规格

> 设计日期：2026-11-11  
> 状态：Issuer 企业 SaaS 端产品/UI 规格 UI-Ready；不代表真实合约锁仓、链上限制或解锁执行已经获准或完成。  
> 唯一入口：资产与发行 → 锁仓记录（既有二级导航，不新增一级/二级菜单）  
> 维护分支：docs/r2-current-product-baseline｜PR #8 Draft / Open / Unmerged。

## 0. 依据、范围与收口结论

本规格承接以下已批准规则，不重新批准既有业务范围：

- U02-02：资产与发行仅保留「资产管理｜认购记录｜锁仓记录」三个二级入口；认购记录与锁仓记录是跨资产查询视图，不复制订单或锁仓主账。
- DEC-071 / U02-08：权益结构和 Token 映射由固定 InstrumentVersion 决定；法律权益单位与 Token 份数分开显示。
- DEC-072 / U02-09：Offering 认购规则明确选择「不锁仓 / 固定天数」；固定天数 1～36,500 天正整数；V1 不支持分期解锁、多段锁仓或按投资者等级配置；从 Token 实际交付时点起算；Offering 关闭不会自动解除既有锁仓；Offering 详情可跳转锁仓记录并自动带入 Asset / Offering 筛选。
- DEC-076 / U02-13：持有人详情只展示锁仓摘要及状态；实际锁仓记录跳转本页；法律/管理限制与业务锁仓分开，锁仓到期不自动解除法律限制。
- DEC-078 / Token 管理 UI-Ready 规格：Token 管理负责合约和真实链上事实；业务锁仓记录归本页；Token 管理只承接必要的链上锁仓/解除执行引用，不创建第二套锁仓主账。
- DEC-033：到期、退出、清退、公司行动和真实清偿由收益与分配及其权威主体处理；锁仓到期不是赎回、清偿或权益终止。
- DEC-058：V1 不开放强制转账、自由交易或任意锁仓策略；冻结/解除须有法律依据、真实授权及必要的链上执行。
- U01 Free / Standard：Free 仅内部预览、不产生真实投资者持仓或 Token 锁仓；Standard 付费和 KYB 通过不自动取得生产执行权。

本模块目标：企业能够查看哪些 Token 已按 Offering 规则锁仓、锁仓从何时开始、何时预计到期、链上限制是否真实生效、到期后是否已确认解除，以及异常应转到哪个权威模块处理。

本模块不负责：创建 Offering 锁仓条款、修改已发布规则、创建认购订单、确认配售/法定持有人、Mint/Burn、手工改 Token 余额、执行法律冻结、赎回/清退或真实资金结算。

## 一、导航与页面职责

### 1.1 唯一导航

一级导航：资产与发行。二级导航保持现有三项：

1. 资产管理
2. 认购记录
3. 锁仓记录

不新增「锁仓管理」一级菜单，不把锁仓记录迁入 Token 管理或持有人管理，不恢复历史五菜单。

### 1.2 页面职责

本页是跨 Asset / Offering 的业务锁仓记录查询与状态跟踪页：

- 读取 Offering 已发布版本中固定的锁仓方式与期限；
- 关联唯一有效配售、合法持有人引用和真实 Token 交付；
- 记录每次实际 Token 交付对应的锁仓起算时间和预计到期时间；
- 分开展示业务锁仓期限、链上限制执行状态、法律/管理限制状态；
- 识别待交付、锁仓中、期限已到、解除处理中、已确认解除和 Unknown/异常；
- 提供到 Offering、认购订单、配售与持有人、Token 管理、收益与分配的权威跳转。

本页不提供手工新增、编辑、删除锁仓记录。锁仓记录由已批准的 Offering 规则和真实配售/Token 交付事实自动形成；纠正必须追溯原来源并追加证据，不能直接覆盖历史。

### 1.3 与相邻模块的分工

| 业务事实 | 权威来源/责任模块 | 本页处理 |
|---|---|---|
| Offering 锁仓方式、固定天数、已发布条款版本 | 资产与发行 → 资产管理 → Offering | 只读引用已发布快照 |
| 认购订单、投资者引用、订单状态 | 投资者与认购 → 认购订单 | 只读关联，不建订单 |
| 配售决定、合法持有人和法律权益数量 | 投资者与认购 → 配售与持有人 | 只读引用，不改法定登记 |
| Token 接收钱包、Mint、链上交付时间、Token 数量 | Token 管理 | 只读引用真实最终确认事实 |
| 合约级时间锁/转让限制及链上解除结果 | Token 管理及真实受权执行主体 | 展示执行引用与核验结果；需要显式链上解除时跳转 Token 管理 |
| 法律/管理冻结、法院/监管限制 | 配售与持有人 → 差异与限制 / 依法有权主体 | 独立展示，不自动随业务锁仓解除 |
| 赎回、清退、到期清偿及公司行动 | 收益与分配 → 到期与退出 | 展示关联事项和跳转，不在本页发起赎回/清退 |
| 认购款、退款、募集款 | 资金与结算 | 不读取或推断为锁仓状态依据 |

### 1.4 三种状态必须分开

1. 业务锁仓期限：Offering 约定的固定天数是否仍在期限内。
2. 链上转让限制：Token 合约是否已真实限制转让、是否已达到解锁条件、是否已经链上确认可转让。
3. 法律/管理限制：是否另有有效冻结、禁转或其他法律限制。

三者可同时存在，互不自动替代：

- 业务锁仓到期不等于链上限制已解除；
- 链上可转让不等于法律/管理限制已解除；
- 法律冻结解除不等于 Offering 锁仓已到期；
- Offering 关闭不等于投资者既有锁仓解除；
- 锁仓解除不等于 Token 已赎回、Burn、清偿或法律权利终止。

## 二、核心生成规则与 V1 边界

### 2.1 锁仓记录生成

- Offering 选择「不锁仓」：不生成业务锁仓记录；但不代表不存在法律/管理或其他合约级转让限制。
- Offering 选择「固定天数」：仅在该 Offering 下存在真实有效配售后，形成待交付锁仓事项；该事项只表示预期锁仓义务，不代表 Token 已锁仓。
- Token 实际交付达到适用链上最终确认后，才形成正式锁仓记录并开始计时。
- 每一条正式锁仓记录对应一个唯一的实际 Token 交付批次/事件，关联唯一配售来源、Offering 规则快照和实际接收钱包。
- V1 正常路径是一项配售决定对应一次完整 Token 交付；如正式获批的特殊场景确需分批交付，每个真实交付批次单独形成锁仓记录，各自按实际交付时间起算，不合并时钟。
- 同一持有人在不同 Offering、不同配售或不同交付批次产生的锁仓记录必须分开；不得合并成一个持有人级总锁仓。
- 未达到最终确认的 Mint Intent、只有交易哈希但未达到适用最终性、或链上事件 Unknown 时，不得开始锁仓计时，不得显示「锁仓中」。

### 2.2 起算与预计到期

- 起算时间使用真实 Token 交付事件的权威链上发生时间；平台接收时间、回调时间、企业点击时间不得代替。
- 另行展示「平台确认时间」和「最近链上核验时间」，避免把区块事件时间与系统观察时间混为一谈。
- 固定天数来自 Offering 发布快照，不允许本页编辑；预计到期时间按该快照中已确认的期限口径计算。
- 页面同时显示完整日期、时分、时区；若来源时间戳或期限口径缺失/冲突，显示「到期时间待核」，不得猜测。
- 锁仓期限到达只表示业务期限届满；是否已经链上解除，必须另行核验真实合约状态或受权解除事件。
- 不在本页重新计算、修改或覆盖已发布 Offering 的锁仓天数。

### 2.3 Offering 发布与生产准入守卫

- 选择固定天数的 Offering，必须在正式发布前确认适用合同/披露文本与锁仓天数一致。
- 真实生产发布前，必须确认所选 Token 方案/合约模板或其他依法批准的执行安排，能够实现并核验该锁仓限制；缺少可执行/可核验安排时，真实发布阻断。
- Free 内部预览可展示锁仓规则样式，但不得生成真实锁仓记录或虚构链上状态。
- 「不锁仓」仅表示 Offering 不设置本期统一基础锁仓；不豁免适用法律、合同、监管或合约本身的转让限制。

### 2.4 V1 明确不支持

- 分期解锁、多段锁仓、按投资者等级/身份/金额差异化锁仓；
- 投资者自定义锁仓天数、Issuer 在交付后修改锁仓期限；
- 多种锁仓计划叠加、自动续锁、滚动锁仓；
- 普通企业用户提前解锁、手工延长、手工缩短或批量解除；
- 自由转让、C2C、撮合、二级市场交易、强制转账；
- 本页手工 Mint、Burn、冻结、解冻、改钱包或改 Token 数量；
- 以锁仓到期代替赎回、退出、还本付息或清退。

如出现有法律效力的提前退出/回购/公司行动，按「收益与分配 → 到期与退出」及相应受权 Token 处置流程处理；不得把它伪装成普通提前解锁。

## 三、页面总览与列表

### 3.1 页面顶部

标题：锁仓记录。

说明文案：
> 按发行方案已发布的锁仓规则，查看投资者 Token 的锁仓期限与实际链上状态。固定天数从 Token 实际交付时点起算；锁仓到期不代表法律限制自动解除。

页面顶部主操作仅为只读/查询类：
- 查看 Offering；
- 查看相关 Token 执行；
- 查看差异与异常。

不显示「新增锁仓」「编辑锁仓」「手动解锁」「批量解锁」按钮。

### 3.2 摘要统计

按当前 Tenant 和筛选范围统计，只有真实权威数据存在时显示：

| 卡片 | 口径 |
|---|---|
| 待交付锁仓 | 已有有效配售且 Offering 固定天数，但 Token 尚未最终交付的预期事项；不计入实际锁仓数量 |
| 锁仓中 | 已最终交付且业务锁仓期限尚未到期的正式记录 |
| 期限已到待核 | 业务期限已届满，但链上可转让/解除状态尚未确认的正式记录 |
| 已确认解除 | 链上自动到期或受权解除结果已达到适用最终性、且核验确认解除的正式记录 |
| 异常 / Unknown | 来源冲突、链上状态未知、非预期转让、时间戳缺失、数量不匹配等记录 |

统计规则：
- Token 份数与法律权益单位分列，不把股数、债权本金 U、参与比例与 Token 份数相加。
- 待交付锁仓不得显示为已锁仓 Token 数量。
- Unknown 不按 0 处理，不因数据源不可达而从统计中消失。
- 无真实记录时显示「暂无锁仓记录」，不展示虚构的「锁仓 0」生产运营卡片。

### 3.3 页面内状态快捷筛选

页面只有一个列表，不新增页面级二级菜单；可用轻量状态筛选：

- 全部；
- 待交付；
- 锁仓中；
- 期限已到待核；
- 解除处理中；
- 已确认解除；
- 异常 / Unknown。

快捷筛选仅改变列表条件，不改变权威状态。

### 3.4 筛选项

| 字段 | 控件 | 规则 |
|---|---|---|
| 搜索 | 输入框 | 支持锁仓记录编号、待交付事项编号、Asset/Offering 名称、订单编号、配售编号、Mint Intent/交易哈希；不开放身份证件、电话、邮箱搜索 |
| Asset | 下拉 | 当前 Tenant 的真实 Asset |
| Offering | 下拉 | 随 Asset 联动，只显示真实关联 Offering |
| 持有人 | 下拉/搜索 | 仅使用企业内脱敏持有人引用编号或脱敏名称，不显示原始 KYC 信息 |
| 锁仓状态 | 多选 | 待交付、锁仓中、期限已到待核、解除处理中、已确认解除、异常/Unknown |
| 链上执行状态 | 多选 | 待核验、锁仓已确认、自动到期待核、解除待执行、执行中、已解除确认、失败、Unknown、不适用 |
| 交付时间 | 日期范围 | 按真实 Token 交付事件时间筛选；待交付事项无交付时间 |
| 预计到期时间 | 日期范围 | 仅适用于已形成正式锁仓记录且到期时间可核验的记录 |
| 最近更新 | 日期范围 | 平台最后一次权威状态更新 |

筛选交互：
- Asset 变化后清除不属于该 Asset 的 Offering 选择。
- 日期起始不得晚于结束。
- 清空筛选恢复默认列表；返回详情后保留原筛选、排序和分页。
- 默认排序：异常/Unknown → 期限已到待核 → 解除处理中 → 锁仓中 → 待交付 → 已确认解除；同状态按最近更新倒序。
- 每页 20 条；移动端转为信息卡片，不横向压缩关键信息。

### 3.5 列表字段

| 列 | 内容与来源 |
|---|---|
| 锁仓记录/事项 | 正式锁仓记录编号；待交付阶段显示待交付事项编号并标注「预期锁仓」 |
| Asset | 资产名称、资产编号 |
| Offering | 发行方案名称、期次及发布版本 |
| 持有人 | 脱敏名称、企业范围内持有人引用编号 |
| 来源 | 认购订单编号、唯一配售决定编号；不显示原始身份资料 |
| Token 数量 | 已交付数量（正式记录）；待交付阶段显示获配待交付数量并明确标注「尚未交付」 |
| 锁仓规则 | 固定天数显示 N 天及 Offering 快照版本 |
| 锁仓起算 | 真实链上 Token 交付时间；待交付显示「待交付」 |
| 预计到期 | 根据固定期限和权威起算时间计算；不可核验时显示「待核」 |
| 业务锁仓状态 | 待交付/锁仓中/期限已到待核/解除处理中/已确认解除/异常 |
| 链上状态 | 锁仓确认、自动到期待核、解除待执行/处理中/已确认、失败、Unknown、不适用 |
| 法律/管理限制 | 独立显示无/待核/有效/解除处理中/已解除；不得并入业务锁仓状态 |
| 最近更新 | 最近一次权威业务或链上事件时间 |
| 操作 | 查看详情；符合条件时查看 Token 执行/差异 |

不展示：
- 没有真实来源的已锁 Token 数量；
- 法律权益数量与 Token 数量混合后的单一数字；
- 推测的解锁成功状态；
- 未经授权的完整钱包地址或个人资料。

### 3.6 列表空态

| 场景 | 文案与下一步 |
|---|---|
| 企业没有任何固定天数 Offering | 「当前没有设置固定天数锁仓的发行方案。可在新建 Offering 时明确选择不锁仓或固定天数。」→ 查看资产与发行 |
| 有固定天数 Offering，但没有真实配售 | 「当前尚无需要生成锁仓记录的有效配售。」→ 查看 Offering / 配售与持有人 |
| 有有效配售但尚未交付 Token | 「有待交付的预期锁仓事项。Token 实际交付并达到链上最终确认后，才开始计算锁仓期限。」→ 查看 Token 管理 |
| 有记录但当前筛选无结果 | 「没有符合当前筛选条件的记录。」→ 清空筛选 |
| 链上数据暂不可用 | 保留最后已知结果和时间，显示「链上状态待核」；不以空列表或 0 替代 |

## 四、锁仓详情

### 4.1 打开方式

点击列表行进入详情页/侧边详情面板；不新增二级导航。详情顶部固定：
- 锁仓记录编号或待交付事项编号；
- Asset / Offering；
- 脱敏持有人引用；
- Token 数量；
- 业务锁仓状态；
- 链上执行状态；
- 唯一安全下一步。

### 4.2 A 区：来源与规则快照

| 字段 | 展示规则 |
|---|---|
| Asset | 名称、编号、资产类型，只读 |
| Instrument | 权益类型、固定 InstrumentVersion，只读 |
| Offering | 名称、编号、发布版本、当前/历史状态，只读 |
| Offering 锁仓方式 | 不锁仓/固定天数；只有固定天数生成本页记录 |
| 固定锁仓天数 | 读取 Offering 发布快照，1～36,500 天，只读 |
| 锁仓条款快照 | 已发布的锁仓说明/合同文件版本及其状态；不允许本页替换 |
| 认购订单 | 唯一订单编号，只读跳转 |
| 配售决定 | 唯一有效配售编号及确认时间，只读跳转 |
| 规则来源 | Offering 版本、适用模板/规则版本及引用依据 |
| Offering 关闭状态 | 显示关闭时间；明确说明关闭不会解除本记录 |

### 4.3 B 区：持有人与 Token 交付

| 字段 | 展示规则 |
|---|---|
| 持有人引用 | 企业内脱敏主体及引用编号；不展示原始 KYC |
| 法定登记引用 | 有效登记编号/状态；待核时明确显示 |
| Token 接收钱包 | 缩略地址 + 网络；完整地址仅在有权详情可查看/复制 |
| Token 方案 | Token 方案版本、合约、网络（真实部署存在时） |
| Mint Intent | 唯一操作编号及状态 |
| 链上交付事件 | 交易哈希、事件引用、区块/最终性（有真实来源时） |
| 实际交付 Token 数量 | 仅统计达到适用最终确认的数量 |
| 法律权益数量 | 只读显示权威法定登记数量和法律单位，与 Token 数量分开 |
| 交付时间 | 链上事件发生时间；平台接收/确认时间另列 |
| 当前链上持有量 | 只读链上查询摘要，标注 As-of 时间；不代表法定权益量 |

待交付阶段：
- 显示已确认配售数量、待交付 Token 数量、Mint 当前状态；
- 起算时间、预计到期时间均显示「待 Token 实际交付」；
- 不显示「锁仓中」或「已锁仓」；
- 不允许从本页发起 Mint，主入口跳转 Token 管理。

### 4.4 C 区：期限与实际执行

| 字段 | 展示规则 |
|---|---|
| 锁仓起算时间 | 真实最终确认 Token 交付事件的链上发生时间 |
| 平台确认时间 | 平台确认该交付事件达到适用最终性的时间 |
| 固定锁仓天数 | Offering 快照只读 |
| 预计到期时间 | 按该 Offering/合约已批准期限口径计算；缺少依据显示待核 |
| 当前时间剩余 | 仅在起算和到期均可核验时显示；不作为法律通知 |
| 执行方式 | 已批准合约模板/合法安排决定：合约自动到期、到期后需受权解除操作或其他已批准方式；只读 |
| 链上锁仓状态 | 未核验/已确认锁仓/自动到期待核/解除待执行/解除处理中/已确认解除/失败/Unknown |
| 链上可转让状态 | 仅在真实查询来源可确认时显示可转让/仍受限/待核；不得从预计到期时间推断 |
| 法律/管理限制 | 独立显示限制类型、责任方、依据、有效期和解除状态 |
| 实际解除时间 | 真实链上自动到期状态确认时间或受权解除事件时间；不得以计划到期时间代替 |
| 最近链上核验 | 时间、数据来源状态和最后确认结果 |

状态展示原则：
- 业务期限未到且链上限制确认：显示「锁仓中 / 链上限制已确认」。
- 业务期限未到但链上限制未确认：显示「锁仓中 / 链上状态待核」或异常，不宣称锁仓已被链上执行。
- 业务期限已到：先显示「期限已到待核」，再依据已批准执行方式核实实际链上状态。
- 合约自动到期：到期后必须查询真实合约状态；只有核实已可转让/限制已解除，才显示「已确认解除」。
- 需要受权解除操作：到期后显示「解除待执行」，跳转 Token 管理的关联链上操作；本页不直接签名或解除。
- 链上状态 Unknown/数据源不可达：保留最后已知状态和时间，不能标记已解除。
- 法律/管理限制仍有效：即使业务锁仓和链上时间锁已解除，也要醒目标注「仍存在独立法律/管理限制」。

### 4.5 D 区：事件时间线与审计

按发生时间倒序展示：
- Offering 发布及锁仓规则版本固定；
- 唯一配售决定确认；
- Mint 申请、批准、提交、链上事件和最终性确认；
- 锁仓记录生成；
- 锁仓开始和预计到期；
- 定期链上状态核验；
- 到期、解除申请/执行、链上确认；
- 法律/管理限制的新增、解除和依据更新；
- 异常发现、复核、责任方、处理结果；
- 依法退出/Burn/登记更正等关联事件。

每条事件显示：事件类型、真实发生时间、平台接收时间、来源模块、关联编号、结果、证据引用、执行/确认主体（如有）。历史不可删除或覆盖。

### 4.6 详情操作

允许：
- 查看 Offering 发布快照；
- 查看认购订单；
- 查看配售与持有人登记；
- 查看 Token 交付与链上执行；
- 在到期且需要显式受权链上解除时，跳转 Token 管理对应记录；
- 查看相关法律/管理限制；
- 查看收益与分配中的到期/退出事项；
- 对数据差异提交「待核/复核」事项（只创建调查请求，不修改原始事实）。

禁止：
- 编辑锁仓天数、起算时间、预计到期时间、Token 数量、接收钱包；
- 手工标记锁仓成功/解锁成功；
- 提前解锁、延长或缩短锁仓；
- 直接执行 Mint、Burn、冻结、转账；
- 删除锁仓记录或清除历史；
- 把 Token 数量改写为法定权益数量。

## 五、状态与迁移

### 5.1 业务锁仓状态

| 状态 | 含义 | 主动作 |
|---|---|---|
| 待交付 | 有效配售引用固定天数 Offering，但 Token 尚未最终交付 | 查看 Token 交付 |
| 锁仓中 | Token 已实际交付并最终确认，业务期限尚未届满 | 查看详情 |
| 期限已到待核 | 业务期限届满，实际链上解除/可转让状态尚未核实 | 核验链上状态 / 查看 Token 管理 |
| 解除待执行 | 已到期，批准的合约方式要求受权主体执行解除 | 前往 Token 管理 |
| 解除处理中 | 唯一解除 Intent 已提交，等待链上结果 | 查看原操作 |
| 已确认解除 | 链上自动到期或受权解除结果已确认，且无未解决的相关链上限制 | 查看历史 |
| 异常 / Unknown | 时间、数量、主体、链上事件或执行状态冲突/未知 | 查看差异 |

已确认解除仅描述该条业务锁仓及其对应链上限制已解除，不代表其他法律/管理限制已解除，不代表可自由转让，也不代表法定持有人发生变化。

### 5.2 链上执行状态（独立维度）

- 待核验；
- 锁仓已确认；
- 自动到期待核；
- 解除待执行；
- 解除处理中；
- 已确认解除；
- 执行失败；
- Unknown / 数据源不可达；
- 不适用（仅在合法安排明确不要求链上锁仓且已通过准入时）。

业务状态与链上状态分列，不用一个状态字段掩盖差异。

### 5.3 状态迁移主线

有效配售 + Offering 固定天数
→ 待交付
→ Token 实际交付达到适用最终确认
→ 锁仓中
→ 固定期限届满
→ 期限已到待核
→ 合约自动到期并核验链上状态，或由真实受权主体提交唯一解除操作
→ 链上结果达到适用最终确认
→ 已确认解除。

异常分支：
- Mint/交付失败或 Unknown：保留待交付状态和原 Token Intent，不开始计时、不重复 Mint。
- 链上锁仓未生效/状态 Unknown：标记异常，升级 Token 管理核验；不得显示已锁定成功。
- 期限到达但链上仍受限：保留「期限已到待核/解除待执行」，不得手工改状态。
- 发现锁仓期间非预期 Transfer：标记重大异常，跳转 Token 管理及配售/持有人核对；不自动反向转账。
- 业务锁仓解除但法律限制仍有效：业务锁仓显示已解除，法律限制单独显示有效。
- 链重组或最终性撤回：相关记录转为待复核，保留原事件与历史，不静默重置。

## 六、跨模块闭环

### 6.1 Offering 到锁仓记录

Offering 创建时明确选择：
- 不锁仓；或
- 固定天数（1～36,500 天）。

发布后锁仓方式/天数固定在 Offering 版本快照中。Offering 详情提供「查看锁仓记录」入口，自动带入 Asset 和 Offering 筛选。发布后不允许普通编辑直接修改锁仓条款；确有合法变更须走受权变更和历史影响评估。

### 6.2 配售到 Token 交付

有效配售决定
→ 生成待交付预期锁仓事项（只表示应适用的固定锁仓规则）
→ Token 管理按配售决定执行唯一 Mint/交付
→ 链上达到适用最终确认
→ 生成正式锁仓记录
→ 以链上交付事件时间开始计时。

资金 FinalMatched、配售有效、法定登记结果和 Token 交付各自独立；本页不以付款截图、订单状态或配售状态开始锁仓。

### 6.3 到期与解除

- 到期时间来自固定 Offering 规则和真实 Token 交付时间。
- 合约自动到期：Token 管理查询真实链上状态，确认可转让/限制解除后回写本页状态。
- 需显式解除：本页跳转 Token 管理，由真实有权主体按批准流程提交唯一解除操作；本页只读结果。
- Unknown 必须核验原事件/Intent，不重复提交解除。
- 不提供普通企业用户提前解锁、批量解除或人工强制修改状态。

### 6.4 法律限制与退出

- 法律/管理限制在配售与持有人中维护受权依据；本页只读引用。
- 到期后如法律限制仍有效，显示业务锁仓已到期但法律限制仍生效；不得提示投资者已完全可转让。
- 赎回、清退、回购、到期清偿和公司行动走收益与分配；需要 Token Burn/限制调整时再引用 Token 管理。
- Burn、赎回或退出完成后，本页只有在权威事件确认时才将相应锁仓记录标为依法终止/已处置；不自行确认资金清偿或法律权利终止。

## 七、Free / Standard、权限与隐私

| 企业状态 | 页面能力 |
|---|---|
| KYB 未通过/审核中/补件 | 导航可见但按统一 KYB 门禁拦截详情；显示认证引导 |
| Free + KYB 通过 | 可查看功能说明/内部预览；没有真实客户锁仓记录，不生成模拟持仓或锁仓 |
| Standard + KYB 通过、生产准入未通过 | 可查看已有真实历史记录（如合法存在）和待准入说明；不开放真实链上执行 |
| Standard + 适用生产准入通过 | 依权限查看本企业真实锁仓记录；链上解除仍由真实有权主体执行 |
| 降级 Free | 历史真实记录只读保留；在途解除、争议和法律义务不得删除或自动取消 |

权限与隐私：
- 仅当前 Tenant 可查看其 Asset、Offering、订单、配售、持有人和锁仓记录；跨 Tenant 不得检索或泄露记录存在性。
- 持有人默认脱敏；不展示原始 KYC、证件、个人电话/邮箱或第三方核验报告。
- 钱包地址默认缩略；完整地址仅在有权详情查看/复制，并明确网络。
- 不显示私钥、助记词、Signer Secret、API 密钥或其他执行凭证。
- 单账号企业模式不新增 V1 内部财务/合规/审批角色；但法律/合约要求的独立批准仍必须引用真实有权主体证据。
- 关键锁仓事实和事件历史不可删除；纠正只能追加证据和后续事件。

## 八、全局异常处理

| 场景 | 页面表现 / 安全下一步 | 禁止行为 |
|---|---|---|
| Offering 未选择锁仓方式 | 不生成锁仓记录，定位 Offering 资料缺项 | 默认推断为不锁仓 |
| Offering 选择不锁仓 | 不生成业务锁仓记录；仍可展示其他法律限制 | 把不锁仓描述为无任何转让限制 |
| 固定天数缺失/非法 | 阻断 Offering 资料检查/发布 | 使用默认天数或静默补值 |
| 固定锁仓没有获准执行/核验安排 | 阻断真实发布并说明缺失准入 | 宣称链上锁仓已具备 |
| Offering 已发布后条款变化 | 使用固定历史快照，要求受权变更 | 覆盖既有锁仓规则 |
| Offering 已关闭 | 既有锁仓继续按原快照跟踪 | 自动解除锁仓 |
| 配售已确认、Token 未交付 | 显示待交付，不显示起算/到期时间 | 提前开始计时 |
| Mint 有 TxHash 但未最终确认 | 保留待交付/待核，查询原 Intent | 标记锁仓中或重复 Mint |
| Token 交付数量与配售不一致 | 标记差异，跳转 Token/配售核对 | 自动修正数量 |
| Token 接收钱包与登记映射不匹配 | 显示主体/钱包差异并受权复核 | 自动变更持有人或钱包 |
| 链上锁仓未确认 | 显示链上待核/失败 | 标记已锁定成功 |
| 交付时间缺失/冲突 | 起算与预计到期显示待核 | 用平台录入时间代替 |
| 到期时间计算依据不一致 | 标记待核，显示 Offering/模板版本 | 选择更早日期自动解锁 |
| 业务期限已到、链上仍受限 | 显示解除待执行/待核并跳转 Token 管理 | 手工标记已解锁 |
| 自动到期后链上查询 Unknown | 保留最后已知状态和核验时间 | 假设已可转让 |
| 解除 Intent 已提交 | 查询原 Intent，保留原记录 | 重复提交解除 |
| 解除失败/Unknown | 显示失败/Unknown 和原操作 | 生成第二笔解除 |
| 法律/管理冻结仍有效 | 单独显示法律限制仍有效 | 随业务锁仓到期自动解除 |
| 锁仓期间出现 Transfer | 重大异常，关联 Token 事件和法定登记调查 | 自动强制转回或默认为合法 |
| 链重组/最终性撤回 | 标记待复核，保留原链上事件 | 删除旧事件/静默重置 |
| 同一事件重复回调 | 幂等关联到原锁仓记录 | 生成重复锁仓记录 |
| 数据源不可用 | 显示最后已知状态与时间 | 用缓存显示全绿 |
| 认购订单取消但 Token 已交付 | 保留真实交付/锁仓事实，走退款/退出等受权流程 | 取消订单即删除锁仓 |
| 企业降级/暂停 | 历史只读，存续义务保留 | 删除锁仓记录或解除链上限制 |

## 十、V1 收口结论与治理

- 本模块仅完成现有 V1「资产与发行 → 锁仓记录」页面的产品/UI 规格；不新增正式功能 ID，不改变 193 项正式功能 ID/首次交付版本归属或后续版本范围。
- 本轮不新增锁仓模型：继续执行 Offering 的「不锁仓 / 固定天数」；固定天数 1～36,500 天；从 Token 实际交付时点起算；不支持分期/多段/按等级配置。
- 锁仓记录由真实配售和 Token 交付事实形成；业务期限、链上执行、法律/管理限制三种状态分离。
- 不将锁仓记录并入 Token 管理、持有人登记、订单或资金主账；不开放提前解锁、自由转让、强制转账、二级交易或复杂锁仓策略。
- 当前规格未批准具体链、合约标准/模板、锁仓执行技术、Signer、最终性阈值或真实生产执行；相关事项继续受 DEC-078 和独立生产准入约束。
- 本次代码、Build、Browser、自动化、真实合约/链上锁仓/解锁和人工 UAT 均未执行。
- Frozen、193 项正式功能 ID/首次交付版本归属、历史 DEC/SCOPE、X-01～X-13 均保持不变；V1 整体仍未 Frozen。
- PR #6、PR #8 保持 Draft / Open / Unmerged，不合并。
- **结论：锁仓记录模块企业 SaaS 产品/UI 规格达到 UI-Ready。**
