### 0.3 本模块必须保留的独立事实

1. 合法 Instrument/Series 义务、M12 法定持有人登记、M13 收益应付/分配批次/实付、M07 Token 链上事实分别独立。
2. 预计收益 ≠ 合法应付；已计算 ≠ 已批准；已批准 ≠ 已真实注资；已注资 ≠ 投资者已领取/收到；Claim 已提交 ≠ 实际 Paid。
3. 到期事件、真实本金/收益清偿、M12 法定权益变更、M07 Token Burn/冻结分别核实；Burn 不等于债务清偿或股权自动消灭。
4. M01 SaaS 订阅费、M11 认购款/退款/募集款、M13 收益/本息/清退款分别记录，不共用一个「支付成功」状态。
5. Offering 关闭、企业降级、欠费或退租，不删除真实存续义务、未付金额、未领取金额、合法权益和责任交接资料。
6. M12 是法定持有人/权益登记权威；Token 余额只作为辅助核对，不替代合法 Record Date 名册。
7. Issuer 页面只展示当前企业有权查看的投资者脱敏信息；不得展示 KYC 原件、证件号码、完整联系方式或不必要的个人身份材料。

### 0.4 设计完成与生产准入边界

- 本文五个页面组均达到页面目标、入口、信息结构、字段、控件、必填/选填、条件展示、校验、按钮、弹窗、状态、空态、异常、跳转和下一步引导完整的 UI-Ready 程度。
- Free 只能使用明确标识的内部 Sandbox/预览数据；不得创建真实收益义务、真实注资、Claim、Push、真实清偿或真实法律权益变更。
- Standard 仅具备相应商业权益；真实收益/本息运营仍须满足适用法律、合同、实际付款主体、资金、Signer、服务及生产准入。
- 本轮不设计 API、数据库、合约、Provider、Signer、生产支付或工程实现。

### 1.1 页面共用入口与布局

- 左侧二级导航仅显示上述三个入口；I-55/I-56/I-57 在「收益分配」下按页面标题进入，不增加第四、第五个二级导航。
- 页面顶部显示当前企业名称和套餐/环境状态；Free 显示明显的「内部 Sandbox」标识。
- 业务筛选统一采用：资产、权益结构类型、发行方案/发行批次、时间范围、业务状态。
- 列表默认按「需要处理/即将到期/最近更新」优先排序；用户可切换最近更新时间。
- 所有详情统一显示：业务对象、权威来源、当前版本、最近核验时间、状态历史、证据文件、当前阻断原因和下一步操作。
- 不展示 Project 独立菜单；页面中的 Project 信息仅作为 Offering 的辅助上下文。
- 所有金额在企业端统一以 **U** 展示；实际付款资产/币种及付款轨道按已核准的 Instrument 与合法支付安排单独标识，不由 U 自动推断。
- 日期同时展示事件日期、Record Date、合同应付日、计划付款日、实际到账日；不得混成一个「支付日期」。

### 1.2 通用列表与详情交互

- 列表行点击进入详情；详情页保留返回原筛选列表。
- 筛选项支持清空；无匹配结果显示「未找到符合条件的记录」，提供清除筛选。
- 状态标签旁可查看状态说明；Unknown、待核验、争议、部分成功不能使用成功色或显示为完成。
- 任何不可逆或影响已批准权益/付款事实的操作，必须先显示影响范围、原版本、关联批次和确认提示。
- 不提供「手动标记已支付」「直接修改法定持有人」「直接修改 Token 余额」「删除已发生收益/付款历史」等操作。

## 2. 跨模块数据来源与责任边界

| 本模块所需信息 | 权威来源 | 本模块允许的操作 |
|---|---|---|
| 资产、权益类型、InstrumentVersion、合同条款、债权付息计划、收益参与比例/期限 | 资产与发行 → 资产管理/权益结构 | 只读引用；合同条款变更返回权益结构创建新版本 |
| Offering、发行批次、发行时间及发行文件快照 | 资产与发行 → Offering | 只读引用；不得在本模块改变发行条款 |
| 合法持有人、法定权利单位、登记生效时点、争议/限制 | 投资者与认购 → 配售与持有人（M12） | 读取受权脱敏名册；提出核验/更正请求，不直接改写登记 |
| Token 余额、交付、冻结、Burn、链上最终性 | Token 管理（M07） | 只读核对；受权 Token 操作回原模块 |
| 收益事件、Record Date 快照、应付计算、分配批次、收益注资与实际支付结果 | 本模块（M13） | 唯一负责本模块的收益/本息/清退业务事实 |
| 认购款、募集款、认购退款 | 资金与结算（M11） | 不读取为收益资金、不转作收益注资 |
| 待办、异常、通知、审计、只读报表 | 数据与共享能力（M17～M21） | 提供任务、提醒、审计和只读汇总；不替代 M13 状态 |
| 外部权威回执、合法登记/支付/服务结果 | 适格外部责任主体及受权服务 | 展示已核验结果与证据；不把服务回调直接视为法律/付款完成 |

### 2.1 投资者隐私

- 列表仅显示持有人引用编号、脱敏姓名/机构名称、必要的权利类别与权利单位。
- 不显示完整身份证件号、护照号、KYC 文件、家庭住址、完整邮箱或电话。
- 收款钱包仅在当前业务确有必要且用户有权时显示缩略地址；钱包变化不得改变法定受益人。
- 任何敏感数据查看均保留审计；普通企业账号不因可进入本模块而自动获得 KYC 原件或完整个人资料权限。

### 2.2 企业账号与有权审批

- V1 一个账号对应一个企业，不新增企业内部多角色/审批人配置。
- 页面记录合同、公司决议、合法审批依据、实际付款主体及证据；「已提供批准依据」不等于平台替公司确认其法律效力。
- 真实公司决议、法定登记、实际付款和 Signer 权限由相应有权主体承担；SaaS 账号本身不自动成为董事会、股东会、法定登记人或实际付款人。
- 页面中「提交核验/提交复核」是业务资料与证据流转，不创建新的企业多级审批制度。

## 3. I-54｜存续档案与义务

### 3.1 页面目标与入口

- **目标：** 让企业一眼看到哪些已发行权益仍然存续、谁承担法律义务、下一项需要履行什么，以及是否存在逾期/争议/未结收益。
- **入口：** 收益与分配 → 存续管理。
- **使用者：** 当前企业账号；依法/依合同有权提供资料的企业代表。
- **页面类型：** 存续档案列表 + 存续详情；详情通过列表行进入，不新增独立导航。

### 3.2 列表布局

**顶部统计卡片**

| 卡片 | 统计口径 |
|---|---|
| 存续中的发行批次 | 尚存在合法权益或未结义务的 Instrument/Offering |
| 近期待履行 | 未来 30 天内合同付息、披露、收益上报或到期事项 |
| 逾期/部分履约 | 已过应履行日期且未全部履行，或仅部分完成 |
| 待核验/争议 | 法律主体、合同、登记、收益或外部证据存在 Unknown/争议 |

统计卡片点击后自动应用对应筛选，不允许统计数与列表口径不一致。

**筛选区**

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 资产 | 可搜索下拉 | 否 | 仅当前企业资产 |
| 权益类型 | 单选下拉 | 否 | 股权 / 债权 / 收益参与权 |
| 发行方案 | 可搜索下拉 | 否 | 只显示当前企业有权访问的 Offering |
| 存续状态 | 多选 | 否 | 存续中 / 待核验 / 争议 / 部分履约 / 逾期 / 待结清 / 已依法结清 |
| 待履行事项 | 多选 | 否 | 披露 / 收益上报 / 利息 / 股息 / 本金 / 到期退出 / 责任交接 |
| 到期/履行日期 | 日期范围 | 否 | 按合同/义务日期过滤 |
| 关键词 | 输入框 | 否 | 资产名称、发行方案、义务主体名称 |

**列表字段**

| 字段 | 展示规则 |
|---|---|
| 资产/发行方案 | 资产名称、Offering 名称；显示发行批次 |
| 权益类型 | 股权 / 债权 / 收益参与权 |
| 法律义务主体 | 发行人、债务人或收益责任主体；来自生效 Instrument |
| 存续状态 | 使用本页状态语义 |
| 下一项义务 | 付息、披露、收益上报、本金到期或其他合同义务 |
| 下一履行日期 | 合同应付日/披露期限；计划日期单独标识 |
| 未结金额 | 已确认应付未清偿金额；未确认时显示「待核验」，不显示 0 |
| 异常提示 | 逾期、部分履约、登记争议、外部 Unknown |
| 最近更新 | 最近一次有效业务事实更新时间 |
| 操作 | 查看详情 |

默认排序：逾期/争议优先，其次未来 30 天待履行，再按最近更新。

### 3.3 存续详情布局

详情分为四个信息区：

1. **基本信息与法律责任**
2. **存续义务与时间线**
3. **披露与文件**
4. **履约记录与历史版本**

**基本信息字段**

| 字段 | 展示/控件 | 规则 |
|---|---|---|
| 资产名称 | 只读 | 来源 Asset |
| 发行方案 | 只读 | 来源 Offering |
| 权益类型 | 只读 | 来源 InstrumentVersion |
| Instrument 版本 | 只读版本号/查看入口 | 显示当前生效及发行时引用版本 |
| 法律发行主体 | 只读 | 来源已批准法律文件/Instrument |
| 实际义务主体 | 只读主体卡片 | 债务人/收益责任主体等；不得从资产相关方自动推断 |
| 核心法律文件 | 文件引用列表 | 显示名称、版本、生效日期、查看权限 |
| 发行/生效日期 | 只读日期 | 来源发行与法律证据 |
| 合同到期日 | 条件展示 | 债权/有期限权益适用；没有约定时显示「未约定」 |
| 存续状态 | 只读状态 | 由未结合法义务与核验证据汇总，不允许手动结束 |
| SaaS 服务状态 | 只读提示 | 与法律存续状态分开展示 |

**存续义务列表字段**

| 字段 | 规则 |
|---|---|
| 义务事项 | 持续披露、债权利息、股息、收益参与分配、本金、到期退出、合同约定其他事项 |
| 义务来源 | Instrument 条款/Offering 披露/合法公司决议/已批准收益事件 |
| 责任主体 | 实际合同/法律义务主体 |
| 计划日期 | 合同日期或已批准计划日期；必须标记日期类型 |
| 当前状态 | 待履行 / 待核验 / 部分履行 / 已履行 / 逾期 / 争议 |
| 金额 | 仅在已形成合法应付时显示 U 金额；预计金额另标「预计」 |
| 关联记录 | 跳转 I-55/I-56/I-57/I-58 对应记录 |

义务列表由生效 Instrument、Offering 及 M13 已形成事件生成；不允许用户通过新增普通待办替代真实合同义务。

### 3.4 披露事项登记

**入口按钮：**「新增披露事项」。

打开右侧抽屉，字段如下：

| 字段 | 控件 | 必填 | 校验/条件 |
|---|---|---:|---|
| 关联资产 | 只读选择 | 是 | 从当前存续详情带入 |
| 关联发行方案 | 只读选择 | 是 | 从当前存续详情带入 |
| 披露类型 | 单选 | 是 | 经营/运营进展、重要事项、收益/财务报告、付息/股息通知、到期/退出通知、其他合同约定披露 |
| 披露标题 | 单行输入 | 是 | 2～120 字 |
| 披露期间 | 日期范围 | 条件必填 | 财务/收益报告必须填写 |
| 事项发生日期 | 日期选择 | 条件必填 | 重要事项必须填写 |
| 披露摘要 | 多行文本 | 是 | 10～2,000 字；只填写事实，不填写保证收益或未经批准承诺 |
| 正式文件 | 文件上传/引用 | 条件必填 | 合同或法律要求正式文件时必填；支持 PDF、DOCX、XLSX |
| 披露依据 | 文件/条款引用 | 是 | 合同条款、公司决议或其他合法披露义务依据 |
| 接收范围 | 只读/受控选择 | 是 | 默认按对应法律义务和已核准受益人范围；不得自由扩展到无权接收者 |
| 是否需要法定送达 | 单选 | 是 | 是 / 否 / 待法律确认；待法律确认时不可标记送达完成 |
| 备注 | 多行文本 | 否 | 内部补充说明 |

**按钮：**
- 保存草稿：保留当前输入，不产生已发布披露。
- 提交披露核验：校验必填字段、文件和依据；进入「待有权主体确认」。
- 取消：关闭抽屉；有未保存内容时二次确认。
- 查看历史：显示同一披露事项的版本。

**披露状态：** 草稿 / 待有权主体确认 / 已批准待发布 / 发布处理中 / 已发布 / 送达待核 / 已送达（仅有合法送达证据时）/ 送达失败 / Unknown / 已撤回。

站内消息已发送或已读不自动等于法定送达；送达责任与证据由适用法律/合同及有权主体确定。

### 3.5 页面操作与状态

| 操作 | 前置条件 | 结果 |
|---|---|---|
| 查看存续详情 | 当前企业有权访问 | 展示当前及历史义务 |
| 查看法律文件 | 有对应文件权限 | 只读查看，不修改 Instrument |
| 新增披露事项 | 当前存续对象有效 | 创建披露草稿 |

| 查看计算/支付 | 已有应付或批次 | 跳转 I-56/I-57 |

**空状态：**
- 尚无合法持有人或发行未形成有效权益：「当前发行尚未形成需要持续管理的有效持有人权益。」
- 暂无待履行义务：「当前没有即将到期的义务；已有合同及历史记录仍保留。」
- 暂无披露事项：「尚未登记披露事项，可在出现合同/法律要求时新增。」

**异常：**
- Instrument 版本来源缺失：阻断新增正式义务，提示返回权益结构核验。
- 义务主体不明确：显示「义务主体待核验」，不允许将资产相关方自动作为付款人。
- SaaS 欠费/退租：保留存续记录只读及依法交接入口；不得删除。
- 送达 Unknown：显示待核，不得显示已送达。
- 跨企业无权访问：显示无权查看，不泄露记录是否存在。

**下一步引导：** 存续事项需要形成收益/本息事件时，进入「收益分配 → 权益快照与收益事件」。

### 4.3 事件类型与来源规则

| Instrument 类型 | 允许的事件 | 事件如何产生 | 禁止事项 |
|---|---|---|---|
| 债权型固定利率 | 周期利息、到期利息、到期本金 | 从已引用 InstrumentVersion 的付息/到期安排自动生成 | 不允许手动重复创建同一期合同付息事件 |
| 债权型无息 | 到期本金 | 从 Instrument 到期日生成 | 不生成利息事件 |
| 股权型 | 合法股息、依法适用的退出/清算事件 | 仅在真实有权公司决议、可分配金额和适用法律条件具备后登记 | 不因预期年化、持有 Token 或资产盈利自动产生已应付股息 |
| 收益参与型 | 合同期限内的周期收益上报/无收益声明 | 发行方按 Instrument 约定的收益期间和口径手动上报 | 不从预期年化区间自动推导实际应付金额 |

- 预期年化收益区间只作投资者披露，不作为 M13 计算输入。
- 收益参与型的 Instrument「收益来源、计算口径、授权参与比例、参与期限、分配频率」均只读引用。
- 收益参与上报的金额必须是发行方按生效合同口径核定的「本期可分配收益金额」，不得将未经核定的营业收入直接当作可分配金额。
- 股权股息金额必须有真实公司决议及可分配金额依据；无决议时只能保存待核资料，不产生已应付金额。

### 4.4 新增收益上报抽屉

**入口按钮：**「新增收益上报」。

仅对收益参与型及有真实合法决议的股权股息开放；债权利息/本金由 Instrument 计划生成，不在此处重复创建。

| 字段 | 控件 | 必填 | 条件与校验 |
|---|---|---:|---|
| 资产 | 可搜索下拉 | 是 | 只显示当前企业 Ready 资产 |

| 发行方案/发行批次 | 可搜索下拉 | 是 | 必须与所选 InstrumentVersion 关联 |
| 收益事件类型 | 单选 | 是 | 收益参与权收益 / 股权合法股息 |
| 收益期间开始 | 日期选择 | 是 | 不早于 Instrument 生效/参与开始日 |
| 收益期间结束 | 日期选择 | 是 | 不早于开始日，不晚于参与结束日/合同有效期 |
| Record Date | 日期选择 | 是 | 必须依据合同/公司决议/适用法域规则 |
| Record Date 时区/规则依据 | 只读引用或受控文本 | 是 | 必须引用已确定的合同/法域规则；未确定时阻断正式快照 |

**条件规则：**
- 选择「本期无可分配收益」时，金额必须为 0，必须填写原因并上传必要凭证；系统将事件标记为「无应付」，不生成 Record Date 付款资格、计算或分配批次。
- 金额大于 0 时，无收益声明必须为「否」；必须提供合同/决议依据和凭证。

- 查看 Instrument 条款：只读跳转权益结构。
- 查看历史版本：查看原报告、原金额、提交时间和更正原因。

**快照操作**

## 5. I-56｜收益计算与分配批次

- **使用者：** 当前企业账号及有权提交/确认资料的企业代表；法律批准和真实付款权仍由适格主体承担。

### 5.2 列表与筛选

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 资产/发行方案 | 可搜索下拉 | 否 | 当前企业范围 |
| 权益类型 | 单选 | 否 | 股权/债权/收益参与权 |
| 事件类型 | 多选 | 否 | 利息/本金/股息/收益参与 |
| Record Date | 日期范围 | 否 | 按已核验快照日期 |
| 计算状态 | 多选 | 否 | 待计算/计算中/待复核/待更正/已批准/争议 |
| 批次状态 | 多选 | 否 | 草稿/待批准/待注资/部分注资/已足额注资/可领取/部分支付/已完成/Unknown |
| 关键词 | 输入框 | 否 | 事件编号、批次编号、资产、Offering |

**待计算列表字段：** 事件编号、资产/Offering、权益类型、收益期间、Record Date、快照版本、预计/合同应付日、计算状态、预计应付金额（未确认时标「候选」）、阻断原因、操作。

### 5.3 创建计算与计算预览

**入口按钮：**「开始计算」。仅在事件有效、Record Date 快照已核验且 Instrument/公司决议来源完整时启用。

**计算来源只读卡片**

- Asset / Instrument / InstrumentVersion / Offering。
- 事件类型、收益期间、合同应付日。
- Record Date 与快照版本。
- 合法义务主体、法律付款责任主体。
- 合同/公司决议版本及文件。
- 计算依据、扣项依据和适用精度。
- 相关限制、争议和 Unknown 提示。

**V1 计算口径**

| 事件类型 | 计算依据 | 页面处理 |
|---|---|---|
| 债权固定利率利息 | 生效 Instrument 的本金、利率、计息起止、付息期次和计息日数规则 | 按已明确的合同规则生成计算预览；「合同其他约定」标记人工核算，必须录入经核定金额和依据 |
| 债权本金到期 | 生效 Instrument 的合法未偿本金，扣除已有真实本金偿付 | 展示应付本金、已偿本金、剩余本金；不能把已广播或 Unknown 付款当作已偿 |
| 股权合法股息 | 已批准公司决议中的本期可分配总额/每股金额及 Record Date 合法股份数 | 只在有效决议和可分配依据完整时计算；按合法权益单位分配 |
| 收益参与权收益 | I-55 已核验的本期可分配收益金额、Instrument 授权参与比例/法律单位和 Record Date 快照 | 以发行方按合同口径核定的可分配金额为基础，按合法参与单位分配；不从预期年化反推 |

- 对于可按合法权益单位比例分配的事件，预览显示每位持有人权利单位、总有效权利单位、分配权重及金额。
- 对于债权合同指定的非标准计息方法，不能由平台自行推导；需显示「人工核算」并附核算说明/证据。
- 预期年化披露不参与实际计算。
- 系统计算结果先标记为「计算预览/候选应付」，只有完成必要复核及合法批准依据后才成为正式应付。

### 5.4 计算明细字段

| 字段 | 控件/展示 | 必填 | 规则 |
|---|---|---:|---|
| 持有人引用编号 | 只读脱敏 | 是 | 来自 Record Date 快照 |
| 持有人名称 | 脱敏 | 是 | 不显示 KYC 原件/完整个人信息 |
| 法律权利单位 | 只读 | 是 | 来自 M12 已核验快照 |
| 分配权重 | 只读计算 | 是 | 根据合法单位及事件条款 |
| 应付毛额 | 只读金额 U | 是 | 计算预览结果 |
| 扣项处理状态 | 单选 | 是 | 不适用 / 已核定 / 待确认 |
| 扣项金额 | 金额输入 U | 条件必填 | 已核定时填写；不适用时为 0 |
| 扣项依据 | 文件引用/说明 | 条件必填 | 已核定扣项必须有依据；待确认阻断正式批准 |
| 应付净额 | 只读金额 U | 是 | 毛额减已核定扣项 |
| 计算状态 | 只读 | 是 | 候选/待复核/已批准/待更正/争议 |
| 异常说明 | 只读/备注 | 条件展示 | 记录名册、计算、税费或精度差异 |

**扣项规则：**
- 不提供全球统一税率/税法算法。
- 明确无适用扣项时，选择「不适用」并填写适用依据/说明。
- 有扣项时，按受权核定金额填写并附依据；不明确时标记「待确认」，阻断正式应付批准和分配批次。
- 不允许通过自由输入负数或负扣项增加持有人收益。

**金额校验：**
- 页面统一 U，最多 6 位小数；超出精度阻断，不静默舍入。
- 毛额、扣项、净额的合计必须相符；总净额不得大于合法可分配金额。
- 合法单位无法精确分配时显示差额，进入人工复核，不静默分摊或舍入。
- 已批准计算被更正时，保留旧版本及其已发生的资金/付款记录，创建新版本并列出影响范围。

### 5.5 复核与合法批准依据

**复核区字段**

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 复核结论 | 单选 | 是 | 通过 / 退回更正 / 存在争议 |
| 复核说明 | 多行文本 | 条件必填 | 退回/争议时必填 |

| 批准日期 | 日期选择 | 是 | 不得晚于当前日期 |
| 批准文件 | 文件上传/版本引用 | 是 | 需可回溯原始批准文件 |
| 责任付款主体 | 主体卡片/引用 | 是 | 不得自动将资产持有人、企业默认钱包或 SaaS 平台推断为付款人 |

**按钮：**
- 保存计算草稿。
- 提交复核。
- 查看计算明细。
- 查看 Record Date 快照。
- 提交更正（生成新版本）。
- 确认已有批准依据（仅记录有权主体和依据，不代表 SaaS 平台代替其作法律批准）。

### 5.6 分配批次创建

**入口：** 仅在应付计算已复核、批准依据完整且无阻断项时显示「创建分配批次」。

**批次字段**

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 批次编号 | 系统生成 | 是 | 不可修改 |
| 关联事件/计算版本 | 只读 | 是 | 一个批次只引用一个确定事件和一个确定计算版本 |
| Record Date 快照版本 | 只读 | 是 | 必须已核验 |
| 受益人数量 | 只读 | 是 | 来自合法快照 |
| 应付毛额合计 | 只读 U | 是 | 来自已批准计算 |
| 扣项合计 | 只读 U | 是 | 来自已核定扣项 |
| 净分配总额 | 只读 U | 是 | 毛额减扣项 |
| 计划分配日 | 日期选择 | 是 | 与合同应付日、实际到账日分开 |
| 合法付款责任主体 | 主体引用 | 是 | 依据 Instrument/公司决议 |

**批次唯一性与部分支付**
- 同一已批准事件和计算版本默认只能创建一个完整分配批次，阻断重复创建。
- 依法允许部分分配时，必须有独立批准依据、明确受益人范围/金额和公平规则，建立单独部分批次；不得在原批次中采用未经批准的先到先得。
- 批次已被支付/领取引用后，不得删除或原地改写受益人、金额和快照版本。

### 5.7 真实注资核验区

**注资字段**

| 字段 | 展示/控件 | 必填 | 规则 |
|---|---|---:|---|
| 合法注资主体 | 只读主体引用 | 是 | 来源已批准付款安排 |
| 注资目标 | 只读受控配置 | 是 | 已批准的分配合约/合法资金主体；不得任意替换 |
| 注资资产/币种 | 只读 | 是 | 来源经批准的实际支付安排；页面金额仍统一 U |
| 应注资金额 | 只读 U | 是 | 本批净分配义务 |
| 已核验注资金额 | 只读 U | 是 | 仅依据真实资金证据 |
| 注资时间 | 只读 | 条件展示 | 真实注资证据时间 |
| 交易/回执编号 | 只读/引用 | 条件展示 | 原始资金 Intent、交易或外部回执 |
| 最终确认状态 | 只读 | 是 | 待核验 / 已确认 / 部分 / Unknown / 失败 |
| 证据文件 | 文件引用 | 条件展示 | 外部付款或合法资金主体凭证 |

**守卫：**
- 发行方不得手动把批次标记为「已注资」；只能提交核对申请/证据，最终状态依据真实资金权威。
- 默认只有全额真实注资且付款授权、受益人收款资格和其他适用条件均确认后，才开放整批 Claim。
- 未注资、部分注资、资金 Unknown、冻结或 Signer/授权不满足时，不开放整批 Claim。
- 如适用法律允许部分分配，须先有独立批准的部分批次和明确金额/受益人范围。
- M11 认购募集款不得默认转作 M13 收益注资。

**批次状态：** 草稿 / 待有权批准 / 已批准待注资 / 注资核验中 / 部分注资 / 已足额注资 / 待启用领取 / 可领取 / Push 待执行 / 部分支付 / 已完成 / Unknown / 争议 / 已取消（仅未产生不可逆事实时）。

**下一步引导：** 批次完成合法注资与付款条件核验后，进入 I-57 查看领取/实付结果；不得以「已足额注资」直接显示「已支付」。

## 6. I-57｜领取与支付对账

### 6.1 页面目标与入口

- **目标：** 汇总每个分配批次和每位合法受益人的实际领取/支付结果，识别部分付款、失败、Unknown 和未领取余额。
- **入口：** 收益与分配 → 收益分配。
- **页面内部视图：** 批次概览 / 受益人支付明细 / 外部付款凭证。
- **范围：** 仅企业端查看、核对、提交凭证和发起受权调查；投资者本人 Claim 页面不在本模块设计范围。

### 6.2 汇总卡片与筛选

**汇总卡片：** 应付总额、已足额注资、已实际支付、部分支付、未领取、失败/Unknown。

| 字段 | 控件 | 必填 | 规则 |

| 分配批次 | 可搜索下拉 | 否 | 只显示本模块批次 |
| 付款方式 | 多选 | 否 | Claim / Push / 外部付款 |

| 关键词 | 输入框 | 否 | 批次编号、脱敏持有人编号、付款引用编号 |

**批次列表字段：** 批次编号、资产/Offering、事件类型、受益人数、净应付总额 U、已注资 U、已支付 U、未领取 U、失败/Unknown 数量、付款方式、批次状态、操作。

### 6.3 受益人支付明细

| 字段 | 展示规则 |
|---|---|
| 持有人引用编号 | 脱敏编号 |
| 持有人名称 | 脱敏 |
| Record Date 快照版本 | 只读 |
| 合法权益单位 | 只读 |
| 应付毛额 | U |
| 已核定扣项 | U |

### 6.4 支付状态与真实证据

| 状态 | 页面含义 | 可执行下一步 |
|---|---|---|
| 待注资 | 批次未满足资金前置 | 返回 I-56 查看注资 |
| 可领取 | 已满足合法注资及领取条件 | 只读显示可领；投资者本人在其授权入口操作 |
| Claim 已提交 | 已存在领取请求/签署/广播 | 查询原 Claim，不重复发起 |
| Push 待执行 | 已有受权 Push 计划，尚未真实出款 | 查看付款责任主体和计划 |
| 处理中 | 外部付款/链上操作尚未最终确认 | 查询原操作 |
| Unknown | 外部事实无法确认 | 保留原 Intent，提交异常核查 |
| 部分支付 | 仅部分金额有真实付款证据 | 展示已付及剩余应付 |

**Paid 条件：** 真实资金/链上或外部付款事实已达到适用最终确认，并且受益人、金额、币种/资产和收款对象匹配。Provider Accepted、Webhook 成功、交易广播、Claim 点击、站内通知已读均不能单独证明 Paid。

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 分配批次 | 只读 | 是 | 从当前批次带入 |
| 持有人引用编号 | 受控选择 | 是 | 只能选择该批次合法受益人 |
| 实际付款金额 | 金额输入 U | 是 | 大于 0，不超过该持有人剩余应付 |
| 实际支付资产/币种 | 受控选择 | 是 | 按该批次已批准安排 |
| 付款日期 | 日期时间 | 是 | 真实付款发生时间 |
| 外部付款引用编号 | 单行输入 | 是 | 不得与已有真实付款记录重复 |
| 收款主体核验 | 受控确认/引用 | 是 | 必须与合法受益人或已授权代理匹配 |
| 付款凭证 | 文件上传 | 是 | 银行回执/合法付款主体凭证/其他批准证据 |
| 说明 | 多行文本 | 否 | 失败、部分付款或特殊差异说明 |

**提交结果：** 进入「外部付款待核验」，不直接变成 Paid。真实责任主体/适用权威证据确认后，才更新实际支付状态。

### 6.6 页面操作与异常

**允许操作：**
- 查看批次详情。
- 查看原 Claim/Push/外部付款记录。
- 查询原操作状态。
- 登记外部付款凭证。
- 提交支付差异/异常核对。
- 导出当前授权范围内的脱敏支付对账记录。

**禁止操作：**
- 发行方手动标记 Paid。
- 发行方代替投资者发起 Claim 或控制其钱包。
- 通过修改收款地址改变法定受益人。
- 对 Unknown 直接再次付款。
- 删除已发生部分付款或历史付款证据。

**异常提示：**
- Claim 广播后 Unknown/链重组：「支付结果尚未确认，请先查询原领取记录；请勿重复领取。」
- Push 失败/部分成功：「仅将已确认金额计入实付，剩余金额继续保留为应付。」
- 外部凭证与批次/受益人不匹配：「凭证信息与本批合法受益人不一致，暂不能确认实付。」
- 重复外部引用编号：「该付款引用已登记，请打开原记录核对。」
- 付款方/Signer失权：「当前付款授权不足，已阻止继续操作。」
- 未领取超期或企业退租：「未领取权益仍保留，需按适用法律/合同处理，不自动退回发行方。」

**下一步引导：** 存在到期本金、部分清偿、逾期或合法退出事件时，跳转 I-58；仅有收益领取未完成时留在 I-57 继续对账。

## 7. I-58｜到期与退出

### 7.1 页面目标与入口

- **目标：** 管理债权本金到期/逾期、合同允许的提前偿付、股权依法适用的回购/注销/清算、收益参与权合同到期结算，以及未结义务的责任交接。

- **页面内部视图：** 到期义务 / 清退与兑付计划 / 未结事项与交接。
- **原则：** 到期不等于已偿付；支付不等于名册已调整；Token Burn 不等于法律义务已清偿。

| 依据生效日期 | 日期选择 | 是 | 不晚于计划执行日期 |
| 计划结算日 | 日期选择 | 是 | 不代表实际支付日 |
| 受影响权益范围 | 只读/受控选择 | 是 | 依合法权益范围；不得任意选无关持有人 |
| Record Date/权益快照 | 只读引用/选择 | 条件必填 | 需要确定受益人范围时必须引用已核验快照 |
| 计划结算金额 | 金额输入 U | 是 | 必须有合法合同/决议依据 |
| 金额口径 | 单选 | 是 | 总金额 / 每法律权益单位金额 |
| 本金金额 | 金额输入 U | 条件必填 | 债权本金结算时必填 |
| 利息/收益金额 | 金额输入 U | 条件必填 | 有合法应付利息/收益时填写 |
| 已清偿金额 | 只读 | 是 | 引用 I-57 已确认实付 |
| 预计剩余金额 | 只读计算 | 是 | 计划金额减已确认清偿 |
| 合法付款主体 | 主体引用 | 是 | 不得默认企业钱包持有人即法律付款人 |
| 付款方式 | 受控选择 | 是 | 仅显示已批准 Claim/Push/外部付款路径 |
| 说明 | 多行文本 | 是 | 说明退出触发条件、适用范围及特殊事项 |
| 依据文件 | 文件上传/引用 | 是 | 必须完整可查看 |

**按钮：**
- 保存草稿。
- 提交合法依据核验。
- 查看合同/公司决议。
- 查看受影响持有人。
- 取消计划（仅未批准、未产生真实付款/登记/Token 事实时可执行）。

### 7.5 退出计划状态与进度

**退出计划状态：** 草稿 / 待合法依据 / 待有权确认 / 待计算 / 待付款 / 部分清偿 / 逾期 / 付款待核 / 待法定登记变更 / 待 Token 处置 / 争议 / 待责任交接 / 已依法结清。

**退出进度清单（按适用事项显示）**

1. 合同/公司决议与合法退出条件已核验。
2. 受影响权益与 Record Date 快照已确认。
3. 应付金额及扣项已核定。
4. 分配/清偿批次已批准。
5. 实际付款已由真实证据确认。
6. M12 法定权益/名册变更已确认（如适用）。
7. M07 Token 冻结/Burn/其他链上处置已确认（如适用）。
8. 未领金额、争议、逾期和交接义务已处理。
9. 有权主体确认本次法律义务已结清。

只有所有适用项均有权威证据时，才可显示「已依法结清」。任何一项 Unknown、部分、争议或未完成，退出计划必须保留对应状态，不能通过人工勾选跳过。

### 7.6 部分清偿与逾期

- 部分支付只减少真实确认的未偿金额；剩余金额继续保留应付/逾期。
- 本金支付与利息支付分别显示；不能把只付利息当作本金已清偿。
- 到期未付自动进入「逾期/待核」展示，不自动产生罚息；罚息仅在适用合同已明确且规则经核定时展示，不在 V1 自动计算。
- 真实付款 Unknown 时保留原 Intent，不能重复发起付款或直接标记失败。
- Token 已 Burn 但本金/收益未清偿，继续保留法律义务和逾期。
- 资金已清偿但 M12 登记或 M07 Token 处置待确认，显示「资金已清偿，权益/Token 处置待核」，不得标记全部结清。

### 7.7 未结义务与责任交接

**交接列表字段：** 资产/Instrument/Offering、原义务主体、拟承接主体、未清偿金额 U、未领取金额 U、未完成事项、争议/诉讼标记、交接依据、交接状态、最近更新。

**发起交接抽屉字段：**

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 原责任主体 | 只读 | 是 | 来源 Instrument/法律文件 |
| 拟承接主体 | 主体信息输入/引用 | 是 | 必须有合法承接依据 |
| 交接范围 | 多选 | 是 | 存续档案、未付本金/收益、未领取款、披露义务、争议事项、投资者记录 |
| 未结义务清单 | 只读 | 是 | 系统汇总，不允许删除 |
| 交接生效日期 | 日期选择 | 是 | 依据文件 |
| 交接依据 | 文件上传 | 是 | 有权法律/合同文件 |
| 交接说明 | 多行文本 | 是 | 说明未完成义务和承接安排 |
| 接收确认 | 文件引用/待确认状态 | 条件必填 | 有权承接主体确认后方可标记交接完成 |

**交接规则：**
- SaaS 退租/套餐降级不自动转移法律责任。
- 仅记录有权主体依法完成的责任交接；平台不替代合同转让、债务承接或监管批准。
- 未完成交接时保留原责任主体、未结义务和证据，不得清除存续档案。

### 7.8 空状态、异常与下一步

- 无到期义务：「当前没有已登记的到期或退出事项。」
- 无合法退出依据：「当前 Instrument 未发现可适用的退出条款/决议，不能创建清退计划。」
- 付款已完成但登记未完成：提示返回配售与持有人核验。
- Token 已 Burn 但未清偿：提示仍存在未结法律义务。
- SaaS 退租但义务未清：显示只读存续和交接提醒。
- 交接依据缺失：不能标记责任交接完成。

**下一步引导：** 所有适用资金、登记、Token 与法律义务均确认后，显示结清证据摘要；否则显示唯一最优先待处理项及其所属模块。

## 10. V1 明确不做

- M13-F008 复杂公司行动重组（V3）。
- 自动保证收益、固定 APR 承诺、从预期年化推导实际收益。
- B 类股权自动到期还本、普遍回购、保本或平台担保。
- 多层瀑布、优先劣后、复利、浮动/阶梯利率、复杂本金摊还。
- 全球统一税法/预扣税自动算法、自动节假日日历和未经合同授权的罚息。
- 未经授权的任意部分批次、先到先得、跨资产清偿。
- V1 多收款方比例分账（V2）、使用型权益（V2）。
- 投资者资格配置、企业人工 KYC 审核、完整 KYC 个人信息展示。
- 发行方代投资者 Claim、修改法定受益人或手动标记 Paid。
- 发行方直接修改 M12 名册、M07 Token 余额或删除历史付款。
- 平台代替实际法律义务主体、董事会/股东会、法定登记人或真实付款人作决定。
