### 0.3 当前 V1 账号与权限规则（优先于历史页面草案）

1. **一个账号对应一个企业。** V1 不提供企业内部成员管理、角色配置、权限分配、审批人分派或多级内部审批。
2. 页面中的「待我处理」是当前企业账号需要完成的资料、业务操作、补件或异常跟进；不是内部员工审批队列。
3. 「我发起的」用于跟踪已提交给平台、外部服务商或其他有权主体的请求；其审核与法律效力由原业务域及有权主体决定。
4. 企业账号不能因登录成功而获得董事会/股东会批准权、法定登记权、KYC/AML 核验权、资金保管权、Signer 权或 Token 执行权。
5. Tenant 隔离、业务对象范围和敏感数据最小化仍然必须执行，但 V1 不将其设计成企业可自行配置的 RBAC。
6. 普通企业账号不查看 KYC 原件、完整证件号码、Signer Secret、私钥/助记词、银行敏感凭证或其他无业务必要的个人数据。

### 0.4 Free / Standard 与真实业务边界

| 能力 | 新开通 Free | Standard 有效期 | Standard 到期降级后的历史企业 |
|---|---|---|---|
| 待办、异常、消息页面 | 可查看本企业账号自身的 KYB、资产/权益/Offering 准备事项、钱包开通状态和系统通知；不产生真实投资者交易/运营事项 | 当前企业真实业务范围内的业务事项、异常和通知 | 保留历史真实投资者交易/运营事项、未结义务、异常和通知的只读查询；不开放新增普通业务操作 |
| 业务规则 | 查看 Free 套餐能力、当前准备事项适用规则和平台强制规则；不修改平台规则 | 查看企业已生效规则和版本；允许的业务参数回原模块修改 | 历史规则/版本及当前平台强制规则只读；不得修改历史业务条款 |
| 审计记录 | 查看本账号、KYB、资产准备及允许的服务事件记录；不提供真实金融/投资者运营审计明细 | 当前企业真实授权范围内的操作与证据摘要 | 保留历史真实业务审计与证据摘要，只读查询和受控导出 |
| 业务报表 | 仅查看资产、权益结构、Offering 的准备状态和配置摘要；不开放投资者、认购、资金、Token、收益运营报表 | 当前企业有权查看的真实业务只读汇总 | 保留降级前已产生的真实投资者、认购、资金、Token、收益历史报表，只读查询 |
| 外部服务 | 可显示 U01 已批准的真实 KYB/MPC 钱包等非交易型服务状态；不开放真实资金、生产 Signer 或 Token 执行连接 | 显示已获准服务的连接状态；真实接入仍须合同、法域、安全和生产准入 | 显示历史连接、撤销/降级和相关证据；不允许新建或变更生产连接 |
| 安全与服务状态 | 可显示账号、KYB、MPC 钱包开通及 Sandbox 服务告警；不开放金融/Token 生产安全操作 | 当前企业范围内的真实服务告警与受权信息 | 保留历史及当前必要服务告警的只读查询；不因历史套餐恢复普通生产操作 |
| 存续义务 | 不存在真实投资者存续义务 | 按适用法律/合同履行现有义务 | 法律/合同义务继续存在；任何真实存续操作须先明确独立受控服务通道及责任主体，不能仅凭历史只读权限或原账号身份推定可写 |

Standard 订阅有效、KYB 通过或页面显示 Provider Connected，均不自动代表真实金融/法律/链上生产权限已获批准。真实服务仍受适用法域、合同、资金责任主体、Provider、Signer、安全和平台生产准入约束。 新开通 Free 与 Standard 降级后的历史企业必须区分：前者没有真实投资者交易/运营数据；后者保留既有真实业务历史只读。降级后的存续义务操作通道尚需单独明确，不能把「历史只读」误写成「法律义务终止」，也不能在未授权时恢复普通企业写权限。

### 0.5 完成定义

- 八个页面组均完成页面目标、入口、信息结构、字段、控件、筛选、校验、按钮、状态、空态、异常、权限边界、跨页跳转和下一步引导。
- 本模块只负责任务协调、异常跟进、通知、规则版本查看、审计、只读报表和服务状态；不复制订单、资金、持有人、Token、收益或 KYB 主账。
- 本文是 UI-Ready 产品规格，不代表 UI 视觉稿、源码、API/数据库、Provider/Signer、真实安全响应、浏览器测试或生产执行已完成。

## 1. 导航与页面结构

### 1.1 一级导航保持不变

继续使用现有 Issuer 九个一级导航和全局入口，不新增第十个一级导航或新的业务菜单。八个页面组的入口归属严格沿用现行架构：待办/异常/消息/安全告警走全局入口，规则设置/外部服务归企业管理，审计记录/业务报表归数据与报表。

### 1.2 八个页面组的现有入口归属

八个逻辑页面组不合并成新的一级/二级导航，继续沿用当前导航结构：

| 现有入口归属 | 页面 | 入口职责 |
|---|---|---|
| 工作台首页/顶部待办入口 | 我的待办 | 汇总当前企业账号需要处理的事项和已发起请求 |
| 工作台首页/业务页面异常入口 | 异常工单 | 查看业务异常、补充证据、查询原结果、跟进处理 |
| 顶部消息入口 | 消息通知 | 业务通知、待办提醒、站内消息和必要邮件投递状态 |
| 企业管理 | 规则设置 | 查看企业当前适用的规则、来源、版本和生效范围 |
| 数据与报表 | 审计记录 | 查询当前企业有权查看的操作记录和证据摘要 |
| 数据与报表 | 业务报表 | 查看项目、投资者、认购、资金、登记、Token 和收益只读统计 |
| 企业管理 | 外部服务 | 查看已获准外部服务及其连接、环境、用途和责任边界 |
| 顶部安全/服务告警及相关业务详情 | 安全与服务状态 | 查看服务健康、Webhook异常、安全告警和恢复核验状态 |

### 1.3 全局入口与回源

- 工作台首页的待办/异常摘要分别进入「我的待办」「异常工单」；不在首页重复建设处理流程。
- 顶部消息图标进入「消息通知」；顶部安全/服务提醒及相关业务告警进入「安全与服务状态」。
- 业务模块发现异常时进入「异常工单」，工单必须保留原业务对象、原 Intent/交易/回执引用。
- 「企业管理」中的规则设置、外部服务入口分别进入「规则设置」「外部服务」；不复制企业资料、钱包或订阅主账。
- 「数据与报表」只承载「审计记录」「业务报表」两个页面组；报表指标必须可下钻回原模块。
- 深链每次重新校验当前企业、对象范围、来源版本和访问授权；撤权后不得继续展示旧缓存中的敏感资料。

## 2. 八页共同设计规则

### 2.1 页面共用页头

| 字段 | 展示规则 |
|---|---|
| 当前企业 | 当前唯一 Tenant 名称；不显示企业切换器或多企业选择 |
| 套餐 | Free / Standard；显示 Sandbox 或真实企业数据环境 |
| 页面名称 | 当前页面标题与简短用途说明 |
| 数据更新时间 | 当前页面数据最后成功查询时间；与业务事件发生时间分开 |
| 来源提示 | 当前列表涉及的原业务模块/服务来源 |
| 权限提示 | 无权查看时显示统一无权提示，不暴露其他 Tenant 对象是否存在 |

### 2.2 统一列表与表单规则

- 列表筛选默认收起次要条件，保留最常用的状态、时间、业务来源和关键词。
- 列表默认优先显示「需要企业处理」「异常/Unknown」「即将到期」，其次按最近更新时间。
- 不允许通过共享页面编辑原业务对象；需要修改时显示「前往原业务模块」。
- 保存草稿只适用于本页面确实存在的补充说明/服务申请草稿，不为原业务另建第二份申请。
- 重要操作必须显示对象、来源、版本、影响范围及确认提示；不允许无说明的危险按钮。
- 已保存的审计、付款、登记、Token、收益和合同事实不可通过共享页面删除或覆盖。
- 统一使用「U」展示平台金额；Token 数量、权益单位、交易数量、链网络及时间戳单独展示，不混算。
- 报表显示数据截至时间；来源 Unknown/Partial/Delayed 必须明确显示，不用 0 替代未知值。
- 状态标签同时有文字说明，不只使用颜色表达；按钮禁用时说明原因。

### 2.3 业务主账与责任边界

| 业务事实 | 权威来源 | 本模块允许的操作 |
|---|---|---|
| 企业 KYB、订阅、套餐能力 | 企业管理/商业订阅 | 查看受权状态和来源，不重复审核 |
| Asset、Instrument、Offering 条款与版本 | 资产与发行 | 只读查看版本；变更回原模块 |
| 投资者 KYC/AML 与资格 | 平台核验服务及投资者身份模块 | 只展示当前企业依法有权查看的脱敏结果；不人工审核、不配置资格 |
| 认购订单与报价 | 投资者与认购 | 只读统计和下钻 |
| 认购收款、退款、募集款释放 | 资金与结算 | 只读状态、证据摘要和异常引用 |
| 配售与法定持有人登记 | 配售与持有人 | 只读状态、名册引用和差异 |
| Token/合约/链上交易 | Token 管理 | 只读链上状态与证据摘要 |
| 收益/本息/注资/实付/未领取 | 收益与分配 | 只读统计和异常引用 |
| 待办、异常、通知 | 本模块协调层 | 维护本模块任务/消息/工单事实，不修改来源业务 |
| 审计与证据追溯 | 本模块审计视图及各业务域原始证据 | 查询和受控导出，不修改原始事实 |
| 外部 Provider 连接与健康 | 外部服务及有权 X 主体 | 展示受权连接状态、健康和问题，不接管外部责任 |

### 2.4 V1 不采用的历史设计

- 不提供 Issuer 内部「待我审批」队列、审批人分配、员工角色或职责矩阵。
- 不允许 Issuer 自定义投资者类别、地区准入、全局投资者限额或 Offering 资格规则；投资者资格由现行平台及合法业务流程决定。Offering 原页面已批准的单笔最高认购 Token 数量和单投资者本期累计最高认购金额属于本期交易条款，不属于本共享模块的全局资格规则。
- 不提供自由规则编辑器、可视化脚本、任意自动配售策略或自动化流程编排。
- 不提供营销消息、全渠道用户偏好、公告 CMS 或自由编辑金融结果通知。
- 不提供敏感 KYC/AML 原件的自助批量导出。
- 不提供预测 BI、收益预测、资金可用余额推断或跨币种未经批准的统一汇总。
- 不提供 Provider 市场、任意 Provider 替换、多服务商智能切换、Signer/私钥管理器或自由 Webhook 脚本。
- 不提供一键退款、改法定名册、Mint/Burn、修改 Token 余额或把技术连接恢复改成业务成功。

## 3. 页面一｜我的待办

### 3.1 页面目标与入口

**目标：** 让企业账号一眼知道当前有哪些资料需要补充、业务步骤需要完成、外部申请需要跟进，以及哪些事项已经完成或逾期。

**入口：** 工作台首页待办摘要、顶部待办入口及原业务页面中的待办链接；不新增一级或二级导航。

**V1 定位：** 单企业账号的工作清单，不是企业内部审批中心。任务由原业务模块、平台或外部服务产生；本页只聚合和导航。

### 3.2 页面信息结构

1. 页头与待处理数量。
2. 三个列表标签：待处理 / 我发起的 / 已完成。
3. 筛选区。
4. 待办列表。
5. 任务详情抽屉：事项说明、来源业务、需要的动作、截止时间、当前状态、相关文件和原业务入口。
6. 页面底部/详情内的下一步操作提示。

### 3.3 统计卡片

| 卡片 | 统计口径 |
|---|---|
| 待处理 | 原业务模块明确要求当前企业账号采取行动的事项 |
| 待补充资料 | 已有明确补件要求且尚未重新提交的事项 |
| 即将到期 | 来源业务存在真实截止时间，未来 7 天内到期 |
| 逾期 | 来源业务真实截止时间已过且事项未完成；无截止时间不推算逾期 |

卡片点击后应用对应筛选；不得自行创造业务截止日期或 SLA。

### 3.4 筛选字段

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 事项状态 | 单选下拉 | 否 | 待处理 / 待补件 / 等待外部处理 / 已完成 / 已逾期 / 待核实 |
| 事项类型 | 多选 | 否 | 企业资料 / KYB补件 / 资产资料 / Offering准备 / 认购与配售跟进 / 资金核对 / Token交付 / 收益与退出 / 服务异常 |
| 来源模块 | 单选下拉 | 否 | 企业管理 / 资产与发行 / 投资者与认购 / 资金与结算 / Token管理 / 收益与分配 / 外部服务 |
| 关联资产或发行方案 | 可搜索下拉 | 否 | 只显示当前企业有权访问的对象 |
| 创建/更新时间 | 日期范围 | 否 | 按任务记录时间筛选 |
| 关键词 | 输入框 | 否 | 事项标题、任务编号、资产/Offering 名称 |

### 3.5 待办列表字段

| 字段 | 展示规则 |

| 事项标题 | 使用业务语言描述要做什么，不显示内部技术错误码作为主标题 |
| 事项类型 | 资料补充 / 业务操作 / 外部申请跟进 / 异常核对 |
| 来源 | 原业务模块及原对象名称 |
| 关联资产/Offering | 有关联时展示；没有时不显示空占位 |

| 截止时间 | 仅展示原业务提供的真实日期及适用时区 |

- 事项编号、事项标题、事项类型。
- 来源业务模块、原业务对象、原记录版本。

- 真实截止时间、日期类型和时区；无期限时显示「未设置明确截止日期」。
- 当前来源业务状态、任务状态、最后核验时间。
- 已提交内容/补件历史和平台/外部处理结果。
- 相关异常编号或通知编号（如有）。
- 下一步操作入口。

### 3.7 页面操作

| 操作 | 规则 |
|---|---|
| 查看事项 | 打开详情抽屉，保留当前筛选 |
| 前往处理 | 跳转原业务模块并带入对象/版本；在原页面完成实际业务操作 |
| 查看提交历史 | 展示本事项原始提交和补件记录，不覆盖旧版本 |
| 查询最新状态 | 只查询原任务/原业务结果，不重复提交不可逆业务操作 |
| 查看相关消息 | 跳转消息通知并定位对应通知 |
| 报告问题 | 对来源错误或无法处理的事项，创建/关联异常工单 |
| 标记已读 | 只改变提醒阅读状态，不改变来源业务状态 |

**明确不提供：** 内部审批人分配、企业员工转办、同意/拒绝员工审批、手动关闭原业务任务、批量批准、自动催办规则配置。

### 3.8 状态、空态与异常

- 待处理：企业账号仍需采取动作。
- 待补件：原业务要求补充资料。
- 等待外部处理：企业已提交，正在等待平台/服务商/有权主体处理。
- 已完成：来源业务确认该事项已完成；不能由本页手动改成完成。
- 已逾期：来源业务提供真实截止日期且尚未完成。
- 待核实：原业务或外部结果 Unknown，不能视为成功或失败。

**空态：**
- 无待办：「当前没有需要您处理的事项。」
- 无已发起请求：「您尚未提交需要跟进的申请。」
- 筛选无结果：「未找到符合条件的事项，可清除筛选后查看全部。」

**异常：**
- 原业务对象已变更：「事项关联的业务版本已更新，请打开来源页面查看最新内容。」
- 外部结果 Unknown：「当前结果尚待核实，请查询原申请，不要重复提交。」
- 账号权限变化：「当前账号无权继续访问该事项，请返回企业工作台。」
- 来源模块暂不可用：「暂时无法读取来源状态，已保留最后一次核验结果。」

**下一步引导：** 有具体业务动作时前往原业务模块；只有外部/数据异常时才进入异常工单。

## 4. 页面二｜异常工单

### 4.1 页面目标与入口

**目标：** 把业务流程中需要调查、核对、补证或外部支持的异常集中展示，帮助企业账号了解问题、当前责任方和下一步，而不在异常页面直接改写资金、登记、Token 或收益事实。

**入口：** 工作台异常摘要、业务页面异常提示及全局异常入口；不新增一级或二级导航。

### 4.2 列表筛选字段

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 异常状态 | 多选 | 否 | 待处理 / 企业待补充 / 外部处理中 / 来源业务待核验 / 已确认恢复 / 已关闭 / Unknown |
| 异常类型 | 多选 | 否 | 资料/资格 / 认购订单 / 收款退款 / 配售登记 / Token链上 / 收益支付 / 外部服务 / 通知投递 / 数据差异 |

| 来源模块 | 单选下拉 | 否 | 按原业务归属 |
| 发现时间 | 日期范围 | 否 | 按异常首次发现时间 |
| 关键词 | 输入框 | 否 | 工单编号、原业务编号、资产/Offering 名称 |

### 4.3 异常列表字段

| 字段 | 展示规则 |
|---|---|
| 工单编号 | 系统生成的唯一编号 |
| 异常标题 | 以用户可理解的业务问题描述 |
| 异常类型 | 对应业务域/外部服务类别 |
| 严重程度 | 仅显示来源系统已确定的等级；没有正式等级时显示「待评估」 |
| 关联业务对象 | 原业务编号、资产/Offering/订单等受控引用 |
| 原业务状态 | M11/M12/M07/M13 等来源的真实状态 |
| 当前处理状态 | 本工单调查/补件/等待外部处理状态 |
| 当前责任方 | 企业账号 / 平台支持 / 外部服务方 / 原业务责任主体；不展示内部员工分派 |

| 操作 | 查看详情 / 补充资料 / 查询原结果 |

### 4.4 工单详情信息结构

1. 异常概览：工单编号、类型、严重程度、首次发现时间、影响范围。
2. 原业务引用：来源模块、业务对象、原 Intent/交易/回执/版本。
3. 当前事实：原业务状态、技术服务状态、工单状态分别展示。
4. 差异与证据：原始错误摘要、外部回执、文件、时间线。
5. 需要企业采取的动作：补件、确认资料、联系服务支持或等待核验。
6. 处理记录：企业提交、平台/服务方回复、来源业务核验。
7. 结果与遗留事项：已确认解决的技术问题及仍未结清的真实业务事项。

### 4.5 补充资料字段

仅在工单明确要求企业补充资料时显示：

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 补充说明 | 多行文本 | 是 | 10～2,000 字，说明与当前异常的关系 |
| 补充文件 | 文件上传 | 条件必填 | 按工单要求的文件类型和数量；支持常见 PDF、DOCX、XLSX、图片 |
| 原业务引用 | 只读 | 是 | 自动关联，不允许手工替换为其他业务对象 |
| 提交人/提交时间 | 系统记录 | 是 | 自动记录，不允许修改 |

### 4.6 页面操作

- 查看原业务：跳转原业务页面，只读查询或在原页面完成合法操作。
- 查询原 Intent/交易/回执：只查询原请求，不发起新的资金/Token/登记操作。
- 补充资料：仅对明确要求企业补件的工单开放。
- 提交核对申请：当企业发现来源状态或外部证据不一致时提交说明。
- 查看处理历史：按时间展示企业、平台和外部服务方处理记录。
- 联系服务支持：仅在服务异常或工单明确提供支持入口时显示。
- 重新打开：仅当原工单允许、仍有未解决证据时申请复查；不直接改变原业务状态。

**明确不提供：** 企业内部异常指派、手动修改严重程度、直接标记资金成功/失败、重复退款、重新 Mint/Burn、手动改法定名册、任意重放 Webhook。

### 4.7 状态、空态与异常

- 待处理：工单已创建，尚未取得明确处理结果。
- 企业待补充：需要当前企业账号提供资料。
- 外部处理中：平台或外部服务方正在调查。
- 来源业务待核验：技术问题可能已恢复，但原业务事实尚未确认。
- 已确认恢复：技术或资料问题已恢复，并有相应证据；不代表原业务所有义务完成。
- 已关闭：工单处理流程结束；来源业务如仍有未结事项，继续显示。
- Unknown：外部事实无法确认。

**关键文案：**
- 「原操作结果尚未确认，请先查询原记录，避免重复退款、Mint 或登记。」
- 「工单已更新，资金、法定登记、Token 和收益结果仍以各自业务模块为准。」
- 「技术服务已恢复，但关联业务结果仍待核实。」

## 6. 页面四｜规则设置

### 6.1 页面目标与入口

**目标：** 让企业了解当前套餐、资产/权益、发行方案、认购/配售和平台强制规则的来源、版本、生效范围及限制；需要修改时回到唯一负责的原业务模块。

**入口：** 企业管理中的规则设置入口，以及原业务页面中的规则版本链接。

**核心原则：** 本页是受控规则目录与版本查看页，不是自由规则编辑器，不是投资者资格配置中心，也不替代资产、权益、Offering、认购、资金和配售页面中的原始配置。

### 6.2 规则分类

| 规则类别 | 权威来源 | 企业端可见/可操作范围 |
|---|---|---|
| Free/Standard 套餐能力 | 企业管理/订阅 | 只读查看当前套餐及可用能力；变更回订阅页 |
| 资产与权益结构条款 | 资产管理/权益结构 | 只读查看当前 Instrument 版本和文件；修改回资产详情 |
| Offering 发行规则 | Offering 发行管理 | 只读查看发行数量、价格、时间、锁仓等已生效版本；修改回 Offering |
| 投资者身份与资格 | 平台身份核验及合法业务来源；Offering 级认购额度来自资产与发行 | 只读显示当前企业依法可见的脱敏 KYC 状态及适用规则来源；Issuer 不配置 KYC 等级、投资者资格、地区白名单、风险等级或资格豁免。已批准的单笔最高 Token 数量/单投资者本期累计最高认购金额仍只在 Offering 原页面配置，本页只读展示其版本与来源，不形成全局投资者限额规则 |
| 认购/付款/配售前置条件 | 认购订单、资金与结算、配售与持有人 | 只读查看当前适用条件和来源版本；修改回原业务模块 |
| 平台/法域强制规则 | 平台受控规则与适用法律依据 | 只读；企业不可覆盖、停用或降低强度 |
| 系统自动检查与提醒 | 原业务模块的既有 Guard | 只读查看检查结果和说明，不提供脚本或自动化流程编辑 |

### 6.3 规则列表字段

| 字段 | 展示规则 |
|---|---|
| 规则名称 | 使用业务名称 |

| 规则来源 | 原业务模块或平台规则来源 |
| 适用范围 | 当前企业、指定资产、Instrument、Offering 或业务事件 |
| 当前版本 | 原来源版本号/生效时间 |
| 当前状态 | 生效 / 草稿 / 待核验 / 已停用 / 冲突 / 不适用 |
| 可修改性 | 可在原模块修改 / 只读 / 平台强制不可修改 |
| 影响提示 | 对新业务的影响；历史已签、已付款、已登记权益的保护说明 |
| 操作 | 查看详情 / 前往来源 |

### 6.4 规则详情字段

- 规则名称、规则编号、来源模块。
- 当前适用企业/资产/Instrument/Offering 范围。
- 当前生效版本、创建/生效/停用时间（来源有记录时）。
- 规则内容摘要、单位、适用条件和例外说明（仅显示已批准的内容）。
- 强制级别与来源依据：平台强制/适用法律/原业务模块配置。
- 历史版本列表及版本差异。
- 关联合同、Offering、订单或已发生业务的引用。
- 当前账号是否可以前往原模块修改。
- 不可修改原因和联系/反馈入口（如适用）。

### 6.5 页面操作

- 查看规则目录和详情。
- 查看历史版本与差异。
- 查看规则来源文件。
- 前往原业务模块：在原页面进行已批准范围内的参数修改。
- 报告规则显示错误：提交异常工单并附来源版本。
- 查看规则生效影响：显示受影响的新业务范围及历史业务保护说明。

**V1 不提供：**
- Issuer 自定义投资者资格、地区限制、全局投资者限额或 AML 豁免；不影响 Offering 页面已批准的本期交易数量/金额上限。
- 自由设置自动配售、资金释放、Mint、收益支付等自动化条件。
- 直接发布/停用平台强制规则。
- 可视化规则引擎、脚本、表达式、任意Webhook。
- 在规则页修改已签合同、历史Quote、已付款、法定名册或已产生的 Token/收益事实。

### 6.6 规则状态与异常

- 生效：来源模块已确认当前版本有效。
- 草稿：来源模块保存但尚未生效。
- 待核验：来源或法律依据尚未确认。
- 已停用：来源模块明确记录停用；历史引用仍保留。
- 冲突：新旧规则或强制约束存在冲突，显示来源和阻断原因。
- Unknown：暂时无法核实当前版本，不得将其显示为生效。

**关键文案：**
- 「此项属于平台或适用法域强制限制，企业不能自行修改。」

## 8. 页面六｜业务报表

### 8.1 页面目标与入口

**目标：** 让企业从一个入口查看项目、投资者、认购、资金、配售/登记、Token 和收益的只读汇总，并能下钻到原业务页面核对。

### 8.2 报表分类

### 8.3 筛选字段

| 字段 | 控件 | 必填 | 规则 |
|---|---|---:|---|
| 报表类别 | 单选 | 是 | 默认显示项目与发行进度 |
| 资产/项目/Offering | 可搜索下拉 | 否 | 仅当前企业有权对象 |
| 权益类型 | 单选 | 否 | 股权 / 债权 / 收益参与权；仅适用报表显示 |
| 时间范围 | 日期范围 | 否 | 默认近 30 天；显示时间口径 |
| 业务状态 | 多选 | 否 | 仅显示所选报表类别支持的状态 |
| 数据截至时间 | 只读 | 自动 | 显示各来源最近成功核验时间 |

### 8.4 报表概览与明细字段

**项目与发行：**
- 资产名称、资产类型、Offering 名称。
- Offering 当前状态、发行开始/结束时间。
- 发行数量/权益容量、已认购/已配售数量（分别标明业务口径）。

**投资者与认购：**
- 脱敏投资者/机构引用编号。
- KYC状态摘要（仅展示当前企业有权查看的脱敏状态）。
- 认购订单数、待处理订单数、已确认订单数。
- 报价金额、订单金额与真实收款分开显示。

**资金与结算：**
- 应收/订单金额。
- 已确认到账金额 U。
- 待核验、部分到账、失败/Unknown。
- 退款申请、真实退款金额、待处理退款。

- Token 已提交、链上确认、Finality、失败/Unknown。

**收益与存续：**
- 收益/本息事件数。
- 合法应付金额 U。
- 已真实注资金额 U。
- 已实际支付金额 U。
- 未领取/未支付金额 U。
- 逾期本金/利息及未结事项。
- 预计收益、预期年化披露和实际应付/实付必须分开展示。

### 8.5 报表通用指标字段

| 字段 | 规则 |
|---|---|
| 指标名称 | 明确业务含义 |
| 当前数值 | 已确认值；Unknown 不显示为 0 |
| 计量单位 | U / Token数量 / 合法权益单位 / 订单数量分别展示 |
| 统计期间 | 起止时间和时区 |

| 口径说明 | 说明订单、实收、登记、Token、收益各自定义 |
| 下钻入口 | 跳转原业务列表或详情 |

### 8.6 操作与导出

- 切换报表类别。
- 筛选、清空和刷新。
- 查看指标口径与来源。
- 下钻原业务对象。
- 导出当前报表允许的脱敏摘要；需要时跳转审计记录查看导出范围与结果。

**不提供：** 预测 BI、收益率预测、自动估值、跨币种汇率换算、资金可用余额推断、投资者风险评分、跨 Tenant 行业数据对比。

### 8.7 空态与异常

- 无业务数据：「当前企业暂无符合条件的业务数据。」

- 无导出权：「当前账号仅可查看屏幕汇总，不能导出该范围的敏感明细。」

## 9. 页面七｜外部服务

**目标：** 让企业了解平台或受权外部主体为当前业务提供了哪些服务、服务用途和连接状态、适用环境、责任主体及当前异常；不让企业接触不应由其管理的技术凭证或生产密钥。

### 9.3 服务列表字段

| 服务用途 | KYB/KYC、收款监测、链节点、签署、登记等 |

| 当前业务范围 | 关联业务模块、资产/Offering 或服务范围 |
| 环境 | Sandbox / 已获准生产环境 / 不适用 |
| 连接状态 | 未开通 / 申请中 / 已连接 / 降级 / 已撤销 / Unknown |
| 最近健康检查 | 时间、结果和来源 |

| 当前问题 | 已知故障、缺少授权、服务中断或待核验 |
| 操作 | 查看详情 / 查看异常 / 联系服务支持 |

### 9.4 服务详情字段

- 服务名称、用途、服务责任主体。
- 关联的当前企业及合法业务范围。
- 服务合同/授权依据（有权展示的摘要和文件引用）。
- 环境、网络或适用地域（来源有记录时）。
- 连接状态、最近技术健康检查时间。
- 业务模块最后一次核验结果和时间。
- 相关异常工单、服务事件和历史状态。
- 凭证状态摘要：有效/待轮换/已撤销/Unknown；不展示 Secret、私钥或助记词。

- 申请开通已批准且适用于当前企业的服务（不代表服务已获批或生产可用）。
- 联系服务支持或提交异常。
- 查看连接历史和凭证状态摘要。
- 查看关联业务状态：跳转原业务模块核实真实结果。

**明确不提供：** 自由选择/购买任意 Provider、修改生产 API Secret、导出私钥、设置客户 Signer、自由切换服务商、直接启动资金/Token/登记生产操作。

### 9.6 服务状态与异常

- 未开通：当前企业没有该服务的有效连接。

- 降级：服务可用性受限，关联业务需按原模块判断。
- 已撤销：授权或凭证已撤销；历史业务记录保留。
- Unknown：连接或服务结果尚不能确认。

**关键文案：**
- 「服务连接已建立，但合法业务执行权限及业务结果仍需分别核验。」
- 「此连接仅用于 Sandbox 测试，不能执行真实资金或 Token 操作。」
- 「当前服务由适格责任主体管理，企业账号不能查看或导出其生产凭证。」

### 10.6 状态、空态与异常

- 新发现：系统发现安全/服务事件。
- 调查中：适格服务责任方正在核实。
- 企业待处理：需要当前企业账号补充资料或确认业务情况。
- 外部处理中：服务商/有权主体处理中。
- 技术已恢复：技术故障已恢复，原业务结果仍需独立核验。
- 业务待核：外部连接恢复，但资金、登记、Token 或收益结果仍 Unknown。
- 已关闭：技术/安全事件流程结束；原业务遗留义务仍按来源模块处理。
- Unknown：事件结果或影响范围尚不能确认。

**关键文案：**
- 「服务连接已恢复，原付款、登记和 Token 结果仍需分别查询确认。」
- 「该通知为已知事件的重复送达，原业务不会重复执行。」
- 「外部事件未通过安全校验，尚未进入业务处理。」
- 「技术事件已处理，不代表关联法律或资金义务已经完成。」

## 15. 本模块完成结论

- 「数据与报表」现有一级导航保持不变；八个逻辑页面按四组页面内分组呈现，不新增一级导航。
- 八个页面组均完成页面目标、入口、信息结构、字段、筛选、控件、操作、状态、空态、异常、权限和跨模块跳转设计。
- V1 一个账号对应一个企业；本模块不引入企业内部成员、角色、审批人分配或复杂权限系统。
- 规则页以受控规则目录和版本查看为主；投资者资格不由 Issuer 自行配置。
- 审计与报表只读；导出仅限系统允许的当前企业脱敏数据。
- 外部服务和安全页面不暴露 Secret/私钥/Signer，不将 Provider 技术状态视为业务完成。
- **产品/UI 设计状态：八个页面组 UI-Ready。**
- **代码实现、视觉稿、浏览器验收、真实 Provider/Signer/资金/登记/Token 安全执行：未执行。**
- 当前企业 SaaS 的业务模块页面已覆盖从企业入驻、资产发行、认购、资金、Token、锁仓到收益/退出及共享管理；下一阶段建议进行**企业 SaaS 全量导航、页面与功能映射及跨模块体验总审计**，暂不自动扩展至平台运营后台、统一投资端或独立投资者门户。
