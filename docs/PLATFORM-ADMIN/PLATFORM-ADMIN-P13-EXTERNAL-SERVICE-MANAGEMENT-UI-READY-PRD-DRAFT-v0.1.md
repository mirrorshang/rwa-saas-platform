# RWA SaaS｜Platform Admin P-13：外部服务管理 UI-Ready 产品规格（Draft v0.1）

> **文档状态：Draft｜2026-11-18**
>
> 本文细化平台总后台「外部服务管理」模块，承接 M22-F001～F008 的外部 Provider/Adapter、健康、Webhook 与凭证隔离责任。
>
> M22-F001～F008 是 V1.0 服务端/外部权威接入能力，历史功能定义不要求额外建设独立前端；P-13 仅提供平台运营必需的连接状态、环境隔离、健康与异常查看及受控处置 UI，不新增服务商市场、自动切换或业务执行功能。

## 0. 产品范围与硬边界

### 0.1 P-13 管理内容

- 平台已批准接入的外部服务连接及其环境/用途/适用范围。
- 服务健康状态、最近探测时间、错误摘要、恢复状态。
- Webhook 签名验证、去重/重放拦截和回调处理结果摘要。
- 外部凭证的安全引用、状态、到期/轮换/撤销记录；仅显示元数据，不显示 Secret。
- 连接异常与 P-07 任务、P-12 安全事件的关联。
- 受权执行连接测试、暂停/恢复连接、发起凭证轮换/撤销请求。

### 0.2 明确不做

- 不在普通后台显示、复制、下载或输入明文 API Secret、私钥、助记词、Signer 密钥或完整 Token。
- 不因平台持有 RPC/API 凭证而取得 Issuer 客户资金、钱包或 Token 执行权限。
- 不建立服务商市场、服务商竞价、智能路由或自动多 Provider 切换（M22-F009 V3）。
- 不代替 KYC/KYB/AML Provider 作出核验结论；不手工把 KYC 状态改为通过。
- 不代替稳定币收款监听、法定登记、电子签署、链上交易或真实资金执行方。
- 不提供任意 URL、Webhook 或脚本自由配置；服务类型与连接参数采用平台批准的适配器配置。
- 不在本页处理 Issuer 商业收费、投资者认购、退款、配售或收益业务。

## 1. 页面结构

P-13 仅设置三个页签：

1. **服务连接**：查看平台已批准服务及各环境连接状态。
2. **健康与事件**：查看探测、Webhook、Provider 回调、错误和恢复记录。
3. **凭证状态**：查看安全凭证引用、到期、轮换、撤销状态和审计。

不建立多级服务市场或 Provider 配置中心。

## 2. P-13-01｜服务连接列表

### 2.1 服务类别

| 服务类型 | 典型用途 | 对应 M22 |
|---|---|---|
| KYB/KYC/AML Provider | 企业商业核验、投资者 KYC、必要 AML/制裁核查 | M22-F001 |
| 稳定币收款监测 | 监测 OP Mainnet USDT 付款及回执 | M22-F002 |
| 节点/RPC/钱包基础设施 | 链状态、交易查询、受控钱包基础设施适配 | M22-F003 |
| 法定持有人登记服务 | 法定名册/登记接口适配 | M22-F004 |
| 电子签署证据服务 | 签署状态与证据引用 | M22-F005 |
| Webhook 接收与验证 | 签名、去重、重放保护及事件处理 | M22-F006 |
| 服务健康监控 | 连接探测、故障与恢复状态 | M22-F007 |
| 凭证/环境隔离 | 凭证引用、权限、环境和用途隔离 | M22-F008 |

M22-F001～F008 代表服务端接入能力，不表示每个 Provider 已选定或生产连接已启用。当前支付网络边界为 OP Mainnet USDT；新增网络须独立审批。

### 2.2 列表筛选

| 字段 | 控件 | 规则 |
|---|---|---|
| 关键词 | 输入框 | 服务连接 ID、Provider 名称、用途、环境 |
| 服务类型 | 下拉 | 上表服务类别 |
| Provider | 下拉 | 仅显示已登记 Provider |
| 环境 | 下拉 | Sandbox、Testnet（如已批准）、Production |
| 连接状态 | 下拉 | 未配置、待验证、健康、降级、不可用、Unknown、已暂停 |
| 凭证状态 | 下拉 | 有效、即将到期、待轮换、已撤销、Unknown |
| 最近更新时间 | 日期范围 | 状态更新时间 |

### 2.3 服务列表字段

- 服务连接编号；
- 服务类型；
- Provider 名称；
- 适用产品/业务模块；
- Tenant/平台范围（仅展示当前账号有权查看的范围）；
- 环境；
- 连接状态；
- 健康状态；
- 凭证状态（仅元数据）；
- 最近成功探测时间；
- 最近失败时间；
- 最近更新时间；
- 操作：查看详情。

默认不展示凭证值、完整 endpoint secret、Webhook Secret 或私钥。

## 3. P-13-02｜服务连接详情

### 3.1 页面分区

1. **连接摘要**：服务类型、Provider、连接 ID、环境、用途、当前状态。
2. **适用范围**：平台级/指定 Tenant、业务模块、网络或产品范围。
3. **连接参数摘要**：适配器类型、非敏感 Endpoint 标识、Provider Account Alias、API 版本。
4. **健康状态**：探测结果、延迟、最后成功/失败时间、错误类别。
5. **Webhook 状态**：验签、事件去重、重放拦截、回调处理摘要。
6. **凭证引用**：Vault/Secret Manager 引用 ID、权限范围、有效期、轮换状态（无明文）。
7. **事件历史**：连接变更、探测、暂停、恢复、凭证轮换、Webhook 异常。
8. **关联任务/安全事件**：P-07 Task ID、P-12 Security Event ID。

### 3.2 连接字段

| 字段 | 说明 |
|---|---|
| Service Connection ID | 系统唯一编号 |
| Provider | 已批准的服务商标识 |
| Service Type | KYB/KYC/AML、收款监测、RPC/钱包、法定登记、签署、Webhook 等 |
| Environment | Sandbox/Testnet/Production |
| Tenant Scope | 平台级或具体 Tenant 引用；跨 Tenant 不混用 |
| Business Purpose | 明确连接用途 |
| Adapter Version | 适配器版本 |
| Endpoint Alias | 非敏感地址/别名；隐藏签名参数和 Secret |
| Credential Reference | Vault 引用 ID，不显示 Secret |
| Connection Status | 未配置/待验证/健康/降级/不可用/Unknown/已暂停 |
| Last Health Check | 最近探测时间及结果 |
| Last Webhook | 最近回调时间与处理摘要 |

### 3.3 允许操作

| 操作 | 条件 | 结果 |
|---|---|---|
| 测试连接 | 当前环境与服务允许健康探测，用户有权限 | 发起无资金/无链上写操作的健康探测，显示结果 |
| 暂停连接 | 有明确故障/安全/合规原因且具备授权 | 暂停该连接的新请求；显示受影响业务范围和保护提示 |
| 恢复连接 | 故障原因解除、健康探测通过、凭证有效 | 恢复连接；不自动重放未知业务请求 |
| 查看事件 | 具备服务只读权限 | 打开健康/Webhook 历史 |
| 创建/关联任务 | 存在服务异常 | 关联 P-07 Task |
| 安全事件升级 | 怀疑凭证泄露、跨环境误用、Webhook 欺骗 | 关联 P-12 Security Event |

**测试连接限制：**仅验证连接/鉴权/健康，不允许真实扣款、退款、Mint、法定登记、签署或任何不可逆操作。

## 4. P-13-03｜健康与事件

### 4.1 健康状态

| 状态 | 页面表达 | 处理 |
|---|---|---|
| Healthy | 健康 | 显示最近成功时间 |
| Degraded | 性能降级 | 显示延迟/失败率摘要，关注受影响业务 |
| Unavailable | 不可用 | 显示错误类别、影响范围、创建/关联任务 |
| Unknown | 状态待核实 | 查询原探测/请求，不伪造成功或失败 |
| Suspended | 已暂停 | 显示暂停原因、操作者与恢复条件 |
| NotConfigured | 未配置 | 不提供启用按钮，提示完成批准的配置流程 |

### 4.2 事件列表

字段：
- Event ID；
- Service Connection ID；
- Provider；
- 环境；
- 事件类型（健康探测、Webhook 验签、回调重复、重放拦截、Provider 超时、连接失败、恢复）；
- 发生时间；
- 处理结果；
- Correlation ID；
- 原业务 Intent/对象引用；
- 关联 Task/Security Event。

### 4.3 Webhook 事件详情

展示：
- 事件 ID；
- Provider 来源标识；
- 签名校验结果；
- 去重键/原事件 ID（脱敏）；
- 是否识别为重复/重放；
- 接收时间与处理时间；
- 原业务 Intent/对象引用；
- 处理状态（已验证/拒绝/重复/待核实/失败）；
- 原始证据引用（受权查看，不默认展示原始 Payload）。

保护：
- 验签失败或来源未知时拒绝进入业务归约；
- 重复回调不得创建重复订单、付款、登记、Mint 或通知业务动作；
- Provider 返回 Unknown 时查询原业务 Intent，不盲目重放；
- 原始 Payload 可能包含敏感信息，只允许按 P-11/P-12 受控访问。

## 5. P-13-04｜凭证状态与环境隔离

### 5.1 凭证列表字段

- Credential Reference ID；
- Provider/服务连接；
- 环境；
- Tenant/平台作用域；
- 凭证用途/权限范围；
- Secret Manager/Vault 引用；
- 状态（有效、即将到期、待轮换、已撤销、Unknown）；
- 创建/轮换时间；
- 到期时间（如 Provider 支持）；
- 最近使用时间；
- 最近审计事件；
- 操作：查看元数据、申请轮换、申请撤销。

不提供查看/复制/下载 Secret 明文。

### 5.2 凭证操作

| 操作 | 条件 | 结果 |
|---|---|---|
| 申请轮换 | 有效凭证需要定期轮换或出现风险 | 创建轮换请求，交由 Vault/受权服务执行；P-13 只显示结果 |
| 撤销凭证 | 已确认泄露/误用或服务停用，具备安全授权 | 触发受权撤销请求，记录撤销结果与影响范围 |
| 查看凭证历史 | 具备审计权限 | 查看引用 ID、状态、操作者、时间；不显示旧 Secret |
| 关联安全事件 | 发现异常使用 | 跳转/创建 P-12 安全事件 |

轮换/撤销确认必须显示：
- 凭证引用 ID；
- Provider、环境、Tenant/平台范围；
- 影响的业务模块；
- 当前未完成请求/回调数量（如可得）；
- 是否需要先暂停连接；
- 操作原因；
- 确认按钮。

未知状态不能显示轮换成功或撤销成功；查询原操作结果后再继续。

### 5.3 环境隔离规则

- Sandbox/Testnet/Production 的凭证、Endpoint、Webhook Secret 和数据存储必须隔离。
- Free Sandbox 不得调用 Production 凭证或真实资金/Signer API。
- Production 凭证只供适格服务端 Adapter 使用；P 后台不显示 Secret。
- Tenant 自有 Provider 凭证与平台凭证分离；P 不能读取客户资金私钥。
- 环境切换不得复制 Secret 值或自动迁移权限。
- 任何跨环境调用失败都记录安全事件并按规则暂停受影响连接。

## 6. 失败与恢复流程

1. 健康探测失败/Provider Unknown：保留原请求 ID，显示状态待核实。
2. 生成/关联 P-07 服务异常任务，指派责任人。
3. 若涉及凭证泄露、Webhook 伪造或跨环境误用，创建 P-12 安全事件。
4. 必要时受权暂停连接或撤销凭证。
5. 服务恢复后先探测并查询原业务 Intent/Provider 回执。
6. 只有原业务权威确认后，才更新真实业务状态；不得将服务恢复直接映射为付款、登记、签署或 Token 成功。

### 7.2 验收用例

1. 服务列表明确显示 Provider、服务类型、环境和连接状态。
2. Sandbox/Testnet/Production 分开筛选，不允许凭证跨环境复用。
3. 测试连接不产生真实资金、签署、登记或链上写操作。
4. 健康状态 Unknown 时保留原请求引用，不标记成功。

9. Free Sandbox 无法调用 Production 凭证。
10. 凭证泄露事件可跳转 P-12；撤销结果回写 P-13 状态。
11. Provider 不可用时创建/关联 P-07 任务；恢复后查询原 Intent，不盲目重放。
12. 未执行用例标记 Not Executed，不得标记 PASS。

## 8. 版本边界与排除

- P-13 只承接 M22-F001～F008 V1.0 服务端/外部权威接入的必要运营可视化和受控管理 UI；不代表任何 Provider 已选定、连接已上线或真实生产已准入。
- M22-F009 多服务商智能切换市场仍为 V3.0，不得在 P-13 加入 Provider 自动竞价/自动切换。
- P-13 不复制 P-08 通知管理、P-12 安全审计、P-07 任务中心。
- 真实 KYC/KYB/AML、资金监听、RPC、法定登记、电子签署服务合同、Webhook 验签算法、密钥托管和生产网络均需独立工程/法务/安全批准。
- P 后台不因外部凭证可见而取得客户资金或 Token 操作权。

**本批结论：P-13 外部服务管理形成 UI-Ready 产品规格 Draft v0.1。以服务连接健康、环境隔离、Webhook 与凭证元数据为核心，不显示秘密、不替代外部业务权威、不建设服务商市场；待产品负责人审核后进入原型。**
