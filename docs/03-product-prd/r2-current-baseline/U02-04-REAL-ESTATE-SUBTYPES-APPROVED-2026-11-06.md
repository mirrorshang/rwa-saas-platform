## 2. 已批准 R21～R26：六类房地产二级模板简化字段
> 本节“必填”=该子类资产进入 **Asset Ready（资料完备）** 的条件，**不代表创建 Draft 草稿时必填**；草稿最低要求仍为一级+二级分类及资产名称。子类输入显示在五步向导第④步「专属属性」，第⑤步预览汇总。与第②③步公共字段只读关联或引用，不二次编辑重复信息。

| 决策 | 房地产二级模板 | Ready 必填专属字段 | 选填/条件必填字段 | MVP 表单边界 |
|---|---|---|---|---|
| **R21** | **住宅** | 住宅形态（单套 / 整栋 / 住宅社区）、建筑面积 | 住宅套数：多套时条件必填 | 不要求结构化建成年份、入住率等额外字段 |
| **R22** | **写字楼** | 建筑面积 | 可出租面积、出租率均选填 | 不强制主要租户、建成年份、其他详尽运营数据 |
| **R23** | **商铺** | 商铺形态（临街商铺 / 商场铺位 / 商业综合体）、建筑面积 | 可出租面积选填 | 不强制租户数量、经营类别 |
| **R24** | **酒店** | 建筑面积、客房数量 | 入住率选填 | 酒店等级/星级、运营品牌不做 MVP 结构化强制字段；**本子类暂缓实施** |
| **R25** | **工业园／仓储物流** | 物业形态（工业园 / 仓库 / 物流设施）、建筑面积 | 可出租面积选填 | 作为一个二级模板，不拆成两个；不强制土地面积或仓储容量 |
| **R26** | **土地** | 土地面积、法定用途 | 土地权利有期限时，权利到期日**条件必填** | 不包含在建项目、期房、房地产开发/融资；**本子类暂缓实施** |

### 通用子类校验范围（已随精简方案批准）
- 数值面积必须 **>0**；可出租面积不得超过对应建筑面积；出租率、入住率限制在 **0%～100%**。
- 客房数量、住宅套数必须为正整数；住宅套数是否触发条件必填取决于选定的「多套」资产形态/实际包含多套，避免在单套住宅重复填写“1”。
- 子类属性暂以常用 m² 与百分比形式呈现；**具体单位选择策略、精度、输入控件、特殊边界例外与法域差异留给 UI-Ready 批次审核**，不得擅自作为生产法律证据或金融定价依据。
- 建成年份、主要租户、运营品牌、酒店星级、仓储容量、经营类别等此次从 MVP 结构化字段中删去；如发行方需表达，可按适用范围在资产简介或选填补充材料中提供，未来升级模板时再审核。
- 全部子类继承第三步「资产权属证明」「资产估值依据文件」及条件性「抵押/权利限制证明」**逐行固定展示并附上传按钮**；其他选填材料通过「＋ 添加其他文件 → 选择类型 → 上传」完成。**不默认给每个二级模板新增额外 Ready 必需文件**。特殊资产/法域如存在法定额外凭证，留后续独立审查，不能因此放松法律/生产准入。

- 当前批准范围是房地产**四个首批可创建子类**；八大类/24 二级分类是未来分类体系，**其他一级类别的实际可创建/可发行模板未在本次获批**。
- 对暂缓模板，可以在选择界面显示「暂未开放」并禁用，或按未来已审 UI 规则决定展示方式；**具体显示/隐藏交互仍在 U02-04 UI-Ready 待审核**。

## 4. 待审核的 U02-04 UI-Ready 收口事项（Draft）
- **UX / 页面**：分类可选/暂缓展示、五步步骤条、字段提示与示例、必填视觉、每步可保存/返回、草稿恢复。
- **表单交互**：选择二级模板后更改类别时的数据处置；子类条件出现/隐藏后脏数据处理；跨步表单状态一致性。
- **数值**：面积单位与精度、百分比输入精度、零/负数/上限、超范围提示与可出租面积和总建筑面积交叉校验。
- **文件**：必需行状态、条件显示、文件上传失败重试、安全扫描/版本、查看更换、离开/刷新数据保持、相应法律文件版本。

- **导航与验收**：资产管理 → 五步新建/编辑 → 资产详情四 TAB → 权益结构入口的路由、空状态、异常及真实 UI 自动化验收标准。
