# DEC-081｜RWA SaaS V1 收益与分配模块 UI-Ready 设计收口

> 日期：2026-11-11  
> 记录性质：**在用户已授权产品负责人独立完成企业 SaaS V1 模块 MVP 闭环的范围内，完成 I-54～I-58 五个页面组的 UI-Ready 详细设计。**  
> 本 DEC 不声称用户逐字段逐项批准，不改变已批准业务规则；不批准新的法律、税务、真实资金、Signer、Token 或生产执行安排。  
> 维护分支：docs/r2-current-product-baseline｜PR #8 Draft / Open / Unmerged。

## 1. 依据与适用范围

本决策承继：
- DEC-033：发行后存续、法定 Record Date 快照、债权/股权收益事件、应付/注资/Claim/Push/实际付款和合法退出的六项产品规则。
- DEC-055：I-54～I-58 五个逻辑页面组及 M13 V1 功能映射。
- DEC-058：V1 手动收益上报、清退/兑付计划、M13 资金与收益主责边界；多方分账和使用型权益后置。
- DEC-059：预期年化信息披露、债权周期付息纳入 V1；具体收益披露字段与债权付息计划以现行 U02-08 为准。
- DEC-080：Asset/Instrument/Offering、订单、资金、配售/法定登记、Token 和锁仓的跨模块一致性规则。
- U02-08 权益结构 UI-Ready 最终规格、M13 原 193 项正式功能主表及现行 R2 总体架构。

本决策只覆盖 Issuer 企业 SaaS「收益与分配」模块，不设计独立投资者门户、统一投资端、平台运营后台或外部服务商 UI。

## 3. UI-Ready 详细设计结论

完整页面字段、布局、操作、校验、状态、空态、异常、跳转和验收目标见：
[收益与分配模块 UI-Ready 最终规格](../docs/03-product-prd/r2-current-baseline/YIELD-AND-DISTRIBUTION-UI-READY-CLOSEOUT-2026-11-11.md)。

### I-54 存续档案与义务

- 以 Instrument/Offering/发行批次为上下文，展示真实法律义务主体、合同版本、存续状态、下一履行事项、逾期/部分履约和未结金额。
- 披露事项支持草稿、依据文件、待有权主体确认、发布与送达状态；站内通知已读不等于法定送达。
- Offering 关闭、企业欠费/退租不删除存续义务和历史权利。

### I-55 权益快照与收益事件

- 债权固定利率/周期付息和到期本金事件从已引用 InstrumentVersion 的既有安排生成，禁止发行方重复创建同一期合同事件。
- 股权股息仅在真实有权公司决议、可分配金额及适用法律条件具备后形成应付事件。
- 收益参与权按 Instrument 约定期间由发行方手动上报本期可分配收益金额，并附口径说明和凭证；支持无收益声明，金额为 0 且有原因/依据时不生成分配批次。
- 预期年化区间只作披露，不参与实际收益计算。
- Record Date 必须有合同/适用法域依据；M13 快照引用 M12 已生效法定名册，Token 余额只作辅助核对。
- 快照列表仅展示企业有权查看的脱敏持有人信息；更正必须形成新版本并保留旧版本及其已发生影响。

### I-56 收益计算与分配批次

- 计算引用已生效 Instrument、合法事件和已核验权益快照。
- 债权按合同付息计划/计息规则生成计算预览；合同其他约定必须标记人工核算。
- 股息/收益参与金额按合法决议或已核定的本期可分配金额及 Record Date 权利单位计算。
- 扣项/税费不采用全球统一算法；未确认时阻断正式应付批准，已核定金额须有依据。
- 一个事件/计算版本默认只形成一个完整分配批次；任何部分批次须独立批准和明确受益人/金额范围。
- 发行方不能手动标记真实注资；未足额注资默认不开放整批 Claim。

### I-57 领取与支付对账

- 企业端按批次和脱敏受益人查看应付、扣项、净额、已真实支付、未付余额和付款状态。
- 支持查看 Claim/Push/外部付款原记录、查询原 Intent、登记外部付款凭证和提交差异核对。
- 外部凭证登记后先进入待核验，不直接标记 Paid；只有真实资金/链上或外部付款证据达到适用最终确认才计入 Paid。
- Issuer 不代替投资者发起 Claim，不控制投资者钱包，不得手动标记 Paid；Unknown 先查原操作，不盲目重复支付。

### I-58 到期与退出

- 债权本金到期由 Instrument 计划生成；提前偿付须有合同依据。
- 股权回购/赎回/注销/清算仅在真实公司决议、合同/章程和法律条件具备时开放；不默认所有股权有回购或到期还本。
- 收益参与权期满结算仅在 Instrument 明确约定时适用。
- 部分清偿保留剩余应付和逾期；实际付款、M12 法定权益调整、M07 Token 处置分别核验。
- 责任交接必须有权法律/合同依据和承接确认；SaaS 退租不自动转移或消灭法律责任。
- 只有所有适用法律义务、实际清偿、法定权益和 Token 处置均有权威证据后，才显示「已依法结清」。

## 4. 不变的业务与数据责任边界

1. M04 负责生效 Instrument 条款、收益参与比例、债权付息安排及法律文件版本。
2. M12 负责法定持有人和权益登记；M13 只引用该权威登记形成 Record Date 快照。
3. M13 是收益事件、应付计算、分配批次、真实注资状态、实付/未领取和到期义务的唯一业务主责。
4. M07 负责 Token/链上交付、限制、Burn 与最终性；不得由 M13 页面改写 Token 事实。
5. M11 负责认购款、募集款和认购退款；不得将 M11 资金当作 M13 收益资金。
6. M17/M18/M20/M21 只提供待办、通知、审计和只读报表，不另建收益或支付主账。
7. 企业端持有人信息脱敏；不展示 KYC 原件、完整证件号码和不必要的个人信息。
8. V1 一个账号对应一个企业；本设计不新增企业内部角色/审批配置。页面记录有权主体、批准依据和证据，不以 SaaS 账号本身授予董事会、法定登记或付款权。

## 5. 版本范围与保护

- 沿用 M13-F001～F007、F009 原 V1.0 功能，不新增正式功能 ID，不修改 DEC-017 原 193 项首次交付版本归属。
- M13-F008 复杂公司行动重组仍为 V3.0，不纳入本轮。
- 多方比例分账、使用型权益仍为 V2；不引入复杂瀑布、优先劣后、复杂税法自动化、复利、浮动利率、复杂本金摊还或自动强制回购。
- 预期年化披露及债权周期付息继续按 DEC-059 与 U02-08 执行；预期年化不参与实际应付计算。
- 不修改 Frozen、历史 DEC/SCOPE、193 项正式功能 ID/首次版本归属；不关闭 X-01～X-13。
- PR #6、PR #8 均保持 Draft / Open / Unmerged；不合并。
- 本文和 UI-Ready 规格不代表源码实现、Build/Browser/自动化验收、真实法律登记、真实资金注资/付款、Signer、合约或生产执行已经完成。

## 6. 后续顺序

- **收益与分配：UI-Ready 设计完成。**
- 当前企业 SaaS 设计的下一模块为「数据与共享能力」：待办、异常、通知、受控规则、审计、业务报表、外部服务连接与安全支持。
- 平台运营后台、统一投资端和独立投资者门户不纳入当前企业 SaaS 模块设计轮次，待用户另行安排。
