# RWA SaaS V1｜I-13 Issuer 标准投资者门户管理 UI-Ready 收口

> 日期：2026-11-11  
> 产品端：Issuer 企业 SaaS  
> 页面归属：一级导航「投资者门户」→ I-13（一个逻辑页面组，不拆分为六个独立页面）  
> 设计状态：UI-Ready  
> 适用范围：Standard 企业对自有标准 V 门户的基础配置、预览、发布/暂停状态查看；Free 企业只允许内部只读预览。  
> 本文件承接 DEC-043、DEC-051、M01-F009、U01 E09 及当前 U02/DEC-069～082。它是当前 I-13 唯一有效页面规格；历史 Master §6.23/§6.33 保留为形成过程，不再直接作为当前执行稿。

## 0. 本次收口的决定与边界

### 0.1 唯一页面与既有功能

- 只保留一个 I-13 页面组，归属现有「投资者门户」一级导航；页面内分区/锚点不产生新页面 ID。
- 复用既有 M01-F009「标准 Issuer 投资者门户」功能，不新增正式功能 ID，不改变 DEC-017 原 193 项首次交付版本归属或 DEC-057 追加 11 项的 V1 追踪口径。
- 本页只管理 Issuer 自有 V 门户；不设计 V 投资者前台，不提供 M 统一投资渠道申请/上架，不替代 P 平台运营后台。

### 0.2 Free / Standard 的强制差异

| 能力 | Free | Standard |
|---|---|---|
| 门户配置 | 不允许编辑、保存门户配置 | 可编辑已批准的标准基础配置 |
| 门户实例/对外地址 | 不创建、不生成、不展示真实公开门户实例或地址 | 满足服务、法律及生产准入后创建/使用真实标准实例与地址 |
| 门户预览 | 仅内部只读预览；明确标注 Sandbox/模拟，不生成可分享链接 | 可预览当前草稿与已生效门户；内部预览不等于正式发布 |
| 对外发布/暂停/恢复 | 不允许 | 仅在所有独立准入条件满足时允许 |
| Offering 展示 | 只读查看内部预览内容，不对外披露 | 仅展示本企业有权且已满足披露条件的 Offering |

Standard 订阅有效、KYB 通过或门户技术服务已连接，均不自动代表法域、法律披露、Issuer 主体、Provider 或生产服务准入通过。系统必须逐项读取真实来源；任一强制条件为失败、Unknown 或来源冲突时，阻断对外发布/恢复。

### 0.3 V1 不提供的能力

- 企业内部成员、角色、RBAC、发布审批人分配或多级内部审批。
- 自由 CMS、Banner、拖拽布局、导航自定义/排序、主题装修、多语言内容编辑、营销内容编辑或个性化推荐。
- 高级白标、自定义域名（按既有版本规划后置）、公开分享未发布预览链接。
- Issuer 自定义投资者类别、地区资格、投资限额、白名单或 AML 豁免。
- 在 I-13 编辑 Offering 条款、权益结构、法定主体、KYC、订单、收款、资金、持有人、Token 或收益事实。
- M 统一投资渠道申请、审核、上架或渠道销售数据。

## 1. 页面入口与信息结构

**入口：** 左侧一级导航「投资者门户」→ I-13。  
**页面标题：** 投资者门户。  
**说明：** 管理本机构的标准投资者门户；发行方案展示与认购资格始终以各自业务状态及适用法律为准。

页面采用单页纵向分区，不新增二级导航：

1. 门户概览与套餐/环境状态
2. 基础展示信息
3. 法律链接与披露来源
4. Offering 展示范围
5. 标准模板与门户预览
6. 发布状态与历史记录

页面页头固定显示当前企业、Free/Standard、当前环境、门户实际状态、最近一次成功核验时间。Free 页面始终显示「内部 Sandbox 预览 · 不是真实投资产品」；Standard 不显示「已获准发行」等未经证实文案。

## 2. 门户概览

### 2.1 字段与展示

| 字段 | 控件/展示 | 规则 |
|---|---|---|
| 当前企业 | 只读 | 当前唯一 Tenant，不提供企业切换器 |
| 套餐与订阅状态 | 只读状态标签 | Free / Standard；订阅状态按 U01 权威来源显示 |
| 环境 | 只读标签 | Free 为内部 Sandbox；Standard 显示真实服务环境状态，不暗示生产获批 |
| 门户实例状态 | 只读 | 未创建 / 配置中 / 已发布 / 已暂停 / 处理中 / Unknown；仅 Standard 真实实例可出现 |
| 标准门户地址 | 只读、复制/打开 | 仅 Standard 已获准且服务端返回有效地址时显示；Free 永不生成或显示公开 URL |
| 最近核验时间 | 只读 | 显示真实来源最后成功查询时间；失败时保留最后成功时间并标注过期 |
| 当前阻断事项 | 只读列表 | 列出套餐、KYB、法律文件、Offering 发布状态、服务授权等真实缺项及回源入口 |

### 2.2 页面主动作

- Free：唯一主动作「内部预览」；不显示配置保存、初始化门户、发布、暂停或恢复按钮。
- Standard 未满足发布条件：主动作「查看发布前检查」；允许在权限范围内编辑基础配置。
- Standard 已满足条件且未发布：主动作「发布标准门户」。
- Standard 已发布：主动作「预览已发布门户」；次操作按实际状态提供「暂停门户」。
- Standard 已暂停：只有重新核验全部条件通过后才显示「恢复门户」。

## 3. 基础展示信息（仅 Standard 可编辑）

| 字段 | 控件 | 必填/校验 | 说明 |
|---|---|---|---|
| 门户展示名称 | 单行文本 | 必填；去除首尾空格；不得为空 | 仅为门户展示名，不改变法定 Issuer 名称 |
| 机构 Logo | 图片上传/预览/替换 | 选填；格式、大小及安全扫描按当前上传服务规则 | 上传/扫描完成不等于正式生效；Free 只读展示固定示例，不提供上传 |
| 机构简介 | 只读标准文案/已批准资料引用 | 不提供自由营销编辑器 | 如当前正式能力不支持该字段，则不显示编辑控件 |
| 标准门户模板 | 固定模板，只读 | 不可切换主题或布局 | 仅展示标准页面组成与数据来源 |
| 保存状态 | 只读 | 草稿 / 保存中 / 已保存 / 失败 / Unknown / 版本冲突 | 草稿保存不改变对外已生效内容 |

**操作：**
- 「保存草稿」：仅 Standard 可用；保存当前允许编辑的基础展示字段，不对投资者生效。
- 「取消修改」：存在未保存修改时二次确认「放弃本次未保存的修改吗？」。
- 「重新加载」：先查询当前服务端版本；有本地未保存修改时提示先保存或放弃。
- 「查看企业资料」：返回企业管理原页面；不得在 I-13 修改企业法定资料。

## 4. 法律链接与披露来源

本区块仅引用已有合法文件/链接，不代写、批准或判断法律文本效力。

| 字段 | 控件/展示 | 规则 |
|---|---|---|
| 法律文件/政策名称 | 只读列表 | 来自企业资料、文件管理或适用法律来源 |
| 文件/链接版本 | 只读 | 显示来源、版本、生效状态和最近核验时间 |
| 适用范围 | 只读 | 按实际法域、Offering、受众和法律主体显示；未知不得默认全球适用 |
| 核验状态 | 状态标签 | 有效 / 缺失 / 已失效 / 待核实 / 来源不可用 |
| 缺项责任入口 | 跳转链接 | 返回企业资料、文件或 Offering 原页面补充，不在 I-13 复制文件主账 |

缺少必要文件、链接失效、版本不匹配、跨企业引用或适用性 Unknown 时，不允许将受影响的 Offering 对外展示；必须显示缺项原因和回源入口。

## 5. Offering 展示范围

本区块只展示当前企业的 Offering 及其真实披露/发布状态，不创建第二套 Offering 状态或资格配置。

| 字段 | 控件/展示 | 规则 |
|---|---|---|
| Offering 名称/编号 | 只读列表 | 仅当前 Tenant 有权访问的 Offering |
| 关联资产/权益结构版本 | 只读 | 引用资产与发行原始版本 |
| Offering 发布状态 | 只读 | Draft / 待发布 / 已发布 / 暂停 / 已结束 / 已关闭等以 Offering 主账为准 |
| 认购窗口 | 只读 | 显示实际开始/结束时间与时区 |
| 法律披露状态 | 只读 | 有效 / 缺项 / 待核实 / 不适用 |
| 门户展示状态 | 只读 | 可展示 / 不可展示 / 待核实，并说明原因 |
| 预览入口 | 按条件显示 | 仅内部受权预览；不创建公开分享链接 |

规则：
- 门户发布不自动发布 Offering；Offering 已发布也不代表门户一定已发布。
- Offering 是否展示只取决于真实发布状态、披露授权及适用法律条件；不允许 Issuer 在本页自定义投资者类别、地区、限额或 KYC 豁免。
- KYC 由平台及适格服务商统一核验；Issuer 只在投资者管理页面查看本企业有权查看的脱敏状态。
- M 统一投资渠道与 Issuer 自有 V 门户完全分开；I-13 不出现 M 渠道申请/上架按钮。

## 6. 标准模板与预览

### 6.1 固定标准模板说明

页面仅展示标准门户的固定组成与数据来源说明，不允许修改布局：
- 机构基础信息与 Logo
- 已获授权展示的 Offering 列表
- Offering 详情与法律披露
- 投资者登录与统一 KYC
- 认购订单及付款状态
- 本人持仓、Token、收益与通知（均由各自权威模块提供）

I-13 不编辑上述业务流程、投资者端 UI 或金融/法律事实。

### 6.2 Free 内部只读预览

- 使用内部 Sandbox 预览，不创建真实门户实例、不生成公网 URL、不保存门户配置。
- 预览必须有持续可见的「Sandbox 模拟 · 不是真实投资产品」标识。
- 不允许公开分享、真实投资者访问、真实认购、付款、持仓、Token 或收益操作。
- 预览内容仅使用已准备的资产/权益/Offering 资料和明确标识的示例结构；不得虚构真实募集进度、投资者、资金、持仓或收益数据。

### 6.3 Standard 预览

- 允许预览当前已保存草稿和已生效门户；草稿预览固定标注「内部预览 · 尚未正式生效」。
- 已发布门户可通过真实有效地址打开；地址不存在或状态 Unknown 时不显示可点击的正式入口。
- 预览不改变门户或 Offering 状态，不触发认购、付款、KYC 或 Token 操作。
- 预览数据读取失败时显示失败原因、最后成功核验时间和单区重试，不清空用户草稿。

## 7. 发布、暂停与恢复

### 7.1 发布前检查

发布前必须重新读取并核验：
1. 当前企业 KYB 与 Standard 订阅状态；
2. M01 标准门户服务/实例状态及真实地址能力；
3. 基础展示信息完整、Logo 上传与安全检查结果（如使用）；
4. 必要法律链接/文件的来源、版本与适用状态；
5. 拟展示 Offering 的真实发布状态及披露/访问条件；
6. 平台安全、法域和真实生产准入状态。

任一必需项失败、Unknown、超时或版本冲突，均阻断发布/恢复。不得用旧缓存、手工勾选或「Provider Connected」代替真实核验。

### 7.2 操作与确认

| 操作 | 条件 | 二次确认/结果 |
|---|---|---|
| 发布标准门户 | Standard、KYB、真实服务实例、法律披露与生产准入全部通过 | 「确认发布标准投资者门户？门户发布不代表每个 Offering 均可见或可认购。」 |
| 暂停门户 | 当前真实状态为已发布，且服务端允许 | 「暂停将限制新的公开访问；已成立订单、投资者权利及存续义务仍须继续处理。确认暂停？」 |
| 恢复门户 | 当前为已暂停，且重新核验全部发布条件 | 「恢复前将重新核验企业、法律文件、Offering 和服务状态。确认恢复？」 |
| 查询操作结果 | 原操作处理中或 Unknown | 只查询原 Intent；不重复创建发布/暂停请求 |
| 查看历史记录 | 有真实来源事件时 | 只读展示时间、操作类型、结果、来源和关联对象 |

V1 一个账号对应一个企业，不建立企业内部发布角色或审批人分配。发布操作仍受真实业务授权、法律主体和平台生产守卫约束；UI 不得将普通登录等同于法定签署权或生产执行权。

### 7.3 独立状态

门户状态、Offering 状态、认购窗口、投资者 KYC/资格、订单状态、资金状态、法定登记、Token 交付必须分别显示。门户暂停不删除订单、实收、退款义务、法定登记、Token 或收益记录。

## 8. 页面状态、空态与异常

| 场景 | 页面反馈 | 下一步 |
|---|---|---|
| Free 访问 | 只显示套餐说明与内部只读预览 | 内部预览 |
| Standard 尚未开通实例 | 显示尚未开通及服务/准入状态，不生成假地址 | 查看企业/服务状态 |
| 无 Offering | 「当前企业尚无可展示的发行方案」 | 前往资产与发行 |
| Offering 不可展示 | 显示真实原因：未发布、已暂停、披露缺失或待核实 | 前往 Offering 原页面 |
| 法律链接缺失/失效 | 标记具体文件和版本，不显示合规通过 | 返回来源页面补充 |
| 保存失败 | 保留本地编辑内容并显示失败原因 | 重试保存/重新加载版本 |
| 页面加载失败 | 保留最后成功核验时间与只读缓存提示 | 重试查询 |
| 服务超时/Unknown | 显示「操作结果待确认，请先查询原操作记录」 | 查询原 Intent |
| 版本冲突 | 显示当前服务端版本与本地未保存修改提示 | 重新加载后人工核对 |
| 权限/租户失效 | 清除失效企业的预览与敏感数据 | 返回当前企业工作台 |
| 发布被阻断 | 显示缺项、来源及责任模块 | 回到原业务模块补齐 |
| 暂停/恢复失败 | 不乐观更新状态，保留原状态 | 查询原操作并联系支持 |

所有状态均使用文字标签，不只依赖颜色；按钮禁用时必须说明原因。

## 9. 跨模块责任与跳转

| 业务事实 | 唯一权威来源 | I-13 允许行为 |
|---|---|---|
| 企业主体、KYB、套餐 | 企业管理/U01 | 只读摘要与回源 |
| 门户实例、配置、发布状态 | M01 标准门户能力 | 按准入编辑基础展示信息、查询状态 |
| Asset/Instrument/Offering 条款与版本 | 资产与发行 | 只读展示、跳转原页面 |
| Offering 发布、销售窗口和披露快照 | Offering | 只读引用 |
| 投资者 KYC/资格 | 平台统一身份与适格服务商 | 只读说明，不审核/覆盖 |
| 认购订单与付款 | 认购订单、资金与结算 | 不编辑、不复制 |
| 法定持有人登记 | 配售与持有人/实际有权登记主体 | 不编辑 |
| Token/链上交付 | Token 管理/实际受权执行主体 | 不编辑 |
| 收益、到期与清退 | 收益与分配/实际义务主体 | 不编辑 |
| 通知、审计与服务事件 | 数据与共享能力 | 只读引用，不复制日志主账 |

从原模块跳入 I-13 时保留当前 Tenant 与来源对象；返回时重新核验权限、版本和状态。禁止从 I-13 创建第二份 Offering、订单、付款、法定登记、Token 或收益记录。
