# DEC-006｜全球化产品定位与首批市场选择原则

- **状态：** 战略原则已确认；候选市场、市场排序与上线范围待证据验证
- **确认日期：** 2026-10-19
- **适用文档：** 第 02 份《产品战略与商业模式》；后续用于第 03 份总体 PRD、第 08 份法律/监管方案及第 09 份商业运营与市场验证计划

## 决策背景

项目需要明确产品定位与首批市场选择之间的关系。产品不应因为当前研究了某些国家，就被设计成只适用于这些国家；同时，也不能仅凭全球化产品定位，推定任一国家/地区的所有资产类别和金融活动都可以合法开展。

## 已确认决策

1. **全球化产品设计：** 建设一套面向全球客户的标准化、可配置、多资产 RWA Tokenization SaaS。通用核心数据模型、产品能力和工作流尽可能跨市场复用；市场差异通过有边界的配置、模块化集成和逐市场验证处理，不将整个平台绑定于单一国家。
2. **全球客户发现：** 客户发现范围不预先局限于日本、阿联酋或其他单一市场。围绕 DEC-005 已确认的 A/B/C 客户优先级，持续收集不同候选市场的客户需求、实际发行计划、决策人可触达性、采购过程与试点可能性。
3. **证据驱动的首批市场选择：** 不预先确认某个国家为首发或优先市场。首批市场排序须结合可触达客户、真实需求与试点证据、预算/采购及付费信号、法律可行性、合格合作方生态、竞争替代方案、交付与持续运营成本及商业可行性综合判断，并记录证据与未决问题。
4. **日本与阿联酋的定位：** 日本和阿联酋保留为候选研究市场，但不是已确认的优先市场，也不构成排他范围。它们与其他候选市场适用同一评估框架。
5. **产品全球化不等于全球业务自动获准：** 每一拟进入市场、资产/金融工具、投资者类别及业务活动组合，都须按实际业务模式完成适用法律定性、许可/注册分析、受监管活动责任分配、合作方确认及上线条件审查。DEC-004 继续适用；软件配置、合同措辞或第三方 API 不能替代许可要求。

## 对产品与执行的约束

- 先设计可复用的核心产品与清晰的法域/资产配置边界，避免把某个候选市场的临时假设固化成全球默认值。
- 对不同候选市场建立可比较的证据记录；不得仅凭宏观市场规模、政策宣传或单个合作方意向认定首发市场。
- 市场优先级、首发资产类别、公司经营主体/许可路径、定价及获客策略是相互关联但不同的决策，必须分别验证。
- 继续遵循 DEC-001 的客户资产门户隔离与授权分发原则、DEC-002 的客户层级与交付边界、DEC-003 的多资产与首批 1–2 类评估原则、DEC-004 的受监管活动责任边界，以及 DEC-005 的客户拓展优先级。

## 尚待验证

- 哪些候选市场存在最可触达且有真实发行计划的目标客户；
- A/B/C 客户群在不同市场的具体需求、采购周期、预算、付费意愿与获客成本；
- 每个候选市场的资产/金融工具法律路径、牌照或注册要求及受监管活动责任主体；
- 可用的法律、KYC/KYB、支付、托管、登记、审计等合格服务商及其商业条件；
- 首批市场与首批 1–2 类资产的组合、交付成本、上线顺序和商业可行性。

## 后续动作

1. 按 DEC-005 对 A 类客户优先开展客户发现，并对 B 类 White-label 与 C 类 API 客户分别验证；客户发现不局限于日本或阿联酋。
2. 建立候选市场评估表，明确证据来源、置信度、法律门槛、客户信号、合作方条件、成本与未决事项。
3. 在取得客户与法律证据前，不将任何候选市场标记为已确认首发市场，也不将任何候选资产类别标记为最终首发资产。
