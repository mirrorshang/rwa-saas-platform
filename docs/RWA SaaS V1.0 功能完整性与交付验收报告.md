## 两条浏览器实操链

住宅 `OFF-3001`：25,000×10 U，总额 250,000 U；七组检查通过、模拟发布和认购窗口开放；三名投资者按 50／30／20% 完成 Mock 订单、付款、配售、登记及快照。2026-12 租金净额 1,000 U 按 `HSP-3001` 固定比例分配，三笔模拟支付后持有人详情有收益记录，刷新不丢失。同周期重复建批次拒绝。

债权 `OFF-3002`：4,000×100 U，总额 400,000 U；模拟发布、两名持有人 250,000／150,000 U。Actual/365 Fixed 从 2026-12-01 至 2028-12-01 生成 24 个利息事件；首期 31 天 4,076.712329 U，分为 2,547.945206／1,528.767123 U。未到期阻断首期批次；到期后支付 24 期利息，并以独立 `DST-1026` 偿还本金 250,000／150,000 U。缺到期快照、名册／Token 未处置时清偿被阻断；补齐后显示剩余本金 0、Sandbox 清偿完成。持有人累计收益不含本金。

## 功能状态与未完成项

- **A：浏览器已点击的 Mock。** 上表五模块的双例操作、失败/Unknown 保护、刷新后的本地记录。所有 A 均带 Sandbox 标识，不是生产结果。
- **B：页面或展示存在，处理不完整。** 投资者门户预览、部分退款／募集结算／对账／合约和报表按钮，不能据此宣称完整生产能力。
- **C：未实现。** 独立 V/M 交易端与 P-15/P-16 跨端执行；原追溯矩阵中的后续版本特性仍按历史范围处理。
- **D：外部权威结果未验证。** 邮箱安全会话、真实 KYB/KYC、钱包签名、收付款、法定登记、链上合约与 Token、V/M 收益回传、服务端持久化和并发事务。

## 风险与交付判断

本次内部 Mock 演示两条闭环已可复现，无已知阻断该范围的 P0；生产上线仍有 D 类前置，不得将本报告作为真实发行、法定登记或财务清偿证明。浏览器本地数据可被用户环境清除，部署需服务端主账与权限；当前错误恢复页保留原始记录，不能代替生产备份。完整点击路径见 [操作手册](Issuer%20SaaS%20V1.0%20全流程操作手册.md)；跨端边界见 [四端泳道图](RWA%20四端业务流程泳道图.md)。

提交前双轴审查发现：同一 Offering 的无计划引用旧债权批次可能漏过清偿守卫，现已统一检查全部未结债权利息／本金批次并加测试。清偿后缺少登记历史，不能事后回建历史快照；当前流程要求清偿前逐期固定并明确阻断，生产回溯须服务端登记变更历史。新增静态间距已改用 Tailwind utility。DemoConsole／DrawerPanel 体量及三模块少量辅助函数重复是后续重构候选，本次没有扩大模块边界。

本报告随开发 PR 提交供产品负责人复核；release 基线是否接受以 PR 审查和仓库 CI/审批结果为准。
