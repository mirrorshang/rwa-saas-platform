## 六模板及跨模块重点验收

1. 六种模板分别检查创建入口、专属字段、条件必填、Ready 证据；当前只有住宅和债权专属 Ready 校验较具体。非上市普通股权、写字楼、商铺、工业园/仓储物流不得因示例资产存在而算完成。房地产五步创建、住宅租赁条件校验必须以手工新建复验。
2. 股权 Instrument 的表决、分红、清算、转让限制以及债权无息模式分别验收；整数权益/Token 映射无法整除必须拒绝。Asset、Instrument、Project、Offering 保持独立版本和引用。
3. 认购记录归订单已完成筛选，锁仓归持有人详情；不得重复主账。Issuer 只展示脱敏 KYC，不能人工审批真实身份。
4. 门户仅 Logo、平台域名前缀、地址/预览、上架资产。数据报表和企业管理只保留批准的精简入口。
5. 测试换算 1 U=¥8 不进入生产金额规则；零持有人、同期间重复分配/付款、债权清偿后停息及到期阻断均需手工新建和服务端幂等验收。
6. M03/M08 的原 V1 功能和 M23/M24 十一项与当前范围冲突。推荐留存批准记录、单列待决，先不实施独立端或平台后台；需产品负责人形成变更审批。

## 高风险缺口的具体交互与验收

| 缺口 | 必要字段与动作 | 校验、状态及验收 |
|---|---|---|
| 非上市企业普通股权模板 | 企业名称、股类、股份总数、发行份额、权利人、表决/分红/清算与转让限制、章程及权属文件；从空表单创建、编辑、保存 | 必填、股数整数与上限、关联文件扫描、产权主体一致；未齐为 Draft，合格才 Ready。不得借示例数据直接通过 |
| 写字楼、商铺、工业园/仓储物流 | 各自用途、面积、权属、出租/经营情况、租约/运营方、估值及专属证明；按模板切换条件字段 | 不适用字段不强制，适用字段缺失不得 Ready；新建三类各跑完整保存与恢复 |
| 股权 Instrument | 股类、每单位权利、表决/分红/清算、限制、总容量、Token 映射、法律文件 | 不得复用收益参与权默认条款；不能整除或超容量拒绝；已引用版只能新建版本 |
| 债权无息模式 | 合同利率模式为“固定/无息”，本金、未偿本金、起息/到期及还款方式 | 无息时利率为 0 且不生成利息，仍可还本；与固定利率互斥，保存与重载一致 |
| 房地产五步创建 | 分类模板→基本/专属资料→权属与估值→租赁/运营→文件和预览确认 | 每步可保存恢复；住宅已出租须有租赁期限及合同，空置不应被无条件要求月租；审核和 Ready 分离 |
