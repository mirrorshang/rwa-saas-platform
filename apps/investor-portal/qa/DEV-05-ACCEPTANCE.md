# DEV-05 订单、异常与客服 Mock 验收（2026-11-26）

## 基线与范围

- 基于 PR #17 DEV-04 HEAD `73efd77a920c00be27a584c755fe07f523323a08` 和已批准的 `V-M-SHARED-UI-READY-PRD-v0.1.md` 第 6 节。
- 仅前端 Mock；无真实客服派单、链上结果、退款指令或到账证明。

## 实现

- “我的投资”认购订单列表、订单详情：项目、Issuer、编号、Token 份数、金额、创建时间、文件版本、付款/配售/登记/交付阶段及原交易引用。
- 区分未付过期、付款核对中、失败、回滚、结果未知、履约异常、退款资格待核实、退款处理中和退款已核实到账。付款失败或回滚不推断退款完成；已付款订单不会因待付款期限过期而变为过期。
- `/demo` 仅对当前账户和渠道的 Mock 订单应用异常与退款结果；退款完成须显式选定，且已有匹配付款才可模拟退款结果。没有投资者主动取消有效认购或手动申请退款入口。
- 帮助与客服表单、本人订单只读带入、问题类型、必填描述、可选交易哈希及截图文件名、本人工单列表/详情、投资者回复、独立演示客服回复及处理状态。截图仅保存文件名，不上传内容。
- 订单和工单均按账户、V/M 渠道隔离；工单状态变化不修改金融业务记录。
