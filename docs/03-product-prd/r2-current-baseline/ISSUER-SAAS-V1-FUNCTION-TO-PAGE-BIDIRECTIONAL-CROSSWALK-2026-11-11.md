# RWA SaaS V1｜Issuer 正式功能 ID 与页面双向映射审计

> 审计日期：2026-11-11  
> 范围：仅 Issuer 企业 SaaS；不设计 V 投资者前台、M 统一投资端、P 平台运营后台。  
> 依据：V1 正式功能范围总表（157 项）、当前九个一级导航、U01/U02 专项 UI-Ready 规格、DEC-069～082、I-13 当前 UI-Ready 规格。  
> 状态：总控审计工作稿；不新增功能 ID、不改变任何历史版本归属，不构成 V1 整体冻结。

## 1. 审计口径

- 当前有效 V1 追踪范围为 157 项；DEC-017 原 193 项首次版本归属保持 V1 146 / V2 22 / V3 20 / TBD 5，DEC-057 追加 11 项后当前 V1 追踪口径为 157。
- 157 项中，132 项属于 Issuer 业务或 Issuer 可见的共享责任范围；另 25 项归属 P 平台运营（3）、V 投资者前台（11）、M 统一投资渠道（7）及 M 统一投资者视图（4），仅标注产品端归属，不纳入本轮页面设计。
- 本矩阵逐项列出 157 个正式 V1 功能 ID，并标明唯一页面责任或其所属产品端。非 Issuer 页面明确标记为本轮范围外，不能误判为 Issuer 页面遗漏。
- 功能 ID 保留不代表每项都必须在 Issuer 客户端形成可编辑页面。按 U01 单账号单企业和 DEC-069 统一 KYC 规则，部分功能只作为系统级守卫、只读来源或其他产品端责任，不新增客户配置页面。
- 页面内 TAB、抽屉、弹窗、列表/详情视图不另计独立页面；Project、文件、KYC、通知、安全等横向能力按当前架构嵌入既有页面或作为全局入口。
- 每个页面必须有明确功能来源；每个 Issuer 相关功能必须有唯一责任页面/承载方式；只读引用不得被误认作第二套主账。

## 2. 现行 Issuer 九个一级导航与页面责任

| 一级导航 | 当前二级入口/页面组 | 唯一责任 |
|---|---|---|

| 企业管理 | 企业资料/KYB｜钱包｜套餐订阅｜规则设置｜外部服务 | 企业商业信息、钱包配置、订阅、受控规则来源、外部服务状态 |
