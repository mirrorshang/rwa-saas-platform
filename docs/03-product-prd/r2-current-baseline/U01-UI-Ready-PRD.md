# U01 企业入驻、认证、钱包与订阅｜UI-Ready PRD
> R2-04｜2026-11-06｜产品规则批准；本文汇编状态：Draft PR 待评审。产品批准 ≠ 实现完成 ≠ 真实金融/密钥/支付生产准入。

## 0. 通用原则
- 一个邮箱账号对应最多一个企业 Tenant；Account/Tenant/KYBApplication/Subscription/Entitlement/Wallet/OfferingReceivingWallet/PaymentOrder 为不同逻辑对象。V1 一个账号自主操作，无多企业切换、团队成员角色和审批分权。
- 登录后可访问工作台及全部导航（可点击、可知晓功能）；未通过企业 KYB 时业务内容/接口不可访问，主内容区域替换为统一认证引导/状态。账号、认证、帮助、协议、退出等必要操作继续开放。
- 企业 KYB 非登录强制条件；KYB 获批才激活 Free 企业业务。Free 全模拟发行闭环与投资者页面内部预览，不公开真实募资；Standard 真实能力仍须独立业务、法律、Provider、Signer、网络、支付安全门。
- UI 所有导航、字段标签、选项、帮助、通知、校验、错误提示用简体中文；协议与链标识、地址、服务商等必要专有名称除外。V2 才做多语言和按地区登记资料适配。
- 本 V1 字段标注为“必填/选填”，不将未定义的“条件必填、按法域自行判断”交给研发。该简化 KYB 不是全球法定完成保证；实际生产法域额外条件需生产准入另审。
- 金额 UI 使用 U 按 USDT 计价；投资者付款 V1 仅 OP Mainnet USDT。SaaS 商业订阅独立支持 USDT 与法币，不能混同网络、收款账户、资金账。
- 所有正式提交/订单/钱包关联须幂等、有版本、记录操作者与时间；防止旧 Mock 漏入真实账。

## A 账号入口（A01～A03）
**页面结构**：邮箱输入 + 邮箱验证码输入（同一入口两步）；协议首次确认嵌入入口，不设传统注册页。
**字段**：邮箱地址（必填、标准格式、长度上限254）；邮箱验证码（必填、6位数字）；服务协议及隐私政策同意（新账户首次使用必选；记录版本、确认时间及账号）。已有账号无须重复接受原版本，协议重大更新时按需重新确认。
**流程**：官网企业登录 → 输入邮箱获取验证码 → 校验有效期、一次性使用、频率限制 → 旧账号登录/新邮箱验证成功后建账号 → 直接进入企业工作台（即使没有 Tenant）。验证码过期、错误、已用、频控、邮件发送失败、网络异常明确报错；可修改邮箱、重新发送；不能产生重复 Account。
**权限**：账户受限/停用拒绝业务访问；会话过期重新邮箱验证；会话、同意记录以服务端真实状态为准。

## B 创建并认证企业（B01～B08）
**入口/形态**：工作台中统一“创建并认证企业”入口；一个五步向导（企业信息→资质→受益人/控制人→联系人→确认提交），加引导、状态与补件视图；不要求 8 个独立路由。每步有进度、上一/下一、草稿自动/手动保存和错误定位；继续时恢复原草稿。创建企业与 KYB 为一个入驻流程，不因录入基础字段直接开通 Free。

### B01 引导
展示用途、准备材料、完成后可用的 Free 模拟能力；按钮“开始企业认证”/“继续填写”；可回工作台继续浏览导航，不强制退出登录。

### B02 企业基本信息
| 字段 | 要求 | 规则 |
|---|---|---|
| 企业法定名称 | 必填 | 与注册证明一致；去首尾空格 |
| 企业类型 | 必填 | 有限公司、股份公司、合伙企业、基金或投资主体、其他 |
| 注册国家或地区 | 必填 | 显示中文国家地区选项，保留稳定代码 |
| 企业注册编号 | 必填 | 不为空；同一注册地＋注册编号重复申请提示，不自动覆盖 |
| 企业注册地址 | 必填 | 单一完整地址文本 |
| 企业官网 | 选填 | 填写时检验网址格式 |

不收集独立英文名、成立日期、经营简介、省市街道拆分等额外字段。

### B03 企业资质文件
| 文件 | 要求 | 规则 |
|---|---|---|
| 企业注册证明/营业执照 | 必填 | PDF/JPG/PNG；每个文件上限20MB |
| 企业资质或经营许可证明 | 选填 | 可上传 |
| 其他补充材料 | 选填 | 可多文件 |

每条文件记录：类别、文件名、大小、格式、上传时间、上传状态、安全扫描状态、版本。提供上传、预览、替换、删除未提交文件；上传失败与扫描异常禁止将文件当作可用。正式提交后的新资料产生新版本，不覆盖旧版本。

### B04 最终受益人及控制人
支持增加多名人员；每人字段：姓名（必填）、身份或职务（必填）、控制关系（必填：直接持股/间接持股/其他控制）、持股比例（选填，0～100）、补充说明（选填）。至少登记一名 UBO/实际控制人，无法识别时可登记主要负责人并说明原因；简化表单不代表任何法域法定 UBO 核验已满足。暂不收集国籍、生日、身份证件号等额外敏感字段。非数值、比例越界阻止提交。

### B05 联系人
联系人姓名（必填）、联系人职务（必填）、联系邮箱（必填，合法格式，默认当前登录邮箱，可改）。不要求联系电话、国家地区、授权代表或备用电话；联系人信息不创建第二登录账号。

### B06 预览提交
只读摘要、每块“修改”、真实性声明（必选，主动勾选）；提交前校验所有必填字段、文件可用性、身份登记、重复主体及安全扫描；提交幂等，生成申请ID、版本快照、提交时间、审计事件。提交后不可直接编辑原快照。超时结果未知时查询原申请，不重复创建。

### B07 认证状态
未创建、资料草稿、已提交、审核中、待补件、已通过、未通过；展示明确状态、原因及下一步。审核中可查看提交资料但不可改写提交版本；待补件进入B08；未通过展示原因及获准重新申请/联系支持入口；已通过解锁业务，自动激活 Free，并异步启动真实 MPC 钱包开通。

### B08 补充资料
仅开放审核要求修改的项目；保留原资料与审核意见；补充解释（选填），重新提交形成新版本，审核再进入已提交/审核中。支持失败重试与状态变化处理。重大法律主体信息变更需再核验，保留旧认证与审批事实。

## C 工作台准入（C01）
登录后始终展示现有侧边一级/二级导航，均可点击；未认证时保留点击菜单的选中态、路径/标题，在主内容区渲染统一 KYB 状态内容，而非真实业务详情，不跳出工作台。未认证首页显示认证 CTA 与能力概览，不显示伪造的业务统计。
| 状态 | 主内容区 | 主操作 |
|---|---|---|
| 无企业 | 入驻引导 | 开始认证 |
| 草稿 | 待完成 | 继续填写 |
| 已提交/审核中 | 当前审核状态 | 查看进度 |
| 待补件 | 审核意见 | 补充资料 |
| 未通过 | 原因与可选后续 | 查看处理意见 |
| 已通过 | 正常业务功能 | 具体业务操作 |
只有认证/账号/帮助/法律页面为未通过状态例外。路由和后端 API 双重门禁；状态未知时拒绝业务数据而非默认放行；认证完成后按实际权益恢复访问。

## D 企业钱包（D01～D05）
**重大覆盖规则**：KYB 获批后**自动分配真实有效 MPC 钱包**（即使 Free），无二选一、无模拟 MPC。MPC 由已准入真实 Provider 执行；可开通中/失败，失败不回滚 KYB/Free，绝不可生成随机模拟地址冒充成功。Provider/Signer、密钥控制与托管责任仍是生产准入门。
**页面**：企业设置→钱包管理，一张钱包列表管理页（系统分配 MPC 固定显示、多个自有钱包），钱包详情、添加自有钱包、设置默认、解绑与异常操作在子视图/弹窗完成。
**自有钱包**：可新增多个，必须连接读取 EVM 地址、OP Mainnet 网络并以一次性消息签名证明地址控制权；服务端核验地址、会话、时间及防重放，绝不收集私钥、助记词。不以浏览器断开连接自动判断链上钱包失效。
**列表字段**：钱包名称（自有钱包选填）、钱包类型、地址（可完整查看和复制）、网络、验证状态、绑定时间、是否默认。系统创建 MPC 额外记录服务商ID、开通状态、失败/重试审计。
**默认钱包**：企业同一时刻只有一个已验证有效钱包为默认，初始为自动分配成功的 MPC；可在 MPC 与任意已验证自有钱包间直接切换默认标记（无需重新签名），原钱包不删除，旧发行收款关联不变。默认是新发行时的预选值，不是唯一可选钱包。
**解绑**：MPC 不允许企业直接删除；已验证自有钱包允许解绑，但正被有效发行使用时不允许直接解绑；默认钱包解绑需先设置其他默认；历史绑定及发行地址快照永久追溯。
**发行关联**：每个 Offering 必须明确关联已验证钱包，默认预选可改选其他有效钱包；保存 walletId、addressSnapshot、chain、type、confirmTime。未有有效钱包时引导先配置/等待真实 MPC 开通，不允许跳过。更改企业默认钱包不静默修改现有 Offering；真实活动发行的收款地址变更需单独受控变更。Free 发行的业务流程/收款事实仍为 Mock；企业真实 MPC 地址不得用作“Free 可真实募资”的借口。
**状态**：MPC 开通中/可用/异常；自有钱包待验证/已验证/失败/解绑；默认切换成功、并发冲突、网络错误、签名拒绝与到期均明确中文反馈。

## E Standard 订阅（E01～E08）
**UI**：企业设置→订阅管理：主页面（当前套餐、周期、到期日、自动续费、历史记录）、购买流程（月/年→USDT或法币→订单确认→支付结果）、续费与取消确认弹窗。未通过 KYB 用户只看到 C01 KYB 拦截。
**商业规则**：
- V1 Free + 一个 Standard 固定月/年价，无发行额百分比收费；最终价格、税费、开票和费率为待配置项。
- 订阅支持 USDT 和法币；法币显示真实结算币种/金额/报价有效期；投资者 OP 主网 USDT 与 SaaS 订阅支付网络分别配置，不擅自承诺某网络现已可付款。
- 默认关闭自动续费；用户主动启用，**仅在付款渠道具备有效周期扣款授权能力时开放**。失败通知并允许手动续费，不无限尝试。
- 可信支付服务最终确认收款后幂等激活 Standard；待支付/结果未知/自行提供哈希均不构成激活条件；异常退款经审核，不做无条件自动退款。
- 到期前 **7天、3天、1天及到期当天**提醒（站内及邮件，以确认的通知能力为准）；关闭自动续费只影响未来，不提前终止已付周期。
- 到期进入 **7天宽限期**：保留既有业务必要存续操作，**暂停新增真实发行**；结束未续费转降级，企业业务历史**只读**，保留订阅恢复、认证与账号入口；必要投资者权益履行须由独立受控机制承接，不强行让降级企业恢复普通业务写入权。
- 钱包及合法存续事实不会因降级被删除。重新付款并通过有效企业和业务准入才恢复对应权限。

**字段**：
- 订阅：Tenant、套餐、月/年周期、开始/到期时间、状态、自动续费标志、授权/渠道标识。
- 订单：编号、套餐、周期、应付金额及实际支付币种、支付网络（USDT时）、报价有效期、支付状态、最终确认时间、对应服务期、回调及幂等键。
- 页面状态：Free、待支付、Standard有效、宽限期、已降级；支付待付、确认中、成功、失败、取消、结果未知；异常给出继续支付/查询/重试/联系支持的准确动作。

## 跨模块强制验收
1. 新账号不经企业创建即进可浏览导航的工作台；不存在多企业切换或 V1 角色/成员配置。
2. 任意业务导航/深链/API在 KYB 未通过时只得到统一 KYB 状态，绝不泄露真实业务数据。
3. KYB 五步字段符合当前表，不保留旧签约代表、英文名称、联系人电话等废止必填项；提交快照、补件版本可追溯。
4. KYB 通过即 Free + **真实** MPC 开通任务，失败不假成功且不回滚 Free；钱包管理可增多个自有钱包、改默认、发行可改选有效钱包。
5. Free 没有真实认购、Token 或资金效果；Standard 也不绕过独立生产准入。
6. 月/年、USDT/法币、支付可信确认、提醒7/3/1/0、7天宽限、新增发行冻结、降级只读及受控存续通道严格区分。
7. 中文端到端 UI、异常及邮件通知；实际用户身份数据、签名、支付、文件服务不得以浏览器 Mock 通过冒充生产通过。
