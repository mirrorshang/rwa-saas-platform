## 3. 已批准的排除项与分离原则
1. 在 Instrument 创建时**不收集本期募资金额、认购单价、募集期限或投资者支付参数**：这些属于 Offering。
2. 同一资产 MVP 不展示「创建第二个权益结构」，也不能通过新建 Draft、变更路由或历史版本重复生成有效权益容量。多 Instrument、复杂股权类别、可转换债权和优先/劣后分层机制留未来规划。
3. 真实股东/债权人/收益参与者的法律身份与 Token 数量**不得默认直接划等号**，法定权利须由对应协议、名册、适用法律与获准链上方案确定。
4. 所有示例数量都仅为解释，不代表生产额度。Ready ≠ 对外发行准入，不能因此跳过法律/资金/Provider/Signer/合约门。
