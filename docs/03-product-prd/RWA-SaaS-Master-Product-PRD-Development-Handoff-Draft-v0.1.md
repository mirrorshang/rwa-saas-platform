## 1. 产品概述

### 1.1 产品定位【已确认】

RWA SaaS 是面向发行机构、资产管理机构和发行企业的**通用多资产Token化技术SaaS**。企业购买服务后，可在同一个工作台管理不同类别资产、多个发行项目及发行轮次，并向其自行拓展的投资者提供独立投资者门户。

产品以标准化、全球可配置为方向；**支持产品配置不等于已获某个国家、资产或金融工具的实际发行许可**。平台提供技术与业务协作能力，不默认替代发行方、持款方、法律登记方或Token签名方的真实法律责任。

### 1.2 产品目标【已确认】

1. 让发行机构从开通SaaS开始，完成资产/权利工具准备、项目与发行、投资者准入和认购、资金对账、配售登记、Token交付、收益及存续管理的完整工作流程。
2. 支持**一个企业同时管理多资产类别、多资产、多项目及多个Offering轮次**，以Project作为主要业务工作空间，模块间信息可关联和按权限筛选。
3. 建立每个发行机构独立的投资者门户，帮助其投资者完成认购和持有后的查询、领取与文件获取。
4. 将SaaS商业订阅、实际发行资格、真实资金、法定权益登记和链上Token事实清晰分开。

### 1.3 目标用户【已确认】

| 用户 | 主要目标 |
|---|---|
| 发行企业/资产管理机构 | 购买SaaS，配置机构、资产与发行，管理投资者及存续义务 |
| 发行机构管理员与业务员工 | 按角色处理项目、合规资料、审批、资金对账、Token和收益等工作 |
| 发行机构的投资者/合法代理人 | 访问该机构门户，浏览获授权Offering、完成资格与认购、查看权益及收益 |
| SaaS平台运营人员 | 商业开户/KYB、租户管理、套餐权益、权限安全、运营支持和审计 |
| 外部合法服务主体 | 按合同和适用法律提供身份核验、法律/评估、资金执行、登记、链签名等服务 |

### 1.4 非目标【已确认】

V1不默认建设平台自营的跨发行机构投资交易市场、公开自动撮合/流动性市场、高级白标多发行方运营平台或商业OpenAPI开发者产品；也不默认由SaaS平台持有投资者募集款或代客户进行有法律效力的Token签名。

### 2.3 Standard自助订阅与USDT商业收款【S-01～S-05 Approved；商业细节Draft】

**正式产品决定（2026-10-26）**：企业可从W-04直接发起**Standard自助订阅**，无需联系销售或人工报价作为必经步骤；访客先注册/进入Free企业工作台，获授权的订阅管理员在**原Tenant**中完成必要商业KYB、协议确认、账单与付款，到账核验并满足商业开通条件后激活Standard。KYB需要人工复核时仍可暂停流程等待审核，**自助不等于绕过合规审核**。

| 决定 | 已明确批准的业务规则 | 尚未批准的内容 |
|---|---|---|
| **S-01 自助订阅** | Standard改为**线上自助订阅**，销售咨询仅为可选帮助；W官网入口引导进入I工作台自助流程，官网不复制KYB/合同/收费主账 | 收费/订阅页面实际字段、最终UI路由、权限码 |
| **S-02 支付资产和网络** | **SaaS商业订阅费**首期接受USDT，首期目标网络为**TRON（TRC-20）、BNB Smart Chain（BEP-20）、Ethereum（ERC-20）**；用户选择明确网络后生成与该网络/Token匹配的订单地址和金额 | 供应商实际签约与地区适用性、Token合约地址及精度、链最终性参数、Gas/钱包、收款运营主体 |
| **S-03 Provider候选** | 优先**验证NOWPayments**，以**Gate Pay**为备选候选；先做合规、商户准入与网络能力核验，再决定接入 | **最终服务商选择仍Draft，不代表已经签约、部署或获准收款** |

| **S-05 商业准入与延期决策** | 保留**商业KYB＋适用合同＋真实SaaS付款核验→原Tenant Standard权益激活**的既有Guard；Standard费用与认购投资者的钱是**两条独立资金链** | 价格、周期金额、免费/付费资源额度、法律条款细节、税费/发票、生产地区准入 |

**必须保持的边界**：

- 官网W-04可展示**「立即订阅」**并将客户引导至企业自助流程；**在正式价格/账期/经营地/Provider未批准和上线前，支付订单不可凭空生成，页面需清晰显示「价格待公布」或订阅暂不可实付的状态**。无需将销售联系当作唯一购买入口。
- 订阅订单必须绑定**Tenant＋商业套餐/账单＋指定USDT网络和该网络Token**；网络对应收款地址/二维码、需付金额、账单有效期和到账状态不得串网复用。错网络、少/多付、迟到账、重复通知、结果Unknown不得直接激活权益；经真实证据匹配后单次激活、受权恢复，不重复收费或建Tenant。
- 首期账单需展示**套餐、最终批准的订阅周期/价格、支付资产USDT、网络、地址、二维码、待付金额、有效期、付款检测/确认/异常**。展示字段属于需要逐页设计的产品要求，**具体数值、Provider响应、状态枚举、链确认次数和实现方案均Draft**。
- 自助USDT收款**只涉及SaaS客户支付平台订阅费（M01商业资金）**，不改变投资者购买Offering时由M11及依法有权资金方处理的资金；**Standard已付费≠Offering获准正式发行、主网Token签名或投资者实际购买权限**。
- 已有Free Tenant沿用原组织、账户与可合法复用草稿；Sandbox订单/模拟资产权益/Token绝不直接变为真实记录。Standard欠费或失效不抹除已成立的合法投资者权益和在途履约义务。

**当前真实交付状态**：上述五项为**产品层Approved**；USDT商户签约、正式收款通道、合约网络核对、支付UI、Webhook/API、正式价格及QA**全部待完成/Not Executed**，不据此声称现在已经可以在线付款。

## 3. 产品组成与信息架构

产品包含四个面向用户的端；外部服务属于业务依赖，**不作为默认的第五个产品端**。

### 3.1 W｜SaaS官网【部分已确认】

**主要导航**：首页｜产品功能｜解决方案｜价格｜帮助中心；另有登录和“免费开始”。

**主要页面与功能**：
- 产品首页：价值主张、核心能力、发行流程、应用场景、套餐、FAQ。
- 产品和解决方案：展示多资产管理、发行、Token、投资者门户及发行后能力；优先面向资产管理机构和发行企业。
- 套餐/价格：展示Free与Standard，Standard**立即订阅（线上自助入口）**；正式价格未批准时标「价格待公布」，不生成真实付费账单；「联系销售」仅为可选咨询。
- 帮助/咨询/政策：FAQ、教程、联系销售简单表单、服务条款/隐私/Cookie/免责声明入口；不默认交付完整CRM。
- 企业注册和登录：邮箱注册及验证，成功后进入Free企业工作台；已拥有单个受权企业时直达，多个时选择企业。投资者从发行机构专属门户登录。
- Standard升级：官网W-04提供自助订阅入口，已有授权企业在I端完成商业KYB、合同、指定USDT网络的账单付款与原Tenant权益激活；不以销售咨询为前置，不在官网复制商业收费主账。

**待完成**：官网14个候选页面组逐页结构、文案、表单校验、邮件异常、Cookie管理、法律正文、响应式和视觉设计；完整官网页面范围尚未整体签收。

## 4. 核心业务流程【主流程已确认】

| 顺序 | 用户业务步骤 | 页面及业务应达到的结果 |
|---:|---|---|
| 1 | **购买/启用SaaS** | 企业从官网注册并验证开通Free；在W-04发起Standard自助订阅，经原Tenant商业KYB、协议、USDT指定网络账单付款核验后激活商业权益；生产权限另Gate |
| 2 | **配置企业工作台** | 企业设置人员、角色、项目访问范围；创建并配置独立投资者门户及访问地址 |
| 3 | **准备资产与权益工具** | 建立Asset和Instrument、确认发行及相关主体、收集权属、法律/评估等必要资料 |
| 4 | **创建并发布发行项目** | 建立Project和Offering、配置价格/窗口/资格/Token/披露，审核必要发布条件并由有权人员明确发布 |
| 5 | **投资者登录及准入** | 投资者访问所属Issuer门户，完成身份、KYC/KYB/AML、Offering资格及钱包控制检查 |
| 6 | **认购及付款** | 查看合法条款、取得报价、完成必要签署、提交唯一订单及预留，按获批网络/币种付款 |
| 7 | **配售、登记及交付** | 确认真实资金匹配、完成合法配售和权威登记、按适用顺序Mint/交付Token，投资者查看持仓 |
| 8 | **募集款管理** | 企业查收款及受限/可结算金额，有权申请和审核，外部合法执行者核准划拨并确认真实到账 |
| 9 | **收益计算及准备** | 按合法记录日快照与条款计算应付，审核分配条件，核对真实注资 |

1. **Free版本真的永久免费吗？**

3. **Free可以模拟完整发行流程吗？**  
   可以。Free支持主要V1业务的模拟演练，包括资产、Offering、投资者、认购、Token、资金及收益等流程，但不会产生真实资金或法定权益。

5. **升级Standard后，需要重新创建企业和项目吗？**  
   不需要重新创建企业Tenant。符合条件的原账号、企业资料和可复用配置可以保留，但模拟交易与法律权益不能直接转为真实业务数据。
6. **支付Standard费用后可以立即发行Token吗？**  
   不能。商业付费与实际发行资格相互独立。真实发行仍需完成相应法律、业务授权、资金和生产安全检查。
7. **如果Standard到期，历史投资者权益会被删除吗？**  
   不会因为商业订阅到期就删除或否定已经合法形成的真实投资者权益、资金记录和法定登记。后续服务限制、持续履约及数据交接必须依照适用的合同与法律规则处理。

不需要先完成完整商业KYB。您可以先注册并体验Free Sandbox。申请升级Standard时，需按照要求完成相应商业KYB和订阅流程。

**Q3：一个账户可以管理多家企业吗？**  
可以在获得相应授权的情况下访问多家企业。登录后，如果您关联多家有效授权企业，系统会先让您选择要进入的企业工作台。

**Q4：忘记登录凭据怎么办？**  
进入企业登录页面，选择对应的凭据找回方式，按照页面提示完成必要验证。如果无法恢复访问权限，可以联系支持团队。

**Q5：投资者是否通过SaaS官网登录？**  
不是。SaaS官网主要供购买和使用平台的企业客户登录。投资者通过其所属发行机构的独立投资者门户注册或登录。

**分类2：套餐与订阅（Q6～Q10）**

**Q6：Free版本是否永久免费？**  
是的。Free没有固定试用到期时间，可持续用于Sandbox业务体验，但需要遵守相应资源配额、安全和服务规则。

**Q7：Free需要绑定银行卡或付款方式吗？**  
免费开通Free不需要预先绑定付款方式。如果后续使用独立收费的服务，应以正式产品规则和服务协议为准。

**Q8：Free与Standard的主要区别是什么？**  
Free用于资产、Offering、投资者、认购、Token及收益等主要业务流程的模拟体验。Standard提供正式商业SaaS权益，但具体真实业务还需要满足额外的法律、业务及生产授权条件。

**Q9：如何从Free升级Standard？**  
有订阅管理权限的企业管理员可以直接从官网「立即订阅」进入原企业工作台的Standard自助升级流程，自助提交商业KYB、确认合同，选择经批准的周期并用指定网络USDT账单付款；核实到账后获得商业权益，不需要先联系销售。可复用符合条件的企业配置，模拟交易不会直接转为真实权益。

**Q10：Standard的价格是多少？**  
Standard的具体价格及计费周期尚未公布。批准后可在W-04价格页查看，并由受权企业管理员在线自助订阅；当前不显示虚构价格或发起真实账单付款。

**分类3：资产与发行（Q11～Q14）**

**Q11：可以管理不同类型的资产吗？**  
可以。同一企业工作台支持管理不同类别资产、金融权利工具和多个发行项目。实际可以发行哪种金融工具，需要结合具体业务和适用法律确定。

**Q12：Project与Offering有什么区别？**  
Project用于组织具体发行项目的资产、权利工具、资料和相关业务；Offering代表该项目下的具体发行安排或轮次。每个Offering都需要关联明确的Project。

**Q13：Free可以模拟完整发行流程吗？**  
可以使用Sandbox模拟主要业务步骤，包括资产与发行配置、投资者资格、认购、资金、配售、Token和发行后管理。模拟过程不会产生真实投资者付款或法定金融权益。

**Q14：订阅Standard后能否直接发行真实Token？**  
不能。商业订阅只是使用生产级业务功能的必要商业条件之一。具体真实发行还需要满足发行主体、金融工具、法律许可、资金、Token授权和安全要求。

**分类4：投资者与Token（Q15～Q18）**

**Q15：平台是否帮助发行企业寻找投资者？**  
RWA SaaS主要提供技术管理工具和机构独立投资者门户。发行机构自行负责拓展投资者，平台不默认提供募资承销或跨机构投资者分发服务。

**Q16：投资者认购成功是否代表已经取得Token和法定权益？**  
不一定。订单、付款、配售、法定持有人登记及Token交付是不同业务阶段。只有完成相应合法程序，才能确认实际取得的权益。

**Q17：Free中的Token可以转换成真实Token吗？**  
不能将Sandbox模拟Token直接视为真实发行的Token。升级Standard后，需要按照实际发行和生产规则重新形成合法授权与执行记录。

**Q18：Standard到期后，历史投资者的权益会消失吗？**  
不会因SaaS商业订阅到期而自动删除或否定已经合法形成的真实投资者权益。相关持续履约、访问限制及交接应按照合同和适用法律处理。

**教程01｜注册并开通企业工作台**

- 卡片简介：**从官网注册账户，完成验证，开始免费使用。**
- 操作步骤：
  1. 点击官网右上角「免费开始」。
  2. 按注册页面要求填写邮箱。
  3. 前往邮箱完成验证。
  4. 注册完成后，系统按已批准的开户规则创建或关联企业工作台。
  5. 进入Free工作台，确认页面显示Sandbox测试模式。
- 按钮：**立即免费开始**→W-08。
- 注意：邮箱验证失败、链接过期或邮箱已注册按注册页面提示处理，不重复创建同一商业企业记录。

**教程02｜认识企业工作台**

- 卡片简介：**了解工作台首页、导航和常用业务入口。**
- 操作步骤：
  1. 登录SaaS企业账户。
  2. 选择有权访问的企业工作台。
  3. 通过左侧导航查看资产与发行、投资者门户、投资者与认购、资金与结算等模块。
  4. 在工作台首页了解项目概览、待办和异常提示。
  5. 根据当前用户权限进入允许操作的模块。
- 按钮：**进入工作台**→按登录和企业授权状态路由。
- 注意：Free显示Sandbox标识，企业/项目/操作访问随授权而异。

**教程03｜创建第一个模拟发行项目**

- 卡片简介：**了解资产、Project和Offering如何关联。**
- 操作步骤：
  1. 在Sandbox工作台中准备一份用于测试的资产资料。
  2. 为资产准备对应的金融权利工具信息。
  3. 创建Project，关联适用的资产和文件。
  4. 在Project中创建Offering，填写必要的模拟发行参数。
  5. 查看发行前检查项及模拟业务状态。
- 按钮：**免费体验发行管理**→W-08或有权工作台。
- 注意：本教程仅规定业务顺序，实际字段/按钮/向导以I端后续详细PRD为准，不表明合法真实发行授权已生效。

**教程04｜配置独立投资者门户**

- 卡片简介：**了解如何设置发行机构自己的投资者入口。**
- 操作步骤：
  1. 进入企业工作台的「投资者门户」模块。
  2. 查看当前企业的标准门户实例。
  3. 按页面要求配置机构名称、Logo及必要法律链接。
  4. 查看有权展示的Offering。
  5. 进行Sandbox门户预览，按权限操作模拟发布或暂停。
- 按钮：**免费体验投资者门户**→W-08或有权工作台。
- 注意：门户已发布不等于Offering自动具备真实展示或合法认购资格。

**教程05｜体验模拟认购及发行后管理**

- 卡片简介：**了解投资者认购、Token和收益如何连接。**
- 操作步骤：
  1. 在Sandbox中准备模拟投资者及适用资格。
  2. 使用模拟投资者门户浏览可访问的Offering。
  3. 演练报价、认购及必要法律文件确认流程。
  4. 查看模拟付款、配售、持有人登记及Token交付状态。
  5. 回到企业工作台查看订单、资金和Token记录。
  6. 演练收益计算、分配与存续业务。
- 按钮：**免费开始模拟体验**→W-08或有权工作台。
- 注意：全部投资者、资金和Token结果仅供测试，不是实际金融凭证。

**教程06｜了解Standard升级**

- 卡片简介：**了解企业什么时候需要升级，以及升级后的限制。**
- 操作步骤：
  1. 在官网套餐页了解Free和Standard。
  2. 由有订阅管理权限的企业管理员进入工作台升级入口。
  3. 按要求完成商业KYB与必要资料补充。
  4. 审阅正式合同，查看最终获批的订阅周期与账单金额。
  5. 选择首期经核验可用的USDT网络（TRON / BNB Smart Chain / Ethereum），按单次账单付款；系统完成真实到账核验后查看原Tenant的Standard权益状态。
  6. 后续账单到期时手动续费，不做钱包自动扣款；若实际发行业务还需另行完成合法授权及生产条件检查。
- 按钮：**查看套餐与价格**→W-04。
- 注意：Standard已付费≠真实Token已获发行许可；模拟订单、模拟资金、模拟权益不直接变生产事实；正式价格、周期金额与商户Provider仍待上线核验。
