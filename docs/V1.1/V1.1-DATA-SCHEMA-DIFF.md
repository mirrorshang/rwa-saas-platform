# V1.1 数据结构差异

`实际源码` 指两个候选前端的本地模型；`候选后端` 指待工程师复核的生产结构，**不代表已有数据库字段**。V1.0 原型状态为 `apps/issuer/src/data.ts` 与 `issuerModule01.ts`；后端目标见 [V1.0 PRD](../V1.0/V1.0-BACKEND-DEVELOPER-PRD.md) §5、§11。

| 对象 / 旧字段 | V1.1 字段与类型、单位 | 必填条件 / 默认 / 枚举 | 关系、约束、来源与迁移 | 状态 |
| --- | --- | --- | --- | --- |
| Asset `details: object` | `assetSchemaVersion?:2`; `publicFields?:string[]` | 新建 v2；旧记录缺失=公开授权待核实；仅六模板白名单 | `publicFields` 只能引用有值且经授权的 AssetVersion 字段；旧数据不回填；无破坏性 | 实际源码；后端候选 |
| Asset `category/subtype` | 六模板保持原分类；新增普通股权创建入口 | 四类非闭环不能发行确认 | 资产证明文件按模板引用；旧分类不自动改名 | 实际源码；后端候选 |
| Instrument `type/terms` | `termsSchemaVersion?:2`; 股权：`shareIssuer/shareClass/shareCount/votingRights/dividendRights/liquidationRights/exitArrangement/termArrangement` | 新版股权必填，股数正整数；无固定期限无需到期日；旧版缺失=待核实 | 不把 `participationRate` 迁成股权；股数与权益总量一致；已引用版本不可改 | 实际源码；后端候选 |
| Instrument `terms` | 债权：`debtor/principal/annualRate/interestMethod/frequency/repayment/maturityDate` | 新版必填；本金 U>0；Actual/365 Fixed、每月付息、到期一次还本 | 投资者名义本金来自权益文件，非底层合同或认购额；不改变旧债权主账 | 实际源码；后端候选 |
| Instrument `terms` | 参与权：`revenueSource/distributableBasis/participationRate/frequency/expiryArrangement` | 新版必填；比例 (0,100]%，不得默认本金返还 | 真实可分配额不由预期收益生成 | 实际源码；后端候选 |
| Instrument 容量 | `tokenLegalMapping:string` + `totalRights/tokenCap` | 新版必填，两个容量为安全正整数且精确整除 | 法律文件需验证映射；后端建议存有理数及版本约束，不能静默取整 | 实际源码部分；后端候选 |
| Instrument 无 SPV 字段 | `spvMode?:不涉及/已有SPV`; `spv?:ExistingSpv` | 新版明确选择；旧记录缺失=待核实 | 单层已有 SPV，名称/地区/注册号字符串/角色/两种关系/三类文件；无依据不 Ready。生产实体唯一性与索引待定 | 实际源码；后端候选 |
| BusinessFile `id/name/category/status/version?` | `visibility?:内部/公开/授权投资者` | 旧缺失=内部或未知，不自动公开；公开必须已扫描且版本整数≥1 | 文件快照按 id+version 引用；直达授权；原文件保留。生产权限表/索引待定 | 实际源码；后端候选 |
| Offering `price/summary/disclosureFiles` | `disclosureSchemaVersion?:2`; `returnDisclosure?:ReturnDisclosure`; `riskDisclosure?:string` | 新版需选择未提供或有依据的预期单值/区间；风险必填；旧缺失=未提供/待核 | 测算记录价格、日期、期间、净/毛、资本增值、假设、税费、依据、风险；改价使旧测算失效 | 实际源码；后端候选 |
| OfferingSnapshot 固定 Asset/Instrument/Project/钱包/文件 | 新增 `issuer`、`returnDisclosure`、`disclosureSchemaVersion`、风险披露 | 确认时深拷贝；旧快照保持原内容 | 后续编辑不得覆盖。生产唯一索引及事件版本由工程师核验 | 实际源码；后端候选 |
| PublicationSnapshot `confirmedOffering` | `PublishedOfferingDisclosure 1.1.0` 白名单导出 | 仅从 Sandbox 已发布的新版固定快照生成 | AssetVersion、InstrumentVersion、Offering、主体、回报、风险和公开文件版本；禁止内部 Asset/KYB 泄露 | 实际源码；后端候选 |
| V/M `Offering` 静态样例 | 可选 `sourcePublicationId/sourceSchemaVersion/spv`；新增 JSON 适配 | 无来源时保持原示例；未知 schema 拒绝 | M 另需 Listing；动态容量/订单/收益不得从披露快照推断 | 实际源码 |
