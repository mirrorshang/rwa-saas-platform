## 二、现行默认用户旅程

**邮箱注册/验证 → 受限试用Tenant即时开通（14天、无预绑付款方式）→ 在试用中探索功能/可预选Standard套餐 → 企业KYB提交及复核 → KYB通过后确认商业合同/在线付款 → 同一Tenant切换至付费商业权益 → 具体Asset/Instrument/Offering另行通过发行合法性Gate后才允许生产执行。**

- 只完成注册即给**试用使用权**，不因试用身份获得客户正式商用、公开Investor Portal、真实资金或生产链上控制权限。
- **KYB后商业付款**保留[DEC-013 CR-01](DEC-013-cr01-10-v1-complete-loop-and-release-directions-approved.md)已批准的正式订阅准入顺序；本次批准的是新增**无需完整KYB的前置试用阶段**，而非“付费后再补KYB”。
- [DEC-010](DEC-010-commercial-packaging-and-pricing-principles.md)原已批准订阅/少维度计价的商业原则，明确保留“具体试用长度、套餐价格、免费层是否存在后续另批”的历史状态；**本DEC在其后正式明确14天限时试用和1个付费标准套餐**，不虚构已完成定价/客户支付意愿验证。
- M01-F004的Tenant是同一受隔离业务空间，**Trial与Paid是授权状态，不另外制造第二个Tenant主账**；正式启用还需KYB与实际商业付款的有效证据。试用到期亦不能与生产到期简单合并。

## 四、到期及保护性权限

| 场景 | 推荐系统行为（已批产品方向） |
|---|---|
| Trial有效 | 在限定测试/模拟能力及额度内编辑/预览，禁止真实生产执行 |
| Trial到期无付费 | 停止新建、编辑、模拟执行；允许登录、查询、受控导出、KYB与付款转换；30天恢复窗口 |
| Trial转正条件不足 | KYB或付费尚未被权威证实，不自动切付费生产权限；必要补件/支付Unknown复核 |
| Paid有效但尚未过真实发行Gate | 可按商用授权准备业务，但不得真实发行或收付 |
| Paid逾期/停用且仍存在合法金融义务 | 不再授权新增业务；保留依法必须查询、对账、退款、本息/收益处置、外部有权执行和责任交接路径 |
| 商业服务正式终止 | 按合同与法域处理审计、留存、数据导出、责任迁移及外部真实权威，不自动消灭历史权益 |

**状态名称、时间/时区与截止精度、免费试用滥用控制、具体恢复/留存执行、第三方成本归属、真实业务特殊法域门及测试用例仍在Step05详细PRD中细化。** 30天是用户已批准的试用恢复窗口产品目标，不作为对所有金融业务资料30天后可删除的法律结论。
