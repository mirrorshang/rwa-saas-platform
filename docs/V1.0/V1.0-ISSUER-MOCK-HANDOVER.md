## 数据与恢复

浏览器当前源的本地 v4 存储为 Mock 数据仓。读取损坏 JSON、缺集合、冲突 ID、断裂引用、已确认快照改写或写入失败时保留原始字节并阻断写入。恢复页允许导出原始记录并导入修复后的有效 JSON。旧版本补字段与 Project 自动关联幂等；不要手工覆盖 storage 来完成验收，也不要在含重要测试记录的浏览器直接清空存储。编号和版本冲突需隔离分析。

## 验收与限制

按 [操作手册](../Issuer%20SaaS%20V1.0%20全流程操作手册.md)从资产页面建立住宅／债权，检查当前状态和下一步入口；用独立演示控制台完成仅限 Mock 的钱包验证、文件扫描、模拟发行、投资者与支付；普通业务页查看记录。检查重复确认／任务／批次、防超额、版本冲突、Unknown 原意图查询、刷新持久化、到期停息、本金独立收据。

生产前须将本地状态机移至服务端权威主账，补租户隔离、并发事务、幂等键、Provider、支付最终性、法定登记、链上 Contract/Token、真实 KYB/KYC、审计和 V/M/Platform 接口。本次前端演示结果不得用于真实资产发行或财务结算。
