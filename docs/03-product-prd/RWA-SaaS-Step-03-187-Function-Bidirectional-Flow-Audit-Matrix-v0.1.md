## 四、可核对的疑似业务语义重复（不是需要直接删除的ID）

| 重叠组合 | 看似重复 | 实际必须保留的单一主责任及跨端只读/动作边界 |
|---|---|---|
| M01-F002 ↔ M09-F002 | 都是KYB | 前者客户机构KYB，后者机构投资者KYC/KYB；必须区分企业客户与投资者 |
| M08-F002/003 ↔ M15-F004 | 都讲门户 | M08为发行机构投资者门户的业务访问，M15-F004为商业白标品牌域名；标准独立URL可能需扩深M08/新增，不能整个M15上移 |
| M04-F006 ↔ M13-F004/005 | 都描述收益 | M04版本化Instrument约定收益权利，M13按权益快照生成应付事件与金额，不能两处计算不同权利来源 |
| M05-F004 ↔ M12-F001 | 都描述发行额度 | M05 Offering定义合法条款，M12统一Series/份额类容量和配售权威；不能两个系统独立扣减 |
| M08-F008 ↔ M12-F006/007 ↔ M07-F006 | 都有关持仓Token | M08仅投资者查看，M12是合法登记引用和配售事实，M07是链上Token与最终性；不删除任何一种 |
| M11-F009 ↔ M13-F006 ↔ D06 | 都显示“出款” | 认购退款/收益还本实付/发行方募资合法释放是三种不同法律用途及付款意图，不能复用为同一操作 |
| M13-F003 ↔ M18-F001/003 | 都是通知 | M13决定应通知的业务事件与权利内容，M18负责投递/渠道/待办，依法有效送达另留证 |
| M21-F003/005 ↔ M11/M13 | 都显示资金收益 | M21只能只读追溯资金、收益权威，不能生成另一套独立应收/应付或实际资金账 |
