# V1.1 本地候选操作手册增量

仅适用于两个候选前端工作树。所有示例文件与资金状态均为 Mock；在真实后端、法律文件和权限服务接入前，不得用于生产发行。

1. 在 Issuer 资产与发行页选择六类模板之一，录入原始事实及文件。住宅/债权仍按原完整闭环准备；其余四类只能保存资料草稿。逐项勾选有依据且获准公开的资产字段，未勾选字段不会导出。
2. 在权益结构页选择**股权、债权或收益参与权**，只填写该类型的法律条款。股权录股份主体、股类、股数、表决、股息、清算、退出；债权录投资者名义本金、固定利率、债务人、Actual/365 Fixed、每月付息与到期还本；参与权录收益口径、比例、周期。权益总量须与 Token 份数精确整除。
3. 选择“不涉及 SPV”或“涉及已有 SPV”。后者录法定名称、注册地区和编号、发行角色、与资产及企业关系，并选择注册、资产授权、权益文件。不能用客服说明或主体名称代替证明。
4. 给核心权益文件设置“公开”权限。Mock 控制台扫描后在详情运行 Ready 检查；仅上传文件名或选择“内部”不足以进入新版公开披露。
5. 以 Ready 资产及权益创建 Offering 草稿，录价格、最低额、期限、风险、发行披露文件。合同债息从固定权益版本读取；预期年化可选“未提供”，若填写则须录价格、日期、期间、口径、增值、假设、税费、依据和风险。改价后点击“已重新核对测算依据与当前价格”，否则确认会被拒绝。
6. 在 Offering 详情查看投资者视角预览并确认。原 Sandbox 发行准备、任务核验和发布流程保持分态。发布后点击“导出已发布披露数据 JSON”，文件来自冻结的 `PublicationSnapshot`，不是编辑中的草稿。
7. 将**本轮浏览器实际导出的文件**交给 V/M 候选工作树，执行 `node apps/investor-portal/scripts/import-issuer-disclosure.mjs <导出文件绝对路径>`。脚本校验 schema、公开文件和渠道字段，保存 `src/generated/published-offerings.json` 并输出 SHA-256。V 以 Issuer slug 查看项目；M 未获单独 Listing 时不显示。所有新项目因无权威动态容量和认购服务保持不可认购。
8. 核对两端发布 ID、Asset/Instrument 版本、价格、权益、SPV、回报和文件列表；尝试直接访问无权文件、修改价格后重确认、重载页面。文件正文及下载需正式授权文件服务；本地 JSON 只有文件元数据。

故障处理：未知 schema 或无效价格、文件版本会被 V/M 拒绝并在市场页提示；不回退到虚构金融字段。Issuer 旧记录缺新字段显示待核实；不改历史发布快照。具体测试结果与截图见 [验收报告](V1.1-ACCEPTANCE.md)。
