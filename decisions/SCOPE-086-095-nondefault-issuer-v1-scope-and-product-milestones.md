| **SCOPE-093** | M15-F001～F007（交付批次待定×7）、M15-F008（P2×1） | White-label 继续为独立商业产品和**独立交付里程碑**；保留已确认的“一家运营商管理多家获授权发行机构”的 V1 业务模型；不强制与 Issuer SaaS 同期，但**未决定自动延后 V2**，允许另行评审同期独立上线；复杂多级经销 P2。 |

## 三、V1 正式范围冻结前置决策门

1. **SCOPE-062 前置条件**：选定 **1～2 类具体参考 Instrument**，核对权利结构、Offering 持续购买模式是否可行、投资者准入、收益/还本、赎回/销毁、权益/法定登记、Token 转让限制、披露通知、资金/退款责任；按其影响重新审定条件性 P1 是否属于实际 V1 上线必需。
2. 首发**法域、受监管活动、发行/登记/收款/退款/签名主体、真实服务商**仍属于独立合规与上线决策门，不能因本次归类而直接进行真实生产金融活动。
3. White-label 和商业 Open API 的实际商业交付日期/版本/合同、客户 SLA 等仍未决定；Issuer V1 的共享业务核心必须支持未来扩展。
4. 要再生成**逐功能实际交付责任、最小方案、异常/权限 Guard、UI/API 及验收要求清单**并单独经产品负责人批准后，才可决定 V1 业务功能范围是否冻结。
5. **不追溯修改第 02～04 份冻结文件、功能树、DEC-001～011 和 ARCH-001 原文**；**PR #6 保持 Draft / Open / Unmerged**。本记录不构成正式研发、合并或真实交易的授权。
